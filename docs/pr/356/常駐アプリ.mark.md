## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマの版 | `project-index.yaml` の `ref` を全て `design-schemas/v12.0.0` に揃え、`content/prompts/openai-transcribe.yaml` の `$schema` も同じ版にする | 画面設計以外の種類は v12.0.0 の違反 0 件で、記載を変えない |
| 画面全体の欄 | 10 件それぞれに `screen_type`・`leave_guard` を記載し、`shell` の画面は `retained_state` を記載する | 値の決め方は knowledge のテンプレート『画面設計』（`template-screen-design`）の `x-rules` |
| 要素の欄 | 要素ごとに v12.0.0 の必須の欄（`label_display`・`confirm`・`retained_state`・`disabled_reason`・`close`・`initial_focus`・`return_focus`・`table` など）を、今の実装の振る舞いを確かめて埋める | 実装と食い違う欄は、設計を良い方へ修正して実装を合わせる |
| enum の値 | `io`・`align` を英語の enum に、`kind` を v11.0.0 の enum（`menu_item`・`window`・`switch` などは近い種類）に置き換える | 種類を替えて禁止になる欄は、その種類で許される欄へ移す |
| 表の列 | `sorting` を `sortable`・`filterable` と `table.default_sort` に分ける | - |
| 外部の端末の画面のコピーの表示 | 押した直後の 2 秒だけアイコンをチェックに替えて成功の色にし、文言は「コピー」のままにする。768px 未満の幅ではコピーをアイコンだけのボタン（削除のボタンと同じ 44px 角。読み上げ名とツールチップは「コピー」）にする | モック `docs/mock/pages/web-transcription/356/a-copy-icon/` |
| 設定画面の追加のボタンの文言 | 目的語の後ろの「を」を省いた形にそろえる（表記のヒントは「プリセット追加」「単語追加」、ハルシネーションは「行追加」、ブラウザ添付・エンドポイントへ送信は「プリセット追加」）。表記のヒントで画面に出す「語」は「単語」にする | モック `docs/mock/pages/settings/356/a-noun-labels/` |
| 文字起こし中の表示のプリセットの名前 | 窓の幅に収まらない名前は末尾を「…」で省き、マウスを合わせると全体を出す（音声ファイルの名前と同じ）。今の実装は省かずに窓を押し広げる | 記載し直しで見つけた漏れ |
| 設定画面の削除のボタン | 行・プリセット・用語集の削除のボタンを、合意済みのモックのとおりごみ箱のアイコンにする（今の実装は「×」の文字）。使う用語集を外すボタンは × のアイコンのまま | - |
| 気づいた設計の修正 | 記載し直しで見つけた漏れ・誤り・より良い設計を、画面ごとに画面設計へ反映し、実装と結合テストを合わせる | 見た目が変わる修正はモックでユーザーの合意を得てから反映する |
