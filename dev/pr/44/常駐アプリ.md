## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 固定の出力先 | 貼り付けて送信・貼り付けのみ・コピーのみの 3 つは今の `OUTPUTS` と `outputs[]` のまま残す。`ai_chat` の出力先と設定は消す | - |
| 既存の設定の読み替え | `settings.toml` の `outputs` に `id = "ai_chat"` の項目があれば、検証の前に `targets[]` をブラウザ添付種類のプリセット（Enter まで送る）へ読み替え、`ai_chat` の項目を外す。保存するときは新しい形で書く | 今の `load_settings` は検証に通らなければ `SettingsError` で起動できず、`save_settings` の `_read_existing` は検証に通らない文書を空の文書として書き直すため、読み替えは両方の読み込みの前に入れる |
| カスタムプリセットの設定 | 設定にプリセットの一覧を持つ。1 件は、タイトル・種類・URL・確定のホットキー・有効 / 無効と、種類ごとの値（ブラウザ添付: Enter まで送るか。エンドポイントへ送る: `Authorization` の値）を持つ。既定は空の一覧 | 置き場所（`outputs[]` の中か別のキーか）・キーの名前はモジュール構成設計で決める。`Authorization` の値は秘密として扱う |
| プリセットの種類 | 種類ごとに届け方の関数を持つ一覧を作り、種類を足すときはその一覧へ登録する形にする。まずはブラウザ添付・エンドポイントへ送るの 2 つ | 品質シナリオ 5 と同じく、種類どうしは import しない |
| ブラウザ添付 | 今の `send_to_ai_chat` の届け方（クリップボード・Edge の `--app`・開くまでの間・貼り付け・Enter までの間・Enter）を、プリセットの「Enter まで送るか」がオフなら貼り付けで止める形にする | 開くまでの間（今の `outputs[ai_chat].open_delay_sec`）の新しい置き場所と、プリセットごとに持たせるかはモジュール構成設計で決める。Enter までの間は今のとおり貼り付けて送信の `enter_delay_sec` を使う |
| エンドポイントへ送る | 起こした文字を JSON にして URL へ POST し、2xx で届いたとする。リダイレクトは追わない。送り直さず、届かなければ `DeliveryError`。送り先のホストは制限しない | 送る中身・認証はインターフェース定義『設定のエンドポイントへ送る』 |
| HTTP の送り方 | `callback/client.py` の `post_json` と同じ httpx の使い方にする。共有するか種類ごとに持つかはモジュール構成設計で決める | 出力先どうしを import しないため、共有するなら `features/outputs` の外へ出す |
| 確定の操作 | 録音の画面のプリセットのボタンとプリセットのホットキーは、今の AI チャットの送り先と同じく、`SessionManager.complete` へプリセットを指す値を渡して確定する | 何で指すか（並びの番号・ID）はモジュール構成設計で決める |
| 配線 | `main.py` の `_wire_outputs` と `build_hotkey_bindings` を、プリセットの種類ごとの注入と、出すとしたプリセットのホットキーの登録に置き換える。プリセットは届けるたびに設定を読む | - |
| 画面 | 録音の画面は AI チャットの見出しと送り先のボタンを、カスタムプリセットの見出しとボタンに置き換える。設定画面は AI チャットの送り先の一覧を、プリセットの一覧（タイトル・種類・URL・種類ごとの値・ホットキー・出す・消す・足す）に置き換える | 見た目はモック作成で designer が決める |
| エラー | 届けられなければ `DeliveryError` を送出し、セッションが `delivery_failed` を知らせて待機中へ戻す | 今の仕組みのまま |
| テスト | 単体は種類ごとの届け方を、外部の操作を差し替えて確かめる（ブラウザ添付は Enter まで送る / 送らない、エンドポイントへ送るは送る中身・2xx 以外・接続できない）。結合は 127.0.0.1 のテスト用の受け口へ届くこと、出さないプリセットと API の録音で送らないこと、`ai_chat` の項目が残った `settings.toml` を読んでプリセットに読み替え、保存すると `ai_chat` の項目が無くなり同じ送り先がプリセットとして書かれることを確かめる。画面の結合テストはプリセットのボタンと設定画面のプリセットの一覧を確かめる | E2E は単一ユースケース設計でシナリオに `test_file` を置いてから作る |
