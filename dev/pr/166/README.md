# 起こした文字の文頭・文末に紛れ込む決まった文言を、登録した一覧で消せるようにする

## 概要

利用者が、文字起こしで文頭・文末に紛れ込む話していない文言（「ご視聴ありがとうございました」など）を一覧に登録し、文中の同じ言葉を消さずに文頭・文末からだけ消せるようになる。

## 背景

[Issue #158](https://github.com/shuhei1101/voice-paste/issues/158) の要望。
faster-whisper の文字起こしで、話していない「ご視聴ありがとうございました」「ありがとうございました」などが文末に入ることがある。
[PR #152](https://github.com/shuhei1101/voice-paste/pull/152) で用語集の正しい表記を空にした行で文言を消せるようになったが、用語集は文全体に効くため、本当に話した同じ言葉も消える。
