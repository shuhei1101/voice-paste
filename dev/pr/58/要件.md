# 要件

## 要望

テスト実行方法の前提どおり `pip install -e . --group dev` で新しく作った venv で、画面・トレイ・ホットキーの E2E が流れるようにする。

- `tests/support/desktop.py` が import する pywin32 を `pyproject.toml` の `[dependency-groups].dev` に宣言し、新しく作った venv で conftest を読み込める
- `Uia.tray_tooltips` が、常駐アプリのアイコンが隠れたアイコンの一覧（オーバーフロー）に入っているとき（テストの常駐アプリを動かす `python.exe` が `IsPromoted=0`）も、そのアイコンのヒントの状態を返す。テストが隠れたアイコンの一覧を開いて読み、Windows のトレイの表示設定は変えない
- 隠れたアイコンの一覧を開いて読んだ後は一覧を閉じ、開く前の前面のウィンドウへフォーカスを戻す（貼り付け先の入力欄のフォーカスを奪わない）
- テスト実行方法の E2E の前提に pywin32 が dev グループから入ることを書き、外部ライブラリの設計書に pywin32 を足す
- 新しく作った venv で、Issue #54 で fail した複合ユースケース「声で入力した文字を貼り付ける」の 6 件と、下の表の `実行のみ` の行の E2E が、トレイの状態を読めないことでは fail・skip しない

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| E2E の前提として `python.exe` のトレイのアイコンをタスクバーへ出しておく（`IsPromoted=1`） | ユーザーの Windows のトレイの表示設定を変える前提になり、強制終了したプロセスのトレイの残像も表に出て消えない（Issue #54 で確かめた）。テストが隠れたアイコンの一覧を開いて読む形で足りる | 予定なし |
| 推移的な依存まで版を固定するロックファイルの導入と uv への移行 | 規約『依存パッケージ管理』から外れているが、今回の要望に含まれない。今回は今の `[dependency-groups].dev` に pywin32 を足す | [#56](https://github.com/shuhei1101/voice-paste/issues/56) |
