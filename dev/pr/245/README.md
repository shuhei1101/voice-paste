# OpenAI の文字起こしで、アプリ側のタイムアウトの定数を外して設けないようにする

## 概要

文字起こしのエンジンが OpenAI API のとき、常駐アプリが応答を待つ時間に上限を設けないようにする。

## 背景

[Issue #234](https://github.com/shuhei1101/voice-paste/issues/234) の要望。
[#204](https://github.com/shuhei1101/voice-paste/pull/204) で、OpenAI API への要求のタイムアウトを公式の SDK の既定（600 秒・接続 5 秒）に合わせた定数 `OPENAI_TIMEOUT_SEC`・`OPENAI_CONNECT_TIMEOUT_SEC` として置いた。
実測での見直し（[#209](https://github.com/shuhei1101/voice-paste/issues/209)）は取り下げになり、ユーザーの判断（[#232 の回答](https://github.com/shuhei1101/voice-paste/pull/232#discussion_r4431424473)）でアプリ側でタイムアウトを設定すること自体が不要になった。
