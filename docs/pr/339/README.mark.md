# トレイのメニューから履歴のフォルダを開き、音声ファイルを指定して文字に起こせるようにする

## 概要

ユーザーが、トレイのメニューから履歴のフォルダを開き、音声ファイルを指定して文字に起こし、出力先へ届けられるようになる。

## 背景

[Issue #338](https://github.com/shuhei1101/voice-paste/issues/338) の要望。
文字起こしに失敗すると、通知に「録音は履歴に残っています。」と出て録音の WAV は履歴のフォルダに残るが、常駐アプリには履歴のフォルダを開く手段も、残った WAV を文字に起こし直す手段も無い。
トレイのメニューのフォルダを開く項目は「設定フォルダを開く」「ログフォルダを開く」だけで、音声ファイルから起こす機能は外の端末のブラウザの画面（[#92](https://github.com/shuhei1101/voice-paste/issues/92)）にだけある。
