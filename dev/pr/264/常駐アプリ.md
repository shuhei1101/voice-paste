## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |

| エンジンの種類 | `EngineName` に `haas` を追加し、`EngineFn` の実装に Haas のサーバーへ送信するアダプタを追加する | 値の名前は設計で確定 |
| WSL の文字起こしのサーバー | WSL の中で Haas のモデルを読み込み、録音の WAV を HTTP で受けて区間ごとの文字を返却するサーバーを新しいサブシステムとして追加する。配置はこのリポジトリの中 | 配置のフォルダと API のスキーマはインターフェース定義設計・モジュール構成設計で確定 |

| faster-whisper への切り戻し | エンジンが `haas` でサーバーへ接続できないときは `local_whisper` で起こし、切り戻したことをトレイの通知とログに記録する | 切り戻す単位は要件.md の `未確定` で決める |
| 表記のヒント | 表記のヒントの単語を Haas の Vocabulary へ指定する。文字起こしの後の用語集の補正は今のまま | `未確定`（読みの作り方。決める段: PoC 検証） |
| 進みの通知 | Haas はオフラインで一度に起こすため、`reports_progress` は `false` にする | サーバーは 30 秒以下を `transcribe`、超えるものを `transcribe_longform` で起こす。`transcribe_longform` が区切った単位で進みを返却できると PoC で分かったら見直す |
| 設定 | `transcription.engine` に `haas` を追加し、`transcription.haas` にサーバーの接続先などのキーを追加する。エンジンの反映は今と同じく再起動 | キーは設計で確定 |
| 設定画面 | エンジンの選択肢に Haas を追加し、「文字起こし（Haas）」のまとまりを追加する | 既存の「文字起こし（OpenAI API）」のまとまりと同じ種類の欄 |

## PoC 結果

比べる相手は faster-whisper（`hotwords` を指定）、Haas は読みを指定した Vocabulary（V1）の値。
時間は 1 件の中央値の合計（Haas は Windows からの HTTP の往復を含む）。

結論: 不成立。
速さは全ての長さで基準を大きく上回り、約 29 秒・約 176 秒の CER も faster-whisper より低い。
数秒の音声の CER と、数秒・約 29 秒の表記のヒントの単語の正解率が基準に届かない（どちらも差は 1 単語・数ポイント）。
読みを指定しない Vocabulary（V2）はほとんど有効ではなく、Haas で表記のヒントを有効にするには読みが要る。
検証の音声は Open JTalk の合成音声で、表記のヒントの単語は 12 単語のため、標本は小さい。

最小再現コードの要点（[poc/haas/server.py](https://github.com/shuhei1101/voice-paste/blob/1ee18dd4c2550c52df1443be6c3c413421bd0d09/poc/haas/server.py)）:

```python
model = haas_asr.load_model("third-intelligence/Haas-ja-v1.0")
VOCABULARIES = {
    "v1": haas_asr.Vocabulary({written: [reading] for written, reading in HINT_WORDS}),
    "v2": haas_asr.Vocabulary([written for written, _ in HINT_WORDS]),
}
samples = haas_asr.load_audio(io.BytesIO(data))
if len(samples) / 16000 <= 30.0:
    text = haas_asr.transcribe(model, [samples], vocabulary=vocabulary)[0]
else:
    text = haas_asr.transcribe_longform(model, samples, batch_size=64, vocabulary=vocabulary)
```

diff の見どころ: `poc/haas/server.py`（30 秒で API を分ける箇所と Vocabulary の 2 通り）、`poc/haas/bench_haas.py`（`wsl.exe` での起動と HTTP の往復の計測）、`poc/haas/results/score.md`（長さごとの比較表）。
