# 要件

## 要望

移行の手順（`/mnt/c/Users/shuhe/repo/tmp/何でも会話/.mindstella/docs/A-5.md`）に沿って、`docs/` の文書を mdmark の記法と規約『表し方の優先順位』に統一し、削除できる文を削除する。

対象は `docs/` の全ての文書（設計書・公開ドキュメント `docs/guide/`・用語集・目次・PR ドキュメント `docs/pr/`）。
`schemas/` は AI Monitor の配布物のため、この PR では手で変更しない。
YAML の設計書のタグ・エイリアス・`description` は、今の Schema がキーを持たないため、[ai-monitor#3188](https://github.com/shuhei1101/ai-monitor/issues/3188) の後に別の Issue で移行する（[確認事項](https://github.com/shuhei1101/voice-paste/pull/282#discussion_r4535513983) の推奨案 A）。
