## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エンジンの種類 | `EngineName` に `haas` を追加し、`EngineFn` の実装に Haas のサーバーへ送信するアダプタを追加する | 値の名前は設計で確定 |
| WSL の文字起こしのサーバー | WSL の中で Haas のモデルを読み込み、録音の WAV を HTTP で受けて区間ごとの文字を返却するサーバーを新しいサブシステムとして追加する。配置はこのリポジトリの中 | 配置のフォルダと API のスキーマはインターフェース定義設計・モジュール構成設計で確定 |
| サーバーの起動 | 要件.md の `未確定`（サーバーの起動方法）で決める | `未確定`（決める段: 単一ユースケース設計） |
| faster-whisper への切り戻し | エンジンが `haas` でサーバーへ接続できないときは `local_whisper` で起こし、切り戻したことをトレイの通知とログに記録する | 切り戻す単位は要件.md の `未確定` で決める |
| 表記のヒント | Haas へは指定しない。文字起こしの後の用語集の補正は今のまま | PoC で用語集の単語の認識を比べる |
| 進みの通知 | Haas はオフラインで一度に起こすため、`reports_progress` は `false` にする | PoC でサーバーが区間ごとの進みを返却できると分かったら見直す |
| 設定 | `transcription.engine` に `haas` を追加し、`transcription.haas` にサーバーの接続先などのキーを追加する。エンジンの反映は今と同じく再起動 | キーは設計で確定 |
| 設定画面 | エンジンの選択肢に Haas を追加し、「文字起こし（Haas）」のまとまりを追加する | 既存の「文字起こし（OpenAI API）」のまとまりと同じ種類の欄 |
| セキュリティ | サーバーは WSL の中の `127.0.0.1` だけで待ち受け、録音を端末の外へ送信しない | Windows から WSL の `localhost` へ届くかを PoC で確認 |
| 外部ライブラリ | サーバー側で NeMo と haas_asr を使用する。常駐アプリの依存には加えない | ライセンスは Apache 2.0 |
| 動作環境 | WSL2・NVIDIA GPU（CUDA）がある Windows の端末で使用できる。無い端末では `local_whisper` のまま動く | 非機能要件の動作環境へ追記 |
