## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 依存の宣言 | `pycaw`・`comtypes`・`pywin32` に `; sys_platform == "win32"` を付け、`uv.lock` を作り直す | Windows で入るバージョンは変えない |
| OS の判定 | OS の判定を `shared/` の 1 モジュールに集める。`main.py` の配線がそれを見て、OS ごとの実装（単一インスタンス・音量・ブラウザ）を選ぶ | 置き場所と名前はモジュール構成設計で決める |
| 単一インスタンス（Windows） | 今の Win32 の実装をそのまま使う | 動きを変えない |
| 単一インスタンス（Linux） | 設定の置き場所から作る名前のロックファイルを `fcntl.flock` で取り、終了の依頼は同じ名前の Unix ドメインソケットで受ける。取られていれば、ソケットへ終了を依頼してロックが放されるのを上限まで待つ | プロセスが落ちると OS がロックを放す。ソケットは抽象名前空間（名前の先頭が NUL）で作り、ファイルを残さない。ロックファイルの置き場所はモジュール構成設計で決める |
| 音量 | Linux では何もしない実装（下げる前の音量をそのまま返し、戻すときは何もしない）を `RecordingService` へ渡す。Linux では `integrations/volume/adapter.py` を読み込まない | `settings.toml` の `lower_volume` が `true` でも Linux では音量を変えない |
| 設定画面 | Linux では「録音」のまとまりから `recording.lower_volume`・`volume_percent`・`fade_sec` の欄を除く。保存しても `settings.toml` の値は変えない | 「録音」の `recording.hide_window` は残す |
| 設定の既定値 | `Settings` のスキーマは共通のまま、共通の既定値に OS ごとの上書きを重ねる。Linux の `recording.lower_volume` の既定値を `false`、`transcription.local_whisper.device` を `cpu`、`compute_type` を `int8` にする | 既に `settings.toml` にある値は書き換えない |
| ブラウザ | Linux では Chromium 系のブラウザの `--app` で開き、見つからなければ既定のブラウザ（`webbrowser` 経由の `xdg-open`）で開く。Windows は今の Edge・`os.startfile` のまま | 探すブラウザと順序は要件の `未確定` |
| テスト | Linux で動かせない Windows 専用のテスト（Win32 の排他・pycaw・SAPI）は Linux で skip する。Linux の排他と何もしない音量・ブラウザの Linux の実装に単体テストを追加する | Linux のテストは検証環境の VM（`ssh voice-paste-ubuntu`）で流し、ログを `テスト結果/` に置く |
| 確かめ方 | 実装の工程で、検証環境の VM で `uv sync --frozen` が成功することと、Xorg のセッションで `python -m voice_paste` を起動してトレイのアイコンが出ることを確かめ、2 つ目を起動して前のプロセスが終わることを確かめる。画面の撮影を `テスト結果/` に置く | Windows では今のテストを全て流して回帰を確かめる |
| 既存機能への影響 | Windows の配線・既定値・設定画面の欄・ブラウザの開き方は変えない | - |
| 動作環境 | 非機能要件の動作環境の決定値に Linux（Ubuntu 24.04・Xorg）を追加する | Wayland は #200 |
