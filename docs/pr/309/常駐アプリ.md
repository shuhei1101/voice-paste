## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の見本 | `settings.sample.yaml` を `config/settings.sample.yaml`、`resources/yogo.csv` を `config/yogo.sample.csv` へ `git mv` する。単体テスト `test_load_settings_when_sample_file` と `tests/unit/conftest.py` の見本のパスを揃える | `config/defaults.yaml` と `shared/constants.py` は変えない |
| `tokens.toml` | `src/voice_paste/ui/tokens.toml` を `content/tokens.toml` へ `git mv` し、`ui/style.py` の `TOKENS_FILE` を `tray.py` の `TRAY_ICON_DIR` と同じくリポジトリの直下（`Path(__file__).resolve().parents[3]`）から引く。`tests/unit/voice_paste/ui/test_style.py` の読み込み先を揃える | - |
| `ui/` | 移さない。knowledge へ規約の修正を起票する | - |
| 既存機能への影響 | 画面・設定の読み込みの動きを変えない。単体テスト・import-linter・`tests/integration/ui/` の結合テストを流して確認する | - |
