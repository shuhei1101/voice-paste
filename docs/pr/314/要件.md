# 要件

## 要望

AI Monitor の配布物を v0.3.0 から v0.4.0 へ追従し、`ai-monitor-version.ini` を `v0.4.0` にする。
終わりの条件は次の表のとおり。

| 対象 | 終わりの条件 |
| --- | --- |
| 配布先の反映作業 | [反映作業](./反映作業/index.yaml) の全ての作業の確認スクリプトが通る |
| 設計書のスキーマ | `dev-docs.yaml` の設計書の種別の行と管理用の YAML の行の `schema` が knowledge の `source`・`path`・`ref` を持ち、`schemas/` に AI Monitor から配られたスキーマのコピーと、適用済みの変換（`schemas/conversions/`）が無い。設計書の Schema が `tags`・`aliases` を持つ |
| 設計書の検査 | 設計書の検証のコマンド（`python -m ai_monitor.design_docs validate`）の違反が、base ブランチにもある対応テストファイルの不在（シナリオの `test_file` の 12 件）を除いて 0 件 |
| ルール索引 | 直下に `rules.yaml` があり、`docs/rules.yaml` が無い |
| データの設計書 | ER 図（ER-1・ER-2）の全てのテーブルが `source` を持ち、`source` が指すデータの設計書が `docs/data/` にある |
| サイトのレイアウト | `python -m ai_monitor.distribution import-site --version v0.4.0` で `docs/_theme/` を取り込み、記録のファイル `ai-monitor-theme.yaml` のバージョンが `v0.4.0` |
| 配信設定・ルール索引・設定スキーマ・MCP ツール | 配布元で増えたキー・行が、`docs/_config.yml`・`rules.yaml`・`settings.yaml` の voice-paste の行に入っている |
| 規約・テンプレート・判定・フェーズ手順 | v0.3.0..v0.4.0 で変わったものに、voice-paste の成果物が従っている |

`未確定`: knowledge のスキーマが持たないキーの扱い（決める段: 実装）

設計書の検査は 1 つの要素につき違反を 1 件ずつ出すため、書き換えと検査を繰り返して全てを出した。base ブランチにもある E2E のテストファイルが無い違反 12 件と、反映作業『配布先のデータの設計書の作成』が直す `tables[].source` の欠落 16 件を除く 202 件は次の表のとおり。

`未確定`: 反映作業『配布先のデータの設計書の作成』が voice-paste の ER 図の ID で止まる不具合の扱い（決める段: 実装）

試験用のクローンで、『各プロジェクトのスキーマの参照への移行』と『設計書の新しいスキーマへの変換』の結果を commit してから実行すると、前提確認で止まった。
配布元のスクリプトは ER 図の ID を `{種類}-{番号}-{連番}` の構造だけと想定し、voice-paste の `ER-1`・`ER-2`（`{種類}-{番号}`）からデータの設計書の ID を決められない。
AI Monitor へ [ai-monitor#3473](https://github.com/shuhei1101/ai-monitor/issues/3473) を起票した。

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | コピーしたスクリプトの `common.py`・`実行.py` に、ER 図の ID が `{種類}-{番号}` のときデータの設計書を `DATA-{連番}` の ID で作成する分岐を追加し、`index.yaml` の `説明` に配布元との違いと #3473 を記載する | この作業 PR で終了の条件を満たせる | 配布元のスクリプトとの差分を作業 PR が持つ |
| B | #3473 が直った AI Monitor のバージョンを待ち、この作業 PR ではデータの設計書の作成を行わない | 配布元のスクリプトのまま実行できる | ER 図の `tables[].source` の欠落の違反 16 件が残り、終了の条件（設計書の検査の違反が 0 件）を満たせない |

推奨: A

voice-paste の設計書の ID は全て `{種類}-{番号}` で、変える分岐は ID の決め方だけになる。
