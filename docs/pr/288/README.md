# 録音を開始した直後の取り消しで固まらないようにし、終了の処理中に録音を始められない理由を示す

## 概要

利用者が、録音を開始した直後に録音の画面の「×」か「取り消し」を押しても、アプリが固まらずに待機中へ戻れるようになる。
終了の処理の間に録音を始めようとした利用者が、録音を始められない理由を知ることができるようになる。

## 背景

[Issue #287](https://github.com/shuhei1101/voice-paste/issues/287) の利用者の報告。
録音を開始した直後に録音の画面の「×」を押すと、アプリが固まることがある（毎回ではない）。
「×」と「取り消し」は、どちらも録音の画面から `SessionManager.cancel` を呼ぶ。
`SessionManager.cancel` は、録音セッションのロックを持ったまま、画面のスレッドで録音を捨てる（マイクの入力を閉じて音量を戻す）。
終了の処理の間に録音を始めようとしても、理由は示されない。
処理中のダイアログは、API から始めた録音の処理中に録音開始のホットキーを押したときだけを扱う。
