## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| SAPI を前提にする非機能要件テスト | `test_max_segment_length.py` の win32 の skip を外す。VM で pass することを確かめる | 変更は `tests/` に閉じ、E2E テスト作成で行う。[#253](https://github.com/shuhei1101/voice-paste/issues/253) の修正が先に要る |
| GPU を前提にする非機能要件テスト | `requires_real_whisper` と `test_transcription_parity.py` の skip の条件を変えず、`test_segment_callback_latency.py` に GPU が無い環境で skip する条件を追加し、テスト実行方法と非機能要件に Linux では skip することを記載する | 決定値は OS で分けない |
| ブラウザの文字起こしを使う非機能要件テスト | `test_web_*.py` の 4 ファイルに、常駐アプリがその OS でブラウザの文字起こしを持たないとき skip する条件を追加する（E2E の同じケースと同じ条件） | - |
| GPU を使わない非機能要件テスト | VM で `--run-e2e` を付けて全件流し、上の skip を除いて pass することを確かめる | 決定値は変えない |
| release の E2E の実行 | `agent_context.yaml` の `phase_extensions.tester` の行の `when` を、release PR の E2E の実行で Windows の全件実行の後とし、本文に SSH の疎通の確認（通らなければユーザーに VM の起動を頼む）・自動起動の常駐アプリの停止・クローンの release ブランチへの更新・`systemd-run --user` での全件の実行・ログの取得・結果の集約への記載を書く | - |
| VM の設定 | SSH の鍵・Xorg の自動ログイン・画面のロックの無効は VM に設定済みのため、反映作業にしない | - |

結論: 成立。
SSH で tester が VM の E2E を全件流せ、GPU を使わない非機能要件テストも VM で pass する。
CPU の参考値は決定値を大きく超えるため、GPU を前提にするテストは Linux では skip する。
VM の起動だけは tester が行えないため、SSH が通らないときにユーザーへ頼む手順にする。

最小再現コードの要点（[#252](https://github.com/shuhei1101/voice-paste/pull/252) の `poc-logs/poc_run.sh`）:

```bash
export DISPLAY=:0 XAUTHORITY=/run/user/1000/gdm/Xauthority
.venv/bin/python -m pytest tests/e2e --run-e2e -v -rs -p no:cacheprovider > poc-logs/e2e.log 2>&1
.venv/bin/python -m pytest tests/nfr --run-e2e -v -s -rs -p no:cacheprovider > poc-logs/nfr.log 2>&1
```

WSL からは `systemd-run --user --unit=vp251-poc --collect ~/vp-251/poc_run.sh` を SSH で流して起動した。
diff の見どころは、`tests/support/whisper_fixtures.py` で GPU の skip を環境変数 `VOICE_PASTE_POC_ALLOW_CPU` で外した箇所（参考値の計測だけに使い、本体には入れない）と、#253 の直し方を当てた 4 ファイル。
