# interface

サブシステムの外部インターフェースと処理フロー（サブシステム結合テストの元）

| [呼び出し元へ返す](./IF-3.py.yaml) | API から始めた録音の結果（連続録音は区間ごとと終わり）を、開始で指定されたコールバック先へ送信する |
| [上限で打ち切る](./IF-2.py.yaml) | 完了が来ないまま録音セッションの上限時間に達した API の録音を打ち切り、履歴に残してコールバック先へ通知する |
| [設定のエンドポイントへ送信する](./IF-7.py.yaml) | 起こした文字を、設定の送信先のエンドポイントへ JSON で 1 回送信する |
| [画面を配信する](./IF-6.py.yaml) | GET /web/。外の端末のブラウザで開く文字起こしの画面と素材を返す |
| [音声を受け付ける](./IF-11.py.yaml) | POST /web/transcriptions。ブラウザから送信された音声を積んでジョブの ID を返す |
| [文字起こしの結果を返す](./IF-4.py.yaml) | GET /web/transcriptions/{job_id}。ジョブの状態・進み具合と、起こした文字か失敗の理由を返す |
| [ブラウザの音声を文字に起こす](./IF-1.py.yaml) | 受け付けたブラウザの音声を 1 件ずつ起こして補正し、履歴とジョブに残す |
| [用語集のプリセットの一覧を返す](./IF-5.py.yaml) | GET /web/glossary-presets。外の端末の画面が選ぶ用語集のプリセットの名前の一覧と、設定で選んでいるプリセットを返す |
| [音声を文字に起こす](./IF-12.py.yaml) | POST /transcriptions。受けた音声を Haas-ja-v1.0 で文字に起こして返す |
| [準備できたかを返す](./IF-13.py.yaml) | GET /health。モデルを読み込み終えたことを返す |
| [停止する](./IF-14.py.yaml) | POST /shutdown。常駐アプリが起動したサーバーを止める |
