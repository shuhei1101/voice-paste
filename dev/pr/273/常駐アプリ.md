## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定のキー | `HaasSettings` に `model`・`dtype`・`device`・`short_audio_limit_sec`・`batch_size`・`alpha`・`guard`・`chunk_sec`・`search_sec`・`window_sec`・`separator` を追加し、既定値を `config/defaults.yaml` に記載する | キーの名前と範囲はモジュール構成設計で確定する |
| 再起動のマーカー | `model`・`dtype`・`device` は `RELOAD_RESTART`、他は `RELOAD_IMMEDIATE` | 要求ごとの値は送信するたびに設定を参照する |
| 起動の引数 | `HaasServer` が `start.sh` へポートに続けてモデル・`dtype`・`device` を指定する | 起動の前から動いているサーバーは `GET /health` の値を設定と比べ、違えばログとトレイの通知で知らせる |
| 送信の項目 | `HaasTranscriber` が `POST /transcriptions` の multipart に要求ごとの値を指定する | 送信するたびに設定を参照する関数を受ける |
| 通知 | 起動の前から動いているサーバーのモデル・`dtype`・`device`（起動の引数で受けた値）が設定と違うとき、トレイの通知の種類を 1 つ追加して知らせる | 通知の見出し・本文はユーザーの目に触れる語彙のため、画面設計で確認事項として出す |
| 設定画面 | 「文字起こし」のまとまりの `transcription.haas.port` の後ろに追加するキーの欄を並べ、補助文に haas_asr の説明の要点を記載する | 欄の部品は型から決まる |
| 既存機能への影響 | 既定値を今の値にし、`settings.yaml` に新しいキーが無い利用者の文字起こしの結果を変えない | 既存の `settings.yaml` の移行は要らない |
