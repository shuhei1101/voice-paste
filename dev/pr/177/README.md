# faster-whisper のオプションで話していない定型句を抑える PoC の結果を記録する

## 概要

話していない定型句（「ご視聴ありがとうございました」など）を faster-whisper のオプションで抑えられるかを確かめた結果を、外部ライブラリの設計書に残す。

## 背景

[Issue #170](https://github.com/shuhei1101/voice-paste/issues/170) の要望。
[PR #166](https://github.com/shuhei1101/voice-paste/pull/166)（起点 [Issue #158](https://github.com/shuhei1101/voice-paste/issues/158)）で、出た定型句を文頭・文末から消す仕組みを入れた。
出さない側の対策は今、`vad_filter` オンと `condition_on_previous_text` オフの既定だけで、文字起こしワーカーは `hallucination_silence_threshold` などのハルシネーションを抑えるオプションを faster-whisper へ渡していない。
