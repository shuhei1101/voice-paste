# 要件

## 要望

- 録音と録音中のシステム音量の下げ戻しを、方針の記録（[構造の決定](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/4_%E6%A7%8B%E9%80%A0%E3%81%AE%E6%B1%BA%E5%AE%9A.md)・[リスクと移行計画](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/5_%E3%83%AA%E3%82%B9%E3%82%AF%E3%81%A8%E7%A7%BB%E8%A1%8C%E8%A8%88%E7%94%BB.md)）と、[#26](https://github.com/shuhei1101/voice-paste/pull/26) で起こしたモジュール構成のとおりに `src/voice_paste/` に作る
  - 録音: `features/recording` の `Recorder` がマイクの入力（16 kHz・モノラル・16 bit）を開き、開始・一時停止・再開・停止（貯めた音を `Recording` で返す）・破棄を行う。一時停止の間の音は貯めない
  - 音量: `integrations/volume` のアダプタが pycaw で既定の再生デバイスのマスター音量を読み、設定の割合（`recording.volume_percent`）へ下げ、録音を終えたら下げる前の音量へ戻す。下げるときと戻すときは設定の秒数（`recording.fade_sec`）をかけて変える（`voice_paste_legacy` の振る舞いを保つ）
  - 音量を下げない設定（`recording.lower_volume = false`）なら音量に触れない
  - 停止・破棄・開始の失敗のどの終わり方でも音量を戻す。マイクを開けないときは音量を戻して `MicrophoneUnavailableError` を送出する（トレイを戻すのは送出を受けるセッション・画面の側）
  - 音量を操作できないとき（pycaw・COM の例外）は `VolumeControlError` に変え、録音は音量を下げずに続ける
  - 録音中の音の大きさ（直近の入力の RMS を 0.0〜1.0 に正規化した値）を返す。録音の画面の波形の元で、一時停止中は 0 を返す
- pycaw は `==` で固定したまま、音量のアダプタ（下げる・戻す）を自前の関数で包み、Windows の実機の既定の再生デバイスで動かす契約テストを置く（品質シナリオ 7）
- 完了の定義
  - 録音の開始・一時停止・再開・確定（停止）・取り消し（破棄）が単体テストで確かめられ、マイクを開けないときに音量が戻る
  - 音量のアダプタの契約テストが Windows の実機で通る
  - import-linter の検査が通る（`features/recording` は `integrations` を import せず、音量の操作を関数型で受け取る）
- 普段使い（`voice_paste_legacy` と、リポジトリの直下の `.env`・`history/`・`log/`）には触れない
