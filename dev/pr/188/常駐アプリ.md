## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 読み上げる文の組 | 3 つの組の「ありがとうございました」を、`DEFAULT_EDGE_PHRASES` のどの文言にも文末で当たらない同じ文と言葉の組（例: 「明日は晴れるでしょう」と「晴れ」）に替える | 3 か所で同じ組にする |
| 用語集で消す行 | `DELETE_ROW` を、替えた 3 文目の言葉を誤変換にした行にする | `DELETED_WORD` は `THREE_SENTENCES[2][1]` のまま |
| テストの設定 | `edge_phrases` は書かず、既定の一覧のまま流す | - |
| 1 回目のワーカーの止め方 | 確定の前に止めるワーカーの番号を引いておき、確定の直後は `taskkill` だけを呼ぶ。`test_normal_when_worker_dies` は `workers_before` を引いた一覧から止める番号を取る | 確定から止めるまでに一覧を引かない |
| 2 回目のワーカーの止め方 | `kill_workers_twice`・`_kill_workers_twice` は、やり直しのワーカーが ready になるのを待つ間に新しいワーカーの番号を引いておき、ready になった直後は `taskkill` だけを呼ぶ | ready の前に番号が引けなければ、ready の後に引いて止める |
| テストのケース | 確かめる内容と期待値（区間ごとの言葉・区間の順・届いた回数・ワーカーの立て直し・失敗の知らせ）は変えない | - |
| 常駐アプリの振る舞い | 変えない | `src/` を変えない |
