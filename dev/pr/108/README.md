# 文字起こし中に、確定で選んだ出力先を固定の出力先の間で切り替えられるようにする

## 概要

録音を確定した利用者が、文字起こし中の表示が出ている間に、確定で選んだ出力先を「貼り付けて送信」「貼り付けのみ」「コピーのみ」の間で切り替えられるようになる。

## 背景

[Issue #51](https://github.com/shuhei1101/voice-paste/issues/51) の要望（[PR #48](https://github.com/shuhei1101/voice-paste/pull/48) のユーザーのコメントから起票）。
今は出力先が確定の操作で決まり、その後は変えられない。
文字起こし中の表示は経過と残りの時間・進みを出すだけで操作を持たず、貼り付け先からフォーカスを奪わないようにフォーカスを取らずに出している。
