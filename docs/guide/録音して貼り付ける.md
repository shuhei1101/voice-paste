# 録音して貼り付ける

ホットキー・トレイ・録音の画面で録音し、出力先を選んで起こした文字を届ける操作

## 録音を開始する

待機中に、次のどちらかで録音を始める。

- 録音を始めるホットキー（既定は `Ctrl+Alt+D`。Linux は `Super+Alt+D`）を押す
- トレイのアイコンの既定の操作か、メニューの「録音を開始」を選ぶ

貼り付けたいアプリの入力欄にフォーカスを配置してから始める。
貼り付けは、そのときアクティブなウィンドウへ入る。

ほかの録音や文字起こしが処理中のときは、始められないことがダイアログで通知される。
マイクを開けないときは、トレイで録音を始められなかったことが通知され、ログに理由が書き込まれる。

録音中は、設定でオンにしていればシステム音量が下がり、録音を終えると戻る。

## 録音の画面

録音を始めると、録音の画面が出る。
画面には状態（録音中・一時停止中）・経過時間・音量の波形が出る。
既定では、ほかのウィンドウより上に残り、カーソルのあるモニターに出る（`ui.topmost`・`ui.follow_cursor`）。

| 操作 | 既定のホットキー | 内容 |
| --- | --- | --- |
| 一時停止・再開 | `Ctrl+Alt+Z`（Linux は `Super+Alt+Z`） | 一時停止の間に話した声は録らず、経過時間も止まる |
| 取り消し | `Ctrl+Alt+Q`（Linux は `Super+Alt+Q`） | 録音を捨てて画面を閉じ、待機中に戻る |
| 出力先のボタン | 出力先ごと | 録音を確定し、選んだ出力先へ届ける。一時停止中でも押せる |
| ×（見出しの右端） | `Ctrl+Alt+Q`（Linux は `Super+Alt+Q`） | 「取り消し」と同じく、録音を捨てて画面を閉じる |
| 非表示（見出しの右端の横線） | - | 録音を続けたまま、その回だけ画面を非表示にする |

ボタンと同じ操作は、どこにフォーカスがあってもホットキーで行える。
各ボタンの名前の下に、そのホットキーが枠で囲んで出る。
長いホットキーでも途中で切れず、ボタンと画面がその幅まで広がる。
ホットキーを出さないようにもできる（[起動と設定](./起動と設定.md#ボタンのホットキーの表示)）。

画面は、状態と経過時間の行をつかんでドラッグすると動かせる。
動かした位置はその回だけで、次の録音はいつもの位置に出る。

非表示にしている間も録音は続き、ホットキーで一時停止・取り消し・確定ができる。
非表示にした画面は、トレイのアイコンの左クリックか、トレイのメニューの「録音の画面を表示」で再表示する。
録音開始のホットキーと同じホットキーの出力先が無い設定では、録音開始のホットキーでも再表示できる（既定の設定では「貼り付けて送信」と同じ `Ctrl+Alt+D` のため、トレイから再表示する）。

録音の画面を表示しない設定（`recording.hide_window`）では、トレイから始めても画面を表示せず、ホットキーだけで操作する。

## 出力先

確定すると、選んだ出力先へ起こした文字を届ける。
オンにした出力先のボタンだけが画面に並ぶ。

| 出力先 | 既定のホットキー | 届け方 |
| --- | --- | --- |
| 貼り付けて送信 | `Ctrl+Alt+D`（Linux は `Super+Alt+D`） | クリップボードへコピーし、貼り付けのキーを送信し、設定の秒数を待って Enter を送信する。設定画面の「Enter と一緒に押す修飾キー」で Ctrl・Alt・Shift をオンにすると、その修飾キーを押したまま Enter を送信する |
| 貼り付けのみ | `Ctrl+Alt+V`（Linux は `Super+Alt+V`） | クリップボードへコピーし、貼り付けのキーを送信する。Enter は送信しない |
| コピーのみ | `Ctrl+Alt+C`（Linux は `Super+Alt+C`） | クリップボードへコピーするだけで、貼り付けも Enter も送信しない。コピーすると「コピーしました」の通知が出て、通知が出ている間に押すと同じ文字をもう一度コピーする |

### 文字起こし中に出力先を切り替える

固定の出力先で確定した録音は、文字起こし中の表示が出ている間、届け始めるまで出力先を切り替えられる。
文字起こし中の表示の出力先のボタンを押すか、切り替えたい出力先のホットキーを押す（既定の `Ctrl+Alt+D` は、文字起こし中は録音を始めず「貼り付けて送信」へ切り替える）。
今の出力先にはマーカーが付き、切り替えると切り替えた先で届ける。
ボタンを押しても貼り付けたい場所のフォーカスは動かないので、貼り付けて送信・貼り付けのみはそのまま貼られる。
カスタムプリセットで確定した録音は切り替えられない。
文字起こし中の表示は、見出しの行をつかんでドラッグで動かせる。

### カスタムプリセット

自分で追加できる届け先。
有効にしたプリセットのボタンが、録音の画面の固定の出力先のボタンの下に、見出し「カスタムプリセット」を付けて並ぶ。
並びは、設定画面の「ブラウザ添付」のタブの順、続けて「エンドポイントへ送信」のタブの順。
最初は 1 件も無い。

プリセットは、設定画面の「ブラウザ添付」「エンドポイントへ送信」のタブで追加・削除・並べ替えをする。
1 件ごとに、次を持つ。

| 項目 | 内容 |
| --- | --- |
| タイトル | ボタンに出す名前 |
| URL | 開く画面、または送信先（http か https） |
| ホットキー | 録音の画面でこのプリセットを選ぶキー。空なら、録音の画面のボタンだけで選ぶ |
| 有効 / 無効 | 無効にしたプリセットは、ボタンを出さず、ホットキーも使用できない |

種類ごとの届け方と項目は次のとおり。

| 種類（タブ） | 届け方 | 種類ごとの項目 |
| --- | --- | --- |
| ブラウザ添付 | クリップボードへコピーし、URL を Microsoft Edge のアプリのウィンドウとして開き、タブのオプションの秒数を待って貼り付ける。Edge が見つからないときは既定のブラウザで開く | Enter まで送信するか、貼り付けだけで止めるか（既定は Enter まで送信する）。開いてから貼り付けるまでの秒数はタブのオプション（既定 3 秒） |
| エンドポイントへ送信 | 起こした文字を URL へ JSON で 1 回 POST する。届かなければ再送せず、トレイで通知する | `Authorization` の値（空なら付けない）。タイムアウトはタブのオプション（既定 1.5 秒、0.5 秒以上 10 秒以下） |

プリセットで届けるのは、ホットキー・トレイから始めた録音を、ボタンかホットキーで選んだときだけ。
API から始めた録音では使用しない。

前の AI チャットの送信先（ChatGPT・Google AI・Claude）は、ブラウザ添付のプリセット（Enter まで送信）に読み替えて出る。
次に設定を保存すると、プリセットとして書き込まれる。

クリップボードを別のアプリが開いたままで書き込めないときは、届けられなかったことが通知され、ログに理由が書き込まれる。

## Linux での操作

Linux（Ubuntu 24.04 の Xorg のセッションと Wayland のセッション）でも、操作は Windows と同じ。
違いは次のとおり。

- 設定画面・録音の画面・文字起こし中の表示・トレイでは、Windows キーを「Super」と表示する（Windows では「Win」のまま）
- 既定のホットキーは `Ctrl+Alt` に代えて `Super+Alt` で組み合わせる（Ubuntu が `Ctrl+Alt+D` を「デスクトップを表示」に割り当てているため）。`settings.yaml` では `<cmd>+<alt>+d` のように記載する
- 貼り付けのキー（`Ctrl+V`）の既定は、Windows と同じ
- 貼り付け先が端末アプリ（GNOME Terminal 等）のときは、設定の貼り付けのキーに代えて `Ctrl+Shift+V` を送信する。「貼り付けて送信」も同じキーで貼り付けてから Enter を送信する

Wayland のセッションでは、次の点が違う。

- 貼り付け先が端末アプリかは、GNOME Shell の拡張 [Focused Window D-Bus](https://extensions.gnome.org/extension/5592/focused-window-d-bus/) で見分け、端末アプリには `Ctrl+Shift+V` を送信する。拡張は、拡張のページか「拡張機能マネージャー」で入れて有効にする。対応する GNOME Shell のバージョンは拡張のページで確認する
- 拡張が入っていないか無効のときは、貼り付け先が端末アプリでも設定の貼り付けのキー（既定は `Ctrl+V`）を送信する。端末アプリでは `Ctrl+V` が貼り付けにならない
- 貼り付けのキーと Enter は、`/dev/uinput` の権限を設定してから送信できる。権限を設定した後は再起動が要る。手順は[起動と設定](./起動と設定.md#wayland-のセッションで要る設定)

## 起こした文字

録音は設定のエンジン（ローカルの Whisper か OpenAI API か Haas。[起動と設定](./起動と設定.md#文字起こしのエンジン)）で文字に起こし、文頭・文末の決まった文言を削除し、用語集で補正してから届ける。

### 用語集

用語集は、誤変換と正しい表記の行の集まり。
正しい表記を空にした行は、起こした文字から誤変換を削除する（「ご視聴ありがとうございました」など、話していない文言を削除するのに使用する）。
設定画面の「用語集」で、行の追加・書き換え・削除ができ、行ごとに補正に使用するかを切り替えられる。
用語集は名前を付けて複数持てる。
最後の 1 件の用語集は削除できない。
補正に使用する用語集は、用語集のプリセットでまとめて選ぶ。
設定画面の「用語集のプリセット」で、プリセットの追加・名前の変更・削除ができる。
プリセットごとに、使用する用語集を選択欄から「追加」し、× で除外する。
除外しても、用語集そのものは消えない。
使用する用語集は、左端のつまみを掴むか `Alt+↑` / `Alt+↓` で並べ替える。
補正に使用するプリセットは 1 つ選ぶ。
補正は、選んだプリセットの用語集のオンの行を、並べた用語集の順・用語集の中の行の順に続けて適用する。
前の行で置き換えた結果へ、次の行を適用する。
保存すると、再起動せずに次の録音の確定から有効になる。

用語集の中身は UTF-8 の CSV で、列は `誤変換`・`正しい表記`・`使う`（`0` の行は補正に使用しない）。
今までの用語集（`glossary_path` の CSV。無ければ設定ファイルと同じフォルダの `yogo.csv`）は、1 つ目の用語集としてそのまま使用できる。
設定画面で追加した用語集の CSV は、設定ファイルと同じフォルダの `glossaries` の下にできる。
一覧から用語集を削除しても、CSV のファイルは削除されない。
プリセットを持たない今までの設定は、補正に使用していた用語集だけを使用する「既定」のプリセットとして読み込まれ、補正の結果は変わらない。
録音を確定するたびに再読み込みする。

### 文頭・文末の決まった文言

文字起こしが文頭・文末に追加する、話していない文言（「ご視聴ありがとうございました」など）は、登録した一覧で削除する。
一覧は 1 つで、上の行から順に、前の行で削除した結果へ次の行を適用する。
文頭は起こした文字の先頭、文末は末尾で、文頭・文末以外に現れる同じ文言は削除しない。
連続録音は、区間の文字ごとに適用する。
一致した文言と、その後ろに続く句読点・感嘆符・疑問符（`。`・`、`・`！`・`？` など）・空白を一緒に削除する。
文言は書き込んだ文字との完全な一致で、`*` は 0 文字以上の任意の文字列として扱う（改行はまたがない）。
文言の末尾の `*` は行の末尾まで、先頭の `*` は行の先頭から一致させる。
行ごとに、適用する位置を「文頭」「文末」「両方」から選ぶ（既定は「文末」）。
最初の一覧は、上から「チャンネル登録*」「ご視聴ありがとうございました」「ありがとうございました」で、位置は全て「文末」。
設定画面の「ハルシネーション」で、行の追加・書き換え・削除・並べ替えができる。
並べ替えは、行の左端のつまみを掴んで動かすか、文言の欄で `Alt+↑` / `Alt+↓` を押す。
保存すると、再起動せずに次の録音の確定から有効になる。

### 表記のヒント

文字に起こすとき、間違えやすい単語の正しい表記をヒントとしてエンジンに引き渡せる。
設定画面の「表記のヒント」で、ヒントのプリセットの追加・名前の変更・削除・並べ替えができ、プリセットの中の単語の追加・書き換え・削除ができる。
プリセットごとに有効・無効を切り替えられ、無効のプリセットの単語は引き渡さない。
有効なプリセットが無いときは、ヒントを引き渡さずに起こす。
保存すると、再起動せずに次の録音の確定から有効になる。
ホットキー・トレイ・API のどこから始めた録音にも、同じヒントを引き渡す。

引き渡すのは、有効なプリセットの単語を一覧の上から順に読点（、）でつないだもの。
単語は 1 つずつ入力し、空にできず、読点（、）・句点（。）・改行を含められない。
単語ごとに読み（ひらがな・カタカナ）を入れられる。
読みはエンジンが Haas のときだけ使用し、読みを入れない単語は手がかりがほとんど有効にならない。
読みは長さに数えない。
つないだ長さは 222 バイト（日本語でおよそ 74 文字。単語の間の読点も数える）まで。
今の長さは「有効なヒントの長さ」に出て、超えると保存できない。

ヒントを引き渡すと、単語の表記のほかに出力の記載方法も変わる。
句読点が付く・区間ごとの改行がまとまる・口癖が一部消える。
並べた表記へほかの単語が引っ張られることもある（例: TypeScript がタイプスクリプトになる）。
引っ張られた単語は、その単語も追加して修正する。

ヒントは、その表記に寄せて起こされやすくするだけで、必ずそう起こすわけではない。
必ず置き換える用語集とは別の仕組み。

### 履歴

確定した録音と起こした文字は、履歴に残る。
配置先と保持期間は[起動と設定](./起動と設定.md)。

ほかのプロセスから録音を操作して文字を受け取る方法は[API](./API.md)。
