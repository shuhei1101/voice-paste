# faster-whisper と組める PyAV の版を依存に宣言する

## 概要

新しく作った venv でも文字起こしが動くよう、faster-whisper と組める PyAV（`av`）の版を `pyproject.toml` の依存に宣言する。

## 背景

[Issue #53](https://github.com/shuhei1101/voice-paste/issues/53) の不具合。
release PR [#52](https://github.com/shuhei1101/voice-paste/pull/52)（Sprint v0.3.0）の E2E で、新しく作った venv に `av` 19.0.1 が入り、faster-whisper 1.2.1 の `av.open(..., metadata_errors="ignore")` が `TypeError` になって文字起こしが毎回失敗した。
`pyproject.toml` は `faster-whisper~=1.0` だけを宣言し、faster-whisper も `av>=11` と下限しか持たないため、入れ直すと誰の環境でも最新の `av` が入る。
`av` を 18.1.0 に戻すと fail した 3 件が pass し、普段使いの develop の venv（`av` 18.1.0）では起きない。
