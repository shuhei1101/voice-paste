# 要件

## 要望

設計書『テスト実行方法』（`docs/test-procedure/TP-1.yaml`）に、補足「画面の起動」（最上位の `notes` の `画面の起動`）を追加し、開発ドキュメントサーバーの行として、作業ブランチの配信の設定で画面を開く手順と止め方を記載する。

- 開発ドキュメントサーバーは project-index と dev-docs の 2 つで、利用者の端末で動いているものと別のポートで起動する
- project-index は配信元の設定を `default_ref`（develop）の commit から参照するため、作業 PR の worktree の `project-index.yaml` の `nav` を重ねて参照させる手順にする（[作業 PR #351](https://github.com/shuhei1101/voice-paste/pull/351) で使用した、端末の設定のコピー・`PROJECT_INDEX_CONFIG`・`DEV_DOCS_CONFIG`・ポートの環境変数・`sources[].config` の 2 つ目への重ね）
- 開く URL（配信元とブランチの指定）と、起動したプロセスだけを止める止め方を記載する
- 記載方法は knowledge のテンプレート『テスト実行方法』の `notes` の `画面の起動`（画面・起動・止め方の表）に従う
- 記載した手順で実際に起動し、作業ブランチの `nav` の画面が開くことと、止めた後に利用者の端末の開発ドキュメントサーバーが動き続けていることを確認する
