## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の確かめ | この PR では実機で E2E を流さず、fail した時点の隠れたアイコンの一覧の中身は読まない | 実機での確かめは Sprint の release の E2E で行う。そこで fail したら tester の切り分けで一覧の中身を読む（確認ログ） |
| 自分のアイコンの探し方 | 候補を 1 つ試すたびに一覧を開き直して候補を並べ直してから、まだ試していない候補を試す | `_tray_center` は消し、位置では覚えない。並べ直した数が減れば先頭から試し直す。`tray_icon_buttons` は一覧を開いたまま返す形のまま、候補を 1 つ試すたびに呼び直す |
| 前のケースのアイコン | 強制終了したプロセスのアイコンが残っていても、メニューが出ない候補として飛ばす | 残ったアイコンは消さない（後始末は変えない） |
| 常駐アプリ | 変えない | `type:test` |
| 既存機能への影響 | 要件.md の `実行のみ` の行の E2E が、`この常駐アプリのトレイのアイコンが見つからない` では fail しない | 前のケースのアイコンが無いときの選び方（初めの候補で `menu_start` が出る）は変わらない |
