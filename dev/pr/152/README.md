# 用語集の正しい表記を空にした行で、誤変換を消せるようにする

## 概要

利用者が、用語集の正しい表記を空にした行を作り、文字起こしで紛れ込む決まった文言（「ご視聴ありがとうございました」など）を、起こした文字から消せるようになる。

## 背景

[Issue #148](https://github.com/shuhei1101/voice-paste/issues/148) の要望。
文字起こしで、話していない「ご視聴ありがとうございました」などの文言が入ることがあり、用語集で消したい。
今の補正は、誤変換と正しい表記の両方がある行だけを使い、正しい表記が空の行を飛ばす。
設定画面も、誤変換がある行で正しい表記が空だと「正しい表記を入れてください。」で保存を止める。
