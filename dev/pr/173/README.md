# 補正に使う用語集を複数まとめて選べる用語集のプリセットを追加し、API からも選べるようにする

## 概要

利用者が、補正に使う用語集を複数まとめた用語集のプリセットを作って切り替えられ、ほかのシステムも API で録音を始めるときにプリセットを選べるようになる。

## 背景

[Issue #168](https://github.com/shuhei1101/voice-paste/issues/168) の要望。
[Issue #87](https://github.com/shuhei1101/voice-paste/issues/87) の対応で用語集を名前を付けて複数持てるようになったが、補正に使うのは設定の `active_glossary` で選んだ 1 つだけで、用途ごとに複数の用語集を組み合わせられない。
API で始めた録音も、設定で選んでいる 1 つの用語集で補正される。
