## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ホットキーの受付 | `HotkeyListener.__init__` を引数なしにし、`start` は常に `keyboard.GlobalHotKeys(包んだ組)` を作る。`_build_injected_listener` を消す | 書式を読めないときの `HotkeyError`・動いている受付の入れ替え・`stop` は変えない |
| 起動の配線 | `main.py` から `ACCEPT_INJECTED_HOTKEYS_ENV` と環境変数を読む行・ログを消し、`HotkeyListener()` で作る | 使わなくなる import が出れば消す |
| 単体テスト | `test_start_when_accept_injected` と `test_main_when_accept_injected_hotkeys` を消し、`test_main` から環境変数を消す行と `accept_injected` の確かめを外す | `test_main` は `HotkeyListener` が引数なしで作られることを確かめる |
| E2E の支えのコード | `FakeHotkeyListener.__init__` と `make_hotkey_listener` から `accept_injected` を消す | E2E のケースは変えない |
| モジュール構成 | 起動と配線・ホットキーと画面から `accept_injected` / `VOICE_PASTE_ACCEPT_INJECTED_HOTKEYS` の記述と、消すテストの行を消す | - |
