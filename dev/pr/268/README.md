# Linux（Ubuntu）の文字起こしは OpenAI API に限ることを使い方へ記載する

## 概要

Linux（Ubuntu）の常駐アプリの文字起こしは OpenAI API で行い、GPU（CUDA）を使用するエンジン（ローカルの Whisper の GPU・Haas）は使用しない、という方針を `docs/使い方/` へ記載する。

## 背景

[#203 のユーザーのコメント](https://github.com/shuhei1101/voice-paste/issues/203#issuecomment-6553952636)で、Linux の文字起こしは OpenAI API に限り、GPU 経由で文字を起こさないと決まった。
[#266 の close の判断](https://github.com/shuhei1101/voice-paste/issues/266#issuecomment-6669721545)の派生として [#267](https://github.com/shuhei1101/voice-paste/issues/267) が起票された。
今の [docs/使い方/起動と設定.md](https://github.com/shuhei1101/voice-paste/blob/develop/docs/%E4%BD%BF%E3%81%84%E6%96%B9/%E8%B5%B7%E5%8B%95%E3%81%A8%E8%A8%AD%E5%AE%9A.md) は「文字起こしのエンジンの既定はローカルの Whisper で、Linux では CPU で動く」とだけ記載し、この方針を記載していない。
