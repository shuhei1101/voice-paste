# Linux（Ubuntu 24.04 の Xorg）で E2E テストを自動で実行できるようにする

## 概要

開発者が Ubuntu 24.04 の Xorg のセッションで、`--run-e2e` を付けた pytest の 1 コマンドで E2E テストを自動で実行できるようにする。

## 背景

[Issue #219](https://github.com/shuhei1101/voice-paste/issues/219) の要望。
E2E テストは Windows の実機を前提にしており、録音の入力は Windows の音声合成（SAPI）で書き出した WAV、外の端末の画面のケースは Windows の Edge を使う。
SAPI を使う `tests/support/inprocess.py` に依存するテストは Linux では skip している。
[#214](https://github.com/shuhei1101/voice-paste/pull/214)（起点 [#199](https://github.com/shuhei1101/voice-paste/issues/199)）では、Linux の起動から貼り付けまでを VM（`voice-paste-ubuntu`）で手で通して確かめ、E2E の自動化はスコープ外にした。
