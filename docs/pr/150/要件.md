# 要件

## 要望

文字起こし中の表示で、`ui.transcribing_show_hotkeys` のオン・オフのどちらでも、出力先の切り替えのボタンを等しい幅（並べた全てのボタンの `width()` が同じ値）で横に並べる。
揃える幅は、名前の最も長いボタンが名前を省かずに収まる幅以上にする。
ホットキーを出さない設定でも幅が揃うことを結合テストで確かめる。
