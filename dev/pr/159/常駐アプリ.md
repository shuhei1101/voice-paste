## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の特定 | 明るい組・暗い組で設定画面を開き、オンのチェックボックスの印が描かれない理由（スタイルシートを当てた部品の印の描き方と色の重なり）を突き止め、計画書に書く | 済: スタイルシートを当てると Windows 11 のスタイルがオンの箱と選んだラジオボタンの印を描かない（モック作成で撮った実画面 `スクリーンショット/qt-now-light.png`・`qt-now-dark.png`） |
| 印を描く仕組み | `QProxyStyle` を継いだ IndicatorStyle（`ui/indicator_style.py`）が、チェックボックス・ラジオボタン・選択欄の開く印を theme_color の色で描く。apply_theme が 1 回だけアプリのスタイルに当てる | スタイルシートの `::indicator` に画像を使う案は、明暗ごとの画像ファイルを持つか書き出す必要があり、色の正本が tokens.toml から離れるため採らない |
| 大きさ・間 | tokens.toml の `[shape]` に `indicator`（16）・`indicator_dot`（8）・`indicator_gap`（8）・`choice_gap`（20）を足す | - |
| チェックボックスの印 | QSS に `QCheckBox::indicator` のオン・オフ・使えない状態・フォーカスの規則を足し、オン・オフを色と形の両方で見分けられるようにする | 印の見た目は要件.md の `## 要望` |
| ラジオボタンの印 | QSS に `QRadioButton::indicator` の規則を足し、チェックボックスと同じ色の役割で揃える | - |
| ほかの印 | 選択欄の開く印・つまみ・選んだボタンの印を明るい組・暗い組で確かめ、見えない・見分けられないものを同じ方針で直す | - |
| アクセシビリティ | 印と背景のコントラストを 3:1 以上にする（WCAG 2.1 の 1.4.11） | 明るい組・暗い組の両方 |
