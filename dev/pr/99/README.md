# 文字起こしに渡す手がかりの語をプリセットで保存して切り替え、設定画面から編集できるようにする

## 概要

ユーザーが文字起こしに渡す手がかりの語（間違えやすい語の正しい表記）をプリセットとして複数保存し、有効・無効を切り替えて、設定画面から編集できるようにする。
あわせて、settings.toml にあって設定画面で変えられない項目を洗い出して提案する。

## 背景

[Issue #88](https://github.com/shuhei1101/voice-paste/issues/88) の要望。
今の常駐アプリにも文字起こしワーカーにも、文字起こしへ手がかりを渡す設定は無い。
ワーカー（[worker.py](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/integrations/whisper/worker.py) の `_transcribe`）は faster-whisper の `transcribe` に言語・ビーム幅・VAD などの値だけを渡している。
用語集の設定画面での編集は [#87](https://github.com/shuhei1101/voice-paste/issues/87)（[#97](https://github.com/shuhei1101/voice-paste/pull/97)）で入った。
