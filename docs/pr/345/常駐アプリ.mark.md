## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 区間の時刻の求め方 | 区切りが持つ話し声の始まりと終わりのサンプル位置を、録音の開始の時刻に「位置 ÷ 16000 秒」を加えた時刻にする | `max_length` の話し終わりは区切った位置。`flush` は、話し終えた後の無音の間の完了なら話し声の最後、話し声の途中の完了なら録音を停止した位置 |
| 区間の型 | `Segment` に話し始めと話し終わりの時刻を追加する | - |
| 結果の型 | `TranscriptionOutcome` に話し始めと話し終わりの時刻を追加する。区間の結果だけが値を持ち、それ以外は `None` | 成功・失敗の区間の両方 |
| 返送の本文 | `CallbackPayload` に `started_at`・`ended_at`（UTC の ISO 8601・ミリ秒まで・末尾 `Z`）を追加し、`None` は `null` で送信する | - |
| 既存機能への影響 | 今あるキーの名前と値、設定の送信先へ送信する `ResultPayload` は変えない | - |
| 性能 | 時刻の計算はサンプル位置からの算術だけで、区切ってから返送が届くまでの時間（`segment_callback_latency`）を変えない | - |
