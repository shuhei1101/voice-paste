# 貼り付けて送信の Enter に一緒に押す修飾キーを設定で選べるようにする

## 概要

ユーザーが設定画面のチェックボックスで Ctrl・Alt・Shift を選び、「貼り付けて送信」が貼り付けた後に送る Enter を、選んだ修飾キーと一緒に押せるようにする。

## 背景

[Issue #84](https://github.com/shuhei1101/voice-paste/issues/84) の要望。
送り先のアプリによっては Enter だけでは送信されず、Ctrl+Enter などで送信する。
develop の [paste_and_send/service.py](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/features/outputs/paste_and_send/service.py) は貼り付けて設定の間を置き、`send_enter()` で Enter だけを送る。
設定は貼り付けてから Enter を送るまでの秒数（`enter_delay_sec`）だけを持つ。
