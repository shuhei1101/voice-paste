# 起動を作り直した新しい構成へ切り替える

## 概要

Windows のショートカットから起動する常駐アプリを、`voice_paste_legacy` から作り直した `src/voice_paste/` の新しい構成へ切り替える。
ユーザーが今までと同じショートカットから、新しい構成の常駐アプリで音声入力を使えるようになる。

## 背景

[Issue #22](https://github.com/shuhei1101/voice-paste/issues/22) の要望。
作り直しの方針（[#13](https://github.com/shuhei1101/voice-paste/issues/13)、記録は [#12](https://github.com/shuhei1101/voice-paste/pull/12) の `dev/pr/12/方針決め/`）の移行の Issue の並びの順 9 にあたる。
画面・トレイ・ホットキーまでの作り直しは [#21](https://github.com/shuhei1101/voice-paste/issues/21)（[#37](https://github.com/shuhei1101/voice-paste/pull/37)）で develop に入っており、新しい構成は並走のため `--data-dir` を必須にして普段使いの置き場所へ書かない形で動いている。
起動のバッチファイル（`voice-paste.bat`）は今も `voice_paste_legacy` を起動している。
