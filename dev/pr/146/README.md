# 閉じた設定画面を破棄し、開き閉めを繰り返してもトップレベルの窓が積もらないようにする

## 概要

常駐アプリで設定画面を何度開いて閉じても、閉じた設定画面の窓が残らず、設定画面の操作が遅くならずメモリも増えないようにする。

## 背景

[Issue #124](https://github.com/shuhei1101/voice-paste/issues/124) の不具合。
[#123](https://github.com/shuhei1101/voice-paste/pull/123)（起点 [#95](https://github.com/shuhei1101/voice-paste/issues/95)）のレビューで見つかった、#123 の対象外の不具合（[指摘](https://github.com/shuhei1101/voice-paste/pull/123#discussion_r4301708770)）。
トレイの「設定」から設定画面を開いて閉じるたびに、`SettingsWindow` と他 2 つのトップレベルの窓が残り、GC しても破棄されない（5 回で 3 → 18）。
保存したときの明暗の当て直し（`on_settings_saved` の `apply_theme`）などが積もった窓まで処理するため、長く使うほど設定画面の操作が遅くなり、メモリが増える。
