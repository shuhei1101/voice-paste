# 要件

## 要望

- 起動のバッチファイル（`voice-paste.bat`）の起動先を、`voice_paste_legacy` から新しい構成（`python -m voice_paste`）へ切り替える
  - デスクトップとスタートメニューの `voice-paste.bat - ショートカット` はこのバッチファイルを開くため、ショートカット自体は変えない
  - 置き場所を指定せずに起動し、設定は `%APPDATA%\voice-paste\settings.toml`、履歴・ログ・一時の音声・トークンは `%LOCALAPPDATA%\voice-paste\` の下に置く
  - CUDA の DLL の場所を通し、`pythonw` でコンソールを出さずに起動する今の振る舞いは保つ
- 新しい構成を `--data-dir` 無しで起動できるようにする（並走のために必須にしている置き場所の指定を任意に戻す）
- `pyproject.toml` の `voice-paste` コマンドの起動先を新しい構成の `main` へ向ける
- 方針の記録（[リスクと移行計画](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/5_%E3%83%AA%E3%82%B9%E3%82%AF%E3%81%A8%E7%A7%BB%E8%A1%8C%E8%A8%88%E7%94%BB.md)）の「起動のたびに前日までのログを消す」を避け、起動のバッチファイルではログを日付で消さない
  - 起動の記録（起動した時刻・使った Python・終了コード）は `%LOCALAPPDATA%\voice-paste\log\launcher.log` へ起動ごとに上書きで書く（`pythonw` はコンソールを出さず、Python が立つ前の失敗はこの記録にしか残らない。常駐アプリの保持期間の削除は日付の名前のログだけを消すため、上書きで大きさを保つ）
- 前の PR で起動の切り替えへ持ち越した次の項目を、この PR で作る
  - 単一インスタンスの確保（[#33](https://github.com/shuhei1101/voice-paste/pull/33)・[#37](https://github.com/shuhei1101/voice-paste/pull/37) から）: 同じ置き場所で 2 つ目を起動すると、前の常駐サービスに名前付きのイベントで終わるよう頼み、名前付きのミューテックスが放されてから立つ。前のプロセスを番号で強制終了しない。待つ上限は非機能要件の前の常駐サービスの終わりを待つ時間（17 秒）。排他の名前は設定の置き場所ごとに変え、E2E の `--data-dir` の起動が普段使いを終わらせない
  - 起動時と常駐中の 24 時間ごとに、保持期間を過ぎた履歴とログを消す配線（[#31](https://github.com/shuhei1101/voice-paste/pull/31) から）
  - 新しい構成のワーカーの立て直しの時間・終わりを待つ時間の測り直し（[#31](https://github.com/shuhei1101/voice-paste/pull/31) から）。測った値で非機能要件の決定値を決め直す
  - 公開ドキュメントの使い方（起動と設定・録音して貼り付ける操作）と API のリファレンス（[#33](https://github.com/shuhei1101/voice-paste/pull/33)・[#37](https://github.com/shuhei1101/voice-paste/pull/37) から）
- 完了の定義
  - ショートカットから起動すると新しい構成の常駐アプリが立ち、トレイのアイコンが待機中になる
  - 常駐中にショートカットからもう一度起動すると、前の常駐サービスが終わり、常駐サービスのプロセスが 1 つだけになる
  - 話し終えてから貼り付くまでの時間（品質シナリオ 3）の中央値が 1.08 秒以下（常駐中・ローカルの Whisper（GPU）・モデル読み込み済みで、約 10 秒話してホットキーで止めてから貼り付くまでを 20 回、実機で測る）
  - E2E を通して master に入っている

`未確定`: スタートアップのショートカット（`shell:startup` の `voice-paste`）の扱い（決める段: モジュール構成設計の後の承認確認）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 起動のバッチファイルへ向け直す | サインインしたときに新しい構成が常駐する | ユーザーの環境のショートカットを書き換える |
| B | 消す | 起動しない exe を指す残骸が無くなる | サインインしたときの自動の起動が無くなる |
| C | 触らない | ユーザーの環境を変えない | 起動しないショートカットが残る |

推奨: A

今は配布用のビルドの `dist\voice-paste\voice-paste.exe` を指しているが、exe は既に無く、サインインしても起動していない。
置いてあることからサインインしたときに常駐させたい意図が読み取れる。
