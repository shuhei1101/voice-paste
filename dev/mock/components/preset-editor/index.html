プリセットの欄

設定画面の「ブラウザで開く」「エンドポイントへ送る」のタブに並べるプリセットの 1 件分。頭に出す・タイトル・並べ替え・消すを置き、下にタイトル・URL・その種類の値（Enter まで送る / Authorization）・確定のホットキーを並べる。種類はタブで決まるので、種類の欄は持たない。

貼り付けた後

空ならホットキーを持たず、録音の画面のボタンだけで選ぶ。

URL の下に「Enter まで送る」を出す。既定はオン。
