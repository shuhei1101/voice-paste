表記のヒントの欄

設定画面に置く、文字起こしに渡す表記のヒントの部品。上に有効なヒントの長さ（バー・今の長さと上限）、下にヒントのプリセットの一覧（有効・無効の切り替え・名前・語の数と長さ・並べ替え・削除、名前の欄、語の欄）と「プリセットを追加」を並べる。

通常（有効と無効）

有効なヒントの長さ 86 / 222 バイト 86 / 222 バイト

上限は 222 バイト（日本語でおよそ 74 文字）。語の間の読点（、）も数える。

ヒントのプリセットはまだありません。無い間は、ヒントを渡さずに文字を起こします。

    語

    このプリセットにはまだ語がありません。

  2. 会議3 語・48 バイト

有効のプリセットの語だけを長さに数える。無効のプリセットは語を薄くして取り消し線を引く。

エラー（長さが上限を超える・語に読点・語が空・名前が重なる）

保存できませんでした。4 件の欄を修正してください。
  • 有効なヒントの長さ: 有効なヒントが長すぎます（258 / 222 バイト）。語を減らすか、プリセットを無効にしてください。
  • プリセット 1 件目の 4 つ目の語: 読点（、）・句点（。）・改行は入れられません。語を分けて追加してください。
  • プリセット 2 件目の 2 つ目の語: 語を入れるか、この欄を削除してください。
  • プリセット 3 件目の名前: プリセット「開発」と同じ名前です。別の名前にしてください。
