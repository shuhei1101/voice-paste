録音
recording.keep_display_on

オンにすると、録音を始めてから終えるまで、PC の画面が自動で暗くならず、スクリーンセーバーも動かない。録音を終えると OS の設定どおりに戻る。

recording.lower_volume
recording.hide_window

オンにすると、録音と文字起こしの間はトレイのアイコンとホットキーだけで操作する。

recording.volume_percent 50%
recording.fade_sec
既定に戻す キャンセル

新しい欄は「再起動で反映」ではないため、「保存」で動いている常駐アプリに適用し、次の録音から有効になる。Windows と Linux のどちらでも同じ欄を出す。
