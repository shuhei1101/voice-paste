# 設定画面のモックで、640px 以下の幅のとき長い設定のキーを欄の行の中で折り返す

## 概要

利用者が、640px 以下の幅で設定画面のモックを開いても、長い設定のキーが欄の行の右端からはみ出さずに読めるようになる。

## 背景

[Issue #163](https://github.com/shuhei1101/voice-paste/issues/163) の要望。
[PR #162](https://github.com/shuhei1101/voice-paste/pull/162)（[Issue #161](https://github.com/shuhei1101/voice-paste/issues/161)）のモック作成で designer が見つけ、641px 以上だけを扱う #162 から切り出した。
#37 のモックの共通スタイルの `@media (max-width: 640px)` の規則は欄の行を縦に積むだけで、設定のキーに折り返しの指定が無いため、`transcription.local_whisper.no_speech_threshold` など区切りの無い長いキーが行の右端を越える。
実際の設定画面（Qt）は窓の最小幅が 720px で、この幅にならない。モックの見た目だけの事象。
