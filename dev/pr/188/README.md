# Sprint v0.6.0 の E2E で fail した、読み上げる文の組とワーカーを止める時刻のテストを修正する

## 概要

release/v0.6.0 の E2E で fail した、読み上げる文の組と文字起こしワーカーを止める時刻のテストを修正し、対象のテストが pass するようにする。

## 背景

[Issue #187](https://github.com/shuhei1101/voice-paste/issues/187) は、release/v0.6.0 の E2E（[release PR #182](https://github.com/shuhei1101/voice-paste/pull/182)）で fail したテスト不備の 2 件を束ねた Issue。
どちらも `tests/e2e`・`tests/support` の中で閉じるテストの修正で、`src/` は変えない。

- [#184](https://github.com/shuhei1101/voice-paste/issues/184): テストが読み上げる「ありがとうございました」が、[#166](https://github.com/shuhei1101/voice-paste/pull/166) で入った文末から消す既定の文言（`DEFAULT_EDGE_PHRASES`）に当たり、その区間の起こした文字が空になる
- [#185](https://github.com/shuhei1101/voice-paste/issues/185): ワーカーを止める前にプロセスの一覧を引く（1 回 5 秒前後）間に文字起こしが終わり、文字起こしの途中でワーカーを止められない
