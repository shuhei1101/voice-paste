# 要件

## 要望

`/web/` の下で、Origin の無い POST を受け付ける。

| 要求 | 変更後の扱い |
| --- | --- |
| Host が `127.0.0.1:{ポート}` か `localhost:{ポート}` でない要求 | 403（変更しない） |
| Origin の無い POST | 通す（今は 403） |
| Origin の無い GET・HEAD | 通す（変更しない） |
| `api.allowed_web_origins` にある Origin の付いた要求 | 通す（変更しない） |
| `api.allowed_web_origins` に無い Origin の付いた要求 | 403（変更しない） |
| 常駐サービスが Linux で動いているときの `/web/` の下の要求 | 404（変更しない） |

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `src/voice_paste/server/middleware.py` の `_guard_web` | [ee11dc7b](https://github.com/shuhei1101/voice-paste/commit/ee11dc7b85f143145168a29273de0db0f95f0c1a)（`外の端末のブラウザから音声を送って文字に起こす画面とエンドポイントを追加する (#171)`） | 外の端末のブラウザだけを想定し、同一オリジンの GET には Origin が付かず、ほかのオリジンのページからの fetch には付くことから、POST は許す Origin のあるときだけ通すと決めた（PR #171 の計画書の「要求の守り」） | 1 回 | ブラウザは POST に Origin を付けるため、Origin の無い POST を通してもほかのオリジンのページからの送信は今と同じく許可リストで断る。#171 の目的を壊さない |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| ゲートウェイを通した外からの Origin の無い POST の区別 | ゲートウェイは Host を `localhost:{ポート}` に書き換えるため常駐アプリでは手元のプロセスと区別できない。外からの認証は Cloudflare Access が持つため、要望の「Host の制限は今と同じ」に従い区別しない | 予定なし |
| MindStella 側の送信の実装 | 別のリポジトリの作業 | shuhei1101/mindstella#402 |
