# トレイのボタンの名前に起動時の「準備中」のヒントを残さない

## 概要

スクリーンリーダーの利用者が、トレイのアイコンのボタンの名前で今の状態だけを聞けるようにする。

## 背景

[Issue #62](https://github.com/shuhei1101/voice-paste/issues/62) の不具合。
常駐アプリを 1 つだけ動かしても、トレイのアイコンのボタンの UI Automation の名前が `voice-paste: 準備中 voice-paste: 待機中` になり、起動時の「準備中」が残る。

Windows はボタンの名前を「アイコンを表示した時点のヒント」と「今のヒント」をつないで作る。
`Tray.__init__` が準備中のヒントを付けてから `show()` しているため、表示した時点のヒントが「準備中」になる。
ヒントを付けずに表示してから `setToolTip` するとボタンの名前が今のヒントだけになることは、[PR #60](https://github.com/shuhei1101/voice-paste/pull/60) の切り分けで確かめた。
#60 は E2E の読み方だけを直し、常駐アプリを変えていない。
