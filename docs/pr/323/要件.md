# 要件

## 要望

`GET /web/assets/app.js` が返却する Content-Type を、Windows のレジストリの `.js` の値に依らず同じにする。
`tests/unit/voice_paste/server/test_web_page.py::test_mount_web_assets` が、ランナー（`windows-latest`）と手元の Windows の両方で pass することを終了の条件にする。

`未確定`: 直し方（決める段: モジュール構成設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `mount_web_assets` が `.js` を `text/javascript` に固定して返却する | どの端末でも同じ型を返却し、[IF-6](https://github.com/shuhei1101/voice-paste/blob/130a6b2/docs/interface/IF-6.py.yaml) の「拡張子に合う Content-Type」を常駐アプリ側で保証する | `StaticFiles` の型の決め方に手を入れる |
| B | テストの期待値を `text/javascript` と `application/javascript` のどちらも許す | 実装を変えない | 端末によって返却する型が変わるまま残る |

推奨: A

`text/javascript` は RFC 9239 が JavaScript の型として定めた値で、端末の設定によって配信の結果が変わる状態を残さないため。
