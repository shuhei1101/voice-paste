## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定 | `recording` に録音中の画面の消灯の抑止のオン・オフ（真偽値）を追加する。キー名は設定の設計で決める | 既定値は要件の `未確定` |
| 抑止の開始と解除 | 録音の service が録音の開始で抑止し、確定・取り消し・失敗・打ち切りで録音を終えるときに解除する。音量の下げ・戻しと同じ箇所で呼び、解除は 1 回だけにする | 一時停止中も抑止を続ける |
| Windows の抑止 | `SetThreadExecutionState` の `ES_CONTINUOUS` と `ES_DISPLAY_REQUIRED` で抑止し、`ES_CONTINUOUS` だけで解除する | 状態はスレッドごとに持つため、抑止と解除を同じ長く続くスレッドで呼ぶ（PoC で確認する） |
| Linux の抑止 | Ubuntu 24.04 の Xorg と GNOME の Wayland で抑止できる方式を PoC で調べる | 抑止できなければ要件の `未確定` の B |
| アダプタの構成 | 音量のアダプタと同じく、OS ごとの実装と何もしない実装を `integrations/` の下に配置し、`main.py` の配線で選ぶ | 録音の service は関数型だけを受け取る |
| 失敗の扱い | 抑止・解除に失敗しても録音は止めず、警告のログを残す | - |
| 異常終了 | Windows はプロセスの終了で抑止が解除される。Linux は PoC で確認する | - |
| 設定画面 | 「録音」の区画に、録音中に画面を暗くしないかのチェックボックスを追加する。文言と位置はモックで決める | Linux で使用できないときは欄を出さない |
| 外の端末の画面 | 録音の開始で `navigator.wakeLock.request("screen")` を取得し、録音の停止・上限での自動送信・画面を離れるときに解放する。画面に戻ったとき録音中なら取得し直す | Wake Lock に対応しないブラウザでは抑止せず録音を続ける |
| 外の端末の画面のオン・オフ | 要件の `未確定` の推奨 A のとき、画面に端末ごとのオン・オフを配置し、端末に保存する | 文言と位置はモックで決める |
| 既存機能への影響 | 音量の下げ・戻しと録音の流れは変えない。API の要求・応答の構造は変えない | - |
| テスト | 単体: 録音の service の抑止と解除の呼び出し・設定のモデル・アダプタ（OS の API は差し替える）。結合: 設定画面の欄・外の端末の画面の Wake Lock の取得と解放 | - |
