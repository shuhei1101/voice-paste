# 設計書に ID を付け、モジュール構成の設計書を物理ファイルごとに分ける

## 概要

AI Monitor の develop の設計書のテンプレートを取り込み、全ての設計書に ID を付けて、モジュール構成の設計書を物理ファイルごとに分ける。

## 背景

[Issue #240](https://github.com/shuhei1101/voice-paste/issues/240) の要望。
AI Monitor の設計書の検証（[ai-monitor#3044](https://github.com/shuhei1101/ai-monitor/issues/3044)）で、モジュール構成の設計書は 1 ファイル = 物理ファイル 1 つになった。
今のモジュール構成の設計書は 1 ファイルに複数の物理ファイルを持つため `container` の検証で誤りが出て、書くツールがその設計書への書き込みを断る（[#238](https://github.com/shuhei1101/voice-paste/pull/238) は直接編集で進めた）。
[#235](https://github.com/shuhei1101/voice-paste/pull/235) の要件のスコープ外で「次の追従 Issue」とした分で、リリースを待たずに取り込むことはユーザーの回答で決めた（[回答](https://github.com/shuhei1101/voice-paste/issues/240#issuecomment-6547731182)）。
