用語集のプリセットの選択欄

外の端末の文字起こしの画面の音声送信の区画で、録音開始・ファイル送信の上に置く選択欄。項目は PC の設定の用語集のプリセットの並び。見本の設定で選んでいるプリセットは「会議」。

案 A（既定は「設定に従う（{名前}）」）

案 A: 通常（既定のまま）

案 A: 別のプリセットを選択

案 A: 無効（録音中）

録音中は変更不可

案 A: 送信中（変更可）

案 A: エラー（一覧の取得失敗）

プリセットの一覧を取得できませんでした。送信した音声は、PC の設定で選択中のプリセットで補正します。

案 A: エラー（一覧に無いプリセット・400）

選択したプリセットが見つかりません
