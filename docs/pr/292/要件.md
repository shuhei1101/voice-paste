# 要件

## 要望

- 常駐アプリで録音している間（録音を始めてから、確定・取り消し・失敗で録音を終えるまで。一時停止中と連続録音を含む）、PC の画面が自動で暗くならない（ディスプレイの消灯とアイドルによるスリープを抑止する）
- 録音を終えたら抑止を解除し、OS の画面の消灯の設定どおりの動きに戻る。常駐アプリが異常終了しても抑止が残らない
- ホットキー・トレイ・録音の画面・API のどの入口から始めた録音でも有効にする
- 設定画面で、録音中に画面を暗くしないかをオン・オフで選べる。設定は settings.yaml に保存する
- 外の端末の文字起こしの画面（`/web/`）で録音している間、端末の画面が自動で暗くならない。録音を止める・上限で自動送信する・画面を離れると解除する
- 抑止に失敗しても録音は続け、失敗をログに残す

`未確定`: 設定の既定値（決める段: 単一ユースケース設計）

| 案 | 内容 |
| --- | --- |
| A | オン |
| B | オフ（今の動きのまま） |

推奨: A

録音中は入力の操作が無く、オフのままでは話している間に画面が暗くなる事象がどの利用者にも起きるため。

`未確定`: Linux（Ubuntu 24.04 の Xorg と GNOME の Wayland）で抑止できるか（決める段: PoC 検証）

| 案 | 内容 |
| --- | --- |
| A | PoC で抑止を確認した方式で Linux にも対応する |
| B | Linux では使用できない機能として設定の欄を出さない（`recording.lower_volume` と同じ扱い） |

推奨: A

PoC で抑止できないと分かった場合だけ B にする。B は要件を縮めるため、ユーザーに確認する。

`未確定`: 外の端末の画面でのオン・オフの選び方（決める段: 単一ユースケース設計）

| 案 | 内容 |
| --- | --- |
| A | 外の端末の画面に端末ごとのオン・オフを配置し、端末に保存する（用語集のプリセットの選択と同じ） |
| B | PC の設定画面の設定に従う |
| C | オン・オフを配置せず、録音中は常に抑止する |

推奨: A

PC の画面と外の端末の画面は別の端末で、暗くしたくない端末が利用者ごとに違うため。
