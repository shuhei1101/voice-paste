# 要件

## 要望

スマホ・iPad・外の PC のブラウザから、録った音声か録ってある音声ファイルを常駐アプリへ送り、文字に起こした結果を受け取れるようにする。
外の端末からは、ゲートウェイ（shuhdev-gateway、Cloudflare Access）を通して今の API（`127.0.0.1:47823`）へ届く。

画面（`GET /web/`）では次のことができる。

| できること | 中身 |
| --- | --- |
| 画面で録る | MediaRecorder で録る。形式は `isTypeSupported` で webm/opus・mp4・ogg の順に選び、`audioBitsPerSecond` に 32kbps を指定する（実際のビットレートはブラウザが決め、Edge の AAC は約 100kbps になる）。録音時間の上限は 30 分で、録音中は残り時間を出す |
| ファイルを指定する | 録ってある音声ファイル（WAV・MP3 など）を選んで送る |
| 送る前に残す | 録音を止めた後の 1 本を IndexedDB に直近 1 件だけ残し、次を録ると置き換える。送信に失敗しても送り直せ、ダウンロードボタンで端末へ保存できる |
| 結果を待つ | 受け付けた `job_id` で結果を取りに行き、進み具合を出す |
| 結果を残す・コピーする | 結果を localStorage に直近 10 件残し、各件にコピーボタンと消すボタンを置く |
| 期限で消す | 音声と結果に保存日時を持たせ、ページを開いたときに期限を過ぎた件を消す |

エンドポイントは次の 2 本を追加する。

| エンドポイント | 中身 |
| --- | --- |
| `POST /web/transcriptions` | multipart の `audio` を受け、ジョブをキューに積んで `202 {"job_id"}` を返す |
| `GET /web/transcriptions/{job_id}` | `state`（`queued`・`running`・`done`・`failed`）・`progress`（`segment.end / duration`）・`text`・`error` を返す |

- 受け付けた音声はキューに積み、ワーカースレッドが 1 件ずつ今の文字起こしワーカーを呼ぶ。セッション（`/sessions`）とは別に扱い、ホットキーの録音中でも受け付ける
- 起こした文字は用語の補正（用語集・文頭・文末の文言の削除）を通し、PC の履歴にも残す
- 録れた形式（webm・ogg・mp4）のまま faster-whisper（PyAV）へ渡し、WAV へ変換しない
- エラーは今の API と同じ problem+json で返す（403 Origin が許可リストに無い・404 ジョブが無い・413 大きすぎる・415 読めない形式）

守りは次のとおりにする。

- `/web/` の下だけ、トークンの代わりに Origin の許可リスト（ゲートウェイの公開のサブドメイン）で通す。`/sessions` の守りは今のまま変えない
- 外からの認証は Cloudflare Access に任せる。ゲートウェイには `--rewrite-origin` を付けずに登録する
- 各要求は 83 秒（ゲートウェイの応答待ちの上限）以内に返し、本文は 100MB（Cloudflare 無料プランの上限）未満に収める

端末に残した音声と結果の保存期限は、どちらも保存日時から 7 日とする（送る前の音声は直近 1 件だけで量が増えず、外の端末で一時的に使う用途では送り直せる期間を長く取るほうが困らないため）。

画面とエンドポイントは常駐アプリの中に置き、画面の HTML・JS・CSS は常駐アプリが `/web/` の下で配信する（画面は常駐アプリの API を呼ぶだけの 1 枚で、独立してデプロイしないため）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 長い音声の分割送信・再開できるアップロード | 本文のとおり、長い音声は分割せず 1 本で送る | 予定なし |
| ブラウザの画面からの出力先（貼り付け・エンドポイントへ送る）の選択 | 要望は文字に起こして画面で受け取るまでで、PC 側の出力先は通さない | 予定なし |
| ゲートウェイの中継で Content-Length を外す不具合 | ゲートウェイ側の不具合で、shuhei1101/shuhdev-gateway#9 が扱う（closed） | shuhei1101/shuhdev-gateway#9 |
| `/sessions` の守り（Origin を断る・Host・トークン）の変更 | 本文のとおり今のまま変えない | 予定なし |
| tailscale serve を通した公開 | ゲートウェイだけで公開すると決まった（[確認ログ](./確認ログ.md)） | 予定なし |
