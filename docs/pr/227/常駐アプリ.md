## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能（結果のレスポンス） | `GET /web/transcriptions/{job_id}` のレスポンスで、設定のエンジンが進みを返すかを伝える。今の項目は変えない | `reports_progress: bool` を追加する |
| 進みを返すかの判定 | `main.py` の `_reports_progress`（`local_whisper` のときだけ True）を `WebApiDeps` にも渡し、デスクトップの文字起こし中の表示と同じ判定にする | `transcription.engine` は再起動で反映するため、起動時に決めた値で足りる |
| 状態表示 | 進みを返さないとき、running の件は「文字起こし中」とスピナーだけを出し、`.result__pct` と `result_progress` を隠す。進みを返すときは今のまま | queued・done・failed・結果消失の表示は変えない |
| アクセシビリティ | `result_progress` を隠すときは読み上げ名「文字起こしの進捗」も読まれないよう `hidden` にする | - |
| 既存機能への影響 | レスポンスへの項目の追加だけで、呼び出し元は同じリポジトリの `app.ts` だけ | 破壊的変更なし |
