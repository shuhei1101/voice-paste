## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 複合 UC シナリオ | 常駐アプリの起動から、ホットキーで録音し、起こした文字を届けるまでを単一 UC の連鎖で写す | 1 回だけ実行して終わる起動（`RESIDENT_MODE=false`）の分岐も写す |
| 単一 UC シナリオ | 要件.md の単一 UC ごとに、実装から読み取れた正常・異常の分岐を写す | 読み取れなかった箇所は承認確認の確認事項に載せる |
| 外部ライブラリ | `pyproject.toml` の依存と、依存に書かれずに直接 import しているものを、動作確認を未確認のまま起こす | - |
| 外部 API | OpenAI の文字起こしと、Hugging Face Hub のモデルの取得を起こす | - |
| 設定 | `config.py` が読む `.env` のキー・設定画面が書くキー・用語集 CSV を、今の既定値のまま起こす | 既定値は暫定値として写す |
| データ | 履歴（録音の WAV と起こした文字）・一時の音声・PID ファイル・ログの置き場所と保持を起こす | - |
| アーキテクチャ図 | サブシステム一覧を実装のプロセスの境界（常駐アプリと文字起こしワーカーの子プロセス）で区切って書き換える | - |
| リスクと技術的負債 | 読み取れた改善の余地を `dev/pr/10/リスクと技術的負債.md` へ 1 件 1 行で足す | 観点は要件.md の `## 要望` |
