## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 完了の知らせ | `copy_only` がクリップボードへ書けた後に、知らせの種類「コピーの完了」と起こした文字を `notify` で渡す。知らせる関数は `inject_copy_only` が `OutputDeps` から選んで部分適用する | 書けなかったときは今までどおり `DeliveryError` を伝え、完了の知らせは出さない |
| 完了の通知 | トレイが情報の通知（`MessageIcon.Information`）で出す。見出しと本文は画面設計で決める | 要件.md の `未確定` |
| 通知を押したときの出し分け | トレイは最後に出した通知の種類と、コピーの完了なら起こした文字を持つ。`messageClicked` で、コピーの完了なら起こした文字をクリップボードへ書き直し、失敗ならログフォルダを開く | 次の通知を出すと、種類を問わず持つものを置き換える |
| コピーし直す | トレイが Signal で起こした文字を伝え、`UiController` が `UiDeps` のコピーする関数で書く | ui は features・integrations を import しない |
| コピーし直せなかったとき | 失敗の通知（`delivery_failed`）で知らせる | - |
| 既存機能への影響 | 失敗の通知の文言・押したときにログフォルダを開く動きは変えない | - |
