トレイ

#37 のトレイのメニューの「録音を開始」の下に「録音の画面を表示」を追加したもの。非表示にした録音の画面を再表示するときだけ押せ、そのあいだはアイコンの左クリックも同じ操作になる。アイコンとほかの項目は #37 のまま。

録音中（録音の画面を非表示にしている）

  • 録音を開始（処理中） Ctrl+Alt+D
  • 録音の画面を表示
  • 設定…（処理中）
  • 設定フォルダを開く
  • ログフォルダを開く
  • 再起動
  • 終了

アイコンの左クリックが「録音の画面を表示」と同じになるため、この項目を既定の項目（太字）にする。録音の画面は非表示にする前の位置に、フォーカスを取らずに出る。

録音中（録音の画面が出ている）

  • 録音を開始（処理中） Ctrl+Alt+D
  • 録音の画面を表示（表示中）
  • 設定…（処理中）
  • 設定フォルダを開く
  • ログフォルダを開く
  • 再起動
  • 終了

録音の画面が出ているあいだは押せず、項目名に理由を出す。アイコンの左クリックは #37 と同じく何もしない。

画面を表示しない録音

  • 録音を開始（処理中） Ctrl+Alt+D
  • 録音の画面を表示（画面を表示しない録音）
  • 設定…（処理中）
  • 設定フォルダを開く
  • ログフォルダを開く
  • 再起動
  • 終了

録音の画面を表示しない設定の録音と、API から始めた録音。戻す画面が無いため押せず、アイコンの左クリックも何もしない。

待機中・文字起こし中

  • 録音を開始 Ctrl+Alt+D
  • 録音の画面を表示（録音していません）
  • 設定…
  • 設定フォルダを開く
  • ログフォルダを開く
  • 再起動
  • 終了

待機中のメニュー。文字起こし中は「録音を開始」と「設定…」が #37 のとおり（処理中）になり、「録音の画面を表示」は同じく（録音していません）で押せない。準備に失敗した起動も同じく押せない。
