# E2E だけが使っていた、合成したキーをホットキーとして受ける起動を消す

## 概要

常駐アプリから、環境変数 `VOICE_PASTE_ACCEPT_INJECTED_HOTKEYS` で合成したキー（SendInput）もホットキーとして受ける起動の切り替えを消す。

## 背景

[Issue #67](https://github.com/shuhei1101/voice-paste/issues/67) の要望。
[PR #66](https://github.com/shuhei1101/voice-paste/pull/66)（[Issue #65](https://github.com/shuhei1101/voice-paste/issues/65)）で実機のマイクで録音する E2E を消し、[PR #76](https://github.com/shuhei1101/voice-paste/pull/76) で画面・トレイの E2E が常駐アプリを pytest のプロセスの中で起動してホットキーの受付を差し替える形になった。
合成したキーを受ける起動を使う E2E は無くなり、テストのためだけの切り替えが `src/` に残っている。
