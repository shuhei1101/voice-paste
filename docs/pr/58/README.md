# 新しく作った venv でも画面・トレイの E2E がトレイの状態を読めるようにする

## 概要

テスト実行方法の前提どおり新しく作った venv で、画面・トレイ・ホットキーの E2E が流れるようにする。

## 背景

[Issue #54](https://github.com/shuhei1101/voice-paste/issues/54) の E2E の不備。
release PR [#52](https://github.com/shuhei1101/voice-paste/pull/52)（Sprint v0.3.0）の E2E を新しく作った venv で流すと、次の 2 つで画面・トレイ・ホットキーの E2E が流れなかった。

- `tests/support/desktop.py` が import する pywin32 が `pyproject.toml` のどこにも宣言されておらず、conftest を読み込めず全件が止まった
- pywin32 を手で入れても、複合ユースケース「声で入力した文字を貼り付ける」の 6 件が、録音を始める前に `トレイが 待機中 にならなかった（今は None）` で fail した。テストの常駐アプリを動かす `python.exe` のアイコンが隠れたアイコンの一覧に入っており、この環境の隠れたアイコンのボタンの名前はヒントを含まないため、`Uia.tray_tooltips` が状態を読めない
