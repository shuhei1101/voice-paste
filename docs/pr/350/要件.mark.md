# 要件

## 要望

- リポジトリの直下の `dev-docs.yaml` を `git mv` で `project-index.yaml` へ改名する。中身は変えない
- ファイル名を参照する `files.yml` の `path` と、レイアウト『voice-paste』（`docs/layout/LAY-1.yaml`）の `name` を `project-index.yaml` へ書き換える
- 端末の設定のうち、配信元 voice-input の設定ファイルとして `.claude/worktrees/develop/dev-docs.yaml` を指す行を、マージの後に `project-index.yaml` へ書き換える
  - project-index の `~/.config/project-index/settings.yaml` の `sources[].config`
  - dev-docs の `~/.config/dev-docs/settings.yaml` の `sources[].config`
  - alias-inject の `~/.config/alias-inject/settings.yaml` の `repositories[].config`
- 書き換えた後、`describe` の一覧に配信元 voice-input が警告なしで出て、`search_docs` で voice-input の文書を検索できる
