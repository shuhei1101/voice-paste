## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 経過の時間の数え方 | `RecordingWindow` のコンストラクタが時計 `clock`（秒を返す関数。既定は `time.monotonic`）をキーワードで受け、`QElapsedTimer` に替えて、録音を始めた・再開した時刻と一時停止までに貯めた経過からその時計で数える | `TranscribingIndicator` と同じ作り。`main.py` は既定のまま渡さない |
| 結合テストの時計 | `build_ui`・`make_ui` が進められる時計（`FakeClock`）を録音の画面へ渡し、`Ui` から引けるようにする。5 件は `QTest.qWait(1200)` に替えて時計を 1.2 秒進め、描き直しを待ってから比べる | 描き直しの待ちは `WAVE_INTERVAL_MS` を跨ぐ分だけにする |
| 単体テスト | 足さない | `RecordingWindow` の振る舞いは画面の結合テストで確かめる（モジュール構成の設計書の方針） |
| 結合テストのケース | 5 件の確かめる内容と期待する表示（「00:01」「00:02」）は変えない | - |
| 常駐アプリの振る舞い | 経過の表示の形・進み方・一時停止の扱いは変えない | - |
