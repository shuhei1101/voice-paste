# 設定画面の「変えた値を捨てる確認」の件数で、出力先のプリセットの数え方を表記のヒント・用語集に揃える

## 概要

ユーザーが設定画面を閉じるときの「変えた値を捨てる確認」で、出力先のプリセットの変更が表記のヒント・用語集と揃えた数え方の件数で出るようにし、結合テストで確かめる。

## 背景

[Issue #149](https://github.com/shuhei1101/voice-paste/issues/149) の要望。
[PR #147](https://github.com/shuhei1101/voice-paste/pull/147) の要件.md の `## スコープ外` の切り出しで、PR #147 で表記のヒントを「変えたプリセット 1 つを 1 件、残っているプリセットどうしの並べ替えを別に 1 件」、[PR #125](https://github.com/shuhei1101/voice-paste/pull/125) で用語集を「変えた用語集 1 つを 1 件」と数えるように決めた。
develop の [settings_window.py](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/ui/windows/settings_window.py) の `SettingsWindow._flat_values` は、出力先のプリセットを `presets.{種類}[{位置}].{項目名}` の項目ごとに 1 件と数え、位置で比べるため、途中のプリセットを消すと後ろのプリセットの項目も変わった扱いになる。
