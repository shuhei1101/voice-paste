# 要件

## 要望

- 貼り付けて送信・貼り付けのみ・コピーのみ・AI チャットへ送るの 4 つの出力先を、方針の記録（[構造の決定](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/4_%E6%A7%8B%E9%80%A0%E3%81%AE%E6%B1%BA%E5%AE%9A.md)・[リスクと移行計画](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/5_%E3%83%AA%E3%82%B9%E3%82%AF%E3%81%A8%E7%A7%BB%E8%A1%8C%E8%A8%88%E7%94%BB.md)）と [#26](https://github.com/shuhei1101/voice-paste/pull/26) で起こしたモジュール構成のとおりに `src/voice_paste/features/outputs/` の出力先ごとのサブフォルダに作り、`OUTPUTS` に登録する
  - 貼り付けて送信: クリップボードへ書き、設定の貼り付けのキーを送り、`outputs[].enter_delay_sec` の間を置いて Enter を送る
  - 貼り付けのみ: クリップボードへ書き、設定の貼り付けのキーを送る
  - コピーのみ: クリップボードへ書く
  - AI チャットへ送る: クリップボードへ書き、選んだ送り先（設定の `outputs[].targets[]` の 1 つ）の URL を Microsoft Edge の `--app` で開き（Edge が見つからなければ既定のブラウザで開く）、`outputs[].open_delay_sec` の間を置いて貼り付けのキーと Enter を送る
  - クリップボードへ書く・キーを送るは `integrations/keyboard` のアダプタ（pyperclip・pynput を包む）にまとめ、出力先は関数で受け取る。クリップボードに書けなければ `DeliveryError` にする
  - AI チャットの送り先は番号付きのキーでなく、設定の送り先の一覧で持つ
- 振る舞いは `voice_paste_legacy` の届け方と同じにする（キーを送る順と間・Edge の探し方）
- 完了の定義
  - 設定の `outputs[].enabled` が `false` の出力先へは届けず、`true` の出力先へは選んだときに届く
  - 出力先を 1 つ足すときに既存のモジュールで変えるのが `OUTPUTS` への 1 行の登録だけで済む（品質シナリオ 5）。各出力先は互いを import せず、`deliver` と `features/session` は出力先の ID 以外を知らない
  - import-linter の検査が通る
- 普段使い（`voice_paste_legacy` と、リポジトリの直下の `.env`・`history/`・`log/`）には触れない
