# 要件

## 要望

640px 以下の幅で、`dev/mock/refs/37/assets/style.css` を読む全てのモックの欄の行で、設定のキー（`transcription.local_whisper.no_speech_threshold` など区切りの無い長いキーを含む）を行の右端の内側に収める。
確かめる幅は 390px と 640px とし、キーが行の右端を越えず、ページに横スクロールが出ないことを基準にする（行の幅を超えるキーは行の中で折り返してよい）。
640px 以下の、欄の行を縦に積む見た目は変えない。
641px 以上の欄の行の規則（[PR #162](https://github.com/shuhei1101/voice-paste/pull/162) で直した置き方）は変えない。
[画面設計](https://github.com/shuhei1101/voice-paste/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E7%94%BB%E9%9D%A2%E8%A8%AD%E8%A8%88/%E5%B8%B8%E9%A7%90%E3%82%A2%E3%83%97%E3%83%AA/%E8%A8%AD%E5%AE%9A%E7%94%BB%E9%9D%A2.py.yaml)の `elements[設定の欄]` は変えない。
