# 要件

## 要望

文字起こしに渡す手がかりの語（間違えやすい語の正しい表記）を設定に新しく持たせ、プリセットとして複数保存し、有効・無効を切り替えて、設定画面から編集できるようにする。
Issue の「システムインストラクション」に当たる、指示に従わせる仕組みは Whisper に無いため、語の表記を寄せる手がかりとして作る（[確認ログ](./確認ログ.md)）。

- 完了の定義
  - 設定画面で、手がかりのプリセットを足す・名前を書き換える・消すことができ、プリセットの中の語を 1 つずつ足す・書き換える・消すことができる。保存すると再起動せずに次の録音の確定から効く
  - プリセットごとに有効・無効を切り替えられ、無効のプリセットの語は文字起こしに渡さない。全てのプリセットを無効にすると、手がかりを渡さない今の文字起こしのまま動く
  - ホットキー・トレイ・API のどこから始めた録音にも、同じ手がかりを渡す
  - 手がかりのプリセットを持たない今の `settings.toml` がそのまま読め、手がかりを渡さない今の文字起こしのまま動く

settings.toml にあって設定画面で変えられない項目を洗い出した結果、画面に足す項目は無い。
develop の設定の設計書で実装済みのキーは全て設定画面に欄がある。
欄が無いのは、読み込むときに新しいキーへ読み替える古い形のキー（`outputs[].open_delay_sec`・`outputs[].targets[]`・`glossary_path`）と、一覧の構造で表すキー（`outputs[].id`・`presets[].kind`）だけ。

手がかりは faster-whisper の `transcribe` の `hotwords` に渡す。
`hotwords` は録音の長さによらず 30 秒のウィンドウごとに同じ前の文脈の枠へ入るため、30 秒を超える録音の後ろの部分にも効く（faster-whisper v1.2.1 の `transcribe.py` L1542-1548）。

手がかりは語の一覧に限り、文は書けないようにする。
1 つの語は空にできず、読点（、）・句点（。）・改行を含められない。
文の形の手がかりでは話した句が消えたため（[文字起こしワーカー](./文字起こしワーカー.md) の PoC 結果）。

渡す手がかりは、有効なプリセットの語を一覧の順に読点（、）でつないだもの。

手がかりを渡すと、語の表記のほかに出力の書き方も変わる（句読点が付く・区間ごとの改行がまとまる・口癖が一部消える）。
一覧に入れた表記へ、ほかの語が引っ張られることもある（TypeScript がタイプスクリプトになる）。引っ張られた語は、その語も一覧に足して直す。
この 2 点は、設定画面の補助文と使い方のページで伝える。

つないだ手がかりの長さは UTF-8 のバイト数で数え、222 バイト以下に限る（日本語でおよそ 74 文字。読点も数える）。
保存の確かめで超えたら保存を止め、エラーを出す。

| 導出の元 | 値 |
| --- | --- |
| 外部の上限 | `hotwords` のトークンが 224 以上なら先頭の 223 トークンに切られる（`max_length // 2 - 1`、`max_length = 448`。L1546-1547） |
| 固定の消費分 | faster-whisper が頭に足す半角の空白の 1 バイト（L1545） |
| 数え方 | Whisper のトークナイザはバイト単位の BPE で、1 トークンは 1 バイト以上を表す。トークン数は UTF-8 のバイト数を超えないため、設定画面はトークナイザを持たずにバイト数で数えて上限を守れる |
| 安全率 | 置かない。バイト数はトークン数の上限そのもので、見積もりの誤差を持たない |
| 決定値 | 223 − 1 = 222 バイト |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 古い形のキー（`outputs[].open_delay_sec`・`outputs[].targets[]`・`glossary_path`）を設定画面に出す | 読み込むときに新しいキーへ読み替え、保存では書かない（`glossary_path` は保存で `glossaries` へ書き移す）。画面に出すと古い形を書き戻すことになる | 予定なし |
| トレイ・ホットキーからの手がかりのプリセットの切り替え | 要望は設定画面からの編集で、ほかの場所からの切り替えを求めていない | 予定なし |
| API の要求ごとに手がかりを渡す（録音を開始する要求の引数に足す） | 要望は設定で持つ手がかりで、API から始めた録音にも設定の手がかりを渡す | 予定なし |
| 文の形の手がかり（書き方の手本を文で渡す） | PoC で、文の形の手がかりでは話した句が消えた。確認で語の一覧に限ると決めた（[確認ログ](./確認ログ.md)） | 予定なし |
| 話し声でない音（息・キーボード・環境音）だけの録音で、手がかりが勝手に出ないかを確かめる | 履歴に該当する録音が無く、確認でそのまま進めると決めた。困ったときはプリセットを無効にして切れる | 予定なし |
