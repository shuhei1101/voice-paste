# 起動の失敗・API を使えない知らせの E2E を、知らせが出たことで確かめる

## 概要

単一ユースケース「常駐アプリを起動する」の E2E の 2 件が、シナリオが挙げる「トレイで知らされている」ことを確かめて pass するようにする。

## 背景

[Issue #69](https://github.com/shuhei1101/voice-paste/issues/69)（`E2E失敗`）の修正。
release PR [#52](https://github.com/shuhei1101/voice-paste/pull/52)（Sprint v0.3.0 の E2E、[#38](https://github.com/shuhei1101/voice-paste/issues/38)）で、`test_error_when_engine_unavailable`・`test_error_when_api_unavailable` が、通知センターに通知が残っているか（`_notification_in_center`）の確かめで fail した。

- 常駐アプリのログには、起動の失敗・API の待ち受けの失敗と、ユーザーへの知らせ（`api_unavailable`）が書かれている
- シナリオは「トレイで知らされている」を挙げ、通知センターに残ることは挙げていない
- 通知が画面に出ているか（トーストが表示されたか）と、通知センターに残らない理由は、まだ切り分けていない
