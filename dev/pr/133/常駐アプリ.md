## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 実機での確かめ | PoC 検証で、develop の常駐アプリを実機の画面に出して起動し、要件.md の 3 点を 3 つの切り替え先で確かめる。前面になったかは、届けた後にメモ帳へ貼られたかと、前面の窓がメモ帳のままかで見る | 外から読めない観点（日本語フォントでの見た目など）だけをユーザーへ回す |
| 前面になるとき | PoC を不成立とし、要件の見直し案を出す | - |
| ついて動かないとき | `HeadRow` の `startSystemMove` を、`mouseMoveEvent` で窓を `move()` する動かし方に替える | `HeadRow` を使う録音の画面も同じ動かし方になる |
| 名前と印が重なるとき | `SwitchButton` の名前と右上の丸い印が重ならない配置へ直す | - |
| 3 点とも期待どおりのとき | 画面設計・モジュール構成設計・単体テスト作成・実装・結合テスト作成の行を対象なしで閉じる | - |
