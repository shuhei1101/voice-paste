# 常駐アプリを起動する・録音する・起こした文字を届ける・録音を文字に起こす の E2E を、録音の入力を WAV に差し替えて置く

## 概要

単一ユースケース「常駐アプリを起動する」「録音する」「起こした文字を届ける」「録音を文字に起こす」で外したままの E2E を、実機のマイクを開かずに流せる形で置く。

## 背景

[Issue #122](https://github.com/shuhei1101/voice-paste/issues/122) の依頼。
作業 PR [#121](https://github.com/shuhei1101/voice-paste/pull/121)（[Issue #77](https://github.com/shuhei1101/voice-paste/issues/77)）の要件.md の `## スコープ外` から切り出した。

- 4 つのシナリオは録音を始めて実機のマイクを開くため、[#65](https://github.com/shuhei1101/voice-paste/issues/65)（[#66](https://github.com/shuhei1101/voice-paste/pull/66)）で E2E を外したままになっている（各シナリオの補足『E2E のテスト』）
- #121 で `tests/support/resident_app.py` の `run_resident_app` に `wav_input` が入り、録音の入力を WAV を流すものに、システム音量を呼ばれた値を控えるものに差し替えられる
