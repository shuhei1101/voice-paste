ホットキーを持つボタン

録音の画面の一時停止・再開・取り消し・固定の出力先・カスタムプリセットのボタン。名前と、同じ操作のホットキーを切らずに出す。案 A は名前の下に、案 B は名前の右に、どちらも枠で囲んだキーで出す。どちらもボタンの幅は中身から決める。

案 A: 通常

案 A: かざした

案 A: フォーカス

案 A: 主の操作

案 A: 取り消し

案 A: ホットキーが空

案 A: 長いホットキー

案 B: 通常

案 B: かざした

案 B: フォーカス

案 B: 主の操作

案 B: 取り消し

案 B: ホットキーが空

案 B: 長いホットキー
