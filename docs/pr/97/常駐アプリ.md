## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 用語集の行の編集 | 設定画面の「用語集」のまとまりで、選んだプリセットの行（誤変換・正しい表記・オン・オフ）を一覧で足す・書き換える・消す。保存で用語集のファイルへ書き戻す | 保存は設定画面の今の「保存」ボタンに揃える |
| 用語集のプリセット | プリセットを名前で足す・名前を変える・消す。補正に当てるプリセットを選ぶ | 当てるのは選んだ 1 つだけ、切り替えは設定画面だけ（[確認ログ](./確認ログ.md)） |
| プリセットの消し方・名前 | 補正に使っているプリセットは消せない（消す操作を無効にする）。名前は空にできず、ほかのプリセットと重ねられない | 画面設計の活性条件・入力チェックで書く |
| 行のオン・オフ | 行ごとにオン・オフを持ち、オフの行は補正で飛ばす。オン・オフの列が無い CSV の行はオンとして読む | 置き換えの順（行の順に前の結果へ当てる）は変えない |
| 用語集の持ち方 | 用語集ごとに CSV を 1 つ置き（列 `誤変換`・`正しい表記` に、オン・オフの列を足す）、`settings.toml` には用語集の名前と CSV の場所の一覧（`glossaries[].name`・`glossaries[].path`）と、補正に使う用語集（`active_glossary`）を持つ。設定画面で足した用語集の CSV は `settings.toml` と同じフォルダの `glossaries/` の下に作り、一覧から消しても CSV のファイルは消さない。設定と ER 図に書く | [確認ログ](./確認ログ.md) |
| 既存の設定との互換 | プリセットの項目を持たない `settings.toml` は、`glossary_path`（キーが無ければ `settings.toml` と同じフォルダの `yogo.csv`）を 1 つ目のプリセットとして読む | 既存の CSV と設定を書き換える反映作業は置かない |
| CSV の書き戻し | 保存で書き戻すのは、設定画面で行を変えた用語集と足した用語集の CSV だけにする。行を変えていない用語集の CSV には触れない | 手で書いた CSV の、片方が空の行やほかの列を落とさないため |
| 読めない用語集の CSV | 開けない・UTF-8 でない・見出しの列が無い・csv が解釈できない CSV は、設定画面では一覧に名前を出し、行の表の代わりに読めなかったことと理由を出す。その行は編集できず、保存でもその CSV に触れない。補正は、読めない用語集を空として扱い、補正せずに届ける（`[WARNING]` を出し、文字起こしは失敗にしない） | 設定画面が開けなくなることと、読めない CSV を空の用語集として上書きすることを避ける。csv が解釈できないときの理由の文言は「CSV の書式が正しくありません（{csv のエラー}）」（[確認ログ](./確認ログ.md)） |
| 既定に戻す | 用語集の一覧は設定ファイルと同じフォルダの `yogo.csv` の 1 件に戻る。用語集の CSV は消さず、書き換えない | - |
| 用語集の CSV のファイル名とパス | 足した用語集の CSV は `glossaries/glossary_{n}.csv`（n は 1 からの連番。フォルダに残っているファイルと、一覧にある場所の番号は使わない）に作る。`glossaries[].path` は、`settings.toml` のフォルダの下の場所を相対パス（区切りは `/`）、それ以外を絶対パスで書き、読むときは相対パスを `settings.toml` のフォルダから解決する。オン・オフは CSV の列 `使う`（`1` / `0`。列が無い・空はオン）に持つ | ER 図『常駐アプリのファイル』の用語集の CSV と、設定の `glossaries[].path` に書いた |
| 反映 | 保存すると再起動せずに次の録音の確定から効く | 今の用語集の `reload: immediate` と同じ |
| 呼び名 | 画面では「用語集」と呼ぶ（1 つの用語集 = 1 つのプリセット。「用語集を足す」「補正に使う」）。出力先のプリセット（`presets`）と別の項目で持つ | [確認ログ](./確認ログ.md) |
| 置き場所 | 設定画面の左のメニューの「文字起こし」の次に「用語集」のまとまりを足し、用語集の一覧と、選んだ用語集の行の表を置く。「文字起こし」からは用語集の CSV の欄を外す | [確認ログ](./確認ログ.md)。採用したモックは `dev/mock/pages/settings/97/a-glossary-group/` |
| 1 つ目の用語集の名前 | 今の CSV を読んだ 1 つ目の用語集の名前は、CSV のファイル名（拡張子を除く。既定は `yogo`）にする | [確認ログ](./確認ログ.md) |
| 空の行 | 誤変換か正しい表記の片方だけが空の行は、保存の時点で欄の下とエラーの一覧に出して止める。両方が空の行は保存で捨てる | [確認ログ](./確認ログ.md)。画面設計の入力チェックで書く。補正が片方が空の行を飛ばす動きは変えない |
| ログ | 補正の `[INFO]` に、読んだプリセットの名前と、オンの行数を出す | - |
