## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 録音の破棄 | 録音中の表示に破棄のボタンを配置する。押したら MediaRecorder を止め、録ったデータを捨てて、端末内の音声（IndexedDB）の保存も送信もしない。マイクのトラックと画面を暗くしない抑止を解放し、録音していない状態の表示に戻す | 確認を出すかは `未確定`（[要件](./要件.mark.md)） |
| 録音の一時停止・再開 | 録音中の表示に一時停止のボタンを配置し、MediaRecorder の `pause`・`resume` を呼ぶ。一時停止中はボタンを「再開」に替える | - |
| 経過時間と上限 | 経過時間・残り時間・上限までの進捗は録った時間だけで数え、一時停止中は止める。上限の自動の停止・送信も録った時間で判定する | 一時停止のまま上限に達することは無い |
| 一時停止中の表示 | 録音中の状態を「一時停止中」の文言とマーカーに替える。一時停止中も「録音停止・送信」と破棄を押せる | 色だけに頼らない |
| 画面を暗くしない抑止 | 一時停止中も録音中と同じく抑止を続け、破棄・停止で解く | 既存の録音中の扱いに合わせる |
| 結果の折りたたみ | 起こした文字が折りたたむ長さを超える件は、先頭だけを出して「続きを読む」のボタンを配置する。押したら全文を出し、ボタンを「折りたたむ」に替える。ボタンは `aria-expanded` で開閉を伝える | 長さは `未確定`（[要件](./要件.mark.md)） |
| コピーボタンの位置 | 結果の 1 件の操作（コピー・削除）を起こした文字の上へ移す。コピーは折りたたみの状態によらず全文を入れる | - |
| 既存機能への影響 | サーバーの API（音声を受け付ける・結果を返却する）と端末に残すデータの構造は変えない | - |
| レスポンシブ対応 | 録音中の操作が増えても、スマホの幅（390px）で横スクロールせずに並ぶようにする | - |
