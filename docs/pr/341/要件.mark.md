# 要件

## 要望

テストの workflow（`.github/workflows/test.yml`）の `workflow_dispatch.inputs` に、実行するテストのパスを受ける任意の入力を追加する。

- 入力を指定したときは、層のフォルダの代わりに、指定したパス（空白区切りで複数）だけを pytest で回す
- 入力を省いたときは、今と同じく層の全件を回す
- テスト 1 件の上限の時間・ジョブのタイムアウト・成果物 `test-log` は、入力の有無によらず層の値のまま変えない
- テスト実行方法（TP-1）の結合テスト（TL-2）の `run_runner` は、`{結合テストのパス}` をこの入力に指定して起動する
