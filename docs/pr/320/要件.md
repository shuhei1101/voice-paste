# 要件

## 要望

develop の workflow `.github/workflows/test.yml` を初めて起動し、次を行う。

| 項目 | 終わりの条件 |
| --- | --- |
| E2E テスト | テスト実行方法の E2E テストの層（`TL-6`）の全件実行（`--run-e2e`）で `tests/e2e/workflow/test_test_yml.py`（IF-15 の 5 つのフロー）を回し、結果のログを配置する |
| ランナーでの全件実行 | 単体テスト（バック）・結合テスト（バック）の層を `run_runner` で回し、passed・skipped の件数を手元の実測（単体 937 passed・57 skipped、結合 807 passed・1 skipped）と比べた表を計画書に記載する |
| 外部ライブラリの確認状態 | LIB-34〜36 の `verification` を、回した結果で `済` にする |
| `astral-sh/setup-uv` のタグ | workflow の `astral-sh/setup-uv` を、公開されている完全なバージョンのタグ（`v10.3.3`）で指定し、LIB-35 の `version.pinning` を同じ指定の仕方にする（確認ログの決着） |

`astral-sh/setup-uv` のタグ以外で fail した場合と、skip の件数が手元と違う場合は、原因を調べて計画書に記載し、修正する作業を別の Issue にする（この作業 PR では修正しない）。
