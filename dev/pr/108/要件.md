# 要件

## 要望

ホットキー・トレイから始めた録音を固定の出力先で確定した後、文字起こし中の表示が出ている間に、届ける出力先を固定の出力先「貼り付けて送信」「貼り付けのみ」「コピーのみ」のうち設定でオンにしたものへ切り替えられるようにする。
切り替えた後は、切り替えた先の出力先で届ける。
切り替えは届け始めるまで受け、届け始めた後の切り替えは受けない。
切り替えても、貼り付け先のアプリの入力欄からフォーカスを奪わない（「貼り付けて送信」「貼り付けのみ」は、切り替えた後も届けるときのアクティブなウィンドウへ貼る）。
文字起こし中の表示に、今の出力先を出す。

切り替えは、各出力先の確定のホットキーと、文字起こし中の表示の出力先ごとのボタンの両方で受ける。
ボタンを押した後は前面を貼り付け先へ戻す。
文字起こし中の表示は、設定でオンの固定の出力先を並べ、今の出力先に印を付けて示す。
文字起こし中の表示の案内の文は、「コピーのみ」のときは「起こした文字をクリップボードにコピーします」にし、カスタムプリセットで確定した録音では出さない。
文字起こし中の表示を、録音の画面と同じく見出しの行をつかんでドラッグで動かせるようにする。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| カスタムプリセット（ブラウザ添付・エンドポイントへ送る）への切り替え | 要望の切り替え先は固定の出力先だけ | 予定なし |
| カスタムプリセットで確定した録音を、固定の出力先へ切り替える | 要望は固定の出力先の間の切り替え。ブラウザ添付のプリセットで確定した録音は貼り付け先へフォーカスを置いていないことがあり、貼り付けへ切り替えると前面の無関係の窓へ貼る | 予定なし |
| 録音の画面を出さない設定（`recording.hide_window`）での切り替え | 文字起こし中の表示を出さない設定で、要望は表示が出ている間の切り替え | 予定なし |
| API から始めた録音の出力先の切り替え | API の録音は呼び出し元へ返す出力先だけを使い、文字起こし中の表示を出さない | 予定なし |
