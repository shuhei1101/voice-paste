トレイの通知

トレイから指定した音声ファイルで起きた失敗の通知。指定したファイルは履歴に残さないため、録音の失敗の「録音は履歴に残っています。」に代えて、ファイルが元の場所に残っていることを添える。押すとログフォルダを開く。

読めない形式のファイルを選んだ

voice-paste

音声ファイルを開けませんでした

「議事録.txt」は音声として読めない形式です。WAV・MP3・M4A などの音声ファイルを選んでください。

録音セッションは作らず、トレイは待機中のまま。

音声ファイルの文字起こしに失敗

voice-paste

文字起こしできませんでした

音声ファイルを読み込めませんでした。指定したファイルは元の場所に残っています。

ヘッダーは読めるが音声のデータが壊れたファイルなど、文字起こしの途中で失敗したとき。

OpenAI API へ送信できない音声ファイル

voice-paste

文字起こしできませんでした

OpenAI API へ送信できる大きさ（25 MB）か形式を外れています。指定したファイルは元の場所に残っています。

設定のエンジンが OpenAI API のときだけ。選ぶ時点では断らず、文字起こしの失敗として知らせる。
