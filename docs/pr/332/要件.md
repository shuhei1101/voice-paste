# 要件

## 要望

テスト実行方法の `run_runner` で、`run_id` を取った後に run を API で参照できるまで待ってから `gh run watch` を呼ぶ。

- `runner` の層（単体テスト（バック）・結合テスト（バック））の `run_runner` の全てに入れる
- `gh api "repos/{owner}/{repo}/actions/runs/$run_id?exclude_pull_requests=true"` を 1 秒おきに最大 10 回試す
- 10 回で参照できなければ `実行 {run_id} を 10 秒参照できません` を標準エラーに出して終了コード 1 で終える
- 待ち方と文言は [project-index#139](https://github.com/shuhei1101/project-index/pull/139) と claude-balancer の TP-275-1 にそろえる
