## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 作成機能 | 開始で連続録音を指定すると、完了が来るまで録音を止めないセッションを始める。指定しなければ今の 1 回の録音 | 指定の形は `要件.md` の `未確定`（連続録音の始め方） |
| 区切り | 話し声の後で無音が設定の長さ以上続いたところで区間を切り出し、録音は止めない。無音だけの間は区間にしない | 見つけ方は `要件.md` の `未確定`（無音の区切りの見つけ方）。区間の最大の長さも同じく `未確定` |
| 文字起こし | 区間を区切った順に 1 つずつ今の文字起こしのワーカーで起こし、用語集で補正する。前の区間を起こしている間に区切った区間は順に待たせる | 録音に遅れず追いつくかを PoC で測る |
| 履歴・監査 | 区間ごとに録音と起こした文字を履歴に残す（履歴を残す設定のとき） | - |
| 通知 | 区間ごとに返送先へ送り、各返送に区間の通し番号を付ける。完了で最後の区間を送った後、終わりと区間の数を 1 回送る | 返送の中身のフィールドはインターフェース定義設計で決める |
| エラー返却 | 区間の文字起こしの失敗はその区間の `failed` として返送し、セッションは続ける。返送先に届かない区間は今の再送の後にログへ書き、次の区間へ進む | - |
| 停止・完了 | 完了で録音を止め、残りの話し声を最後の区間として起こしてから終わりを返送する | 停止（`/stop`）の連続録音での意味はインターフェース定義設計で決める |
| 上限 | 連続録音のセッションの長さに上限を持ち、達したら完了と同じく残りを起こして終わりを返送する | 上限の決め方は `要件.md` の `未確定`（連続録音のセッションの長さの上限） |
| 既存機能への影響 | 連続録音を指定しない開始・ホットキーの録音は今のまま。連続録音の間も入口をまたいだ排他を保つ | - |
| 性能 | 区切ってから返送が届くまでの時間を非機能要件に決める | 値は PoC で測ってから決める |
