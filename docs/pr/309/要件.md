# 要件

## 要望

| Issue | 終わりの条件 |
| --- | --- |
| [#301](https://github.com/shuhei1101/voice-paste/issues/301) | 設定の見本（`settings.sample.yaml`・`resources/yogo.csv`）と既定値（`config/defaults.yaml`）の置き場所を決めてまとめ、移したファイルを指す設定の設計書（`docs/config/CFG-1.yaml`）・公開ドキュメント・フォルダ構成の設計書を修正した |
| [#302](https://github.com/shuhei1101/voice-paste/issues/302) | `ui/` を規約の構成のどこに置くか（規約に `ui/` を加えるかを含む）と、`tokens.toml` の置き場所を決めて直し、モジュール構成の設計書とフォルダ構成の設計書を修正した |

動きは変えない。
利用者の設定ファイル `settings.yaml`・`settings.local.yaml` の場所は変えない。
移したファイルを指すコード・テスト・`pyproject.toml`・`src/files.yml`・`tests/files.yml`・設計書・公開ドキュメントを、移した後のパスに揃える。

| 対象 | 配置先 | 根拠 |
| --- | --- | --- |
| 設定の既定値 | `config/defaults.yaml`（移さない） | knowledge の規約『コンテンツの置き場所』が既定値の配置先を `config/defaults.yaml` と定める |
| 設定の見本 | `settings.sample.yaml` を `config/settings.sample.yaml`、`resources/yogo.csv` を `config/yogo.sample.csv` へ移す | 既定値と見本を `config/` の 1 か所にまとめる。`resources/` はトレイのアイコンだけになる |
| トレイのアイコン | `resources/tray/{state}.png` を `resources/tray_{state}.png` へ移し、`tray/` を削除する | 見本を移すと `resources/` の中身が `tray/` だけになり、knowledge の規約『フォルダ構成の切り方とレビュー』の「中身が 1 つだけのフォルダは作らない」に当たる |
| `src/voice_paste/ui/` | 今の場所に残し、knowledge の規約『トップレベルレイアウト + feature 内構造』のトップレベルへ、デスクトップの画面の入口 `ui/` を `server/` と並べて加える修正を knowledge へ起票する | import-linter の契約で `server` と `ui` は同じ層の入口で、規約の既存のフォルダに当てはまる場所が無い |
| `tokens.toml` | `content/tokens.toml` へ移す | 設定の 3 レイヤーで上書きしない、アプリが参照する定義で、knowledge の規約『コンテンツの置き場所』の `content/` に当たる。`content/` の下に 1 ファイルだけのフォルダは切らない |
