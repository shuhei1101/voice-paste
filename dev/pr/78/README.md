# API で連続して録音し、無音で区切った単位ごとに順に文字に起こして返送先へ渡す

## 概要

同じ端末のほかのプロセスが、API で録音を止めずに続けさせ、無音で区切った単位ごとに起こした文字を、区切りの順に返送先で受け取れるようになる。

## 背景

[Issue #43](https://github.com/shuhei1101/voice-paste/issues/43) の要望。
作り直しの方針（[#13](https://github.com/shuhei1101/voice-paste/issues/13)、記録は [移行計画](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/5_%E3%83%AA%E3%82%B9%E3%82%AF%E3%81%A8%E7%A7%BB%E8%A1%8C%E8%A8%88%E7%94%BB.md) の順 10 の補足）で、連続録音は API ができた後に API の上へ足すと決めている。
[#1](https://github.com/shuhei1101/voice-paste/issues/1) の草案の「連続して録音し、無音などで区切って文字起こしを順に渡す使い方」（AITuber のゲーム実況で配信者の声を常時録音して渡す）にあたる。
今の API（`POST /sessions`・`/stop`・`/complete`）は、1 回の録音を確定してから 1 回だけ文字に起こして返送先へ返す。
