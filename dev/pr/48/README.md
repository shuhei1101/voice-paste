# 録音の画面をドラッグで動かし、録音中に隠して戻し、× で取り消せるようにする

## 概要

ホットキー・トレイから録音しているユーザーが、録音の画面をドラッグで動かし、録音を続けたままその回だけ画面を隠してトレイかホットキーで戻し、× で録音を取り消せるようになる。

## 背景

[Issue #46](https://github.com/shuhei1101/voice-paste/issues/46) の不具合。
作り直した録音の画面（[#21](https://github.com/shuhei1101/voice-paste/issues/21)、[#37](https://github.com/shuhei1101/voice-paste/pull/37)）は枠なしの窓でタイトルバーが無く、動かす・その回だけ隠す・× で閉じるができない。
作り直す前の版（`voice_paste_legacy/gui.py`、[#42](https://github.com/shuhei1101/voice-paste/pull/42) で削除）は普通の窓で、どれもできていた。
v0.3.0 は普段使いの起動先を新しい構成へ切り替えるリリース（[#22](https://github.com/shuhei1101/voice-paste/issues/22)）で、この後退を残すと master を普段使いしているユーザーの録音の画面が動かせず・閉じられなくなる。
