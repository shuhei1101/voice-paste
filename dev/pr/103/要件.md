# 要件

## 要望

録音の画面・確定のホットキーで「コピーのみ」（出力先 `copy_only`）を選んで確定し、クリップボードへ書けたとき、トレイの Windows の通知でコピーの完了を知らせる。
通知を押すと、その通知のときに起こした文字をクリップボードへもう一度書く（コピーした後に別の内容で上書きしたときに戻すため）。
通知を押してコピーし直す動きを既定とし、実現できないと分かったときだけ通知だけにする。
失敗の通知を押したときは、今までどおりログフォルダを開く。
「コピーのみ」以外の出力先・カスタムプリセットで届けたときは、完了の通知を出さない。

コピーの完了の通知は、見出しを「コピーしました」、本文を「任意の場所に貼り付けてください。この通知を押すと、もう一度コピーします。」にする。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 「貼り付けて送信」「貼り付けのみ」・カスタムプリセットの完了の通知 | 要望に含まれない。貼り付け先に文字が入ることで届いたと分かる | 予定なし |
| 完了の通知を出すかを設定で切り替える | 要望に含まれない | 予定なし |
| 通知センターに残る通知（畳まれた後に押してコピーし直す） | `QSystemTrayIcon.showMessage` の通知は通知センターに残らない。畳まれた後は Win+V のクリップボードの履歴で代えられる（Issue 本文） | 予定なし |
