## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 一覧の置き場所 | settings.toml に、文言の行の並びを持つキーを 1 つ足す | 並びが当てる順。キー名と行の項目はモジュール構成設計で決める |
| 既定の一覧 | キーが無いときは既定の一覧を使う。既定は「ご視聴ありがとうございました」「ありがとうございました」と、調べたモデルで出やすい文言 | 調べた文言と出所は外部ライブラリ『faster-whisper』に書く |
| 消す段 | 用語集の置き換えの前に、一覧の行を上から順に当てて文頭・文末に一致した文言を消す | 用語集の置き換えで文言の形が変わる前に当てるため |
| 一致 | 完全な一致と `*`（端の `*` は行の端まで）。行ごとに文頭・文末・両方を選ぶ（既定は文末） | `要件.md` の `## 要望` |
| 消した後に空になった文字 | 起こした文字が空のときと同じに扱う | 既存の空の結果の扱いを変えない |
| ログ | 消した文言を「{文頭 / 文末}: {消した文字}」で 1 行に出す | 用語集の置き換えのログに揃える |
| 設定画面 | まとまりのメニューに一覧のまとまりを足し、行を足す・書き換える・消す・上下へ動かす | まとまりの名前は「ハルシネーション」。並べ替えの操作はモック作成で決める |
| 入力チェック | 文言が空の行は保存で捨てる | 一致の書き方が `*` を使うときの書き誤りの扱いは単一ユースケース設計で決める |
| 既存機能への影響 | API から始めた録音・連続録音の区間も同じ補正を通るため、同じく消える | インターフェース定義の入出力は変えない |
