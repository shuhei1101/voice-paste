# 設定画面で値を変えたまま終了しても、破棄の確認で止まらず終了コード 0 で終わるようにする

## 概要

設定画面で値を変えたまま開いている間に常駐アプリを終了しても、変えた値を捨てる確認で止まらず、片付けて終了コード 0 で終わるようにする。

## 背景

[Issue #68](https://github.com/shuhei1101/voice-paste/issues/68)（`E2E失敗`）の修正。
release PR [#52](https://github.com/shuhei1101/voice-paste/pull/52)（Sprint v0.3.0 の E2E、[#38](https://github.com/shuhei1101/voice-paste/issues/38)）で、単一ユースケース「トレイから操作する」の `test_normal_when_quit_with_unsaved_settings` が 2 通りの終え方とも fail した。

- トレイの「終了」: 変えた値を捨てる確認のダイアログが出て、常駐アプリが終わらない
- Ctrl+Break: 常駐アプリが終わらず、テストの側が待ちきれずにプロセスを止めて終了コードが 1 になる（`常駐サービスを終えた` のログが出ず、片付けていない）
- 終了はどちらも `QApplication.quit` を呼ぶだけで、設定画面の `closeEvent` は強制で閉じる印が無ければ変えた値を捨てる確認を出す。終了のときに設定画面を確認なしで閉じる処理が無い
