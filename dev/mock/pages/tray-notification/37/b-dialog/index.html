ダイアログで知らせる（案 B）

文字起こしに失敗・届けられないの 2 つだけをダイアログで知らせる。マイク・API・エンジンの準備の失敗は案 A と同じ通知で知らせる。

文字起こしに失敗

voice-paste

文字起こしに失敗しました

録音を読めませんでした。録音は履歴に残っています。

TranscriptionError: invalid WAV header

ログフォルダを開く 閉じる

「常に手前に表示」で出し、閉じるまで残る。ダイアログが出ていても、次の録音は始められる。

届けられない

voice-paste

届けられませんでした

クリップボードに書けませんでした（ほかのアプリが使っています）。起こした文字は履歴に残っています。

pyperclip.PyperclipWindowsException: Error calling OpenClipboard

ログフォルダを開く 閉じる

「常に手前に表示」で出し、閉じるまで残る。ダイアログが出ていても、次の録音は始められる。

ほかの知らせ

マイクを開けない・API の待ち受けに失敗・文字起こしのエンジンを準備できないは、案 A と同じトレイの通知で知らせる。
