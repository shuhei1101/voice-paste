# 要件

## 要望

複合ユースケースの E2E を、#78 で変わった返送の中身と `save_recording` の引数に追従させ、release/v0.4.0 で fail している次の 3 件を pass させる。

- `tests/e2e/複合ユースケース/test_transcribe_from_other_system.py::test_normal_when_transcription_empty`
- `tests/e2e/複合ユースケース/test_transcribe_from_other_system.py::test_error_when_transcription_failed`
- `tests/e2e/複合ユースケース/test_paste_voice_text.py::test_error_when_transcription_failed`

直す範囲は次の 2 つ。

- `test_normal_when_transcription_empty` の返送の中身の期待に、`segment_number`・`segment_count` を `None` で含める（インターフェース定義『呼び出し元へ返す』と `docs/リファレンス/API.md` の「`continuous` を指定しない開始では常に `null`」のとおり）
- `tests/support/inprocess.py` の `break_saved_recordings` が差し替える関数を、`save_recording` の 3 つ目の位置引数 `segment_number` を受けて本物へ渡す形にする（`SessionManager` は `save_recording(session.id, recording, None)` と 3 つの位置引数で呼ぶ）

常駐アプリ（`src/`）と設計書は変えない。
各ケースが確かめている期待値（返送の中身・通知・履歴・次の録音を始められること）は保つ。
