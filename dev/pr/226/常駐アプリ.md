## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| バリデーション | 保存を止める確かめは今の設定のモデルのまま使い、設定画面に二重に実装しない | - |
| エラー表示 | Origin の形式の失敗を `to_field_message` で `input_checks` の文言に変え、その欄の下とエラーの一覧に出す | 文言は [確認ログ](./確認ログ.md) |
| 失敗の見分け方 | `ApiSettings._origins_must_be_origin_form` が `PydanticCustomError`（type は新しい定数 `WEB_ORIGIN_FORM_ERROR_TYPE`、ctx の `invalid` に違う行）で断り、`to_field_message` がこの type で文言を選ぶ | - |
| 既存機能への影響 | settings.toml の読み込み時に断る挙動は変えない | ログの文は先頭の `Value error, ` だけが無くなる |
