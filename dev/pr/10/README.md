# 既存コードから現状の設計書を起こす

## 概要

既存の voice-paste のコードから今の振る舞いを写したシナリオと現状の棚卸し（外部 API・外部ライブラリ・設定・データ・部品の一覧）を起こし、見つけた改善点をリスクと技術的負債の一覧に溜める。

## 背景

[Issue #3](https://github.com/shuhei1101/voice-paste/issues/3) の要望。
このリポジトリには設計書が無く、[#8](https://github.com/shuhei1101/voice-paste/pull/8) で入れた土台（開発ドキュメントの骨格・アーキテクチャ図・非機能要件）の次の工程にあたる。
RE の後は [#1](https://github.com/shuhei1101/voice-paste/issues/1) でベストプラクティスに沿って作り直す前提で、画面の見た目・メニュー項目も作り直しで整理する。
ユーザーは master のコードをビルドせずに普段使いしており、起動は `voice-paste.bat` のショートカットで行っている。
