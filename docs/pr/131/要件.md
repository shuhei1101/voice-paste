# 要件

## 要望

ボタンの名前の下にホットキーを出すかを、録音の画面（一時停止・再開・取り消し・出力先の確定・カスタムプリセットのボタン）と文字起こし中の表示（出力先の切り替えのボタン）で別々に、設定画面「画面」のまとまりで選べるようにする。

- 完了の定義
  - 「画面」のまとまりに、録音の画面の欄と文字起こし中の表示の欄の 2 つのチェックボックスがあり、片方だけをオフにできる
  - 片方をオフにして保存すると、再起動せずに次に出すその画面から、全てのボタンが名前だけを出す。もう片方の画面のボタンは今どおりホットキーを出す
  - オフにした画面でも、ホットキーでの操作（一時停止・取り消し・確定・出力先の切り替え）は今どおり効く
  - 今の `settings.toml` がそのまま読め、更新した直後の 2 つの画面の出し方が今の `ui.show_hotkeys` の値のとおりになる

- 設定のキー
  - 録音の画面は `ui.show_hotkeys`、文字起こし中の表示は `ui.transcribing_show_hotkeys`
  - `ui.transcribing_show_hotkeys` が無い `settings.toml` は `ui.show_hotkeys` の値で読む
- 設定画面の欄の名前
  - 「録音の画面のボタンにホットキーを出すか」「文字起こし中の表示のボタンにホットキーを出すか」

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 設定画面のホットキーの欄・トレイのメニューのホットキーの表示 | 要望は録音の画面と文字起こし中の表示のボタンの表示 | 予定なし |
| 録音の画面の「隠す」「×」をかざしたときの説明に添えるホットキー | #96 と同じく、ボタンに常に出る表示ではないため、出さない設定の対象にしない | 予定なし |
| [docs/使い方/録音して貼り付ける.md](https://github.com/shuhei1101/voice-paste/blob/develop/docs/%E4%BD%BF%E3%81%84%E6%96%B9/%E9%8C%B2%E9%9F%B3%E3%81%97%E3%81%A6%E8%B2%BC%E3%82%8A%E4%BB%98%E3%81%91%E3%82%8B.md) の「ホットキーを出さないようにもできる」の行 | 起動と設定の「ボタンのホットキーの表示」の節への参照で、節の名前を変えなければ直す所が無い | 予定なし |
