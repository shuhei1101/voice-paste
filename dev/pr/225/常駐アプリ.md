## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既定のモデル | `OpenAISettings.model` の既定を `gpt-transcribe` にする | [確認ログ](./確認ログ.md) |
| 手がかりと言語の渡し方 | 設定のモデルの名前から渡し方を選ぶ。`gpt-transcribe` は手がかりの語を `keywords[]`、言語を `languages[]` に載せ、`prompt` を送信しない。それ以外のモデルは今のまま `prompt`・`language` に載せる | モデルと渡し方の対応の持ち方はモジュール構成設計で決める |
| 手がかりの上限 | 今の手がかりの上限（`HINT_MAX_BYTES` = 222 バイト）を変えない。`keywords[]` の語の数・長さの上限は OpenAI が公開していない | `<`・`>` を含む語は `keywords[]` に入れない |
| 送信する音声の上限 | 語ごとのパートの分だけ要求の本文の固定の消費分が増えるため、`OPENAI_MAX_AUDIO_BYTES` を 26,209,484 から 26,204,569 にする | 非機能要件『OpenAIへ送信する音声の上限』 |
| 既存の settings.toml | 書かれた `gpt-4o-mini-transcribe` は書き換えずにそのまま使う | [確認ログ](./確認ログ.md) |
| 料金 | 既定のモデルの単価を外部 API・非機能要件・アーキテクチャ図の設計書に載せる | - |
| 疎通 | 外部疎通テストを決めたモデルで 1 回流し、結果を外部 API の設計書の動作確認に記録する | 従量課金。見積もりは規約『開発時の従量課金APIの実行』に沿う |
