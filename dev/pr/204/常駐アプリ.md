## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エンジンの設定 | `transcription.engine` に `openai` を追加し、OpenAI だけが使う値（モデル・言語・ベース URL）を `transcription.openai` のグループに置く。既定の `engine` は `local_whisper` のまま | 既定のモデルは `gpt-4o-mini-transcribe`（[確認ログ](./確認ログ.md)） |
| API キー | 環境変数 `OPENAI_API_KEY`、無ければ `settings.toml` と同じフォルダの `secrets/openai_api_key` から読む。`openai` を選んだときだけ起動時に読む | 判定フローチャート『設定値の置き場所』の「ホーム配下の秘匿ファイル」 |
| OpenAI のエンジン | OpenAI の文字起こしの API に録音の WAV と手がかり（`prompt`）を送信し、起こした文字を区間の並び（`list[str]`）で返す `EngineFn` を `integrations/openai/` に置く。HTTP は採用済みの httpx で送信する | 失敗（認証・レートリミット・タイムアウト・通信）は `EngineError` にし、既存の異常系に入れる |
| エンジンの選び分け | `build_handlers` が設定のエンジンを見て、`local_whisper` なら今の `WhisperWorkerClient` を起動し、`openai` なら OpenAI のエンジンを作る（文字起こしワーカーは起動しない） | `local_whisper` の配線は変えない |
| 起動時の確かめ | `openai` のとき、API キーを読めなければ起動の失敗にする。`local_whisper` のとき、faster-whisper を見つけられなければ、extra を入れて環境を作り直すよう示して起動の失敗にする | 既存の `StartupError` の経路 |
| 依存の分離 | `faster-whisper`・`nvidia-cublas-cu12`・`nvidia-cudnn-cu12` を `[project.optional-dependencies]` の `local-whisper` へ移す。`av` は外の端末の音声の読み取りでも使うため無条件の依存に残す | `uv.lock` を更新する |
| VAD のモデル | 連続録音の Silero VAD のモデルを、faster-whisper のパッケージに頼らず開く | `silero_vad_v6.onnx` を `src/voice_paste/integrations/vad/assets/` に同梱する |
| 起動のバッチファイル | `voice-paste.bat` の `uv sync --frozen` に `local-whisper` の extra を含める | 常に含める |
| 設定画面 | エンジンの選択肢に `openai` を追加し、`transcription.openai.*` の欄を既存の欄と同じ種類で追加する | API キーは欄に出さない |
| 文字起こし中の表示 | OpenAI API は区間ごとの進みを返さないため、`openai` のときは進みのバーを出さず、残りを見積もらずに経過だけを出す | 画面設計『文字起こし中の表示』 |
| テスト | 単体は OpenAI のアダプタを httpx の Mock で確かめる。OpenAI API へ実際に送信する外部疎通テストを `tests/external/` に置く | 外部疎通テストは従量課金のため、実行の前に規約『開発時の従量課金APIの実行』で見積もる |
| コスト | OpenAI API は従量課金。確定 1 回・連続録音の区間 1 つ・ブラウザの音声 1 件ごとに 1 回送信する | 単価と 1 回あたりの見積もりは非機能要件に書く |
| 既存機能への影響 | `local_whisper` の設定・文字起こしワーカー・既定の動きは変えない | 設定の見本と既定値の一致のテストは `[transcription.openai]` を含めて通す |
