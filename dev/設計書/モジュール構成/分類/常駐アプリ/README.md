# 常駐アプリ

常駐アプリ の設計書

| ページ | 概要 |
| --- | --- |
| [APIサーバー](./APIサーバー.yaml) | FastAPI の app を組み立て、127.0.0.1 での待ち受け・Host・Origin・トークンの守りと、例外の HTTP への変換を持つ。uvicorn を専用のスレッドで動かす。 |
| [セッション](./セッション.yaml) | 録音から出力までの 1 回分の流れ（セッション）の状態と、入口をまたいで同時に 1 つだけ動かす排他を持つ。録音・文字起こし・補正・出力先・履歴は関数型越しに受け取り、API の route もここに置く。API の連続録音では、区切った区間を区切った順に起こして返し、最後に終わりを返す。 |
| [ブラウザの文字起こし](./ブラウザの文字起こし.yaml) | 外の端末のブラウザから受けた音声のジョブを積み、1 件ずつ起こして補正し、状態と結果を返す feature（`features/web_transcription/`）。 |
| [ホットキーと画面](./ホットキーと画面.yaml) | グローバルのホットキーの受付（runtime/hotkey）と、PySide6 の画面とトレイ（ui）の入口としての境界。画面の構成・見た目・部品は #21 のデザインの工程で起こす。 |
| [共通](./共通.yaml) | どの層からも使う設定のモデル・ログ・例外・置き場所のパスと、feature の間を渡る型を持つ。ほかの層に依存しない。 |
| [出力先](./出力先.yaml) | 起こした文字の届け方を出力先ごと・カスタムプリセットの種類ごとのサブフォルダに分け、一覧への登録で追加できる構造にする。出力先どうしは import しない。 |
| [外部連携](./外部連携.yaml) | 文字起こしワーカーの子プロセス・OpenAI API の文字起こし・システム音量・キーボードとクリップボード・ブラウザ添付の画面を開くブラウザ・HTTP の POST・話し声の判定（Silero VAD）を包むアダプタ。feature の関数型を満たし、外の例外をアプリの例外に変える。 |
| [文字起こし](./文字起こし.yaml) | 設定で選んだエンジンで録音を文字に起こす。エンジンは関数型で受け取り、エンジンごとの設定を渡す。 |
| [起動と配線](./起動と配線.yaml) | 常駐サービスの入口。単一インスタンスを確かめ、各 feature と外部連携を関数で配線し（composition root）、API・ホットキー・トレイを立てて画面のイベントループを回す。 |
| [録音](./録音.yaml) | マイクで録音し、録音中はシステム音量を下げて戻す。入口を問わず同じ録音を使い、画面には触れない。連続録音では録音を止めずに無音で区切り、区間を区切った順に渡す。 |
