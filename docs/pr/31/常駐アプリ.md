## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エンジンの型 | `features/transcription/types.py` にエンジンの種類（`local_whisper`）とエンジンの関数型（録音のパスと進みの知らせ先を受け、区間ごとの文字を返す）を置く。エンジンを足すときは関数型の実装を足して `main.py` で登録する | Issue の「エンジンのインターフェースを型（Protocol）で持つ」はこの関数型で満たす。エンジンはローカルの Whisper だけで、型はあとからエンジンを足すために残す |
| 文字起こし | `transcribe` はエンジンを注入で受け、空白だけの区間を除いて改行でつなぐ。区間が無ければ空文字。`EngineError` は理由を持たせた `TranscriptionError` に変える | - |
| ローカルの Whisper | `WhisperWorkerClient` が子プロセスを `python -m voice_paste.integrations.whisper.worker` で、CUDA の DLL の場所を PATH の先頭へ足して起動し、ready を待つ。起動時の 1 回目は ready を待つ上限をかけない（モデルの取得や冷えた読み込みがある）。応答の途中で終わったら 1 回だけ起動し直して同じ録音を送り直し、やり直しも落ちたら起動し直してから `EngineError` を送出する。ワーカーが error を返したときは起動し直さない。常駐の終了時は `stop` で止める | 立て直しで ready を待つ上限は非機能要件の文字起こしワーカーの立て直しの時間（10 秒）、`stop` の待ちは非機能要件の文字起こしワーカーの終わりを待つ時間（仮に 3 秒）を使う |
| エンジンごとの設定 | ローカルの Whisper は `LocalWhisperSettings` だけを読む。設定の `transcription.engine` は `local_whisper` だけを取り、`transcription.openai.*` と `OpenAISettings` は消す | 設定のモデルは #28 で実装済み。`.env` からの移行で `TRANSCRIPTION_ENGINE=openai` はエラー、`OPENAI_API_KEY` は写さない |
| OpenAI | 作らない（ユーザーが使わない）。作った `integrations/openai/`・その単体テスト・外部疎通テストを消す | 確認ログの「OpenAI のエンジンを残すか」 |
| 補正 | `load_glossary` は UTF-8（BOM ありも）の CSV を読み、`誤変換`・`正しい表記` の前後の空白を除いてどちらかが空の行を飛ばし、ファイルが無ければ WARNING を出して空を返す。`apply_glossary` は用語集の行の順に、前の行で置き換えた結果へ次の行を当てる | 置き換えの結果を `voice_paste_legacy` の `load_yogo`・`apply_yogo_replacements` と一致させる（品質シナリオ 2）。BOM つきの CSV を読めるのは `voice_paste_legacy` からの直し |
| 履歴 | `save_recording` は履歴を残す設定なら `history/{YYYYMMDD}/{日時}_{session_id}.wav`、残さない設定なら `tmp/{session_id}.wav` に書く。`append_text` は録音と同じ名前の `.txt` に書き、一時の音声なら何もしない。`purge_expired` はフォルダ名の日付が保持期間を過ぎたものだけを消し、日付でない名前は残す。`discard_temporary` は処理を終えた一時の音声を消し、`purge_expired` は取り残された一時の音声のうち処理中のセッション（注入で受け取る）でないものを消す | 置き場所は #28 の `AppPaths` から引き、並走の間は開発用の置き場所を渡す |
| 録音の型 | 履歴が受け取る `Recording`（モノラルの 16 bit の音・サンプルレート・長さ）を `shared/types.py` に置く | 録音を作る側は [#18](https://github.com/shuhei1101/voice-paste/issues/18) |
| 依存の向き | `features` の 3 つはどうしで import せず、エンジンの実装（`integrations`）を import しない。import-linter の検査を通す | - |
| エラー返却 | 文字起こしの失敗は `TranscriptionError`、エンジンの失敗は `EngineError`（#28 の `shared/errors.py`）で表す | HTTP への変換は [#19](https://github.com/shuhei1101/voice-paste/issues/19) |
| 既存機能への影響 | `voice_paste_legacy`・`voice-paste.bat`・リポジトリの直下の `.env`・`history/`・`log/` を変えない | - |
| `settings.sample.toml`・`.env.sample` | `settings.sample.toml` から `[transcription.openai]` を消す（設定のモデルと一致させる）。`.env.sample` は `voice_paste_legacy` が読むため変えない | `test_load_settings_when_sample_file` が見本と既定値の一致を確かめる |
| `.gitignore` | `history/` の行を `/history/` にし、外すのをリポジトリの直下の履歴（`voice_paste_legacy` の実行時生成）だけに絞る | どの階層にも当たる形だと、新しい構成の `src/voice_paste/features/history/` と `tests/unit/voice_paste/features/history/` まで git の管理から外れる |
