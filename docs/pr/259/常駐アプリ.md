## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| まとまり 1 つの設定（`ContinuousSettings`・`OpenAISettings`・`HistorySettings`） | `load_test_default_settings()` の該当のまとまりを取り、テストの値だけを `model_copy(update=...)` で替える | PoC [#252](https://github.com/shuhei1101/voice-paste/pull/252) の commit dcb4c48 と同じ直し方 |
| ルートの設定（`test_paste_latency.py`） | `make_settings()` で既定の設定に `transcription.local_whisper`（`model_dump(mode="json")` の値）と `glossary_path` を重ねて検証する | - |
| 外部疎通テストの既定の止め方 | `settings.model == "gpt-transcribe"` の確認は残し、既定の設定の `transcription.openai` に対して確かめる | 課金する前に既定の変化で止める意味は変わらない |
| テストの実行 | 単体テストを全て流し、修正した非機能要件テスト 5 ファイルを `--run-e2e` で流す | 外部疎通テストは課金するため流さず、設定の組み立てまでを確かめる |
