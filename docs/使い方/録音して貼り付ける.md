# 録音して貼り付ける

ホットキー・トレイ・録音の画面で録音し、出力先を選んで起こした文字を届ける操作

## 録音を始める

待機中に、次のどちらかで録音を始める。

- 録音を始めるホットキー（既定は `Ctrl+Alt+D`）を押す
- トレイのアイコンの既定の操作か、メニューの「録音を始める」を選ぶ

貼り付けたいアプリの入力欄にフォーカスを置いてから始める。
貼り付けは、そのときアクティブなウィンドウへ入る。

ほかの録音や文字起こしが処理中のときは、始められないことがダイアログで知らされる。
マイクを開けないときは、トレイで録音を始められなかったことが知らされ、ログに理由が書かれる。

録音中は、設定でオンにしていればシステム音量が下がり、録音を終えると戻る。

## 録音の画面

録音を始めると、録音の画面が出る。
画面には状態（録音中・一時停止中）・経過時間・音量の波形が出る。
既定では、ほかのウィンドウより上に残り、カーソルのあるモニターに出る（`ui.topmost`・`ui.follow_cursor`）。

| 操作 | 既定のホットキー | 内容 |
| --- | --- | --- |
| 一時停止・再開 | `Ctrl+Alt+Z` | 一時停止の間に話した声は録らず、経過時間も止まる |
| 取り消す | `Ctrl+Alt+Q` | 録音を捨てて画面を閉じ、待機中に戻る |
| 出力先のボタン | 出力先ごと | 録音を確定し、選んだ出力先へ届ける。一時停止中でも押せる |
| ×（見出しの右端） | `Ctrl+Alt+Q` | 「取り消す」と同じく、録音を捨てて画面を閉じる |
| 隠す（見出しの右端の横線） | - | 録音を続けたまま、その回だけ画面を隠す |

ボタンと同じ操作は、どこにフォーカスがあってもホットキーで行える。
各ボタンの名前の下に、そのホットキーが枠で囲んで出る。
長いホットキーでも途中で切れず、ボタンと画面がその幅まで広がる。
ホットキーを出さないようにもできる（[起動と設定](./起動と設定.md#録音の画面のホットキーの表示)）。

画面は、状態と経過時間の行をつかんでドラッグすると動かせる。
動かした位置はその回だけで、次の録音はいつもの位置に出る。

隠している間も録音は続き、ホットキーで一時停止・取り消し・確定ができる。
隠した画面は、トレイのアイコンの左クリックか、トレイのメニューの「録音の画面を出す」で戻す。
録音開始のホットキーと同じホットキーの出力先が無い設定では、録音開始のホットキーでも戻せる（既定の設定では「貼り付けて送信」と同じ `Ctrl+Alt+D` のため、トレイから戻す）。

録音の画面を出さない設定（`recording.hide_window`）では、トレイから始めても画面を出さず、ホットキーだけで操作する。

## 出力先

確定すると、選んだ出力先へ起こした文字を届ける。
オンにした出力先のボタンだけが画面に並ぶ。

| 出力先 | 既定のホットキー | 届け方 |
| --- | --- | --- |
| 貼り付けて送信 | `Ctrl+Alt+D` | クリップボードへコピーし、貼り付けのキーを送り、設定の秒数を置いて Enter を送る。設定画面の「Enter と一緒に押す修飾キー」で Ctrl・Alt・Shift をオンにすると、その修飾キーを押したまま Enter を送る |
| 貼り付けのみ | `Ctrl+Alt+V` | クリップボードへコピーし、貼り付けのキーを送る。Enter は送らない |
| コピーのみ | `Ctrl+Alt+C` | クリップボードへコピーするだけで、貼り付けも Enter も送らない |

固定の出力先は、この 3 つだけ。

### カスタムプリセット

自分で足せる届け先。
有効にしたプリセットのボタンが、録音の画面の固定の出力先のボタンの下に、見出し「カスタムプリセット」を付けて並ぶ。
並びは、設定画面の「ブラウザ添付」のタブの順、続けて「エンドポイントへ送る」のタブの順。
最初は 1 件も無い。

プリセットは、設定画面の「ブラウザ添付」「エンドポイントへ送る」のタブで足し・消し・並べ替えをする。
1 件ごとに、次を持つ。

| 項目 | 内容 |
| --- | --- |
| タイトル | ボタンに出す名前 |
| URL | 開く画面、または送り先（http か https） |
| ホットキー | 録音の画面でこのプリセットを選ぶキー。空なら、録音の画面のボタンだけで選ぶ |
| 有効 / 無効 | 無効にしたプリセットは、ボタンを出さず、ホットキーも使えない |

種類ごとの届け方と項目は次のとおり。

| 種類（タブ） | 届け方 | 種類ごとの項目 |
| --- | --- | --- |
| ブラウザ添付 | クリップボードへコピーし、URL を Microsoft Edge のアプリのウィンドウとして開き、タブのオプションの秒数を置いて貼り付ける。Edge が見つからないときは既定のブラウザで開く | Enter まで送るか、貼り付けだけで止めるか（既定は Enter まで送る）。開いてから貼り付けるまでの秒数はタブのオプション（既定 3 秒） |
| エンドポイントへ送る | 起こした文字を URL へ JSON で 1 回 POST する。届かなければ送り直さず、トレイで知らせる | `Authorization` の値（空なら付けない）。タイムアウトはタブのオプション（既定 1.5 秒、0.5 秒以上 10 秒以下） |

プリセットで届けるのは、ホットキー・トレイから始めた録音を、ボタンかホットキーで選んだときだけ。
API から始めた録音では使わない。

前の AI チャットの送り先（ChatGPT・Google AI・Claude）は、ブラウザ添付のプリセット（Enter まで送る）に読み替えて出る。
次に設定を保存すると、プリセットとして書かれる。

クリップボードを別のアプリが開いたままで書けないときは、届けられなかったことが知らされ、ログに理由が書かれる。
録音と起こした文字は履歴に残る。

## 起こした文字

録音は設定のエンジン（ローカルの Whisper）で文字に起こし、用語集で補正してから届ける。
用語集は、誤変換と正しい表記の行の集まり。
設定画面の「用語集」で、行を足す・書き換える・消すことができ、行ごとに補正に使うかを切り替えられる。
用語集は名前を付けて複数持てて、補正に使う用語集を 1 つ選ぶ。
保存すると、再起動せずに次の録音の確定から効く。

用語集の中身は UTF-8 の CSV で、列は `誤変換`・`正しい表記`・`使う`（`0` の行は補正に使わない）。
今までの用語集（`glossary_path` の CSV。無ければ設定ファイルと同じフォルダの `yogo.csv`）は、1 つ目の用語集としてそのまま使える。
設定画面で足した用語集の CSV は、設定ファイルと同じフォルダの `glossaries` の下にできる。
一覧から用語集を消しても、CSV のファイルは消えない。
録音を確定するたびに読み直す。

文字に起こすとき、間違えやすい語の正しい表記をヒントとして Whisper に渡せる。
設定画面の「表記のヒント」で、ヒントのプリセットを足す・名前を変える・消す・並べ替えることができ、プリセットの中の語を足す・書き換える・消すことができる。
プリセットごとに有効・無効を切り替えられ、無効のプリセットの語は渡さない。
有効なプリセットが無いときは、ヒントを渡さずに起こす。
保存すると、再起動せずに次の録音の確定から効く。
ホットキー・トレイ・API のどこから始めた録音にも、同じヒントを渡す。

渡すのは、有効なプリセットの語を一覧の上から順に読点（、）でつないだもの。
語は 1 つずつ書き、空にできず、読点（、）・句点（。）・改行を含められない。
つないだ長さは 222 バイト（日本語でおよそ 74 文字。語の間の読点も数える）まで。
今の長さは「有効なヒントの長さ」に出て、超えると保存できない。

ヒントを渡すと、語の表記のほかに出力の書き方も変わる。
句読点が付く・区間ごとの改行がまとまる・口癖が一部消える。
並べた表記へほかの語が引っ張られることもある（例: TypeScript がタイプスクリプトになる）。
引っ張られた語は、その語も足して直す。

ヒントは、その表記に寄せて起こされやすくするだけで、必ずそう起こすわけではない。
必ず置き換える用語集とは別の仕組み。

確定した録音と起こした文字は、履歴に残る。
置き場所と保持期間は[起動と設定](./起動と設定.md)。

ほかのプロセスから録音を操作して文字を受け取る方法は[API](../リファレンス/API.md)。
