## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 起動のバッチファイル | `voice-paste.bat` の起動先を `pythonw -m voice_paste`（引数なし）に替える。venv の有効化・CUDA の DLL の `PATH`・`chcp 65001`・`FOR_DISABLE_CONSOLE_CTRL_HANDLER` は保つ。今日以外の日付のログを消す処理は外し、起動の記録は `%LOCALAPPDATA%\voice-paste\log\launcher.log` へ起動ごとに上書きで書く | bat の中は ASCII だけで書く |
| 起動の引数 | `--data-dir` を任意にし、渡さなければ `resolve_app_paths(None)` で platformdirs の置き場所を使う。`--migrate-env` はそのまま | E2E・非機能要件テストは今までどおり `--data-dir` に一時フォルダを渡す |
| `voice-paste` コマンド | `[project.scripts]` の `voice-paste` を `voice_paste.main:main` へ向ける | `voice_paste_legacy` は [#23](https://github.com/shuhei1101/voice-paste/issues/23) で消すまで `python -m voice_paste_legacy` で起動できる |
| 単一インスタンス | `runtime/single_instance.py` に `instance_name`（設定の置き場所の SHA-256 の先頭 16 文字を名前にする）・`acquire_single_instance`・`SingleInstanceLock` を置き、ctypes で Win32 の名前付きのミューテックス（`Local\{名前}`）と終了の依頼のイベント（`Local\{名前}-quit`）を使う。`main` はログを設定した直後に取り、終了の依頼を受けたら `QMetaObject.invokeMethod` で `QApplication.quit` をメインスレッドで呼び、片付けの最後に放してから `relaunch` する | 待つ上限は非機能要件に足した前の常駐サービスの終わりを待つ時間（17 秒）。上限までに取れなければログに書いて 1 で終わる。依存を足さない（ctypes は標準ライブラリ）。前の常駐サービスへの依頼から排他を取れるまでを `test_single_instance_timeout` で 10 回測り、余裕を決め直す |
| 古い履歴とログの削除 | `main.py` に `purge_old_files`（`purge_old_logs` と、履歴を残す設定のときだけ `purge_expired`）を置き、起動時に 1 回と、`RepeatingTimer` で `PURGE_INTERVAL_SEC`（24 時間）ごとに呼ぶ | 常駐中は処理中のセッションの一時の音声を残す |
| 品質シナリオ 3 | 話し終えてから貼り付くまでの時間を、`build_handlers` で配線した `SessionManager` へマイクの入力と貼り付けのキーだけを差し替えて通し、刷新前と同じ録音・設定・用語集で 20 回測る非機能要件テスト（`test_paste_latency`）を足す。中央値が 1.08 秒以下であることを確かめる | 区間は刷新前と同じく録音を止めた時点から貼り付けのキーを押す直前まで。`--run-e2e` を付けたときだけ走らせる |
| ワーカーの時間の測り直し | ワーカーの起動から ready まで（`test_worker_recovery_time`）と、標準入力を閉じてから終わるまで（`test_worker_stop_timeout`）を 20 回ずつ測る非機能要件テストを足し、測った最大から決定値を決め直す | 決め直した値は非機能要件と `main.py` の定数へ反映する。ワーカーの終わりを待つ時間を決め直したら、前の常駐サービスの終わりを待つ時間の内訳と決定値も導き直す |
| 起動の E2E | 常駐アプリを起動する のシナリオ（前の常駐サービスが動いている・保持期間を過ぎた履歴とログがある を含む）の E2E テストを足す | 対応テストファイルとテスト関数は E2E テスト作成で付ける |
| 並走の記述 | 設定・ER 図・アーキテクチャ図・共通・テスト実行方法の「並走の間」の記述を、普段使いが新しい構成になった後の内容に書き直した | `.env` と `voice_paste_legacy` の記述は [#23](https://github.com/shuhei1101/voice-paste/issues/23) で消す |
| 対応テストファイル | 起動と配線の `test_files` は、足した単体テストの関数がまだ無いため設計の段で外した | テストのレビューを終えたときに planner が `tests/unit/voice_paste/test_main.py`・`runtime/test_timer.py`・`runtime/test_settings_store.py`・`runtime/test_process.py`・`runtime/test_single_instance.py` を記入する。非機能要件の 4 項目の `test_file` も同じときに記入する |
| テスト | `parse_args`・`main` の単体テストに、`--data-dir` を渡さないとき（platformdirs の置き場所は差し替えて、普段使いの置き場所に触れない）・前のプロセスが放さないとき・終了を頼まれたときを足す。`acquire_single_instance`・`SingleInstanceLock` は実物の Win32 の名前付きの排他で、`purge_old_files` は削除の関数を差し替えて確かめる | - |
