# 要件

## 要望

- 設定の `transcription.engine` で、`local_whisper` に加えて OpenAI API（`openai`）を選べる。`openai` を選ぶと、録音の確定・API の完了・連続録音の区間・外の端末のブラウザの音声のどれも OpenAI API で文字に起こす
- OpenAI のエンジンにも、今の手がかり（表記のヒントのプリセットの語）を渡す
- OpenAI のモデルなど OpenAI だけが使う値は、エンジンごとの設定のグループ（`transcription.openai`）に置く
- API キーは環境変数 `OPENAI_API_KEY` があればそれを、無ければ `settings.toml` と同じフォルダの `secrets/openai_api_key` を読む（ユーザーが置いた `~/.config/voice-paste/secrets/openai_api_key` はそのまま読める）。Git の管理下にも `settings.toml` にも設定画面にもログにも出さない
- `faster-whisper`・`nvidia-cublas-cu12`・`nvidia-cudnn-cu12` を無条件の依存から外し、`local_whisper` で使う extra にする。extra を入れずに環境を作っても、`openai` を選んでいれば常駐アプリが起動し、録音・連続録音・文字起こし・届けるまでが動く
- 連続録音の VAD は、faster-whisper のパッケージが無くても今と同じ Silero VAD のモデルを開ける
- `local_whisper` を選んでいて extra が入っていない環境では、起動を止め、extra を入れて環境を作り直すよう理由を示す
- `local_whisper` を使う今の環境（Windows・既定の設定）の動きは変えない。起動のバッチファイルは今までどおり `local_whisper` の依存を含めて環境を作る

`未確定`: 使う OpenAI のモデルと、設定の既定値（決める段: 単一ユースケース設計。規約『ユーザー確認が必須な事項』の「使う API とモデルの選択」のため、ユーザーへ確かめる。確かめるまで `transcription.openai.model` に既定値を置かない）

`whisper-1`・`gpt-4o-transcribe`・`gpt-4o-mini-transcribe` は 2027-02-26 に提供が終わる（[Deprecations](https://developers.openai.com/api/docs/deprecations) の 2026-08-26 の告知）。単価は [料金表](https://developers.openai.com/api/docs/pricing) の値で、1 分の録音 1 回あたりの見積もり。

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `gpt-transcribe` を既定にする。手がかりはプリセットの語を `keywords[]`、言語は `languages[]` で渡す | 提供の終わりが告知されていない後継のモデル。手がかりを語の一覧のまま渡せる。1 分あたり $0.0045 | `keywords[]` に `<`・`>`・改行を含む語があると要求ごと断られる（その語は送信しない） |
| B | `gpt-4o-mini-transcribe` を既定にする。手がかりは `prompt`、言語は `language` で渡す | 1 分あたり約 $0.003（トークン課金の見積もり）で A より安い | 2027-02-26 に使えなくなり、モデルを変える作業がもう一度要る |

推奨: A

B は 4 か月で提供が終わるため、後継の A を既定にする。モデルは `transcription.openai.model` で変えられる。

`未確定`: faster-whisper が無いときの Silero VAD のモデルの置き場所（決める段: モジュール構成設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | faster-whisper 1.2.1 が同梱する `silero_vad_v6.onnx` を常駐アプリのパッケージへ同梱し、そこから開く | 依存も通信も増えない。今と同じモデル | モデルの更新を手で追う。ライセンスの表記が要る |
| B | 起動時に配布元から取得してキャッシュする | リポジトリが大きくならない | 初回にネットワークが要り、取得の失敗が起動の失敗になる |

推奨: A

連続録音は起動時に VAD を開くため、ネットワークに依存させない。

`未確定`: 起動のバッチファイルで extra を含めるか（決める段: モジュール構成設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 常に `local_whisper` の extra を含めて `uv sync --frozen` を流す | 今の環境の動きが変わらない | `openai` を選んでいても faster-whisper・nvidia-* が入る |
| B | `settings.toml` の `transcription.engine` を読んで extra を選ぶ | 要る依存だけが入る | バッチファイルが TOML を読む。設定を変えた後の起動で環境が作り直される |

推奨: A

Windows の端末では `local_whisper` を使い続けるため、動きを変えない。extra を入れない環境は Linux の起動の手段（[#199](https://github.com/shuhei1101/voice-paste/issues/199)）が作る。
