## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 依存の宣言 | `pyproject.toml` の `[dependency-groups].dev` に pywin32 を足す | 版の書き方は dev グループの既存の行（`~=`）に揃える |
| トレイの状態の読み取り | `Uia.tray_tooltips` は、タスクバーのボタンから `voice-paste:` のヒントを読めないとき、隠れたアイコンの一覧を開き、一覧の中のボタンの名前から状態を読む | 一覧を開くボタンは既存の `HIDDEN_ICONS_BUTTON_NAMES` で探す |
| フォーカスの戻し | 一覧を開いて読んだ後は一覧を閉じ、開く前の前面のウィンドウを前面に戻す | `wait_tray_state` の待ちの間にも呼ばれるため、貼り付け先の入力欄のフォーカスを奪わない |
| 既存機能への影響 | 新しく作った venv で `pip install -e . --group dev` を流して conftest を読み込め、`python.exe` が `IsPromoted=0` の環境で、Issue #54 で fail した 6 件がトレイの状態を読めないことでは fail しない | 一覧を開かずに読める環境の読み方は変えない |
