# 要件

## 要望

- `project-index.yaml` の `documents[].schema` の `ref` を全て `design-schemas/v12.0.0` へ上げ、`content/prompts/openai-transcribe.yaml` の `$schema` の参照も同じ版へ上げる
- 画面設計書 `docs/screen/SCR-1`〜`SCR-10` の全てが `design-schemas/v12.0.0` の `screen.schema.yaml` の検査に通る。2026-11-28 時点の develop で v12.0.0 の検査にかけると、画面設計書 10 件で 337 件の違反が出る（画面設計以外の種類の設計書は違反 0 件）
  - 画面全体: `screen_type`・`leave_guard` を記載する（10 件とも欠けている）
  - 要素: `label_display`・`confirm`・`retained_state`・`disabled_reason`・`close`・`initial_focus`・`return_focus`・`table` などの必須の欄を埋める
  - `io`・`align` の値を英語の enum（`input`・`output`・`input_output`・`left`・`center`・`right`）にする
  - `kind` の値を v11.0.0 の enum にする（`menu_item`・`window`・`switch`・`action`・`notification`・`icon`・`canvas` は enum に無い）
  - `table_column` の `sorting` を `sortable`・`filterable` と `table.default_sort` に分ける
  - 種類ごとに禁止になった欄（`overflow` の範囲・表示の決まりの文）を、その種類で許される欄へ移す
- 記載し直す途中で気づいた漏れ・誤り・より良い設計（保持すべき状態が抜けていた・スプリッターが無い・アイコンで足りるラベル など）は、画面設計を修正し、常駐アプリの画面（`src/voice_paste/ui`）と外の端末の画面（`src/voice_paste/server/web`）の実装と結合テスト（`tests/integration`）まで合わせる
- 見た目が変わる修正は、変わる画面だけモックを作ってユーザーの合意を得てから画面設計へ反映する
