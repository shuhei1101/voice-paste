# 要件

## 要望

[dev/pr/171/反映作業/許す Origin の設定/実行.sh](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/171/%E5%8F%8D%E6%98%A0%E4%BD%9C%E6%A5%AD/%E8%A8%B1%E3%81%99%20Origin%20%E3%81%AE%E8%A8%AD%E5%AE%9A/%E5%AE%9F%E8%A1%8C.sh) の計画と書き込みを次のとおりに修正する。

| `[api]` の `allowed_web_origins` | 今の判定 | 修正後の判定 | 書き込み |
| --- | --- | --- | --- |
| キーが無い | `absent` | `absent`（変えない） | `[api]` の見出しの次の行へ `allowed_web_origins = ["https://voice-paste.shuhdev.com"]` を追加する（変えない） |
| 空のリスト | `other`（`failed（other）` で止まる） | `empty` | `[api]` の中の `allowed_web_origins = []` の 1 行を `allowed_web_origins = ["https://voice-paste.shuhdev.com"]` へ置き換える。他の行は変えない |
| 対象の Origin を含む | `present` | `present`（変えない） | 書き込まず `skipped` で終わる（変えない） |
| 対象の Origin を含まない空でないリスト | `other` | `other`（変えない） | 書き込まず `failed（other）` で止まる（変えない） |
| `[api]` が無い | `no_api` | `no_api`（変えない） | 書き込まず `failed（no_api）` で止まる（変えない） |

- `empty` で、`[api]` の中に置き換える `allowed_web_origins = []` の行がちょうど 1 行見つからない場合（複数行に分けて書かれている等）は、書き込まず `許す Origin の書き込み: failed（empty）` で止まる
- 置き換えた後の適用前の検証は今と同じにする（TOML として読めて、`[api]` の `allowed_web_origins` に対象の Origin が含まれる）
- 修正後に `--dry-run` を流し直し、同じフォルダの `dry-run.log` を今の常駐アプリの `settings.toml`（空のリストを持つ）に対する出力へ更新する
- v0.6.0 の反映作業で止まった「許す Origin の設定」と、回していない「ゲートウェイへの登録」を、この作業 PR の反映作業（[反映作業/index.yaml](./反映作業/index.yaml)）として release が master へ入った後に回す

変更するのは作業 PR #171 の反映作業のスクリプトだけで、シナリオが記述する常駐アプリの動作は変わらない。
