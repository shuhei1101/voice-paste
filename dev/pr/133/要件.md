# 要件

## 要望

[PR #108](https://github.com/shuhei1101/voice-paste/pull/108) で文字起こし中の表示に足した出力先の切り替えのボタンと見出しの行のドラッグを、常駐アプリを実機の Windows の画面（offscreen でない）に出して確かめ、次の 3 点が期待どおりかを記録する。
期待と違った点だけを直す。

| 見る点 | 期待する結果 | 期待と違うときの対応 |
| --- | --- | --- |
| 届いたときの貼り付け先 | メモ帳の入力欄にフォーカスを置いたまま切り替えのボタンを押し、見出しの行を動かしても、「貼り付けのみ」「貼り付けて送信」はメモ帳へ貼られる。「コピーのみ」は貼られず、クリップボードに入る | 前面になるなら、設計を見直す |
| 窓を動かす | 見出しの行を動かしている間、窓がカーソルについて動く | `QWindow.startSystemMove` の代わりに、見出しの行の `mouseMoveEvent` で窓を `move()` する |
| ボタンの見た目 | 日本語フォントで、出力先の名前と右上の丸い印が重ならない | ボタンの配置を直す |

確かめる手順は [Issue #112](https://github.com/shuhei1101/voice-paste/issues/112) の `## 手順` に従い、「貼り付けのみ」「コピーのみ」「貼り付けて送信」の 3 つの切り替え先で 1 回ずつ流す。
