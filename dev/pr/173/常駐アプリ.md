## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の置き場所 | settings.toml に、用語集のプリセットの一覧（名前・使う用語集の名前の並び）と、補正に使うプリセットの名前のキーを足す | キー名はモジュール構成設計で決める |
| 既定のプリセット | プリセットの一覧のキーが無いときは、今の `active_glossary` の用語集（無ければ 1 つ目の用語集）だけを使うプリセットを 1 つ持つとして読む | 今の settings.toml で補正の結果が変わらない |
| 補正 | 選んでいるプリセットの用語集を、録音を確定するたびに全て読み直し、オンの行を当てる | 重なった行の当て方は `要件.md` の `未確定` |
| 読めない用語集 | プリセットの用語集のうち読めない CSV は飛ばし、残りの用語集で補正する | 今の読めない用語集を空として扱う動きに揃える |
| 用語集を消したとき | 消した用語集の名前を、それを使うプリセットからも外す | 用語集の名前を変えたときは、プリセットの指す名前も変える |
| 設定画面 | 用語集のまとまりに、プリセットの一覧（足す・名前を変える・消す）と、プリセットごとに使う用語集を選ぶ欄、補正に使うプリセットの選択を足す | 補正に使うプリセットは消せない。見た目はモックで決める |
| 入力チェック | プリセットの名前は 1 文字以上で、ほかのプリセットと重ならない | 用語集の名前の確かめに揃える |
| API | `POST /sessions` の本文でプリセットを指定でき、指定が無いときは設定で選んでいるプリセットを使う。一覧に無いプリセットは録音を始めずに返す | 指定の仕方は `要件.md` の `未確定` |
| ログ | 補正のログに、プリセットの名前と使った用語集ごとの行の数を出す | 今の「用語集で補正する（{名前}・補正に使う {n} 行）」に揃える |
| 既存機能への影響 | 連続録音の区間・ブラウザの音声も同じ補正を通る。ブラウザの音声は設定で選んでいるプリセットを使う | `要件.md` の `## スコープ外` |
