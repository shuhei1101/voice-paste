# 要件

## 要望

出力先「貼り付けて送信」が貼り付けた後に送る Enter を、設定で選んだ修飾キーを押したまま送る。
修飾キーは Ctrl・Alt・Shift の 3 つで、それぞれを設定画面「出力先」のまとまりのチェックボックスでオン・オフする。

- 完了の定義
  - Ctrl だけをオンにすると、貼り付けて設定の秒数（`enter_delay_sec`）を置いた後に Ctrl+Enter を送る
  - 2 つ以上をオンにすると、オンにした修飾キーを全て押したまま Enter を送る
  - 全てオフ（既定）なら、今と同じく Enter だけを送る
  - 設定画面で切り替えて保存すると、再起動せずに次の届けから効く
  - 修飾キーの項目を持たない今の `settings.toml` がそのまま読め、全てオフとして動く

`未確定`: ブラウザ添付の「Enter まで送る」プリセットの Enter にも当てるか（決める段: 単一ユースケース設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 当てる（貼り付けて送信の修飾キーを、秒数と同じく共用する） | 秒数と扱いが揃う | プリセットの送り先（ChatGPT・Claude など）が Enter で送るとき、修飾キーで送れなくなることがある |
| B | 当てない（貼り付けて送信だけに当てる） | Issue の範囲に収まり、プリセットの今の動きを変えない | 秒数は共用で修飾キーは共用しない、という差が残る |
| C | プリセットごとに持つ | 送り先ごとに合わせられる | プリセットの欄と設定のキーが増え、要望より広い |

推奨: B

Issue が挙げているのは「貼り付けて送信」で、プリセットの送り先は Enter で送る Web のチャットが既定に並んでいるため。

`未確定`: 設定画面に出す 3 つのチェックボックスの名前（決める段: 画面設計）

| 案 | 内容 |
| --- | --- |
| A | 「Enter と一緒に Ctrl を押す」「Enter と一緒に Alt を押す」「Enter と一緒に Shift を押す」 |
| B | 「送るキーに Ctrl を足す」「送るキーに Alt を足す」「送るキーに Shift を足す」 |

推奨: A

押すキーの組み合わせがそのまま読め、隣の欄「貼り付けてから Enter を送るまで待つ秒数」と語が揃うため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| Win キーを Enter と一緒に押す | 要望は Ctrl・Alt・Shift で、Win キーとの組み合わせは Windows のショートカットに当たりやすい | 予定なし |
