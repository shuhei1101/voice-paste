# 要件

## 要望

[docs/使い方/起動と設定.md](https://github.com/shuhei1101/voice-paste/blob/develop/docs/%E4%BD%BF%E3%81%84%E6%96%B9/%E8%B5%B7%E5%8B%95%E3%81%A8%E8%A8%AD%E5%AE%9A.md) の `## Linux で起動する` に、Linux（Ubuntu）の常駐アプリの文字起こしは OpenAI API で行い、GPU（CUDA）を使用するエンジン（ローカルの Whisper の GPU・Haas）は使用しない、という方針を記載する。
常駐アプリの動き・設定の既定値は変えない。

`未確定`: 今の Linux の既定（ローカルの Whisper を CPU で動かす。`起動と設定.md` の「文字起こしのエンジンの既定はローカルの Whisper で、Linux では CPU（`device: cpu`・`compute_type: int8`）で動く」）の扱い（決める工程: ドキュメント修正）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 既定は変えず、Linux では OpenAI API を選んで使用すること・GPU のエンジンは使用しないことを記載する。ローカルの Whisper を CPU で動かす今の既定の記述は残す | 動きを変えず、この Issue のスコープ（`type:docs`）に収まる | 起動した直後はローカルの Whisper（CPU）で動き、OpenAI API へ切り替える操作が要る |
| B | Linux の既定のエンジンを OpenAI API に変える | 起動した直後から方針どおりに動く | 設定の既定値の変更（動きの変更）でこの Issue のスコープの外になり、別の Issue が要る |

推奨: A

ユーザーのコメントは「基本的には OpenAI の API だけで使って、GPU 経由で文字起こしすることはない」で、GPU のエンジンを使用しないことが主眼のため。
