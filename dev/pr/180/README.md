# 外の端末のブラウザの画面から送信する音声で、補正に使う用語集のプリセットを選択できるようにする

## 概要

利用者が、外の端末のブラウザの画面（`/web`）から音声を送信するときに、補正に使う用語集のプリセットを選択できるようになる。

## 背景

[Issue #175](https://github.com/shuhei1101/voice-paste/issues/175) の要望。
[PR #173](https://github.com/shuhei1101/voice-paste/pull/173) で用語集のプリセットを追加し、API の録音の開始（`POST /sessions`）ではプリセットを指定できるようになった。
ブラウザの画面から送信する音声は、設定で選んでいるプリセット（`active_glossary_preset`）で補正し、送信する側からは選択できない（#173 のスコープ外としてユーザーの確認で決定）。
