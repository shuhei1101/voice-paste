トレイ

#291 のメニューの「録音の画面を表示」の下に「音声ファイルを文字に起こす…」、「ログフォルダを開く」の下に「履歴フォルダを開く」を追加したもの。「音声ファイルを文字に起こす…」は待機中だけ押せる。

待機中

  • 録音を開始 Ctrl+Alt+D
  • 録音の画面を表示（録音していません）
  • 音声ファイルを文字に起こす…
  • 設定…
  • 用語集の設定…
  • ショートカットの設定…
  • 設定フォルダを開く
  • ログフォルダを開く
  • 履歴フォルダを開く
  • 再起動
  • 終了

「履歴フォルダを開く」は履歴の配置先（%LOCALAPPDATA%\voice-paste\history\）が無ければ作ってからエクスプローラーで開く。履歴を残さない設定でも押せる。

録音中

  • 録音を開始（処理中） Ctrl+Alt+D
  • 録音の画面を表示
  • 音声ファイルを文字に起こす…（処理中）
  • 設定…
  • 用語集の設定…
  • ショートカットの設定…
  • 設定フォルダを開く
  • ログフォルダを開く
  • 履歴フォルダを開く
  • 再起動
  • 終了

録音から届けるまでの間（API から始めた録音の間を含む）は「録音を開始」と同じく押せず、項目名に理由を添える。

音声ファイルの文字起こし中

  • 録音を開始（処理中） Ctrl+Alt+D
  • 録音の画面を表示（録音していません）
  • 音声ファイルを文字に起こす…（処理中）
  • 設定…
  • 用語集の設定…
  • ショートカットの設定…
  • 設定フォルダを開く
  • ログフォルダを開く
  • 履歴フォルダを開く
  • 再起動
  • 終了

音声ファイルの文字起こしから届けるまでの間は録音を始められない。ホットキーを押したときは処理中のダイアログを出す。

「音声ファイルを文字に起こす…」を選んだ後

文字に起こす音声ファイルを選ぶ

C:\Users\user\AppData\Local\voice-paste\history\2026-11-20\

  • 20261120-083012.wav
  • 20261120-083012.txt
  • 20261120-091544.wav

ファイルの種類: 音声ファイル (*.wav;*.mp3;*.m4a;*.mp4;*.ogg;*.webm;*.flac) ／ すべてのファイル (*.*)

開く キャンセル

OS 標準のファイルを開くダイアログを、履歴のフォルダを最初に開いた状態で出す（この枠は見立てで、見た目は OS が決める）。開くと形式を確かめて文字起こしを始め、読めない形式ならトレイの通知で知らせる。キャンセルでは何もしない。
