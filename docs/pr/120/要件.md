# 要件

## 要望

常駐アプリから、環境変数 `VOICE_PASTE_ACCEPT_INJECTED_HOTKEYS` で合成したキー（SendInput）もホットキーとして受ける起動の切り替えを消す。
`src/`・単体テスト・E2E の支えのコード・モジュール構成に `ACCEPT_INJECTED_HOTKEYS` / `accept_injected` / `_build_injected_listener` を残さない。

ホットキーの受付は常に `keyboard.GlobalHotKeys` で行い、普段の起動の振る舞い（合成したキーを受けないこと・書式を読めないホットキーで `HotkeyError` を送出すること・動いている受付の入れ替え）は変えない。

Issue の該当箇所のうち、`tests/support/real_service.py`・`tests/e2e/conftest.py` の `accept_injected_hotkeys` と、テスト実行方法の `VOICE_PASTE_ACCEPT_INJECTED_HOTKEYS=1` を付けて起動する行は、[PR #76](https://github.com/shuhei1101/voice-paste/pull/76) で develop から消えている。
代わりに、PR #76 で足した `tests/support/resident_app.py` の `FakeHotkeyListener` と、その作り手が `accept_injected` を受けている。
