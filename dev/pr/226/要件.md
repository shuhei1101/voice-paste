# 要件

## 要望

- 設定画面の「外の端末に許す Origin」の欄（`api.allowed_web_origins`。1 行 = 1 オリジン）に、`http://` か `https://`（小文字）の後にホストと `:ポート` だけが続く形式（`scheme://host[:port]`）でない行（末尾の `/`・パスが付いている、スキームが無い、http・https 以外か大文字のスキーム 等）を入れて保存・保存して再起動を押したときの、違反・文言・出す位置を画面設計『設定画面』の `input_checks` に追加する
- 保存を止める確かめは、設定のモデル（`ApiSettings._origins_must_be_origin_form`）が既に行っている。今は失敗の文言が設定画面の文言に変わらず、pydantic の文（`Value error, ...`）がそのまま画面に出るため、`to_field_message` で `input_checks` に定めた文言に変える
- 出す位置は、ほかの入力チェックと同じ「その欄の下とエラーの一覧」にする
- この欄は Linux では出さないため、確かめは Windows の設定画面に限る
- 画面に出す文言は「形式の違うオリジンがあります（{違う行を読点でつないだもの}）。https://example.com のように、http:// か https:// で始め、末尾の / とパスを付けずに入れてください。」にする（[確認ログ](./確認ログ.md)）

## 影響するユースケース

| 種別 | ユースケース | 影響 | 依存 |
| --- | --- | --- | --- |
| 単一ユースケース | [設定を変える](https://github.com/shuhei1101/voice-paste/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%82%B7%E3%83%8A%E3%83%AA%E3%82%AA/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/%E8%A8%AD%E5%AE%9A%E3%82%92%E5%A4%89%E3%81%88%E3%82%8B.yaml) | 実行のみ（`異常シナリオ（確かめに通らない値を入れる）` の流れは変えないが、失敗を文言に変える `to_field_message` を変えるため） | |

## 更新ドキュメント

なし

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 設定のほかのキーの `allowed` と `input_checks` の突き合わせ | 設定『常駐アプリ』の `allowed` を持つキーのうち、`input_checks` に無いのは `outputs[].targets[]`（設定画面に欄が無い）・`outputs[].enter_modifiers`・`edge_phrases[].position`（チェックボックス・選択で、違う値を入れられない）・`glossaries[].path`（設定画面が書く）・`glossary_presets[].glossaries`（一覧から選ぶ）で、自由に入れられる欄で漏れているのは `api.allowed_web_origins` だけ | 予定なし |
| `api.allowed_callback_hosts` の形式の確かめ | 設定『常駐アプリ』が `allowed` を定めておらず、要望に含まれない | 予定なし |
