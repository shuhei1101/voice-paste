# 要件

## 要望

[#246](https://github.com/shuhei1101/voice-paste/pull/246) で設定のモデルの項目が既定値を持たない必須の項目になった後も、非機能要件テストと外部疎通テストが設定のモデルを組み立てられるようにする。
次の表の各箇所を、[tests/support/settings.py](https://github.com/shuhei1101/voice-paste/blob/develop/tests/support/settings.py) の既定の設定（`load_test_default_settings()`・`make_settings()`）にテストの値を重ねて組み立てる形へ修正する。
終わりの条件は、表のテストが `ValidationError`（Field required）を出さずに設定のモデルを組み立てられること。
