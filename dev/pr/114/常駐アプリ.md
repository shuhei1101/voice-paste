## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ロック | `uv lock` で `uv.lock` を作り、`.python-version` と合わせて commit する。`pyproject.toml` の宣言の範囲は変えない | `.python-version` の版は `未確定`（要件.md） |
| 環境の置き場所 | 要件.md の決定に従い、バッチファイル・テスト実行方法・設計書の参照を揃える | `未確定`（要件.md） |
| セットアップ | `setup/setup_venv.bat` の venv の作成と `pip install -e .` を `uv sync --frozen` に置き換える | uv が無いときは導入先を示して止める |
| テストのコマンド | テスト実行方法の各種テストと lint を uv で作った環境で流す形に書き換え、lint に `uv lock --check` を足す | - |
| 外部ライブラリ（バージョン固定） | `uv.lock` を版の出所にし、外部ライブラリの設計書の `version.source` と `version.current` を揃える | - |
