# 要件

## 要望

faster-whisper の `transcribe` へ話し声の無い区間から出る定型句を抑えるオプション（`word_timestamps`・`hallucination_silence_threshold`）を渡す PoC の結果を、外部ライブラリ『faster-whisper』の不具合「話していない定型句が文末に入る」へ記録する。
記録するのは、試した組み合わせ・定型句が出なくなった件数・話した文字が欠けた件数と、オプションを渡さない判断。
文字起こしワーカーへ渡すオプションと設定は変えない。
