# 要件

## 要望

AI Monitor の develop の設計書のテンプレート（[ai-monitor#3038](https://github.com/shuhei1101/ai-monitor/issues/3038) の設計書の ID と ID での参照、[ai-monitor#3044](https://github.com/shuhei1101/ai-monitor/issues/3044) の物理ファイルごとのモジュール構成）を、リリースを待たずに `dev/テンプレート/` へ取り込み、変換スクリプト `v0.4.0.py` で全ての設計書を変換する。
取り込む元は AI Monitor の origin/develop の [864a95d81](https://github.com/shuhei1101/ai-monitor/commit/864a95d81)（設計書のテンプレートを最後に変えた commit は [31f29d06d](https://github.com/shuhei1101/ai-monitor/commit/31f29d06d)）で、AI Monitor の次のリリースへ追従するときに、この commit からの差分だけを見られるようにする。
終わりの条件は次の表の全ての行を満たすこと。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 変換スクリプト（`dev/テンプレート/変換/`）の取り込み | voice-paste の `dev/テンプレート/` は変換スクリプトを持たない（v0.3.0 の追従でも取り込んでいない）。変換は AI Monitor の develop の worktree から流す | 予定なし |
| `ai-monitor-version.ini` の書き換え | 取り込む元はリリース前で、付けるバージョンが無い。v0.3.0 のまま残し、取り込んだ commit は `## 要望` に記載する | 予定なし |
| `dev/pr/{114,142,171,235}/反映作業/index.yaml` が目次の Schema で検証される 12 件 | AI Monitor 側の不具合で、設計書の誤りではない | [ai-monitor#2704](https://github.com/shuhei1101/ai-monitor/issues/2704) |
| voice-paste を dev-docs の配信元へ登録する | AI Monitor の develop で設計書の読み書きの手段が dev-docs の MCP（[ai-monitor#3119](https://github.com/shuhei1101/ai-monitor/issues/3119)）へ変わったが、voice-paste は配信元に無い。配信元の登録はリポジトリの直下の `dev-docs.yaml` と端末の設定で行う。`dev-docs.yaml` はこの PR で取り込む Schema と置き場所を前提にするため、マージの後に別の PR で行う | [#249](https://github.com/shuhei1101/voice-paste/issues/249) |
| 変換スクリプトが、型が `ref` ではない文字列の項目（非機能要件の `source`）に書いた設計書の参照を `{ID}#{項目のパス}` へ書き換えない | AI Monitor の `dev/テンプレート/変換/v0.4.0.py` の不具合で、今回の要望に含まれない。voice-paste の残った 2 件はこの PR で手で書き換えた | [ai-monitor#3141](https://github.com/shuhei1101/ai-monitor/issues/3141) |
| 変換スクリプトがメソッドの `connectivity_tests` を疎通テストの振り分け先に数えず、Schema に沿った設計書の変換を断る | AI Monitor の `dev/テンプレート/変換/v0.4.0.py` の `_split_module_docs` の不具合で、今回の要望に含まれない | [ai-monitor#3140](https://github.com/shuhei1101/ai-monitor/issues/3140) |
