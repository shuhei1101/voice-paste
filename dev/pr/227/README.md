# 外の端末の文字起こしの画面で、進みを返さないエンジンのときは「文字起こし中」だけを出す

## 概要

ユーザーが文字起こしのエンジンに OpenAI API を選んでいるとき、外の端末の文字起こしの画面で、文字起こし中の件に「文字起こし中 0%」と進みのバーが出ず、「文字起こし中」だけが出るようにする。

## 背景

[Issue #208](https://github.com/shuhei1101/voice-paste/issues/208) の要望。
[#204](https://github.com/shuhei1101/voice-paste/pull/204) で追加した OpenAI API のエンジンは途中の進みを返さないため、ブラウザの文字起こしのジョブの `progress` は起こし終えるまで 0.0 のまま残る。
外の端末の文字起こしの画面はエンジンを問わず `progress` を % と進みのバーで出すため、進んでいないように見える。
デスクトップの文字起こし中の表示は #204 で、エンジンが進みを知らせない（`UiDeps.reports_progress` が False）ときに進みのバーを出さないようにした。
