# 要件

## 要望

ドメイン用語として使用している旧命名を、次の新命名に置き換える。

| 旧命名 | 新命名 | 意味 |
| --- | --- | --- |
| セッション | 録音セッション | 録音から出力先までの流れを同時に 1 つだけ動かす単位 |
| 返送先 | コールバック先 | 呼び出し元が指定し、起こした文字を受け取るエンドポイント（`callback_url`） |

置き換える範囲と終わりの条件:

| 範囲 | 終わりの条件 |
| --- | --- |
| `docs/`（`docs/pr/` を除く）の文書・設計書 | ドメイン用語の「セッション」「返送先」が 0 件。「録音セッションの ID」のように、新命名の後ろに続く単語はそのまま残す |
| 画面の文言と API の応答・設定の説明の文字列 | 利用者・呼び出し元に表示する文字列に、ドメイン用語の旧命名が 0 件 |
| `src/`・`tests/` のコメント・docstring | ドメイン用語の旧命名が 0 件 |
| open の Issue の本文（[#278](https://github.com/shuhei1101/voice-paste/issues/278) を除く） | ドメイン用語の旧命名が 0 件 |
| 用語集 | `docs/terms.yaml` を新しく作り、新命名を用語（意味つき）として、旧命名をその用語の `avoid` として記載する。dev-docs の配信元に `alias_type: term` の行で登録し、`list_match_words` で新命名が返る |

次の単語は置き換えない。

| 単語 | 理由 |
| --- | --- |
| 「Xorg のセッション」「Wayland のセッション」「GNOME のセッション」「デスクトップのセッション」「セッションバス」・ONNX Runtime の VAD のセッション・VM のログインのセッション | OS・ライブラリの一般の単語で、ドメイン用語ではない |
| 文字起こしワーカー・連続録音・区間 | 話し合いで変えないと決めた単語 |
| コードの識別子（`session`・`callback_url`・`/sessions` など） | 英語の名前で旧命名の和語を含まない。API のパス・キーを変えると呼び出し元の互換を壊す |

設計書の参照のキー（`NFR-1#requirements[API のセッションの上限時間]` など）に旧命名が入るものは、参照先の名前と参照元を同時に置き換えて参照を保つ。
