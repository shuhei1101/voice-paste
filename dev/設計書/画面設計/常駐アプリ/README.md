# 常駐アプリ

常駐アプリの録音の画面・文字起こし中の表示・トレイ・設定画面とダイアログ、外の端末の文字起こしの画面

## 目次

<!-- table: data -->

| ページ | 概要 |
| --- | --- |
| [録音の画面.py](./録音の画面.py.yaml) | 録音中の状態・経過時間・波形と、一時停止・取り消し・出力先を選んでの確定 |
| [文字起こし中の表示.py](./文字起こし中の表示.py.yaml) | 確定から届けるまでの経過と残りの時間を、フォーカスを取らずに出す |
| [トレイ.py](./トレイ.py.yaml) | 状態ごとのアイコンと、録音・設定・フォルダ・再起動・終了のメニュー |
| [トレイの通知.py](./トレイの通知.py.yaml) | 裏の処理で起きた失敗と、「コピーのみ」のコピーの完了を Windows の通知で知らせる |
| [処理中のダイアログ.py](./処理中のダイアログ.py.yaml) | API の録音の処理中に録音開始のホットキーを押したときに、始められない理由を知らせる |
| [設定画面.py](./設定画面.py.yaml) | settings.toml の全てのキーをまとまりに並べ、確かめてから保存する |
| [変えた値を捨てる確認.py](./変えた値を捨てる確認.py.yaml) | 設定画面で変えた値を捨てて閉じるかを確かめる |
| [既定に戻す確認.py](./既定に戻す確認.py.yaml) | 全ての設定を既定の値へ戻すかを確かめる |
| [外の端末の文字起こしの画面.html](./外の端末の文字起こしの画面.html.yaml) | 外の端末のブラウザで録るかファイルを送信し、文字起こしの結果を受け取ってコピーする |
| [取り消せない操作の確認.html](./取り消せない操作の確認.html.yaml) | 外の端末の画面で、結果の削除と文字起こし前の音声の置換を確かめる |
