# 要件

## 要望

常駐アプリのトレイのアイコンのボタンの UI Automation の名前に、今の状態のヒント（`voice-paste: {状態}`）だけが入るようにする。
起動して待機中になった後のボタンの名前に `voice-paste: 準備中` を含めない。

アイコンのヒントの文言（`voice-paste: {状態}`）と、起動してから待機中になるまで準備中のアイコンとヒントを出すことは変えない。

| 種別 | ユースケース | 影響 | 依存 |

| 単一ユースケース | [常駐アプリを起動する](https://github.com/shuhei1101/voice-paste/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%82%B7%E3%83%8A%E3%83%AA%E3%82%AA/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/%E5%B8%B8%E9%A7%90%E3%82%A2%E3%83%97%E3%83%AA%E3%82%92%E8%B5%B7%E5%8B%95%E3%81%99%E3%82%8B.yaml) | 実行のみ（トレイのアイコンを出す順を変えるため、準備中から待機中へ移るトレイの確かめが壊れないことを見る） | |

## 更新ドキュメント

なし

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |

| `ui/tray.py` の `Tray.__init__` の末尾 | [f811586](https://github.com/shuhei1101/voice-paste/commit/f8115861fca7df59b879e9c21d55c78f3e64eccb)（`録音の画面をドラッグで動かし、録音中に隠して戻し、× で取り消せるようにする (#48)`） | 「録音の画面を出す」の初期の文言を付ける行を足した | 3 回 | - |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| E2E でボタンの UI Automation の名前を読んで確かめる | E2E はトレイのヒントをプロセスの中で読む形（[PR #76](https://github.com/shuhei1101/voice-paste/pull/76)）で、ボタンの名前を読まない。読むには実機のトレイを UI Automation で読む支えを戻すことになり、要望に含まれない | 予定なし |
