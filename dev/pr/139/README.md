# 開発コマンドのページを足し、依存の追加・更新と取り込み後の追従のコマンドを書く

## 概要

開発コマンドのページを足し、依存を足す・上げる・外すときと、取り込んだ変更に手元を追従させるときに打つ uv のコマンドを書く。

## 背景

[Issue #116](https://github.com/shuhei1101/voice-paste/issues/116) の不具合。
判定フローチャート『コマンドの書き先』は依存の追加・更新・削除と取り込み後の追従のコマンドを開発コマンドのページの節へ書くと定めるが、このプロジェクトには開発コマンドのページもその Schema も無い。
コーディング規約『依存パッケージ管理』は `pip install` で venv に直接入れないと定めるが、代わりに打つコマンドの置き場所が無い。
[作業 PR #114](https://github.com/shuhei1101/voice-paste/pull/114)（[Issue #56](https://github.com/shuhei1101/voice-paste/issues/56)）のレビューの[指摘](https://github.com/shuhei1101/voice-paste/pull/114#discussion_r4300874906)から切り出した。
