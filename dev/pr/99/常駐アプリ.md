## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定のキー | settings.toml に手がかりのプリセットの一覧（名前・語の一覧・有効か）を足す。既定は空の一覧 | キーが無い今の settings.toml は空の一覧として読む |
| 作成・編集・削除 | 設定画面にまとまりを足し、プリセットを足す・名前を書き換える・消す・並べ替える。プリセットの中の語を 1 つずつ足す・書き換える・消す | 一覧の部品はカスタムプリセットの一覧に揃える。左のメニューの「文字起こし」の次に「表記のヒント」のまとまりを足す（[確認ログ](./確認ログ.md)） |
| 有効・無効 | プリセットごとの切り替えを一覧の各まとまりの頭に置く | 有効なプリセットの語は一覧の順に読点（、）でつなぐ |
| バリデーション | 名前は空を許さず、一覧の中で重ねない。語は空を許さず、読点（、）・句点（。）・改行を含められない。有効なプリセットの語をつないだ手がかりは UTF-8 で 222 バイト以下に限る | 上限の導き方は要件の `## 要望` |
| エラー表示 | 保存のときに確かめ、既存のエラーの一覧と欄の下に出す | 既存の設定画面の出し方に揃える |
| 文字起こしへの受け渡し | 録音を確定するたびに設定の有効な手がかりを組み立て、ワーカーへの transcribe の要求に載せる。有効な手がかりが無いときは載せない | 再起動せずに次の確定から効く |
| 既存機能への影響 | 有効な手がかりが無いときの文字起こしの結果は今と同じ | 用語集の補正は文字起こしの後に今のまま当てる |
