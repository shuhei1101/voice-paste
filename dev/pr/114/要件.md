# 要件

## 要望

依存の管理を pip から uv へ移し、`uv.lock` で推移的な依存まで版を固定する。

- `uv lock` で作った `uv.lock` と `.python-version`（3.14。普段使いの環境と同じ版）を Git 管理する
- 環境はリポジトリの直下で `uv sync --frozen`（dev グループ込み）を流して uv の既定の `.venv/` に作り、`uv.lock` と同じ版が入る
- `uv lock --check` が差分なしで通る（`pyproject.toml` と `uv.lock` が食い違っていない）
- テスト実行方法の前提とコマンドを `.venv/` と uv で入れる形へ書き換える
- 起動のバッチファイル（`voice-paste.bat`）が `.venv/` の環境を使う
- pip で `venv/` を作る `setup/setup_venv.bat` と、`venv/` を有効にするだけの `activate.bat` を消す（リポジトリの直下の起動のバッチファイルを 1 つに絞る）
- uv で作った環境で単体テスト・lint が全て pass し、下の表の `実行のみ` の E2E のケースが pass する

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| CI での `uv sync --frozen` によるロックとの乖離の検証 | リポジトリに CI が無い。乖離は `uv lock --check` を単体テストと一緒に回して確かめる | 予定なし |
| `av` の上限 `<19` を外す | faster-whisper の対応待ちで、今回のロックは今の上限のまま作る | [#57](https://github.com/shuhei1101/voice-paste/issues/57) |
