## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| モジュール構成の設計書のログの行 | 補正・履歴・共通・ブラウザの文字起こしのログの行の文言を、実装で変えるログの文言に合わせる（「消した」→「削除した」、「消せなかった」→「削除できなかった」、「（消す）」→「（削除）」） | 説明の文の中の「消した」は自然な用法のため残す |
| ログの文言 | 「文頭・文末の文言を消した」「古い履歴を消した」「古いログを消した」を「削除した」に、「古い履歴を消せなかった」「一時の音声を消せなかった」「取り残された音声を消せなかった」を「削除できなかった」に、「貼り付けのキーを送った」「Enter を送った」「・Enter まで送った」を「送信した」にする | 「録音を取り消した」「立て直す」「起動し直した」「起動し直せなかった」「コピーし直せなかった」は複合語の自然な用法のため残す |
| `DELETED_MARK` | 値を `（消す）` から `（削除）` にする | 定数名は変えない |
| `.py` のコメント・docstring | 対応表の避ける語を使う語に置き換える（足す → 追加する、送る → 送信する、消す → 削除する、直す → 修正する、印 → マーカー、口 → インターフェース、形 → 構造・形式 など） | 文の意味が変わらない範囲で置き換え、それ以外の文言は維持する |
| `app.ts`・`style.css`・`index.html` のコメント | `.py` のコメントと同じ | `app.js` は `npm run build` で `app.ts` から生成し直す |
| ログの文言を照合するテスト | `tests/e2e/単一ユースケース/test_transcribe_recording.py` のログの照合（「文頭・文末の文言を消した」で始まる行）を、変えたログの文言に合わせる | ほかにログの文言を照合するテストが無いことを、実装の後に検索で確かめる |
| 単体・結合・E2E・非機能要件・外部疎通のテストのコメント・docstring | 対応表の避ける語を使う語に置き換える | テストの関数名・期待値は変えない |
