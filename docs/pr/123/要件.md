# 要件

## 要望

画面の結合テスト（`tests/integration/ui/`）を含む結合テストを、設計書『テスト実行方法』の全件実行（`.venv/Scripts/python.exe -m pytest tests/integration` の 1 プロセス）で流して、止まらず全件 pass させる。

- 前のテストが作った窓・トレイ・ダイアログが、後のテストに残らない（テストの後に、そのテストが作ったものを閉じるだけでなく片付け終える）
- 1 プロセスで流した所要時間が、`tests/integration/` の下をファイルごとに別のプロセスで流した所要時間の合計の 1.2 倍以内に収まる
- ファイルを流す順（`test_tray.py`・`test_recording_window.py` を先に流すなど）で、テスト 1 件の所要時間が延び続けない
- 原因を突き止め、`常駐アプリ.md` の `## 変更方針` に書く

## 影響するユースケース

なし（シナリオと常駐アプリの振る舞いを変えず、E2E の対象にもしない。直すのは結合テストの支えのコード）

## 更新ドキュメント

なし
