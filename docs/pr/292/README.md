# 録音している間、画面が自動で暗くならないようにする設定を追加する

## 概要

利用者が録音している間は PC と外の端末の画面が自動で暗くならず、その動きを設定でオン・オフできるようになる。

## 背景

[Issue #290](https://github.com/shuhei1101/voice-paste/issues/290) の要望。
話している間はキーボードとマウスを操作しないため、長く話すと画面が自動で暗くなり（ディスプレイの消灯・スリープ）、画面の内容を参照できない。スマートフォンでも同じことが起きる。
常駐アプリには録音の間だけシステム音量を下げて戻す設定（`recording.lower_volume`）があるが、画面の消灯を抑止する仕組みは無い。
