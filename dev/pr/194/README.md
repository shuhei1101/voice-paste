# 反映作業「許す Origin の設定」で、allowed_web_origins が空のリストのときに Origin を書き込めるようにする

## 概要

tester が、常駐アプリの `settings.toml` の `allowed_web_origins` が空のリストでも、反映作業「許す Origin の設定」でゲートウェイの公開のサブドメインを書き込めるようにする。

## 背景

[Issue #191](https://github.com/shuhei1101/voice-paste/issues/191) の要望。
E2E 実行 Issue [#167](https://github.com/shuhei1101/voice-paste/issues/167)（Sprint v0.6.0）で、作業 PR [#171](https://github.com/shuhei1101/voice-paste/pull/171) の反映作業「許す Origin の設定」が dry-run で `failed（other）` で止まった（[報告](https://github.com/shuhei1101/voice-paste/issues/167#issuecomment-6415674140)）。
v0.6.0 の常駐アプリは全てのキーを書き出すため、`[api]` に `allowed_web_origins = []` があり、スクリプトはこれを別の Origin が書いてある状態と同じに扱う。
後に回す「ゲートウェイへの登録」も回していない。
