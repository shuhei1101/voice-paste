## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| テストの準備 | 2 つのテストで、`recording.lower_volume=True` の設定を渡して明暗を当てた設定画面を開く（`themed_window` に設定を渡せるようにするか、テストの中で `apply_theme_to_app` と `open_window` を呼ぶ） | どちらにするかは結合テスト作成で決める |
| テストの確かめ | 色の数え方と期待値、`assert checkbox.isChecked()` は変えない | - |
| 既存機能への影響 | `src/` と、ほかのテストの準備は変えない | - |
