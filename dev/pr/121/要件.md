# 要件

## 要望

単一ユースケース「設定を変える」の正常シナリオと「正常シナリオ（カスタムプリセットを足す）」の E2E を置き、`--run-e2e` を付けて流しても実機のマイクを開かないようにする。

- 2 つのケースは、画面・トレイの E2E と同じく常駐アプリを pytest のプロセスの中で `main()` から起動し、録音の入力を WAV を流すものに、システム音量を呼ばれた値を控えるものに差し替える（実機のマイクを開かず、システム音量を変えない）
- 正常シナリオのケースは、シナリオの期待値 4 つを確かめる。録音が始まることは、差し替えたホットキーの受付に登録された新しい組み合わせの関数を呼んで録音中になることで、前の組み合わせで始まらないことは、設定画面を閉じた後の登録に前の組み合わせが無いことで確かめる
- カスタムプリセットを足すのケースは、シナリオの期待値 3 つを確かめる。プリセットの URL は 127.0.0.1 で待ち受けるテスト用の受け口にし、次の録音の画面にそのプリセットのボタンが出ること、登録されたそのプリセットのホットキーの関数を呼んで確定し、起こした文字が受け口へ届くことを確かめる
- シナリオ『設定を変える』の 2 つのシナリオに `test` を持たせ、Mock の行と補足『E2E のテスト』を差し替えた形に合わせる
