# 要件

## 要望

641px 以上の幅で、`dev/mock/refs/37/assets/style.css` を読む全てのモックの欄の行で、設定のキー（`ui.wave_gain` など）と「再起動で反映」のバッジを 1〜2 文字ずつ縦に折らずに出す。
確かめる幅は 641px・700px・768px とし、行の幅に収まるキーとバッジの文言が 1 行に収まっていることを基準にする（行の幅を超えるキーだけは右端で折り返してよい）。
641px 以上の `.row` の規則が持つ、欄の名前の列に最低 9em の幅を残す目的は保つ。
640px 以下の、欄の行を縦に積む見た目は変えない。
[画面設計](https://github.com/shuhei1101/voice-paste/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E7%94%BB%E9%9D%A2%E8%A8%AD%E8%A8%88/%E5%B8%B8%E9%A7%90%E3%82%A2%E3%83%97%E3%83%AA/%E8%A8%AD%E5%AE%9A%E7%94%BB%E9%9D%A2.py.yaml)の `elements[設定の欄]` の「欄の右に settings.toml のキーを出す」は変えない。

長いキー（`transcription.local_whisper.compute_type` など）は、欄の枠の幅で置き方を切り替える。最長のキーが名前・入力と 1 行に収まる枠の幅（680px 以上）ではキーを欄の右に置き、それより狭い枠ではキーを名前の下の 2 段目に回す（[確認ログ](./確認ログ.md)）。
