# 常駐アプリ

常駐アプリの API と、呼び出し元への返送

## 目次

| ページ | 概要 |
| --- | --- |
| [録音を開始する.py](./録音を開始する.py.yaml) | POST /sessions。画面を出さない録音を始めてセッションの ID を返す |
| [録音を停止する.py](./録音を停止する.py.yaml) | POST /sessions/{session_id}/stop。録音を止めて完了を待つ |
| [録音を完了する.py](./録音を完了する.py.yaml) | POST /sessions/{session_id}/complete。録音を確定して文字起こしを始める |
| [呼び出し元へ返す.py](./呼び出し元へ返す.py.yaml) | API から始めた録音の結果を、開始で指定された返送先へ送る |
| [上限で打ち切る.py](./上限で打ち切る.py.yaml) | 完了が来ないままセッションの上限時間に達した API の録音を打ち切り、履歴に残して返送先へ知らせる |
