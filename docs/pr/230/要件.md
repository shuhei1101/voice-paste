# 要件

## 要望

テストの補助コードが `voice_paste.main` のモジュール直下の `send_paste` を差し替えず、`select_platform_adapters` が返した `PlatformAdapters` の `send_paste` を差し替えるようにする。
`src/` と設計書のシナリオは変えない。

満たす基準:

- 次の 3 か所が `monkeypatch.setattr(main_module, "send_paste", ...)` を呼ばず、`dataclasses.replace` で `PlatformAdapters` の `send_paste` を差し替える
  - [tests/support/inprocess.py](https://github.com/shuhei1101/voice-paste/blob/develop/tests/support/inprocess.py) の `start_inprocess_app`
  - [tests/support/resident_app.py](https://github.com/shuhei1101/voice-paste/blob/develop/tests/support/resident_app.py) の `_spy_on_main`（`adapter_overrides` に入れる）
  - [tests/nfr/test_paste_latency.py](https://github.com/shuhei1101/voice-paste/blob/develop/tests/nfr/test_paste_latency.py) の `test_paste_latency`
- 同じ 2 か所の補助コード（`start_inprocess_app`・`_spy_on_main`）の Enter の送信も、`monkeypatch.setattr(main_module, "send_enter", ...)` に代えて `PlatformAdapters` の `send_enter` を差し替える
  - `build_handlers` は Enter の送信を `adapters.send_enter` から受け取るため、Wayland のセッションの `UInputKeyboard.send_enter` はモジュール直下の差し替えで替わらない
- `start_inprocess_app` を使う E2E・非機能要件テストと、`run_resident_app` に貼り付けのキーの控え（`keys`）を渡す E2E が、起動の時点で `AttributeError` にならない
- 確かめる内容と期待値（控えた貼り付けのキー・Enter の回数・貼り付けまでの時間）は変えない
