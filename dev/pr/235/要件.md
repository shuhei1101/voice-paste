# 要件

## 要望

AI Monitor の配布物を v0.2.0 から v0.3.0 へ追従する（差分: [v0.2.0...v0.3.0](https://github.com/shuhei1101/ai-monitor/compare/v0.2.0...v0.3.0)）。
終わりの条件は次の表の全ての行を満たすこと。

<!-- table: data -->

| 分類 | 終わりの条件 |
| --- | --- |
| テンプレート | `dev/テンプレート/` の `*.schema.yaml` が v0.3.0 と同じ中身になる（v0.3.0 と違う index・シナリオ・テスト実行方法・モジュール構成・共通・画面設計・非機能要件を差し替え、無い `フェーズ.schema.yaml` を追加して `dev/テンプレート/index.yaml` に行を追加する） |
| テンプレート | `python -m ai_monitor.design_docs convert --from v0.2.0 --to v0.3.0` を流し、v0.3.0 の AI Monitor で流した設計書の検証で出るのが、`dev/pr/*/反映作業/index.yaml` が目次の Schema で検証される誤り（[ai-monitor#2704](https://github.com/shuhei1101/ai-monitor/issues/2704)）だけになる（v0.2.0 から v0.3.0 の間に変換の定義は無い） |
| 規約・外部規約・フェーズ手順・判定・観点 | v0.2.0 から v0.3.0 で変わったページを読み直し、従っていない成果物を修正するか、無いことを確かめた結果を計画書に記載する |
| サイトのレイアウト・配信設定 | 取り込まない（今後は別の方法で公開する。[確認ログ](./確認ログ.md)） |
| ルール索引 | 追加する行が無いことを確かめる（全プロジェクト共通の `rules.global.yaml` は AI Monitor のクローンから直接読み、voice-paste の `docs/rules.yaml` はこのプロジェクト固有の行だけを持つ） |
| プラグイン | 取り直す作業を置かない（AI Monitor の稼働中の worktree（develop）へ入ったプラグインの変更はモニターが自動で更新する） |
| 設定スキーマ | [反映作業](./反映作業/index.yaml) の `設定スキーマの追従` の状態が `済` になる（v0.3.0 で増えたキーのうち既定値で動かない `my_plugins_repo` を追加し、voice-paste の行の `rule_indexes` から実在しない索引を外す） |
| MCP ツール | 割り当てを変えない（v0.3.0 は `settings.yaml.example` の `agents[].mcp_tools` を持たず、既定の割り当てが `settings.yaml` の指定と合わさって効いている） |
| 準拠バージョン | `ai-monitor-version.ini` の先頭行が `v0.3.0` になる |

<!-- /table -->

## 影響するユースケース

なし（アプリの振る舞い・API・画面を変えない）
