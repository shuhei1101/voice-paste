## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 旧いコードと配布用のビルド | `voice_paste_legacy/`・`setup/build_exe.bat`・`.env.sample`・`scripts/`・`resources/manual.txt`・`resources/icon.ico` を消す | `setup/setup_venv.bat` は残す（[要件](./要件.md) のスコープ外） |
| 移行用の仕組み | `env_migration.py` と、`main.py` の `CliArgs.migrate_env`・`--migrate-env`・`_migrate_env_if_requested` と `main` の処理 4 を消す。モジュール構成の共通・起動と配線から同じ項目とテストを消す | `未確定`（[要件](./要件.md) の `--migrate-env` を消す時点。決める段: モジュール構成設計） |
| 依存 | `pyproject.toml` から python-dotenv・openai・pystray・Pillow を消し、`[tool.setuptools]` を `src/` だけから `voice_paste` を拾う形にする。外部ライブラリの python-dotenv・PyInstaller・openai・pystray・Pillow と外部 API の OpenAI API を消し、それぞれの目次の行を外す | 消した依存が新しい構成の import に無いことを、`pip install -e .` し直した venv での単体テストと起動で確かめる |
| 外部ライブラリ・外部 API の使用箇所 | `used_in` から `voice_paste_legacy/`・`setup/build_exe.bat` を外し、新しい構成の呼び出し箇所だけにする | 呼び出し箇所が `src/` に無いもの（tkinter は `tests/support/paste_target.py` だけ）は実際の呼び出し箇所を書く |
| 設定の設計書 | ファイル一覧の `.env`・`.env.sample` と、`voice_paste_legacy/config.py` が読む `.env` のキーを消し、`settings.toml` だけの一覧にする。冒頭リード・目次の summary・`glossary_path` の説明・`.env` からの写し方の補足を同じ内容へ直す | `.env` のキーと `settings.toml` のキーの対応は、`--migrate-env` を消した後は読む人がいないため残さない |
| モジュール構成の出所の記述 | 「voice_paste_legacy の {関数} と同じ」を「刷新前と同じ」に直し、値と振る舞いはそのまま残す | 値の根拠（刷新前と揃える）は残す |
| テスト | `tests/transcription/`・`test_env_migration.py`・`mock_env.py` を消し、`conftest.py` から `mock_environment` を外す。`test_main.py` から `--migrate-env` のテストを消す。`whisper_fixtures.py` は python-dotenv を使わずに固めた設定を読む | `未確定`（[要件](./要件.md) の固めた設定の読み方。決める段: モジュール構成設計） |
| テスト実行方法 | 単体テストの全件実行を `tests/unit` だけにし、説明から `tests/transcription` を外す。E2E の前提を普段使いが新しい構成だけになった内容へ直す | - |
| 参照の残り | `.gitignore` に `.env.migrated` を足し、`voice-paste.code-workspace` から `./dist/voice-paste` を外す。アーキテクチャ図の前提から `voice_paste_legacy` の行を外す | 完了の定義の文字列が残っていないことを、スコープ外に残す記述を除いて grep で確かめる |
