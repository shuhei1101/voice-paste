## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定 | `UiSettings` に明暗 `theme`（`'system'`・`'light'`・`'dark'`）を足す。既定は `'system'`、反映は `immediate` | 設定の設計書に行を足す |
| 既存の設定との互換 | 項目を持たない `settings.toml` は既定の `'system'` で読む。保存しても他のキーの値とコメントは変えない | 今の設定の読み書き（tomlkit）のまま |
| 明暗の決め方 | `'light'`・`'dark'` は設定どおり、`'system'` は今と同じく OS の明暗で決める。`build_stylesheet` と `theme_color` は、この決め方で選んだ組の色を使う | OS の明暗を読むのは `'system'` のときだけ |
| 当て直し | 設定を保存したときと、`'system'` で OS の明暗が変わったとき（`QStyleHints.colorSchemeChanged`）に、アプリ全体のスタイルシートを当て直し、開いている窓を描き直す | 再起動は要らない |
| 配色 | `tokens.toml` の `[color.light]`・`[color.dark]` を、録音の画面の案 A（`dev/mock/pages/recording-window/94/a-cool-gray/index.html`）の色の値の表へ差し替える。ライトの窓の面は青みのグレー `#eef1f4`、ダークの面は `#22272e`、外側の縁はライト `#818b98`・ダーク `#768390` | primary・primary_hover・on_primary・on_primary_line は今の値のまま |
| 録音の画面の見分けやすさ | 窓の外側の縁だけに使うトークン `frame` を `tokens.toml` に足し、枠なしの窓（録音の画面・文字起こし中の表示）と `QMenu` の外側の縁を `frame` で描く。中の線（`border`）は今の淡さのまま。白い背景・黒い背景のアプリに対して縁を 3:1 以上にする | 設定画面とダイアログは OS の枠で描かれるため対象外。影は付けない |
| 設定画面 | 「画面」のまとまりの先頭に、欄の名前「画面の明暗」と「Windows の設定に従う」「ライト」「ダーク」のラジオボタンを並べる | 欄の部品は型（リテラルの列挙）から決まり、画面設計の補足「まとまりと欄」に行を足す。`UiSettings` の先頭に項目を置く |
| モック | 録音の画面のライト・ダークの配色の案と、設定画面の「画面」のまとまりの明暗の欄を作る | designer へ依頼する |
