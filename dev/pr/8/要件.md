# 要件

## 要望

- AI Monitor の土台を入れる（初期構築の工程が作るもの一式）
  - 構成方針は Python（`pyproject.toml`）・Windows 常駐・画面は tkinter・トレイは pystray・文字起こしは faster-whisper（ローカル）と OpenAI
  - 起動口の `voice-paste.bat` は残す
- 旧形式のドキュメントとエージェント向けの古いガイドを消す（`## 更新ドキュメント` の削除の行）
  - `docs/issues/` のうち、まだ実装されていない新機能の構想（マルチ OS 対応）だけを `下書き` の Issue へ移してから消す
  - `docs/issues/transcribing_ui.md` の文字起こし中の表示は実装済み（`voice_paste/gui.py` の経過表示ウィンドウ）のため移さない
- develop へ master を取り込み、不要なブランチを消す（`## 反映作業`）
- ソースコード（`voice_paste/`・`tests/`・`setup/`・起動のバッチファイル）は変えない
- ラベルは AI Monitor の定義で揃っており、open の Draft PR・古い Issue も無いため、作り直し・閉じる対象は無い

## 影響するユースケース

なし（設計書がまだ無く、ソースコードも変えない。現状の書き出しは [#3](https://github.com/shuhei1101/voice-paste/issues/3) が担う）
