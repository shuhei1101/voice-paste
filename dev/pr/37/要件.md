# 要件

## 要望

- 録音の画面・文字起こし中の表示・設定画面・トレイのメニュー・ダイアログ（処理中に開始が来た・起動に失敗した ほか、セッションの知らせ）を PySide6 で `src/voice_paste/ui/` に作り、グローバルのホットキーの受付を pynput で `src/voice_paste/runtime/` に作る
  - 画面の構成・見た目・項目の並び（設定画面のまとまり・トレイのメニューの並びを含む）は、デザインの工程（デザインスタイル選定・画面一覧・画面遷移・モック作成）で designer が決め、ユーザーが合意したものに合わせる
  - 方針の記録（[構造の決定](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/4_%E6%A7%8B%E9%80%A0%E3%81%AE%E6%B1%BA%E5%AE%9A.md)の画面の行）の designer に渡す要件: 設定ファイルの項目は全て画面で変えられる。設定画面の欄は設定のモデルから組み立てる。録音の画面は表示中も最前面を保つ
- 画面・トレイ・ホットキーは入口として配線された `SessionManager` のメソッド（開始・一時停止・再開・確定・取り消し）と設定のモデルだけを呼び、録音・文字起こし・出力先を直に呼ばない。ほかのスレッド（API・ホットキー・ワーカー）からの知らせは Qt の Signal でメインスレッドへ渡し、画面の部品はメインスレッドだけが触る
- 確定の操作（録音の画面とホットキー）で、設定でオンにした出力先と AI チャットの送り先を選んで届ける
- セッションの知らせ（`state_changed`・`busy`・`microphone_unavailable`・`transcription_failed`・`delivery_failed`・`api_unavailable`）をトレイのアイコン・ダイアログ・画面で知らせる
- 設定画面で保存した値を設定のモデルで確かめてから書き、反映が `immediate` の項目（出力先のオン・オフを含む）は動いている常駐アプリに効かせ、再起動が要る項目はそれと分かるように出す
- トレイのアイコンの画像をリポジトリに同梱し、PySide6 のトレイで読む
- `main.py` の配線に、画面・トレイ・ホットキーの受付と Qt のイベントループを加え、ショートカットからでなく開発用の起動（`--data-dir`）で新しい構成の画面・トレイ・ホットキーが動くようにする
- PySide6（`pyside6-essentials`）の依存を版を決めて `pyproject.toml` に書く
- 完了の定義
  - designer の画面の設計どおりの画面とトレイが PySide6 で動く
  - ホットキーで録音を始めて確定し、選んだ出力先へ貼り付けられる（声で入力した文字を貼り付ける の E2E を通す）
  - 録音の画面が表示中も最前面を保つ（「常に手前に表示」でないほかのウィンドウを前面に出しても録音の画面が上に残る。ほかの「常に手前に表示」のウィンドウより上に保つ手当てはしない。[#4](https://github.com/shuhei1101/voice-paste/issues/4)）
  - import-linter の検査が通る（`ui`・`runtime` が `features` の中を直に import しない）
- 普段使い（`voice_paste_legacy` と、リポジトリの直下の `.env`・`history/`・`log/`）には触れない
