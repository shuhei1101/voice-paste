# 要件

## 要望

`GET /web/assets/app.js` が返却する Content-Type を、Windows のレジストリの `.js` の値に依らず同じにする。
`tests/unit/voice_paste/server/test_web_page.py::test_mount_web_assets` が、ランナー（`windows-latest`）と手元の Windows の両方で pass することを終了の条件にする。

直し方は、`mount_web_assets` が `.js` を `text/javascript; charset=utf-8` に固定して返却する（[MOD-21](https://github.com/shuhei1101/voice-paste/blob/fix/server/fix-js-content-type/docs/module/MOD-21.py.yaml) の `WebAssetFiles`）。
テストの期待値を `application/javascript` まで広げる直し方は、端末によって返却する型が変わるまま残るため採らない。

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |

| `src/voice_paste/server/web_page.py` の `mount_web_assets` | [ee11dc7](https://github.com/shuhei1101/voice-paste/commit/ee11dc7)（`外の端末のブラウザから音声を送って文字に起こす画面とエンドポイントを追加する (#171)`） | 外の端末の画面が読む JS・CSS を `/web/assets/` で配信するために置いた。Content-Type は `StaticFiles` の既定に任せた | 1 回 | 型を固定しても、置き場所の外と無いファイルを 404 にする目的を壊さない |
