# ソースコードとテストのコメント・docstring・ログの文言の語を、語の選び方の規約に合わせて修正する

## 概要

開発者が、`src/`・`tests/` のコメント・docstring・ログの文言を、文書と画面の文言と同じ語で読めるようにする。

## 背景

[Issue #186](https://github.com/shuhei1101/voice-paste/issues/186) の要望。
作業 PR [#183](https://github.com/shuhei1101/voice-paste/pull/183)（起点 Issue [#174](https://github.com/shuhei1101/voice-paste/issues/174)）は文書と画面の文言の語を修正し、ソースコードとテストのコメント・docstring・ログの文言を `## スコープ外` としてこの Issue へ切り出した。
`src/`・`tests/` には、knowledge の規約『文章の書き方』の `## 語の選び方` の対応表で避ける語（送る・足す・消す・直す・印・口・形 など）が残っている。
