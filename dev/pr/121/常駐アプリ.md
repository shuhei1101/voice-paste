## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 録音の入力・システム音量の差し替え | `run_resident_app` に録音の入力を受ける引数を足し、渡されたときは `main_module.open_input` をその `WavInput` に、`lower_volume`・`restore_volume` を `VolumeLog` に差し替える | `WavInput`・`speech_input`・`VolumeLog` は `inprocess.py` から使う。引数を渡さないケースの起動は変えない |
| 正常シナリオ | `hotkeys.start` を別の組み合わせに変えて「保存」→「キャンセル」で閉じた後、`FakeHotkeyListener.bindings` に新しい組み合わせがあり前の組み合わせが無いこと、新しい組み合わせの関数を呼ぶとトレイが録音中になることを確かめ、取り消しの関数で録音を終える | テスト名 `test_normal`。入力は無音の WAV（文字起こしまで進めない） |
| カスタムプリセットを足す | 「エンドポイントへ送る」のまとまりでタイトル・URL（`CallbackReceiver` の受け口）・確定のホットキーを入れたプリセットを足して「保存」→「キャンセル」で閉じた後、録音開始の関数で録音を始め、録音の画面にそのプリセットのボタンが出ること、そのプリセットのホットキーの関数を呼ぶと起こした文字が受け口へ届くことを確かめる | テスト名 `test_normal_when_add_custom_preset`。入力は `speech_input` の音声合成の WAV で、ローカルの Whisper（GPU）で起こす |
| シナリオ『設定を変える』 | 2 つのシナリオに上のテスト名の `test` を持たせ、Mock の行に録音の入力（WAV）とシステム音量の差し替えを足す。補足『E2E のテスト』の E2E を置かない旨の段落を、録音を始めるケースの差し替えの説明に書き換える | シナリオの流れと期待値は変えない |
| テスト実行方法 | E2E テストの前提の画面・トレイの E2E の行に、録音を始めるケースの差し替えと受け口を足す | [要件](./要件.md) の `## 更新ドキュメント` |
| 常駐アプリ（`src/`） | 変えない | - |
