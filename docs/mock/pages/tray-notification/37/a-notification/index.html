トレイの通知（案 A）

裏の処理で起きた失敗を、全て Windows の通知で知らせる。通知は数秒で畳まれ、通知センターに残る。操作は「ログフォルダを開く」の 1 つ。

マイクを開けない

voice-paste

録音を開始できませんでした

マイクを使用できません。マイクが接続されているか、ほかのアプリが使用していないかを確認してください。

ログフォルダを開く

録音を始めようとしてマイクを開けなかったとき。

文字起こしに失敗

voice-paste

文字起こしできませんでした

録音を読み込めませんでした。録音は履歴に残っています。

ログフォルダを開く

理由を 1 文で出し、詳しい内容はログに書く。

届けられない

voice-paste

届けられませんでした

クリップボードに書き込めませんでした（ほかのアプリが使用しています）。起こした文字は履歴に残っています。

ログフォルダを開く

貼り付け・AI チャットのどの出力先でも同じ見出しで出し、理由を変える。

API の待ち受けに失敗

voice-paste

API を使用できません

ポート 47823 をほかのアプリが使用しています。ホットキーとトレイからの録音は使えます。

ログフォルダを開く

起動の途中で出る。常駐アプリは動き続ける。

文字起こしのエンジンを準備できない

voice-paste

起動できませんでした

文字起こしのエンジンを準備できませんでした（モデル large-v4 が見つかりません）。設定を修正して再起動してください。

ログフォルダを開く

トレイのアイコンは失敗のまま残る。
