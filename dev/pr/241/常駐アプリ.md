## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| WAV の書き出し | `synthesize_speech` を OS で分け、Windows は SAPI のまま、Linux は PoC 検証で決めた音声合成で 16 kHz・モノラル・16 bit の WAV を書き出す | 音声合成の手段は `未確定`（[要件](./要件.md)） |
| ブラウザーの起動 | `launch_edge` の実行ファイルを OS で分け、Linux は PoC 検証で決めたブラウザーの実行ファイルを使う。起動の引数（headless・`--use-file-for-fake-audio-capture`）と DevTools Protocol の操作は変えない | ブラウザーは `未確定`（[要件](./要件.md)） |
| プロセスの一覧と終了 | `process_table` と `kill_tree` を OS で分け、Linux は `/proc` から番号・親・コマンドラインを読み、子孫へ SIGKILL を送る。`inprocess.py` の Toolhelp の snapshot も Linux では `/proc` から読む | Windows の動きは変えない |
| SIGBREAK | Ctrl+Break のケースは Linux では skip し、後片付けで戻すハンドラは、その OS にあるシグナルだけにする | `signal.SIGBREAK` は Windows にだけある |
| 文字起こしの待ちの上限 | Linux の既定（CPU・int8）で起こすため、E2E の待ちの上限が足りるかを PoC 検証で測る | 足りなければ OS で上限を分ける。値は規約『資源の値の決め方』で導く |
| 実行の前提 | Linux は Xorg のセッションで流す（クリップボードの `xclip` が `DISPLAY` を要る）。Qt は今と同じ offscreen | |
