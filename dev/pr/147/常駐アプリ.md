## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表記のヒントの変更の数え方 | 要件.md の `## 要望` で決めた数え方で、`_changed_count` の件数に表記のヒントの変更を入れる | 足す・消すだけでは並べ替えに数えない |
| 数えに使う値 | `HintPresetPanel` に、開いたとき・保存したときのプリセットを並べ替え・消しても追える手がかりを持たせ、プリセットごとの値と、残っているプリセットどうしの順を返すメソッドを足す。`_flat_values` は `hint_presets` の 1 キーの代わりにこの値を入れる | 用語集の `GlossaryPanel.change_values` と同じ形にする |
| 確認を出すかの判定 | 表記のヒントを変えていれば確認を出し、変えていなければ出さない今の判定を保つ（件数が 0 か） | 保存の直後に閉じても確認を出さない今の順（保存の後に `_baseline` を置き直す）を保つ |
| 保存する値 | `collect` が返す `hint_presets` の値は変えない | 数えだけを変える |
| 結合テスト | プリセットを足す・消す・名前を変える・語を変える・有効を切り替える・並べ替える操作のそれぞれと、2 つのプリセットを変える操作、途中のプリセットを消す操作（並べ替えに数えない）、保存してから並べ替える操作で、確認の本文の件数を確かめる | `tests/integration/ui/test_settings_window.py` |
