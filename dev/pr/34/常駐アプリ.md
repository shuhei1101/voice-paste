## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 出力先の登録 | `paste_and_send`・`paste_only`・`copy_only`・`ai_chat` の各サブフォルダに `OutputFn` を満たす関数を置き、`OUTPUTS` に 1 行ずつ登録する。出力先どうしは import しない | 品質シナリオ 5 |
| 貼り付けて送信 | クリップボードへ書き、貼り付けのキーを送り、`enter_delay_sec` の間を置いて Enter を送る | `voice_paste_legacy` の `paste_enter` と同じ順 |
| 貼り付けのみ・コピーのみ | 貼り付けのみはクリップボードへ書いて貼り付けのキーを送る。コピーのみはクリップボードへ書くだけ | - |
| AI チャットへ送る | クリップボードへ書き、選んだ送り先の URL を Edge の `--app` で開き（見つからなければ既定のブラウザ）、`open_delay_sec` の間を置いて貼り付けのキーと Enter を送る | 送り先の選び方は「AI チャットの送り先の渡し方」 |
| AI チャットの送り先の渡し方 | 確定の操作で選んだ送り先の URL を、`SessionManager.complete` の `output_target` で受けて `Session.output_target` に持たせ、`deliver` が `OutputFn` の `target` に入れて渡す。出力先の ID と宛先を 1 つの文字列に混ぜない | 送り先の一覧は設定に ID を持たないため、URL をそのまま宛先にする |
| キーボードのアダプタ | `integrations/keyboard/sender.py` に `copy_to_clipboard`・`send_paste`・`send_enter` を置き、pyperclip・pynput を包む。クリップボードに書けないときは `DeliveryError` に変える | 出力先は関数で受け取り、単体テストで差し替える |
| AI チャットの画面を開く | `integrations/browser/opener.py` の `open_app_window` が Edge の `--app` で開き、Edge が無ければ既定のブラウザで開く。起動できなければ `DeliveryError` | `voice_paste_legacy` の `_open_ai_app` と同じ探し方 |
| 配線 | `main.py` の `_wire_outputs` で、各出力先へキーボードのアダプタ・設定の貼り付けのキー・間（`enter_delay_sec`・`open_delay_sec`）を部分適用する | 設定のオン・オフは今の `enabled_ids` のまま |
| エラー | 届けられなければ `DeliveryError` を送出し、セッションが `delivery_failed` を知らせて待機中へ戻す | セッションの扱いは [#33](https://github.com/shuhei1101/voice-paste/pull/33) で実装済み |
| テスト | 各出力先の単体テストでアダプタを差し替え、呼ぶ順と間を確かめる。結合テストは入口がホットキーのセッションから確定した出力先へ届くこと、オフの出力先へ届かないことを、キーボードのアダプタを差し替えて確かめる。キーボードのアダプタの実機のクリップボードへの読み書きは外部疎通テストで確かめる | - |
| 依存の向き | `features/outputs` の各出力先は `integrations` を import せず、`main.py` が配線する。import-linter の検査を通す | - |
