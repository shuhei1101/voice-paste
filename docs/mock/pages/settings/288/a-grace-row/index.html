「録音」のまとまりの「音量を変えるときの秒数」の下に、取り消しの猶予の秒数の欄を足す。ほかのまとまり・欄はこれまでのモックのまま。

録音

recording.fade_sec
recording.cancel_grace_sec

録音を始めてからこの秒数の間に取り消すと、録音の画面をすぐ閉じ、録音はこの秒数が経ってから捨てる。0 にすると、取り消したその場で捨てる。

recording.hide_window

オンにすると、録音と文字起こしの間はトレイのアイコンとホットキーだけで操作する。

既定に戻す キャンセル 保存

既定は 5 秒。保存するとすぐに効く（再起動は要らない）。

0 以上の数値を入れてください（例: 5）。

録音を始めてからこの秒数の間に取り消すと、録音の画面をすぐ閉じ、録音はこの秒数が経ってから捨てる。0 にすると、取り消したその場で捨てる。

recording.hide_window

オンにすると、録音と文字起こしの間はトレイのアイコンとホットキーだけで操作する。

既定に戻す キャンセル 保存

設定のモデルの確かめ（0 以上）に通らないと、ほかの欄と同じく保存せずに欄の下へ理由を出す。
