# 設定画面を開いたまま録音でき、トレイから用語集とショートカットの設定へ直接開けるようにする

## 概要

利用者が、設定画面を開いたまま録音でき、トレイのメニューから設定画面の「用語集」「ショートカット」の箇所を直接開いて、用語集のプリセットを切り替えるショートカットを登録できるようになる。

## 背景

[Issue #289](https://github.com/shuhei1101/voice-paste/issues/289) の要望。今は設定画面を開いている間はホットキーの受付を止めるため録音できず、裏に隠れた設定画面はトレイの「設定…」を選び直しても最前面に出てこない。
用語集のプリセットを切り替える操作はショートカットに割り当てられず、ショートカットを登録する行と行の追加は設定画面の下のほうにある。
Issue の「確認が要ること」の 2 点の解釈は、利用者が Issue の起票元の話し合いで「この解釈でよい」と決めた。
