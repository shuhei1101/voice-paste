# 要件

## 要望

- 今の `voice_paste/` を `voice_paste_legacy/` へ移し、起動のバッチファイル（`voice-paste.bat`）から今と同じに動かす
  - 移した後も、ホットキーで録って貼り付ける・設定画面・トレイ・ログ・履歴の振る舞いと、ログ・履歴・PID ファイルの名前と置き場所を変えない
  - `pyproject.toml`・`setup/build_exe.bat`・`tests/` の参照も `voice_paste_legacy` へ追随させる
- 刷新前の文字起こしの特性テストを固める（品質シナリオ 2）
  - 録音は履歴（`history/`）から N 件選び、選んだ録音を固めた用語集と設定で今のローカルの Whisper（GPU）に起こさせて補正した文字を期待値として固め、同じ入力で N 件一致することを確かめる
  - 用語集の補正だけを切り出し、決まった入力に決まった出力を返すことも確かめる
- 刷新前の値を測って記録し、品質シナリオの未確定の決定値を埋める
  - 話し終えてから貼り付くまでの時間: 約 10 秒の録音で、止めてから貼り付くまでを 20 回測った中央値（品質シナリオ 3）
  - 文字起こしワーカーのモデルの読み込みの時間（品質シナリオ 4 の立て直しの時間の根拠）
  - 刷新前の API の開始の応答時間・処理中の開始へのエラーの応答時間に当たる値（品質シナリオ 1・6）
- 完了の定義は、起動のバッチファイルが `voice_paste_legacy` を起動して今と同じに動き、用語集の補正と刷新前の録音の文字起こしの特性テスト・話し終えてから貼り付くまでの時間の測定の記録があること
