# 設定画面で形式の違う「外の端末に許す Origin」を保存したときの文言を入力チェックに定める

## 概要

ユーザーが設定画面で `api.allowed_web_origins` に形式の違うオリジンを入れて保存したとき、どう直せばよいかが分かる文言を、その欄の下とエラーの一覧で受け取れるようにする。

## 背景

[Issue #207](https://github.com/shuhei1101/voice-paste/issues/207) の要望。
[#204](https://github.com/shuhei1101/voice-paste/pull/204) のレビューで、対象外の逸脱として報告された（[レビューのスレッド](https://github.com/shuhei1101/voice-paste/pull/204#discussion_r4398724206)）。
設定『常駐アプリ』は `api.allowed_web_origins` を `scheme://host[:port]` の形式と定めているが、画面設計『設定画面』の `input_checks` にこの確かめが無い。
設定画面の保存は設定のモデルで形式の違うオリジンを断っているが、文言が定まっておらず pydantic の文がそのまま画面に出る。
