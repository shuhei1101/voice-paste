## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 用語集の変更の数え方 | 要件.md の `## 要望` で決めた数え方で、`_changed_count` の件数に用語集の変更を入れる | [確認ログ](./確認ログ.md) |
| 数えに使う値 | `GlossaryPanel.change_values` を足し、用語集ごとに CSV の場所をキーにして（名前, 行）を、`active_glossary` に補正に使う用語集の場所を返す。`_flat_values` は用語集の 3 つのキーの代わりにこの値を入れる | 補正に使う用語集を場所で持つため、名前を変えても切り替えとして数えない |
| 確認を出すかの判定 | 用語集を変えていれば確認を出し、変えていなければ出さない今の判定を保つ（件数が 0 かで決める） | 保存の直後に閉じても確認を出さない今の順（`GlossaryPanel.mark_saved` の後に `_baseline` を置き直す）を保つ |
| 書き戻し | 書き戻す CSV を決める `GlossaryPanel.changed_rows` は変えない | 数えだけを変える |
| 結合テスト | 用語集を足す・消す・名前を変える・補正に使う用語集を変える・行を変える操作のそれぞれと、組み合わせた操作で、確認の本文の件数を確かめる | `tests/integration/ui/test_settings_window.py` |
