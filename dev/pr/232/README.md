# OpenAI の文字起こしのタイムアウトを、実際の応答時間の実測で見直す

## 概要

文字起こしのエンジンが OpenAI API のときのタイムアウト（今は公式の Python SDK の既定の 600 秒・接続 5 秒）を、実際の応答時間の実測の p99.9 + 50% へ見直す。

## 背景

[Issue #209](https://github.com/shuhei1101/voice-paste/issues/209) の要望。
[#204](https://github.com/shuhei1101/voice-paste/pull/204) で OpenAI API のエンジンを入れたとき、下流の実測が無いため規約『資源の値の決め方』の公開仕様の値として SDK の既定を置き、実測で見直す作業を残した。
#204 の外部疎通テストで測ったのは約 3 秒の音声 1 回（1.97 秒）だけで、p99.9 を出すには足りない。
測るのは [#206](https://github.com/shuhei1101/voice-paste/issues/206) で変えた既定のモデル `gpt-transcribe`。
