# 常駐アプリ

常駐アプリ（src/voice_paste/）の分類ごとのモジュール構成

## 目次

| 分類 | ページ | 概要 |
| --- | --- | --- |
| 入口 | [起動と配線.py](./起動と配線.py.yaml) | main.py・単一インスタンス・依存の向きとその検査 |
| 入口 | [APIサーバー.py](./APIサーバー.py.yaml) | FastAPI の app・要求の守り・例外の変換・uvicorn の起動 |
| 入口 | [ホットキーと画面.py](./ホットキーと画面.py.yaml) | ホットキーの受付と、画面・トレイへの橋渡し |
| 機能 | [セッション.py](./セッション.py.yaml) | 録音から出力までの状態と排他、API の route |
| 機能 | [録音.py](./録音.py.yaml) | マイクの録音と録音中の音量 |
| 機能 | [文字起こし.py](./文字起こし.py.yaml) | 設定のエンジンで録音を文字に起こす |
| 機能 | [補正.py](./補正.py.yaml) | 用語集での補正 |
| 機能 | [出力先.py](./出力先.py.yaml) | 出力先の一覧と各出力先、呼び出し元への返送 |
| 機能 | [履歴.py](./履歴.py.yaml) | 録音と起こした文字の保存と古い履歴の削除 |
| 基盤 | [外部連携.py](./外部連携.py.yaml) | 文字起こしワーカー・OpenAI・システム音量・キーボードのアダプタ |
| 基盤 | [共通.py](./共通.py.yaml) | 設定のモデル・ログ・例外・置き場所・feature の間を渡る型 |
