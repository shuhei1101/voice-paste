# Haas の認識の調整を全て設定と設定画面から変えられるようにする

## 概要

ユーザーが、文字起こしのエンジンを Haas にしたときの認識の調整（モデル・計算の精度・装置・手がかりの強さと採否の守り・区切りの長さ・バッチの大きさ・一度に起こす音声の長さの上限 等）を、設定と設定画面から変えられるようになる。

## 背景

[Issue #271](https://github.com/shuhei1101/voice-paste/issues/271) の要望。
[#264](https://github.com/shuhei1101/voice-paste/pull/264) で Haas をエンジンに追加したが、設定で変えられるのは `transcription.haas.distribution` と `transcription.haas.port` だけで、認識の調整は `haas_server` の固定値か haas_asr の既定値のまま変えられない。
