## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定のキー | settings.toml に指示のプリセットの一覧（名前・本文・有効か）を足す。既定は空の一覧 | キーが無い今の settings.toml は空の一覧として読む |
| 作成・編集・削除 | 設定画面にまとまりを足し、プリセットを足す・名前と本文を書き換える・消す・並べ替える | 一覧の部品はカスタムプリセットの一覧に揃える。まとまりの置き場所はモック作成で決める |
| 有効・無効 | プリセットごとの切り替えを一覧の各まとまりの頭に置く | 複数有効のときの扱いは要件の `未確定` |
| バリデーション | 名前は空を許さず、一覧の中で重ねない。本文は空を許さない | 長さの上限の確かめは要件の `未確定`（複数有効のとき）が決まってから決める |
| エラー表示 | 保存のときに確かめ、既存のエラーの一覧と欄の下に出す | 既存の設定画面の出し方に揃える |
| 文字起こしへの受け渡し | 録音を確定するたびに設定の有効な指示を組み立て、ワーカーへの transcribe の要求に載せる。有効な指示が無いときは載せない | 再起動せずに次の確定から効く |
| 既存機能への影響 | 有効な指示が無いときの文字起こしの結果は今と同じ | 用語集の補正は指示の後に今のまま当てる |
