## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既定値 | `_item(...)` の既定値と `OS_DEFAULT_OVERRIDES` の値を、値を変えずに `config/defaults.yaml` へ移す（OS ごとの値は `os_overrides.{windows\|linux}` のセクション）。pydantic のモデルは範囲・説明・再起動のマーカーと検証を持ち続ける | OS ごとの既定値の持ち方はモジュール構成設計で案 A に決着 |
| 読み込み | 既定値 → 環境の値 → checkout の上書きの順に、キーごとに後のレイヤーで上書きしてから pydantic で検証する | 既定値・在る checkout の上書きが読めないときは、今の `settings.toml` を読めないときと同じ起動の失敗にする |
| 保存 | 設定画面の保存は環境の値だけに書き、既定値と checkout の上書きのファイルは書き換えない。環境の値には既定値と違うキーだけを書き、既定値と同じ値にしたキーは外す | 全てのキーを書くと、既定値を変えても手元の古い値が勝ち、既定値のレイヤーが効かない（単一ユースケース設計で決着） |
| 既定に戻す | 環境の値から全てのキーを外し、既定値（と checkout の上書き）で動くようにする | - |
| 移行 | 起動時に `settings.yaml` が無く `settings.toml` があれば、既定値と違うキーだけを `settings.yaml` へ移し、`settings.toml` は残す | [確認ログ](./確認ログ.md) |
| `--data-dir` | 渡したフォルダの下の `settings.yaml` を環境の値として読み、checkout の上書きは読まない | 一時のフォルダで起動する E2E テストを手元の `settings.local.yaml` から切り離す（単一ユースケース設計で決着） |
| 形式 | YAML にし、ruamel.yaml の round-trip でコメントを保って読み書きする | [確認ログ](./確認ログ.md)、ライブラリ選定 |

モジュール構成設計と実装に渡すこと:

- 保存は、変えたキーを書き換え、既定値に戻したキーを外す処理を、コメントを移す関数（PoC の `add_key_keep_comments`・`delete_key_keep_comments`）を通して行う
- 書くときは YAML 1.1 で文字列でなくなる値を引用符で囲む representer を入れ、ファイルは UTF-8 で開く
- ruamel.yaml はライブラリ選定で比べ、採用したら外部ライブラリの設計書に、上の 2 つの振る舞いを調査した不具合と対処法として書く

最小再現コードの要点（キーを外すときに、外したキーの後ろのコメントを前のキーへ移す）:

```python
def delete_key_keep_comments(mapping: CommentedMap, key: str) -> None:
    keys = list(mapping.keys())
    index = keys.index(key)
    slot = mapping.ca.items.pop(key, None)
    nested = _pop_trailing(mapping[key])  # 表を外すときは中の最後のキーのコメント
    del mapping[key]
    trailing = [None, None, nested, None] if nested is not None else slot
    if trailing is None or trailing[2] is None:
        return
    if index > 0 and isinstance(mapping[keys[index - 1]], (dict, list)):
        prev_value = mapping[keys[index - 1]]
        existing = _pop_trailing(prev_value)
        if existing is not None:
            existing.value += trailing[2].value
            _attach_trailing(prev_value, existing)
        else:
            _attach_trailing(prev_value, trailing[2])
    elif index > 0:
        prev_slot = mapping.ca.items.setdefault(keys[index - 1], [None, None, None, None])
        if prev_slot[2] is None:
            prev_slot[2] = trailing[2]
        else:
            prev_slot[2].value += trailing[2].value
```

PR #247 の diff の見どころは、`check_add`・`check_delete` の「そのまま追加・削除したとき」と「コメントを移したとき」の出力の比較（結果のファイルの `キーの追加`・`キーの削除`）。
