# 出力先を足すときに直す箇所を OUTPUTS への登録だけにする

## 概要

出力先を 1 つ足すときに既存のモジュールで変えるのを、`features/outputs` の一覧（`OUTPUTS`）への登録だけで済む形にする。

## 背景

[Issue #45](https://github.com/shuhei1101/voice-paste/issues/45) の要望。
品質シナリオ 5（[品質目標](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/2_%E5%93%81%E8%B3%AA%E7%9B%AE%E6%A8%99.md)）と非機能要件「出力先を足すときに変える既存のモジュール」は、出力先を足すときに変える既存のモジュールを `OUTPUTS` への登録の 1 か所としている。
develop の今の実装では、設定のモデル（`shared/settings.py`）・配線（`main.py`）・設定画面（`ui/windows/settings_window.py`）にも出力先ごとの書き足しが要る。
[#35](https://github.com/shuhei1101/voice-paste/issues/35)（[#44](https://github.com/shuhei1101/voice-paste/pull/44)）の [要件のスコープ外](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/44/%E8%A6%81%E4%BB%B6.md) から切り出した。
