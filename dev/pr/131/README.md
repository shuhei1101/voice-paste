# ボタンにホットキーを出すかの設定を、録音の画面と文字起こし中の表示で分ける

## 概要

ユーザーが、録音の画面のボタンと文字起こし中の表示のボタンで、ホットキーを出すかを別々に選べるようにする。

## 背景

[Issue #111](https://github.com/shuhei1101/voice-paste/issues/111) の要望（[PR #108](https://github.com/shuhei1101/voice-paste/pull/108) のユーザーの[コメント](https://github.com/shuhei1101/voice-paste/pull/108#discussion_r4277785675)から切り出した）。
`ui.show_hotkeys` は [#96](https://github.com/shuhei1101/voice-paste/pull/96) で録音の画面のボタンに足し、[#108](https://github.com/shuhei1101/voice-paste/pull/108) で文字起こし中の表示の出力先の切り替えのボタンにも効く 1 つの設定にした（欄の名前「録音の画面と文字起こし中の表示のボタンにホットキーを出すか」）。
今は片方の画面だけでホットキーを出さないようにはできない。
