# 要件

## 要望

- 開発コマンドの設計書 `docs/dev-command/CMD-1.yaml` に、AI Monitor の `ai_monitor.design_docs` の `publish` と `generate` を実行する分類を追加する
  - `publish`: `docs/index.yaml` と `docs/{種類}/index.yaml` から `docs/README.md`・`docs/{種類}/README.md` を、`docs/guide/` の文書の分類から `docs/_theme/_data/nav.project.yml` と分類のトップページ `docs/guide/{分類}.md` を書き出し、文書の公開範囲から `docs/_config.yml` の `exclude` を書き換える
  - `generate`: YAML の設計書から `docs/generated/` の Markdown を生成する
  - 前提（AI Monitor のクローンと、その場所での実行方法）と、実行して書き出されることの確認（`verification`）を記載する
- フォルダ構成の設計書 `docs/layout/LAY-1.yaml` の次の生成物のエントリに、`generated_from`（生成元のパスと、追加した分類への参照）を記載する
  - `docs/README.md`（生成元: `docs/index.yaml`）
  - `docs/_theme/_data/nav.project.yml`（生成元: `docs/guide/`）
  - `docs/guide/{分類}.md`（分類のトップページ。生成元: `docs/guide/`）
  - `docs/generated/`（生成元: `docs/`）
- `notes` の「目次と行のファイル」で、`docs/{種類}/README.md` をエントリに記載しない扱いは保ち、生成するコマンドを追加した分類で引けるように記載する
