## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| セッションの種類の判定 | Linux で `XDG_SESSION_TYPE` が `wayland` のときを Wayland のセッションとし、それ以外を Xorg のセッションとして今の実装を使う。判定は `shared/` に置き、`select_platform_adapters` が受け取って実装を選ぶ | Windows と Xorg の分岐の中身は変えない |
| ホットキー | Wayland のセッションでは、PoC で決めた方法で設定のホットキーを受け付け、今の `HotkeyListener` と同じく配線された関数を呼ぶ | `未確定`（[要件](./要件.md) のホットキーの受け方） |
| 貼り付けのキーと Enter の送信 | Wayland のセッションでは、PoC で決めた方法で貼り付けのキーと Enter（修飾キーつき）を送信する。`PlatformAdapters` に Enter の送信も持たせ、Wayland のセッションでは差し替える | `未確定`（[要件](./要件.md) のキーの送信の方法） |
| クリップボード | Wayland のセッションでは `wl-clipboard`（`wl-copy`）で書く。pyperclip が `WAYLAND_DISPLAY` を見て `wl-copy` を選ぶかを PoC で確かめ、選ぶなら `copy_to_clipboard` は変えない | 「コピーのみ」の後に Wayland のアプリで貼り付けられることを確かめる |
| 画面 | 録音の画面・文字起こし中の表示（フォーカスを取らない）・トレイ・設定画面を Wayland のセッションで出し、位置とフォーカスが Xorg と同じに振る舞うかを PoC で確かめる。振る舞わなければ Qt のプラットフォームを `xcb`（XWayland）に固定する | |
| OS のパッケージと権限 | Wayland のセッションで要る OS のパッケージ（`wl-clipboard`・キーの送信のツール）と、要る設定（uinput の権限・GNOME のショートカットの登録）を手順のページに記載する。起動のスクリプトは入っているかを確かめない | 権限の設定は利用者が sudo で行う |
| 通しの確認 | VM の `/etc/gdm3/custom.conf` の `WaylandEnable=false` を外して Wayland のセッションでログインし、#199 と同じく PipeWire の仮想マイクへ WAV を流して、起動 → ホットキー → 文字起こし → テキストエディターへの貼り付けを通す | 確かめた後、VM を Xorg のセッションへ戻す |
