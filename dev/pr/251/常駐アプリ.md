## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| SAPI を前提にする非機能要件テスト | `test_max_segment_length.py` の win32 の skip を外し、WAV を `synthesize_speech` で書き出す。VM で pass することを確かめる | 変更は `tests/` に閉じ、E2E テスト作成で行う |
| GPU を前提にする非機能要件テスト | 案 A なら skip の条件を変えず、テスト実行方法と非機能要件に Linux では skip することを記載する | `未確定`（[要件](./要件.md) の 1 つ目） |
| GPU を使わない非機能要件テスト | VM で `--run-e2e` を付けて全件流し、pass することを確かめる。fail したテストは原因ごとに扱いを決める | 決定値は変えない |
| release の E2E の実行 | `agent_context.yaml` の `phase_extensions.tester` の行の `when` を、release PR の E2E の実行で Windows の全件実行の後とし、本文に VM の起動・前提の確認（自動起動の常駐アプリの停止・メモリ 8 GB）・`.venv/bin/python -m pytest tests/e2e --run-e2e` の実行・結果の集約への記載を書く | VM を操作する手段は `未確定`（[要件](./要件.md) の 2 つ目） |
| VM の設定 | PoC 検証で決めた手段に要るユーザーの操作（SSH の鍵の登録・自動ログイン）を、反映作業（実行者 `ユーザー`）に書く | 反映作業は PoC 検証の後に `反映作業/index.yaml` へ書く |
