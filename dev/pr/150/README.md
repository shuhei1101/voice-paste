# 文字起こし中の表示でホットキーを出さない設定のとき、出力先の切り替えのボタンを等しい幅で並べる

## 概要

利用者が、文字起こし中の表示でホットキーを出さない設定にしても、出力先の切り替えのボタンが等しい幅で並んで見える。

## 背景

[Issue #136](https://github.com/shuhei1101/voice-paste/issues/136) の要望。
`ui.transcribing_show_hotkeys` がオフのとき、出力先の切り替えのボタンの幅が名前の長さのまま 128 / 114 / 100 px と揃わず、画面設計『文字起こし中の表示』の「等しい幅で横に並べる」と食い違う。
[PR #133](https://github.com/shuhei1101/voice-paste/pull/133)（起点 [Issue #112](https://github.com/shuhei1101/voice-paste/issues/112)）の結合テスト作成で見つかった #133 より前からの挙動で、#133 の範囲外として切り出された（[完了報告](https://github.com/shuhei1101/voice-paste/pull/133#discussion_r4306964197)）。
