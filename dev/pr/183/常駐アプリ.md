## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の語 | 要件.md の `## 要望` の直し方で、文章でない所を対応表と判定フローチャートの語に置き換える。項目の論理名を変えたら `refs` と項目のパスも追随させる | 設計書の YAML は `replace_in_design_docs`・`write_design_doc_*` で書く |
| 画面の文言 | 画面設計の要素の表示文言・エラーの文言を先に決め、実装の文字列をそれに揃える。操作の語は規約『入力と文言』の操作の語の対応表、メッセージは同規約の語と書式に従う | 置き換えの一覧は `## 画面の文言の置き換え` |
| 出力先の種類の名前 | 「エンドポイントへ送る」など、画面に出る名前を画面設計と揃える。設定ファイルに保存する `kind` の値は変えない | 既存の settings.toml の読み込みは変わらない |
| 設定画面の見出し | 設定のモデルの見出し・説明は画面設計と設計書/設定の論理名に揃える。設定のキーは変えない | - |
| テスト | 画面の文言・種類の名前を引く断言と、文言で要素を探す操作を、変えた文言に追随させる | 振る舞いは変えない |
| 既存機能への影響 | 振る舞い・API の入出力・設定のキー・保存するファイルの形式は変えない | API のエラーの `detail` に日本語の文言があれば、画面の文言と同じ規則で直し、インターフェース定義に揃える |

## 画面の文言の置き換え

画面ごとに「今の文言 → 直した文言」を並べる（reviewer の合格の後にユーザーへ確かめる）。
文言は画面設計の `label`・補足の表と、設定画面の欄の名前の元になる設定のモデルの説明（最初の 1 文）から引く。

### トレイ

| 要素 | 今の文言 | 直した文言 |
| --- | --- | --- |
| 録音開始の項目 | 録音を始める（処理中）・（準備に失敗） | 録音を開始（処理中）・（準備に失敗） |
| 録音の画面を戻す項目 | 録音の画面を出す（表示中）・（画面を出さない録音）・（録音していません） | 録音の画面を表示（表示中）・（画面を表示しない録音）・（録音していません） |

### トレイの通知

| 通知 | 今の文言 | 直した文言 |
| --- | --- | --- |
| `microphone_unavailable` | 録音を始められませんでした / マイクを開けません。マイクがつながっているか、ほかのアプリが使っていないかを確かめてください。 | 録音を開始できませんでした / マイクを使用できません。マイクが接続されているか、ほかのアプリが使用していないかを確認してください。 |
| `transcription_failed` | 文字起こしに失敗しました | 文字起こしできませんでした |
| `api_unavailable` | API を使えません | API を使用できません |
| `engine_unavailable` | 起動に失敗しました / 文字起こしのエンジンを準備できません（{理由}）。設定を直して再起動してください。 | 起動できませんでした / 文字起こしのエンジンを準備できませんでした（{理由}）。設定を修正して再起動してください。 |
| `settings_invalid` | 起動に失敗しました / 設定ファイルを読めません（{理由}）。設定フォルダの settings.toml を直して再起動してください。 | 起動できませんでした / 設定ファイルを読み込めませんでした（{理由}）。設定フォルダの settings.toml を修正して再起動してください。 |
