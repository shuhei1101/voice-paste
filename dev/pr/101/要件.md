# 要件

## 要望

設定画面で「保存」を押したら、確かめて settings.toml へ書いた後も設定画面を開いたままにし、保存できたことを画面で伝える。

- 完了の定義
  - 「保存」を押して確かめに通ると、settings.toml と用語集の CSV へ書き、反映が immediate の設定を動いている常駐アプリに効かせたうえで、設定画面は開いたまま、入れた値と選んでいたまとまりを保つ
  - 保存できたことが、設定画面を見ているユーザーに分かる
  - 保存の後に欄を変えずに「キャンセル」・Esc・窓の閉じるを押すと、変えた値を捨てる確認を出さずに閉じる
  - 確かめに通らないときの動き（書かず、エラーの一覧と欄の下のエラーを出す）は今のまま
  - 「保存して再起動」は今のまま、保存して設定画面を閉じ、常駐アプリを再起動する

保存できたことは、フッターの上（既定に戻した知らせと同じ場所）に知らせを出して伝え、欄を変えたら消す（[確認ログ](./確認ログ.md)）。

| 保存した欄 | 知らせ | ボタン |
| --- | --- | --- |
| 反映が immediate の欄だけ | 保存しました。 | なし |
| ホットキーを含む | 保存しました。新しいホットキーは、設定画面を閉じると効きます。 | なし |
| 反映が restart の欄を含む | 保存しました。「再起動で反映」の設定 {件数} 件は、再起動するまで前の値で動きます。 | 今すぐ再起動 |
| ホットキーと反映が restart の欄を含む | 保存しました。新しいホットキーは、設定画面を閉じると効きます。「再起動で反映」の設定 {件数} 件は、再起動するまで前の値で動きます。 | 今すぐ再起動 |

ホットキーは録音開始・一時停止・取り消しとプリセットの確定のホットキーで、貼り付けに送るキー（`keyboard.paste_key`）は含めない。
{件数} は開いたときの値から変わった「再起動で反映」の欄の数。

ホットキーの受付は今のまま、設定画面を開いている間は止め、閉じたときに新しい設定で張り直す。
保存した新しいホットキーは、設定画面を閉じてから効く。
開いている間に受け付けないのは、ホットキーの欄で押したキーで録音が動かないための決まりで、保存で閉じなくなっても設定画面を使い続ける間はその理由が残る。
