# 画面・トレイの E2E を実機のマウス・キーボードを使わずに流せるようにする

## 概要

画面・トレイの E2E を、実機のマウス・キーボードを動かさず、操作された体を常駐アプリへ渡す形にする。
ユーザーは E2E を流している間も PC の操作を止めずに使える。

## 背景

[Issue #75](https://github.com/shuhei1101/voice-paste/issues/75) のユーザーの依頼。
release PR [#52](https://github.com/shuhei1101/voice-paste/pull/52)（Sprint v0.3.0 の E2E、[#38](https://github.com/shuhei1101/voice-paste/issues/38)）で E2E を流す時間を確かめたところで、ユーザーから「マイク・マウス・キーボードなど外につながる入力はモックにし、操作された体でシステムへ渡す。画面の上でユーザーの操作を止めさせるものは極力モックにする」と依頼があった（[返信](https://github.com/shuhei1101/voice-paste/pull/52#discussion_r4226561446)）。

- 画面・トレイの E2E（`tests/e2e/単一ユースケース/` の 3 ファイル）は実機の常駐アプリを起こし、`tests/support/desktop.py` の `click`（`SetCursorPos`・`mouse_event`）・`type_keys`（SendInput）・`force_foreground`（`keybd_event` の Alt）で実機のマウスとキーを使う
- 実機のマイクの録音は [#66](https://github.com/shuhei1101/voice-paste/pull/66) で外し、複合ユースケースの E2E は常駐アプリを pytest のプロセスの中で配線する形になっている
- v0.3.0 の E2E は、計画でこの PR の後に流す形になっている
