# 依存の管理を uv と uv.lock へ移し、推移的な依存まで版を固定する

## 概要

依存の管理をコーディング規約『依存パッケージ管理』どおり uv へ移し、`uv.lock` を Git 管理して、入れ直しても推移的な依存まで同じ版が入るようにする。

## 背景

[Issue #56](https://github.com/shuhei1101/voice-paste/issues/56) の不具合。
規約は uv を標準とし `uv.lock` を Git 管理すると定めるが、このリポジトリには `uv.lock` が無く、`pyproject.toml` の範囲指定と `pip install -e . --group dev` だけで依存を入れている。
[作業 PR #55](https://github.com/shuhei1101/voice-paste/pull/55)（[Issue #53](https://github.com/shuhei1101/voice-paste/issues/53)）は新しい venv に PyAV 19 が入り文字起こしが失敗した事象を `av` の上限の宣言で直したが、推移的な依存が入れ直すたびに変わる状態は残っている。
