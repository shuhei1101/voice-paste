# 要件

## 要望

- 起動の切り替えで使われなくなった旧いコードと配布用のビルドの仕組みを消す
  - [voice_paste_legacy/](https://github.com/shuhei1101/voice-paste/tree/develop/voice_paste_legacy) の全体
  - 配布用のビルド（`setup/build_exe.bat`）と、ビルドだけが同梱していた `resources/manual.txt`・`resources/icon.ico`（トレイは `resources/tray/` の画像を使う）
  - `voice_paste_legacy` の設定の見本 `.env.sample`
  - 刷新前の応答時間を測るスクリプト（`scripts/measure_legacy_latency.py`。`scripts/` に他のファイルは無い）
  - `voice_paste_legacy` のテスト（[tests/transcription/](https://github.com/shuhei1101/voice-paste/tree/develop/tests/transcription)）と、`voice_paste_legacy` の `.env` の値を環境変数で差し替えるテストの仕組み（`tests/mocks/mock_env.py` と `tests/conftest.py` の `mock_environment`）
- 移行のために置いた一時的な仕組みを消す
  - `.env` を `settings.toml` へ写す `src/voice_paste/shared/env_migration.py`（`migrate_env`）と、`main.py` の起動の引数 `--migrate-env`、それぞれの単体テスト
  - #22 とこの Issue は同じ Sprint（v0.3.0）で master へ入るため、[#41](https://github.com/shuhei1101/voice-paste/pull/41) の反映作業の設定の移行は、`--migrate-env` が残っている #41 のマージ commit（[72bf714](https://github.com/shuhei1101/voice-paste/commit/72bf71422ff1920c5d473c07a6c2c489b7964a1a)）で行う（反映作業）
- 依存を消す
  - `pyproject.toml` の python-dotenv と、`voice_paste_legacy` だけが使う openai・pystray・Pillow
  - `[tool.setuptools]` の `voice_paste_legacy` の `package-dir` と、`packages.find` の `.`（`voice_paste_legacy` を拾うための探し先）
  - テストの補助（`tests/support/whisper_fixtures.py`）は、固めた設定（`tests/nfr/fixtures/whisper.env`、git 管理外）を python-dotenv を使わずに `KEY=VALUE` の行として読む（空行と `#` で始まる行は飛ばす）。ファイルは変えない
- 残る参照を直す
  - `.gitignore` に `.env.migrated`（移した後の `.env`。API キーを含む）を足す
  - `voice-paste.code-workspace` から配布用のビルドの出力（`./dist/voice-paste`）のフォルダを外す
  - E2E テスト（`tests/e2e/複合ユースケース/test_paste_voice_text.py`）の説明の「普段使いの `voice_paste_legacy`」を、普段使いの置き場所（`%APPDATA%\voice-paste`・`%LOCALAPPDATA%\voice-paste`）に触れない旨へ直す
  - 設計書の `voice_paste_legacy`・`.env`・配布用のビルドの記述（[常駐アプリ](./常駐アプリ.md)・[文字起こしワーカー](./文字起こしワーカー.md) の計画書）
- 完了の定義
  - `voice_paste_legacy`・`dotenv`・`build_exe`・`PyInstaller`・`migrate_env`・`--migrate-env` の文字列が、`dev/pr/`・[docs/はじめに/変更履歴.md](https://github.com/shuhei1101/voice-paste/blob/develop/docs/%E3%81%AF%E3%81%98%E3%82%81%E3%81%AB/%E5%A4%89%E6%9B%B4%E5%B1%A5%E6%AD%B4.md)・スコープ外に残す記述を除いてリポジトリに無い
  - `pip install -e .` し直した環境で `python -m voice_paste` が起動し、単体テストと import-linter の検査が通る
  - 影響するユースケースの E2E が通る

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `.gitignore` の `voice_paste.pid`・`cache/`・`/history/`・`log/`・`build/`・`dist/` の行 | 普段使いのリポジトリの直下に `voice_paste_legacy` と配布用のビルドが作ったファイルが残っており、行を外すと git の追跡に上がる | 予定なし |
| 普段使いのリポジトリの直下に残る `history/`・`log/`・`cache/`・`dist/`・`build/`・`voice_paste.pid` の削除 | ユーザーの手元のファイルで、`history/` は写した後も元を残す取り決め（#41 の反映作業） | 予定なし |
| 非機能要件の根拠の「刷新前（voice_paste_legacy）」・「`scripts/measure_legacy_latency.py` で測り直した」の記述 | 今の判断: 決定値を導いた記録のため残す（消すと決定値の根拠が辿れない）。参照として消すかはレビューで確定する | 予定なし |
| `setup/setup_venv.bat`・`activate.bat` | 今の判断: 残す。配布用のビルドでも移行用の仕組みでもなく、新しい構成の仮想環境の作成と有効化に使う。方針の構造の決定のルート直下の並びに無いため、消すかはレビューで確定する | 予定なし |
| 連続して録音し無音で区切って順に渡す使い方と [#5](https://github.com/shuhei1101/voice-paste/issues/5) | Issue の補足のとおり、この後に API の上へ足す | 起票予定 |
