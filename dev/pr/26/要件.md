# 要件

## 要望

- 作り直しのあるべき姿の設計書を、方針の記録（[dev/pr/12/方針決め/](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/)）の決定どおりに起こす
  - シナリオ: ほかのプロセスが API で録音を開始・停止・完了し、呼び出し元が指定したエンドポイントへ起こした文字を受け取る使い方と、ホットキーで録って貼り付ける今の使い方
  - アーキテクチャ図: 1 つの常駐サービス（API のサーバー・画面とトレイ・ホットキー）と文字起こしワーカーの子プロセス、API の呼び出し元との境界
  - 非機能要件: 品質シナリオ 1〜7 を要件の一覧に載せる
  - モジュール構成: `src/voice_paste/` の機能フォルダ型（`main.py`・`shared`・`features`・`integrations`・`runtime`・`server`・`ui`）と依存の向き
  - インターフェース定義: API の開始・停止・完了のリクエスト・レスポンス・エラー応答（処理中の開始は 409）と、API の守り（127.0.0.1 での待ち受け・Host の確認・Origin の付いた要求の拒否・トークンの照合）
- 完了の定義は、API の開始・停止・完了とホットキーで録って貼り付ける使い方のシナリオ、`src/voice_paste/` のモジュール構成、API のインターフェース定義が develop にあること
- 刷新中は新機能を足さない（連続録音と [#5](https://github.com/shuhei1101/voice-paste/issues/5) は書かない）
- 画面の構成と見た目は書かない（[#21](https://github.com/shuhei1101/voice-paste/issues/21) のデザインの工程で決める）
- コード（`voice_paste/`・`tests/`・`setup/`・起動のバッチファイル）は変えない
