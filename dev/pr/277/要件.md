# 要件

## 要望

- `dev/` を廃止し、その下の文書を `docs/` の下へ移す。移した後の `dev/` に残る追跡するファイルは、この PR の PR ドキュメント `dev/pr/277/` だけにする（`docs/pr/` への移動は ai-monitor#3307 の反映作業が行う）
- 構成は [ai-monitor#3307](https://github.com/shuhei1101/ai-monitor/pull/3307) の [dev/pr/3307/モニター.md](https://github.com/shuhei1101/ai-monitor/blob/cc97586e6/dev/pr/3307/%E3%83%A2%E3%83%8B%E3%82%BF%E3%83%BC.md) の `### 種類のフォルダ` と `### 置き場所の規則` に合わせる。今の `docs/` の公開ドキュメントも同じ 1 回の PR で組み替える
- 移し先は下の表のとおりにする

  | 今 | 移した後 |
  | --- | --- |
  | `dev/設計書/{種別}/`（YAML の設計書） | `docs/{kind}/`（`scenario`・`interface`・`module`・`screen`・`config`・`er`・`architecture`・`nonfunctional`・`external-api`・`library`・`dev-command`・`test-procedure`）。中はフラットにし、ファイル名を `{ID}.yaml`（今 `.{lang}.yaml` のものは `{ID}.{lang}.yaml`）にする |
  | `dev/設計書/デザイン方針.md` | `docs/design-policy.md` |
  | `dev/テンプレート/*.schema.yaml` | `schemas/{kind}.schema.yaml`。AI Monitor の配布物の Schema（ai-monitor#3104 の `common.schema.yaml` の `$defs/mermaid` の変更を含む）で置き換える |
  | `dev/pr/{PR 番号}/`（この PR の分を除く）・`dev/mock/` | `docs/pr/{PR 番号}/`・`docs/mock/`（束のフォルダで、中の構成は変えない） |
  | `docs/はじめに/`・`docs/使い方/`・`docs/リファレンス/` | `docs/guide/`。はじめに・使い方・リファレンスは各文書のメタデータ `category` にし、上タブ（`nav.project.yml`）と分類のトップページを `category` から書き出す |

- 各文書の公開範囲をメタデータ `visibility` で持つ。`docs/guide/` の文書は `public`、`dev/` から移した文書は `internal` にする
- `docs/_config.yml` を配置し、`exclude` に `internal` の種類のフォルダと `pr/`・`mock/`・`generated/` を記載する。Pages の配信の結果（`bundle exec jekyll build` の `_site/`）に `internal` の文書が無いことを確認し、ログを `テスト結果/` に配置する
- 文書の置き場所を記載するファイル（`dev-docs.yaml` の `paths`・`schema`、`CLAUDE.md`・`README.md`、`.gitignore` の `dev/generated/`、`docs/index.yaml`・`dev/index.yaml` の目次、Markdown の文書どうしの相対リンク）を移した後のパスにする
- 設計書の検証（`python -m ai_monitor.design_docs validate`）の結果が、移す前と後で同じになる

`未確定`: 文書を持たず目次（`index.yaml`・`README.md`）だけを持つフォルダ（`dev/エージェント運用/` の `規約/`・`チェックシート/`・`判定フローチャート/` と `dev/コーディング規約/`）の扱い（決める段: ドキュメント修正）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 移さずに削除する | 中身の無い種類のフォルダを作らない | 規約などを追加するときに種類のフォルダから作る |
| B | 目次だけの種類のフォルダ（`docs/rule/`・`docs/checksheet/`・`docs/flowchart/`）として移す | 今の目次の構成を保つ | 文書の無いフォルダが Pages の除外と目次に残る |

推奨: A

種類のフォルダは文書をフラットに並べる場所で、文書を追加するときに作れば足りるため。
