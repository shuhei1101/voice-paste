# 既存の文書を mdmark の書き方と表し方の優先順位（図 → 表 → 箇条書き → 文）に移行する

## 概要

voice-paste の `docs/` の文書を、mdmark の書き方と表し方の優先順位（図 → 表 → 箇条書き → 文）に統一し、タグ・エイリアス・用語・description・関連を今の規約で再設定する。

## 背景

[#257](https://github.com/shuhei1101/voice-paste/issues/257) の要望。
dev-docs への移行で文書の配信は統一したが、文書の中身は Mermaid の図・文の羅列・AI Slop の単語を含む旧記法のまま残っている。
`dev/` の廃止と AI Monitor の配布物の Schema への追従は [#277](https://github.com/shuhei1101/voice-paste/pull/277) で済んでおり、この PR は移した後の `docs/` を対象にする。
