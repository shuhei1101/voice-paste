## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 差し替えの補助 | `run_resident_app` で、貼り付けのキー（`send_paste`・`send_enter`）を `KeyLog` に、ブラウザを開く呼び出し（`open_app_window`）を渡された URL を控えるものに差し替えられるようにする。マイクを開けないケースのために、開くと `MicrophoneUnavailableError` を出す録音の入力を足す | 渡さないケースの起動は変えない。保存した録音を壊す・区間の文字起こしを失敗させる差し替えは `inprocess.py` の `break_saved_recordings`・`fail_transcription_of_segment` を使う |
| トレイの操作 | トレイのアイコンの左クリックはアイコンの `activated`（Trigger）を、通知を押す操作は `messageClicked` を emit して渡す | 録音の画面を戻す・コピーし直す・ログの置き場所を開く |
| 常駐アプリを起動する | `test_normal`・`test_error_when_api_unavailable` で、録音開始のホットキーの関数を呼んでトレイが録音中になることを確かめ、取り消しの関数で終える。`test_normal_when_old_ai_chat_settings_remain` で、録音の画面に出すとした送り先のプリセットのボタンだけが出ることと、そのボタンで確定すると控えた URL が送り先の URL で、クリップボードに起こした文字が入り、貼り付けと Enter が控えられることを確かめる | 入力は前 2 つが無音の WAV、古い AI チャットは `speech_input` |
| 録音する | `tests/e2e/単一ユースケース/test_record.py` を新しく置き、シナリオの `test` のケースを置く（「ほかの窓を前面に出す」「主のモニターに出す」「カーソルのあるモニターに出す」「録音の画面を動かす」は置かない） | テストファイルを置いた後に、シナリオに `test_file` を持たせる（設計書の書くツールは、無いテストファイルを指す `test_file` を書かない） |
| 起こした文字を届ける | `tests/e2e/単一ユースケース/test_deliver_transcript.py` を新しく置き、全シナリオのケースを置く。貼り付けは控えたキーとクリップボードで、返送先・送り先は受け口に届いた中身で確かめる | 同上。クリップボードはテストの後に元の文字へ戻す（`clipboard_sentinel`） |
| 録音を文字に起こす | `tests/e2e/単一ユースケース/test_transcribe_recording.py` に「文字起こしの手がかりを渡す」以外のシナリオのケースを足す | 手がかりのケース（`build_handlers` で配線）は変えない |
| 4 つのシナリオ | 各シナリオに上のケースのテスト名の `test` を持たせ、Mock の行に差し替えるものと流す WAV を書いた。補足『E2E のテスト』の E2E を置かない旨を、差し替えた形の説明に書き換えた | シナリオの流れと期待値は変えない。単一ユースケース設計で済 |
| テスト実行方法 | [要件](./要件.md) の `## 更新ドキュメント` | - |
| 常駐アプリ（`src/`） | 変えない | - |
