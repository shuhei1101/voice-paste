設定画面

「画面」のまとまりの先頭に、欄「画面の明暗」（ui.theme）と「Windows の設定に従う」「ライト」「ダーク」のラジオボタンを足したもの。ほかの欄は今のまま。

ライト（既定の「Windows の設定に従う」で Windows がライト）

voice-paste の設定
  • 出力先
  • ブラウザ添付
  • エンドポイントへ送る
  • ホットキー
  • 録音
  • 文字起こし
  • 画面
  • 履歴とログ
  • API
画面
画面の明暗 ui.theme
ui.topmost
録音の画面を出す位置 ui.position
ui.follow_cursor
ui.wave_gain
既定に戻す キャンセル 保存

開いたところ。既定は「Windows の設定に従う」。配色は録音の画面の案 A を当てている。

ダーク（「ダーク」を選んだ）

voice-paste の設定
  • 出力先
  • ブラウザ添付
  • エンドポイントへ送る
  • ホットキー
  • 録音
  • 文字起こし
  • 画面
  • 履歴とログ
  • API
画面
画面の明暗 ui.theme
ui.topmost
録音の画面を出す位置 ui.position
ui.follow_cursor
ui.wave_gain
既定に戻す キャンセル 保存

「ダーク」を選んで保存すると、Windows がライトでも全ての画面がダークになる。保存すると再起動せずに開いている画面へ効く（反映は即時のため「再起動で反映」の印を付けない）。
