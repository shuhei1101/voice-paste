# 要件

## 要望

用語集（誤変換と正しい表記の組）を設定画面から編集し、用語集をプリセットとして複数持って切り替え、行ごとにオン・オフできるようにする。

- 完了の定義
  - 設定画面で、用語集の行（誤変換・正しい表記）を足す・書き換える・消すことができ、保存すると再起動せずに次の録音の確定から効く
  - 用語集のプリセットを名前を付けて足す・名前を変える・消すことができ、補正に使うプリセットを設定画面で選べる
  - 用語集の行ごとにオン・オフを切り替えられ、オフの行は補正に使わない
  - 今の `glossary_path`（キーが無ければ `settings.toml` と同じフォルダの `yogo.csv`）の「誤変換」「正しい表記」の 2 列の CSV がそのまま読め、その CSV を 1 つ目のプリセットとして、全ての行をオンとして扱う

補正に当てる用語集のプリセットは、設定画面で選んだ 1 つだけにする。
プリセットを切り替える場所は設定画面だけにする。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 用語集以外の設定の GUI 化 | 別の Issue で扱う | [#88](https://github.com/shuhei1101/voice-paste/issues/88) |
| 正規表現など、文字の一致以外の置き換え方 | 要望は今の「誤変換を正しい表記へ置き換える」動きを設定画面から編集することで、置き換え方は変えない | 予定なし |
| トレイのメニューからの用語集のプリセットの切り替え | 確認で切り替える場所を設定画面だけと決めた（[確認ログ](./確認ログ.md)） | 予定なし |
| 画面の結合テスト（`tests/integration/ui`）を 1 つのプロセスで流すと、遅くなり続けて終わらない | この PR の前の develop でも起きる不具合で、要望に含まれない。ファイルごとに別のプロセスで流して確かめた | [#95](https://github.com/shuhei1101/voice-paste/issues/95) |
