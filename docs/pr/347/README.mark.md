# 外の端末の文字起こしの画面に録音の破棄と一時停止を追加し、長い結果を折りたたんでコピーのボタンを上に配置する

## 概要

外の端末の利用者が、画面で録っている音声を文字に起こさずに破棄したり、録音を一時停止・再開したりでき、長い結果をスクロールせずにコピーできるようになる。

## 背景

[Issue #346](https://github.com/shuhei1101/voice-paste/issues/346) の要望。
ゲートウェイ（shuhdev-gateway）で配信している外の端末の文字起こしの画面（画面設計『外の端末の文字起こしの画面』）は、録音中の操作が「録音停止・送信」だけで、録った音声を送信せずに捨てる手段も一時停止も無い。
結果の 1 件は起こした文字を全文で並べ、その下にコピーのボタンを配置しているため、文字が多いとコピーのたびに一番下までスクロールする必要がある。
常駐アプリの録音の画面は [#18](https://github.com/shuhei1101/voice-paste/issues/18) で一時停止・再開・取り消しを持っているが、外の端末の画面には無い。
