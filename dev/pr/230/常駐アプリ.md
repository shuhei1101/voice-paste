## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `start_inprocess_app` | `send_paste`・`send_enter` のモジュール直下の差し替えを消し、既にある `replace(...)` に `send_paste=keys.send_paste`・`send_enter=keys.send_enter` を加える | - |
| `_spy_on_main` | `keys` を渡されたとき、`adapter_overrides["send_paste"]`・`adapter_overrides["send_enter"]` に控えの関数を入れる | 既存の `select_platform_adapters` の差し替えにそのまま乗る |
| `test_paste_latency` | `send_paste` のモジュール直下の差し替えを消し、既にある `replace(...)` に `send_paste=_send_paste` を加える | - |
| テストのケース | 確かめる内容と期待値は変えない | - |
| 常駐アプリの振る舞い | 変えない | `src/` を変えない |
