## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 応答時間の測定 | 既定のモデル `gpt-transcribe` へ、最長の録音を繰り返し送信し、送信から応答までの秒と接続にかかった秒を記録する。p99.9 を求められる回数を測る | 回数と録音の長さは見積もりの後に決める（要件の `未確定`） |
| タイムアウト | `OPENAI_TIMEOUT_SEC` を、応答時間の実測の p99.9 + 50% にする | 固定の値 1 つ |
| 接続のタイムアウト | `OPENAI_CONNECT_TIMEOUT_SEC` を、接続にかかった時間の実測の p99.9 + 50% にする | - |
| 文字起こしの最長 | 非機能要件の内訳の文字起こしの最長（3 回 × タイムアウト + 待ちの上限 × 2）を、求めた値で計算し直す | - |
| 料金 | 測定の前に規約『開発時の従量課金APIの実行』で見積もり、閾値を超えるならユーザーへ確かめる。測った後に実費の目安を報告する | - |
