# PR12: AI送信ボタンに Claude を追加

## 概要
AI送信ボタンの3つ目として Claude (Edge PWA) を追加する。

## 作業内容
- [x] `.env.sample` に `AI_SEND_3_*` を追加（Claude / `https://claude.ai/new` / `<ctrl>+<alt>+3` / 有効）
- [x] `voice_paste/settings_gui.py` に AI3 の UI 行を追加（既存 AI1/AI2 と同パターン）
- [x] `voice_paste/settings_gui.py` の `_save` で AI3 設定を保存対象に含める

## 実装
| 追加/編集 | ファイルパス | クラス.メソッド | 変更内容 |
|-----------|-------------|----------------|---------|
| 編集 | .env.sample | - | `AI_SEND_3_ENABLED/NAME/URL/HOTKEY` を追加 |
| 編集 | voice_paste/settings_gui.py | SettingsWindow.__init__ | `_ai3_enabled/_ai3_name/_ai3_url/_ai3_hotkey` 属性追加 |
|  |  | SettingsWindow.show | AI3 行のウィジェット生成（既定値: Claude / claude.ai/new / Ctrl+Alt+3） |
|  |  | SettingsWindow._save | AI3 の収集・差分判定・`AI_SEND_3_*` キー書き込みを追加、`_ai_keys` / 連番処理ループに AI3 を含める |

## ユーザー確認事項
### 動作確認チェックリスト
- [ ] 録音モーダルに「Claude」ボタンが3つ目として表示される
- [ ] `Ctrl+Alt+3` で Claude へ送信される（PWAが起動しテキストが貼り付け＋Enter）
- [ ] 設定画面で AI3 の有効/名前/URL/ホットキーが編集・保存できる
- [ ] 既存の ChatGPT / Google AI ボタンが従来通り動作する

## 設計メモ
- `config.AI_SEND_APPS` は `AI_SEND_N_*` を while ループで動的読み込みするため、`.env.sample` 追加だけで読み込みは自動対応
- `gui.py` のボタン生成も `AI_SEND_APPS` を回すため変更不要
- `settings_gui.py` のみ AI1/AI2 が固定で書かれているため AI3 も明示追加が必要
