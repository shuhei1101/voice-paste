# 「コピーのみ」で確定したとき、コピーの完了を Windows の通知で知らせる

## 概要

「コピーのみ」で確定した利用者が、コピーの完了を Windows の通知で知り、その通知を押して同じ内容をコピーし直せるようになる。

## 背景

[Issue #50](https://github.com/shuhei1101/voice-paste/issues/50) の要望（[PR #48](https://github.com/shuhei1101/voice-paste/pull/48) のユーザーのコメントから起票）。
今の「コピーのみ」はクリップボードへ書くだけで、コピーできたかが画面に出ない。
トレイの通知は失敗だけを知らせ、通知を押すと常にログフォルダを開く。
