## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 録音の入力 | `features/recording/client.py` が sounddevice の入力を 16 kHz・モノラル・int16 のコールバックのストリームで開く。開けなければ例外をそのまま上げ、`Recorder` が `MicrophoneUnavailableError` に変える | 形式は `voice_paste_legacy` と同じ（履歴と文字起こしが受ける `Recording` に合わせる） |
| 録音の操作 | `Recorder.start` は音量を下げてから入力を開く。`pause` は入力を開いたまま貯めるのを止め、`resume` で再び貯める。`stop` は入力を閉じて音量を戻し、貯めた音を `Recording` で返す。`discard` は入力を閉じて音量を戻し、貯めた音を捨てる | `start`・`stop` はセッションの `StartRecordingFn`・`StopRecordingFn` を満たす |
| 音量を戻す保証 | 停止・破棄・開始の失敗のどの終わり方でも、下げた音量を 1 回だけ戻す。下げていなければ戻さない | 方針の記録のリスク「マイクを開けないと音量が戻らない」への対策。`features/recording` の単体テストで確かめる |
| 音量のアダプタ | `integrations/volume/adapter.py` の `lower_volume` は今の音量を読んで割合を掛けた音量へ、`restore_volume` は渡された音量へ、どちらも `fade_sec` をかけて変える。COM の初期化と解放をこの中で行い、pycaw・COM の例外を `VolumeControlError` に変える | フェードの段数と、進行中のフェードを次の操作で打ち切ることは `voice_paste_legacy` の振る舞いを保つ。フェードは別のスレッドで進め、呼び出し元を待たせない（`fade_sec` が 0 のときだけ呼び出しの中で変える） |
| 音量を操作できないとき | `Recorder.start` は `VolumeControlError` を WARNING で残して音量を下げずに録音を始める | 録音を止めない |
| 音量を下げない設定 | `recording.lower_volume = false` なら `Recorder` は音量の関数を呼ばない | 設定のモデルは [#28](https://github.com/shuhei1101/voice-paste/pull/28) で実装済み |
| 録音中の音の大きさ | `Recorder` が直近の入力の RMS を int16 の最大で割って 0.0〜1.0 で返す。一時停止中と録音していないときは 0 | 録音の画面の波形の元。表示は [#21](https://github.com/shuhei1101/voice-paste/issues/21) |
| 契約テスト | `tests/external/voice_paste/integrations/volume/test_adapter.py` に、Windows の実機の既定の再生デバイスで `lower_volume`・`restore_volume` を動かし、下げた後と戻した後のマスター音量を読んで確かめるテストを置く。終わりには元の音量へ戻す | 品質シナリオ 7。pycaw の版を上げたら回す。`--run-external` のガードに乗せ、既定の再生デバイスが無い環境では skip する |
| 依存の向き | `features/recording` は `integrations` を import せず、音量の操作を関数型で受け取る。import-linter の検査を通す | - |
| エラー返却 | マイクの失敗は `MicrophoneUnavailableError`、音量の失敗は `VolumeControlError`（[#28](https://github.com/shuhei1101/voice-paste/pull/28) の `shared/errors.py`）で表す | HTTP への変換は [#19](https://github.com/shuhei1101/voice-paste/issues/19) |
| 外部ライブラリ | pycaw は `==20251023` のまま変えない | 方針の記録のリスク「pycaw の版で API が変わる」 |
| 既存機能への影響 | `voice_paste_legacy`・`voice-paste.bat`・リポジトリの直下の `.env`・`history/`・`log/` を変えない | 並走の間の普段使い |
