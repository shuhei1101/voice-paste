# 設定画面の「変えた値を捨てる確認」の件数で、表記のヒントのプリセットの数え方を決めて結合テストで確かめる

## 概要

ユーザーが設定画面を閉じるときの「変えた値を捨てる確認」で、表記のヒントのプリセットの変更が決めた数え方の件数で出るようにし、結合テストで確かめる。

## 背景

[Issue #127](https://github.com/shuhei1101/voice-paste/issues/127) の要望。
[PR #125](https://github.com/shuhei1101/voice-paste/pull/125) の要件.md の `## スコープ外` の切り出しで、PR #125 で用語集の変更を「変えた用語集 1 つを 1 件、補正に使う用語集の切り替えを別に 1 件」と数えるように決めた。
develop の [settings_window.py](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/ui/windows/settings_window.py) の `SettingsWindow._flat_values` は、表記のヒントのプリセットの一覧（名前・語・有効か・並び）の変更をまとめて 1 件と数え、プリセットを 2 つ変えても 1 件になる。
