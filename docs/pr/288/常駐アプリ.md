## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の特定 | 未特定。止まる箇所を、報告者の端末で再現させて記録してから対策を決める | 報告の時刻（2026-11-13 00:55〜00:58 JST）のログでは、開始と取り消しは重なっていない（開始から取り消しまで 1.37 秒・1.66 秒。`SessionManager.start` は通知まで含めてロックを離している）。報告者の端末（既定の入力: Razer Seiren V3 Mini・MME）での計測では、マイクの入力を開いた直後〜1.5 秒後に止めて閉じるまでが 0.04〜0.14 秒、音量のエンドポイントを開いて読むまでが 0.02 秒で、どれも報告の場面で長く止まる根拠を持たない。取り消しに入った時刻はログに出ないため、画面のスレッドが取り消しの中で止まったのか、その後（`UiController._apply_session`・録音の画面を閉じる処理）で止まったのかも分からない。調べ方は下の `未確定` |
| 開始の直後の取り消しの対策 | 原因の特定の後に決める | `未確定`（[要件](./要件.md) の対策の案。決める段: 原因の特定の後のモジュール構成設計） |
| 終了の処理の間の開始 | 終了の処理の間に録音を始める操作を受けたら、終了の処理中で今は録音を始められないことを示す | 処理中のダイアログで示す（[確認ログ](./確認ログ.yaml)）。`start_local_session` が断られた理由（今の録音セッションの入口）を busy の通知の detail（`BUSY_REASON_API` / `BUSY_REASON_FINISHING`）にし、`UiController` から `show_busy_dialog` へ引き渡す |
| 処理中のダイアログ | 断った理由（API の録音の処理中・終了の処理中）ごとに本文を分ける | 終了の処理中の本文は「前の録音を文字に起こして届けています。終わってから、もう一度録音開始のホットキーを押してください。」 |
| 回帰のテスト | `start_local_session` の単体テスト（断った理由ごとの detail）と、処理中のダイアログの結合テスト（終了の処理中の本文）を追加する。開始の直後の取り消しの回帰のテストは、原因の特定の後に、その経路を決定的に起こせるレイヤーに置く | 開始の直後の取り消しは E2E（SC-8 の `正常シナリオ（開始の直後に取り消す）`）でも、画面のスレッドが 0.5 秒以内にイベントを処理することを確認する |

`未確定`: 止まる箇所の調べ方（決める段: レビューの後、報告者に依頼する）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 録音の画面の `_cancel` の入口・出口、`SessionManager.cancel` のロックの取得の前後、`UiController._apply_session` の入口・出口に DEBUG の時刻のログを入れた版を報告者の端末で動かして再現させ、固まっている間に `py-spy dump --pid {常駐アプリ} --native` で画面のスレッドのスタックを取る | 止まった箇所のスタックを外から取れる | 報告者が固まっている間に py-spy を入れて打つ必要がある |
| B | A の時刻のログに加え、画面のスレッドの停止を検出する見張りを入れる。画面のスレッドが `QTimer` で 0.1 秒ごとに時刻を記録し、別のスレッドが 1.0 秒以上更新されないのを見つけたら、そのときの画面のスレッドのスタック（`sys._current_frames`）を `[WARNING]` でログに書き込む（1 回の停止につき 1 回）。報告者はこの版をいつもどおり使い、固まったらログの場所を伝える | 報告者は再現の場で操作しなくてよく、毎回ではない事象でも次に起きたときに記録が残る。見張りは常駐アプリに残し、ほかの固まる報告の調査にも使える | 見張りのスレッドとそのテストがこの PR に加わる。A の `--native` のスタック（PortAudio・COM の中）は取れない |

推奨: B

事象は毎回ではなく、報告者が固まった瞬間に別の操作をするのは難しい。B ならいつもどおり使うだけで、次に固まったときの画面のスレッドのスタックがログに残る。Python のスタックで止まった呼び出し（`stream.stop`・`restore_volume`・Qt の呼び出しなど）までは分かる。
どちらも、報告者がこのブランチの版で常駐アプリを起動する操作が要る。
