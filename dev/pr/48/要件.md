# 要件

## 要望

ホットキー・トレイから始めた録音の録音の画面に、動かす・その回だけ隠す・× で取り消すの 3 つの操作を戻す。

- 録音の画面をドラッグで動かせる
  - 枠なしの窓のまま、見出しの行（状態・経過時間の行）をつかんで動かす。見出しの右端に「隠す」（横線のアイコン）と「×」を置く
  - 動かした位置はその回だけ使い、次の録音は今どおり `ui.position`・`ui.follow_cursor` で決まる位置に出す
- 録音中に、その回だけ録音の画面を隠せる
  - 隠した後も録音は続き、ホットキーでの一時停止・取り消し・確定もそのまま効く
  - 隠した画面は、トレイから戻せる。録音開始と同じホットキーの出力先が無い設定では、ホットキーからも戻せる
    - トレイはアイコンの左クリックとメニューの「録音の画面を出す」、ホットキーは録音開始のホットキーで戻す（設定のキーは足さない）
    - 録音開始と同じホットキーの出力先がある設定（既定の設定では、録音開始と「貼り付けて送信」がどちらも `<ctrl>+<alt>+d`）では、録音開始のホットキーは今どおりその出力先で確定し、ホットキーでは戻せない
    - 録音の画面を出さない設定の録音と API から始めた録音では、アイコンの左クリックは何もせず、「録音の画面を出す」は押せない
  - 次の録音では、録音の画面をいつもどおり出す（`recording.hide_window` は変えない）
  - 隠した回も文字起こし中の表示は出し、確定した時点の録音の画面の位置（動かしていれば動かした位置）に出す
- 録音の画面に閉じるボタン（×）があり、押すと「取り消す」のボタンと同じく録音を捨てて待機中に戻る
- 完了の定義
  - 録音の画面をドラッグすると、窓がカーソルに付いて動く
  - 隠すと録音の画面が消え、録音（経過時間と音量）は続く。トレイから戻すと（録音開始と同じホットキーの出力先が無い設定ではホットキーからも）、同じ録音の経過時間と状態のまま録音の画面が出る
  - × を押すと、取り消しと同じく録音を捨てて録音の画面を閉じ、履歴に残さない
  - 隠したとき・× で閉じたときに、前面が録音を始める前の貼り付け先へ戻る
  - 戻したときに、録音の画面がフォーカスを取らない（今の出し方と同じ）

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 録音の画面のホットキーの表示の見切れと、「AI チャットへ送る」の呼び名 | 同じ録音の画面を触るが、目的が別（表示の見切れと呼び名） | [#47](https://github.com/shuhei1101/voice-paste/issues/47) |
| 文字起こし中の表示を動かす・閉じる | 要望に含まれない。文字起こし中の表示は操作を持たない表示で、届け終えると閉じる | 予定なし |
| 「コピーのみ」で確定したときの、コピーの完了の通知と通知からの再コピー | 要望に含まれない（PR #48 のスレッドでユーザーが別件として依頼） | [#50](https://github.com/shuhei1101/voice-paste/issues/50) |
| 文字起こし中に、確定で選んだ出力先を切り替える | 要望に含まれない（PR #48 のスレッドでユーザーが別件として依頼） | [#51](https://github.com/shuhei1101/voice-paste/issues/51) |
