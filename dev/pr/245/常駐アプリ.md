## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 要求のタイムアウト | `httpx.Client` に `timeout=None` を渡し、応答・接続・書き込み・プールの待ちの全てに上限を設けない | 引数を外すと httpx の既定の 5 秒が掛かるため、`None` を明示する |
| 定数 | `OPENAI_TIMEOUT_SEC`・`OPENAI_CONNECT_TIMEOUT_SEC` をコードとモジュール構成から削除する | 他に参照する箇所は無い |
| 再送 | 回数・間隔・対象の例外を変えない | `httpx.TimeoutException` を再送の対象に残す（アプリ側で上限を設けなくても、相手側や OS で切れたときに送出されうる） |
| 単体テスト | `httpx.Client` に `timeout=None` が渡ることを確かめるテストを足す | 引数を外しただけの実装（httpx の既定の 5 秒）を検出するため |
| 外部 API の制約 | 非機能要件の `external_constraint` の公式の SDK の既定値の記述は事実として残す | 決定値と根拠だけを書き換える |
