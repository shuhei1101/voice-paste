# 設定画面の「変えた値を捨てる確認」の件数で、用語集の変更の数え方を決めて結合テストで確かめる

## 概要

ユーザーが設定画面を閉じるときの「変えた値を捨てる確認」で、用語集の変更が決めた数え方の件数で出るようにし、結合テストで確かめる。

## 背景

[Issue #98](https://github.com/shuhei1101/voice-paste/issues/98) の要望。
[PR #97](https://github.com/shuhei1101/voice-paste/pull/97) のレビューの任意の指摘の切り出し。
develop の [settings_window.py](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/ui/windows/settings_window.py) の `SettingsWindow._flat_values` は、用語集の一覧・補正に使う用語集・行を変えた用語集の行をそれぞれ 1 件として数え、用語集を 1 つ足すだけで 2 件になる。
確認の件数に用語集の変更が入ることを確かめる結合テストも無い。
