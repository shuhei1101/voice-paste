# 要件

## 要望

- 設定のエンジン（`transcription.engine`）が途中の進みを返さない（`openai`）とき、外の端末の文字起こしの画面の文字起こし中（`running`）の件に、% と進みのバー（`result_progress`）を出さず「文字起こし中」だけを出す
- 進みを返すエンジン（`local_whisper`）のときは、今のまま「文字起こし中 {n}%」と進みのバーを出す
- 進みを返さないことは、インターフェース定義『文字起こしの結果を返す』（`GET /web/transcriptions/{job_id}`）のレスポンスに `reports_progress: bool` を追加して画面へ伝える。今のレスポンスの項目は変えない
- 進みを返すかの判定は、デスクトップの文字起こし中の表示（#204 の `UiDeps.reports_progress`。`main.py` の `_reports_progress`）と同じ判定を使い、画面ごとに判定を分けない
