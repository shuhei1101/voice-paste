# 録音の画面のボタンに出すホットキーを、設定で出す・出さないを切り替えられるようにする

## 概要

ユーザーが、録音の画面のボタンにホットキーを出すか出さないかを設定で選べるようにする。

## 背景

[Issue #86](https://github.com/shuhei1101/voice-paste/issues/86) の要望。
録音の画面のボタンに出すホットキーが見切れて読めないという報告のうち、ボタンを 2 行にしてキーキャップ風に出す部分は [#47](https://github.com/shuhei1101/voice-paste/issues/47)（作業 PR [#82](https://github.com/shuhei1101/voice-paste/pull/82)）で入った。
残る「ホットキーの表示・非表示を切り替えたい」をこの PR で扱う。
develop の [recording_window.py](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/ui/windows/recording_window.py) の `HotkeyButton` は、ホットキーが空でなければ常に名前の下にキーを出し、出さない設定は無い。
