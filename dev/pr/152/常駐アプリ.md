## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 補正に使う行 | `load_glossary` は、オンで誤変換が入っている行を補正に使う（正しい表記の空を問わない） | 誤変換が空の行は今と同じく飛ばす |
| 置き換え | `apply_glossary` は、正しい表記が空の行では誤変換を空文字へ置き換える。ログは「{誤変換}→（消す）」と出す | 行の順に当てる規則は変えない |
| 今の CSV の正しい表記が空の行 | 消す行として扱う | CSV の列は増やさない |
| 入力チェック | 正しい表記の欄の「正しい表記を入れてください。」を外す。誤変換の欄のチェックは残す | エラーの一覧の行の失敗は誤変換だけになる |
| 消す行の表示 | 用語集の行の表の上に「正しい表記を空にすると、誤変換を消す。」を出す | 行ごとの表示は置き換える行と同じ |
| 保存 | `save_glossary` は今と同じく正しい表記が空の行を書く（両方が空の行だけを捨てる） | 変えない |
| 既存機能への影響 | API から始めた録音・連続録音の区間の補正も同じ `apply_glossary` を通るため、同じく消える | インターフェース定義は変えない |
