## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 実機での確かめ | PoC 検証で、develop の常駐アプリを実機の画面に出して起動し、要件.md の 3 点を 3 つの切り替え先で確かめる。前面になったかは、届けた後にメモ帳へ貼られたかと、前面の窓がメモ帳のままかで見る | 外から読めない観点（日本語フォントでの見た目など）だけをユーザーへ回す |
| 前面になるとき | PoC を不成立とし、要件の見直し案を出す | - |
| ついて動かないとき | `HeadRow` の `startSystemMove` を、`mouseMoveEvent` で窓を `move()` する動かし方に替える | `HeadRow` を使う録音の画面も同じ動かし方になる |
| 名前と印が重なるとき | `SwitchButton` の名前と右上の丸い印が重ならない配置へ直す。採用したモック（[dev/mock/pages/transcribing-indicator/108/c-both/](https://github.com/shuhei1101/voice-paste/blob/develop/dev/mock/pages/transcribing-indicator/108/c-both/index.html)）のとおり、ボタンの右と上に余白を取って枠の外側へ印をはみ出させ、名前・ホットキーの文字と重ねない | 今は印を枠の内側（右端から 2〜16 px）に描いており、名前の右の余白 12 px より広いため重なる。余白の分だけ窓の幅が広がる |
| 3 点とも期待どおりのとき | 画面設計・モジュール構成設計・単体テスト作成・実装・結合テスト作成の行を対象なしで閉じる | - |

結論は成立。
前面を奪うことと、`startSystemMove` で窓が動かないことの 2 つの仮説はどちらも起きず、設計の見直しは要らない。
ボタンの見た目だけが期待と違い、`## 変更方針` の「名前と印が重なるとき」のとおり `SwitchButton` の配置を直す。

検証の前提: 最初の流しでは、検証スクリプトがメモ帳を前面にしただけで入力欄にフォーカスが無く（`InputSiteWindowClass`）、3 回で貼られなかった。
入力欄をクリックしてフォーカスを置く準備に直して流し直した結果を上の表に書いた（押す前に前面がメモ帳の入力欄でない回は、不成立にせずやり直す）。

最小再現コードの要点（[poc/transcribing_indicator_focus.py](https://github.com/shuhei1101/voice-paste/blob/0a28492ca9c76e84daf1e2f1591e47cb3fc8f614/poc/transcribing_indicator_focus.py) の `drag` と `run_case`）:

```python
# 実物のマウスで見出しの行をつかみ、10 px ずつ動かして、待ってから窓の左上とカーソルの差を読む
_move_cursor(x, y)
left0, top0, _, _ = win32gui.GetWindowRect(hwnd)
win32api.mouse_event(win32con.MOUSEEVENTF_LEFTDOWN, 0, 0)
time.sleep(DRAG_PRESS_WAIT_SEC)
cursor_x, cursor_y = win32api.GetCursorPos()
offset0 = (left0 - cursor_x, top0 - cursor_y)
for index in range(1, DRAG_STEPS + 1):
    _move_cursor(round(x + step * index), y)
    time.sleep(DRAG_STEP_WAIT_SEC)
    if index % DRAG_SAMPLE_EVERY == 0:
        left, top, _, _ = win32gui.GetWindowRect(hwnd)
        cursor_x, cursor_y = win32api.GetCursorPos()
        offsets.append((left - cursor_x, top - cursor_y))
win32api.mouse_event(win32con.MOUSEEVENTF_LEFTUP, 0, 0)

# ボタンを実物のマウスで押した直後・放した直後・届けた直後に、前面の窓がメモ帳かを読む
click(*geometry.buttons[result.target_output])
result.foreground_after_click = win32gui.GetForegroundWindow() == notepad.hwnd
```

diff の見どころ: 常駐アプリは `main()` から実機の画面に出して起動し、`voice_paste.main` の `HotkeyListener`・`open_input`・`lower_volume`・`restore_volume`・`SessionDeps`（文字起こしの戻りを 8 秒遅らせる）だけを差し替えている（`install_spies`）。
ホットキーの関数とマウスの操作は Qt のメインスレッドの外のスレッドから行い、画面の部品の位置はメインスレッドで読む（`MainThreadCall`）。
