# 設定画面のモックで、中くらいの幅のとき設定のキーとバッジが縦に折れないようにする

## 概要

利用者が、641〜768px 前後の幅で設定画面のモックを開いても、設定のキーと「再起動で反映」のバッジを縦に折れずに読めるようになる。

## 背景

[Issue #161](https://github.com/shuhei1101/voice-paste/issues/161) の要望。
[PR #159](https://github.com/shuhei1101/voice-paste/pull/159) のモックのレビューで、reviewer が対象外の逸脱として報告した。
#37 のモックの共通スタイルの 641px 以上の `.row` の規則で、設定のキーの列が狭い幅でほぼ 0 まで縮み、キーとバッジが 1〜2 文字ずつ縦に折れる。
実際の設定画面（Qt）には無い、モックの見た目だけの事象で、#37 のスタイルを使う後のモックにも同じ折れが出る。
