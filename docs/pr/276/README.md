# 今ある E2E のテストと、E2E だけが使う部品を develop から削除する

## 概要

develop から今ある E2E のテスト（`tests/e2e/`）と、E2E だけが使用する支えのコード・手順・設計書の記述を削除する。設計書のシナリオは残す。

## 背景

[Issue #275](https://github.com/shuhei1101/voice-paste/issues/275) の要望。
E2E はメジャーのリリースの前にまとめて作ることにし、0.x の間は回さず修正もしない。
今ある E2E は仕様の変更で古くなり、エージェントが参照して誤解するため削除すると決まった。
関係: [shuhei1101/ai-monitor#3317](https://github.com/shuhei1101/ai-monitor/issues/3317)
