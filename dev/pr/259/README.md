# 非機能要件テストと外部疎通テストで設定のモデルを既定の設定から組み立てる

## 概要

非機能要件テストと外部疎通テストが、設定のモデルを既定の設定から組み立てて、`ValidationError` を出さずに流れるようにする。

## 背景

[Issue #253](https://github.com/shuhei1101/voice-paste/issues/253) の不具合。
[#246](https://github.com/shuhei1101/voice-paste/pull/246)（9495b5f）で設定のモデルの項目が既定値を持たない必須の項目になり、設定のモデルを引数なしや一部の引数だけで作るテストが `--run-e2e` で `ValidationError`（Field required）で失敗する。
作業 PR [#251](https://github.com/shuhei1101/voice-paste/pull/251)（起点 [#250](https://github.com/shuhei1101/voice-paste/issues/250)）の PoC [#252](https://github.com/shuhei1101/voice-paste/pull/252) で見つかり、#251 は `tests/nfr/test_max_segment_length.py` を Windows と Linux で流すためにこの修正を待っている。
