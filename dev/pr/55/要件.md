# 要件

## 要望

`pip install -e . --group dev` で新しく作った venv に、faster-whisper 1.2.1 の `av.open(..., metadata_errors="ignore")` を受け付ける `av` の版が入るようにする。

- `pyproject.toml` の `dependencies` に `av>=11,<19` を足す（下限は faster-whisper の宣言 `av>=11` に揃え、上限は `metadata_errors` を受け付けない 19 を外す）
- 新しく作った venv に入る `av` が 19 未満になり、E2E の文字起こしのケース（下の表の `実行のみ` の行）が pass する
- 外部ライブラリの設計書に、`av` を直に宣言したことと、`av` 19 と faster-whisper 1.2.1 が組めない不具合と対処を残す

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `av` の上限を外す | faster-whisper が `av` 19 に対応した版を出すまで外せない。今回入れる上限を前提にする | 起票予定 |
| 推移的な依存まで版を固定するロックファイルの導入 | 依存は互換リリースの範囲で宣言する方針で、ロックファイルを持つかは依存の管理の方針の変更になる。今回の不具合は `av` の上限だけで直る | 予定なし |
