# 要件

## 要望

アプリの明暗を、設定画面「画面」のまとまりで「Windows の設定に従う」「ライト」「ダーク」から選べるようにする。
あわせてライト・ダークの配色を見直し、録音の画面が出ていることを背景のアプリから見分けられるようにする。
配色はモックで案を出し、ユーザーが選ぶ。

- 完了の定義
  - 「ライト」を選んで保存すると、OS がダークでも全ての画面（録音の画面・文字起こし中の表示・設定画面・ダイアログ・トレイのメニュー）がライトの配色になる。「ダーク」も同様
  - 「Windows の設定に従う」（既定）では、今と同じく OS の明暗で配色を選び、常駐中に OS の明暗を切り替えると画面の配色も切り替わる
  - 保存すると、再起動せずに開いている画面と次に出す画面へ効く
  - 明暗の項目を持たない今の `settings.toml` がそのまま読め、「Windows の設定に従う」として動く
  - ライトの窓の面・地は真っ白（`#ffffff`）にせず、録音の画面の窓が白い背景のアプリの上でも縁と面で見分けられる
  - ダークの録音の画面の窓も、黒い背景のアプリの上で縁と面で見分けられる

配色は録音の画面のモックの案 A（青みのグレー）にする（[確認ログ](./確認ログ.md)）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| トレイのアイコンの明暗 | アイコンは Windows のタスクバーの上に出し、アプリの明暗の設定の対象外 | 予定なし |
| Windows の通知（トレイの通知）の配色 | Windows が描き、アプリから色を変えられない | 予定なし |
| ライト・ダーク以外の配色（ハイコントラストや色の自由な指定） | 要望はライトとダークの 2 つ | 予定なし |
