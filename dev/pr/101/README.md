# 設定画面で保存しても画面を閉じないようにする

## 概要

ユーザーが設定画面で「保存」を押した後も、設定画面を開いたまま設定を続けられるようにする。

## 背景

[Issue #89](https://github.com/shuhei1101/voice-paste/issues/89) の要望。
今の設定画面は「保存」を押すと、確かめて settings.toml へ書いた後に画面を閉じる。
閉じる動きは [#37](https://github.com/shuhei1101/voice-paste/pull/37) で画面を作り直したときからのもので、画面設計『設定画面』の保存ボタンの action が「確かめて保存し、設定画面を閉じる」と定めている。
ホットキーの受付は設定画面を開いている間は止まり、閉じたときに今の設定で張り直す。
