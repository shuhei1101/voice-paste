# 実機のマイクで録音するテストを消し、録音のファイルを内部で渡して文字に起こすテストにする

## 概要

実機のマイクで録音するテストを消し、録音のファイルを内部で渡して文字に起こせるかを確かめるテストに置き換える。

## 背景

[Issue #65](https://github.com/shuhei1101/voice-paste/issues/65) のユーザーの依頼。
release PR [#52](https://github.com/shuhei1101/voice-paste/pull/52)（Sprint v0.3.0 の E2E、[#38](https://github.com/shuhei1101/voice-paste/issues/38)）の E2E の再実行中に、ユーザーから「実際にマイクを使って録音するテストは全部消す。やってよいのは、録音のファイルを内部で渡して文字に起こせるかを確かめるテストまで」と依頼があった。
ユーザーの家のマイクの環境を、テストの側は理解できないため。

- `tests/e2e/` の 8 ファイルは実機の常駐アプリを起こし、`tests/support/desktop.py` の `speak`（SAPI でスピーカーから読み上げてマイクに拾わせる）か API の開始で、実機のマイクで録音する
- `tests/nfr/` の API の開始・処理中・セッションの上限時間の 3 ファイルも実機のマイクで録音する
- release は、マイクで録る E2E の fail が残ったまま止まっている。#38 の E2E はこの PR の後に流す
