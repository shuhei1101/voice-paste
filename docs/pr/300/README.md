# フォルダ構成の設計書（layout）を作成し、今のフォルダ構成をレビューの観点で確認する

## 概要

レビューで voice-paste のフォルダ構成の問題を洗い出せるよう、knowledge のテンプレート（layout）の書式でフォルダ構成の設計書を作る。

## 背景

[Issue #269](https://github.com/shuhei1101/voice-paste/issues/269) の要望。
このリポジトリにはフォルダ構成の設計書が無く、フォルダ構成の問題をレビューで洗い出せない。
テンプレートは [shuhei1101/knowledge#219](https://github.com/shuhei1101/knowledge/issues/219) で knowledge に入り、スキーマのコピーを持たずに knowledge のスキーマを参照する方式は [shuhei1101/ai-monitor#3188](https://github.com/shuhei1101/ai-monitor/issues/3188) で決まった。
