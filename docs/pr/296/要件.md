# 要件

## 要望

- [docs/guide/API.md](../../guide/API.md) の「録音を開始する」に、次を記載する
  - 設定の `recording.keep_display_on` による抑止が効くのは、常駐アプリが動いている PC の画面だけ
  - API を呼ぶほかのシステムの画面を別の端末のブラウザで開いて録音を操作するときは、呼び出し元の画面が録音している間 Screen Wake Lock（`navigator.wakeLock.request("screen")`）を取得し、録音を終えたら解放する
- 常駐アプリと API の振る舞いは変えない
