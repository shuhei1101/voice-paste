# 要件

## 要望

外の端末の文字起こしの画面（`GET /web/`）に、録音の破棄と一時停止・再開を追加し、長い結果を折りたたんで、コピーのボタンを起こした文字の上に配置する。

- 録音中に、録った音声を送信せず、端末内の音声（IndexedDB）にも残さずに録音を止める操作（破棄）を追加する。破棄した後は録音していない状態に戻り、端末内の音声は破棄の前のまま変わらない
- 録音中に、録音を一時停止・再開する操作を追加する。一時停止している間は経過時間と残り時間が進まず、上限時間は録った時間で数える。一時停止している間も「録音停止・送信」と破棄を押せる
- 一時停止していることを、文言とマーカーで録音中と分けて出す（色だけに頼らない）
- 起こした文字が一定の長さを超えた結果は、先頭だけを出して折りたたみ、「続きを読む」で全文を出す。全文を出した後は折りたたみに戻せる
- コピーのボタンを、結果の 1 件の起こした文字の上に配置し、折りたたんだままでも全文をコピーする
- 画面設計『外の端末の文字起こしの画面』・シナリオ『ブラウザから音声を送信する』『ブラウザで結果を受け取る』『外の端末のブラウザから音声を送信して文字で受け取る』・モック・使い方『外の端末から文字に起こす』を合わせる
- マージの前に、起点 Issue のやりたいこと（破棄・一時停止と再開・折りたたみ・コピーのボタンの位置）から落とした機能が無いかを突き合わせて確認する

| 決めたこと | 内容 |
| --- | --- |
| 破棄・一時停止のボタンの配置と文言、破棄の前の確認 | 「録音停止・送信」の横に「一時停止」（一時停止中は「再開」）と「破棄」を並べ、スマホの幅では「録音停止・送信」を 1 行目に出す。破棄は「録音を破棄しますか」の確認を出してから止める |
| 折りたたむ長さ | 表示の行数で決め、5 行を超えたら折りたたむ |
