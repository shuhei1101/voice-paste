# プロジェクトの土台を入れ、着手前の片付けを済ませる

## 概要

既存の voice-paste に AI Monitor の土台（開発ドキュメントの骨格・アーキテクチャ図・非機能要件・README・CLAUDE.md）を入れ、着手前の片付けを済ませて、リバースエンジニアリングと方針決めへ進める状態にする。

## 背景

[Issue #6](https://github.com/shuhei1101/voice-paste/issues/6) の要望。
[#3](https://github.com/shuhei1101/voice-paste/issues/3) でユーザーが立ち上げを先に進めると回答して起票された。
既存コードはあるが開発ドキュメントが無く、旧形式の作業メモ（`docs/PR/`・`docs/issues/`）とエージェント向けの古いガイド（`.claude/skills/guide/`・`PROJECT_SKILL.md`・`CLAUDE.md`）が残っている。
develop は master の音量フェードの修正（`11a4faf` まで）を含まず、不要なブランチも残っている。
ユーザーは master のコードをビルドせずに普段使いしているため、ソースコードには手を入れない。
