# 要件

## 要望

- 設定の `transcription.engine` で、`local_whisper` に加えて OpenAI API（`openai`）を選べる。`openai` を選ぶと、録音の確定・API の完了・連続録音の区間・外の端末のブラウザの音声のどれも OpenAI API で文字に起こす
- OpenAI のエンジンにも、今の手がかり（表記のヒントのプリセットの語）を渡す
- OpenAI のモデルなど OpenAI だけが使う値は、エンジンごとの設定のグループ（`transcription.openai`）に置く
- API キーは環境変数 `OPENAI_API_KEY` があればそれを、無ければ `settings.toml` と同じフォルダの `secrets/openai_api_key` を読む（ユーザーが置いた `~/.config/voice-paste/secrets/openai_api_key` はそのまま読める）。Git の管理下にも `settings.toml` にも設定画面にもログにも出さない
- `faster-whisper`・`nvidia-cublas-cu12`・`nvidia-cudnn-cu12` を無条件の依存から外し、`local_whisper` で使う extra にする。extra を入れずに環境を作っても、`openai` を選んでいれば常駐アプリが起動し、録音・連続録音・文字起こし・届けるまでが動く
- 連続録音の VAD は、faster-whisper のパッケージが無くても今と同じ Silero VAD のモデルを開ける
- `local_whisper` を選んでいて extra が入っていない環境では、起動を止め、extra を入れて環境を作り直すよう理由を示す
- OpenAI のモデルの既定値は `gpt-4o-mini-transcribe` にし、手がかりは `prompt`、言語は `language` で渡す（[確認ログ](./確認ログ.md)）
- `local_whisper` を使う今の環境（Windows・既定の設定）の動きは変えない。起動のバッチファイルは今までどおり `local_whisper` の依存を含めて環境を作る
- faster-whisper が無いときの Silero VAD のモデルは、faster-whisper 1.2.1 が同梱する `silero_vad_v6.onnx` を常駐アプリのパッケージへ同梱し、そこから開く（ライセンスの表記を添える）
- 起動のバッチファイルは、常に `local_whisper` の extra を含めて `uv sync --frozen` を流す
