# 録音の画面のホットキーを見切れずに出し、「確定して届ける」の見出しを消す

## 概要

録音の画面で、ユーザーがどのホットキーでボタンを押せるかを見切れずに読めるようにし、出力先のボタンの上の「確定して届ける」の見出しを消す。

## 背景

[Issue #47](https://github.com/shuhei1101/voice-paste/issues/47) の要望。
録音の画面のボタンは名前の右にホットキーを並べており、ボタンの幅に収まらず `Ctrl` だけしか見えないことが多い。
「AI チャットへ送る」の呼び名は [#35](https://github.com/shuhei1101/voice-paste/issues/35)（[#44](https://github.com/shuhei1101/voice-paste/pull/44)）でカスタムプリセット（種類「ブラウザ添付」）へ置き換え済みで、トレイの通知に出る理由の文に「AI チャット」が残っている。
