## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ドメイン用語の「セッション」 | 「録音セッション」に置き換える。「セッションの ID」は「録音セッションの ID」、「API のセッション」は「API の録音セッション」にする | 文の中で既に「録音のセッション」と記載した箇所も「録音セッション」にそろえる |
| ドメイン用語の「返送先」 | 「コールバック先」に置き換える | - |
| 一般の単語のセッション | 「Xorg のセッション」「Wayland のセッション」「デスクトップのセッション」「セッションの種類」（デスクトップの種類）「セッションバス」は置き換えない | - |
| 設計書の名前と参照のキー | 名前に旧命名を持つ項目（NFR-1 の要件の名前・モジュール構成『常駐アプリ / セッション / service.py』など）は、名前と参照元の `[名前](id:...)`・`refs` を同じ commit で置き換える | 置き換えた後に設計書の検証のコマンドで参照の誤りが 0 件であることを確認する |
| 設計書の書き換えの手段 | YAML の設計書は `write_docs` の `text_edits` で置き換える | - |
| API の応答と設定の説明の文字列 | `CallbackNotAllowedError` の文言を「コールバック先のホストが許されていません」、設定の説明を「連続録音の録音セッションの上限時間」にする | 文言を照合するテストがあれば同じ文言へ修正する |
| コードのコメント・docstring | `src/`・`tests/` のドメイン用語の旧命名を置き換える | 識別子（`session`・`callback_url`・`features/session` など）は変えない |
| 用語集 | 種類 `glossary`（Schema は `schemas/glossary.schema.yaml`、置き場所は `docs/glossary/`）を足し、`docs/glossary/GLO-1.yaml` の `terms` の行ごとに `id`・`name`（新命名）・`description`（意味）・`avoid`（旧命名）を持たせる。`dev-docs.yaml` の `documents` に `alias_type: term`・`records: terms` の行を追加し、`docs/index.yaml` に `glossary/` の行を追加して README を生成し直す | 変えないと決めた単語（文字起こしワーカー・連続録音・区間）も、意味を添えて用語として記載する。設計書の検証は種類のフォルダで種類を決めるため、`docs/` の直下ではなく種類のフォルダに置く |
| open の Issue | [#258](https://github.com/shuhei1101/voice-paste/issues/258) の本文の「セッションの上限」を「録音セッションの上限」に置き換える | 反映作業『open の Issue の旧命名の置き換え』 |
| 既存機能への影響 | 動きは変えない。単体テストを全件流して pass を確認する | - |
