# 要件

## 要望

knowledge の規約『文章の書き方』の `## 語の選び方`、判定フローチャート『語の選び方』、規約『入力と文言』の `## 文言` を正として、次を直す。

| 対象 | 直し方 |
| --- | --- |
| 文章でない所（画面のボタン・ラベル・見出し・メッセージ、文書の見出し・表の列名・項目名・論理名） | 対応表の語に置き換える。対応表に無い語は判定フローチャートで決める |
| 文章 | 自然な文のまま残し、冗長表現（することができる・を行う）と話し言葉を直す。文の中の「消す」「直す」は意味が通れば残してよい |
| 画面のボタン | 漢語の「する」を省く（追加・プリセットを追加）。画面タイトルは名詞にする |
| 画面のメッセージ | エラーは「〜できませんでした」「〜が見つかりません」で終え、原因と対処を入れる。意思の確認は「〜しますか?」にする |
| 長音 | 語末の -er / -or / -ar / -y に付ける |
| 同じものの呼び名 | 1 つに揃える（例: 出力先の種類「エンドポイントへ送る」と文中の「送信」を混ぜない） |

ファイル名・見出し・項目の論理名を変えたときは、それを指すリンクと参照（設計書の項目のパス・`refs`・テストの関数名に出る論理名）も直す。
コードの識別子・Enum の値・定数・設定のキーは英語のまま変えない。

終わりの条件:

- 直した後に `集計/reposcan.py`（`/mnt/c/Users/shuhe/repo/knowledge/tmp/ui、ドキュメントの文章ベストプラクティス/集計/reposcan.py`）で数え直し、`## スコープ外` を除く範囲の前後の件数を PR に記載する。直す前は develop の `e782ed6` で 7190 件（427 ファイル、1 万字あたり 106.4）
- `reposcan.py` が数えない `.py` は、[集計/pyscan.py](./集計/pyscan.py) で、`src/voice_paste/ui/`・`src/voice_paste/shared/settings.py`・`src/voice_paste/features/outputs/`・`tests/` の文字列リテラル（docstring・式文だけの文字列・ログの呼び出しの引数を除く）を同じパターンで数え直し、前後の件数を PR に記載する。直す前は develop の `e782ed6` で 139 件（25 ファイル）
- 残った件数は全て、文章の中の自然な用法か、`## スコープ外` の範囲のもの

画面に出す語はユーザーの目に触れる語彙のため、置き換えの一覧（[常駐アプリ.md](./常駐アプリ.md) の `## 画面の文言の置き換え`）はユーザーが承認した（[確認ログ](./確認ログ.md)）。
