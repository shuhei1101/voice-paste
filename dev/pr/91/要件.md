# 要件

## 要望

出力先「貼り付けて送信」が貼り付けた後に送る Enter を、設定で選んだ修飾キーを押したまま送る。
修飾キーは Ctrl・Alt・Shift の 3 つで、それぞれを設定画面「出力先」のまとまりのチェックボックスでオン・オフする。

- 完了の定義
  - Ctrl だけをオンにすると、貼り付けて設定の秒数（`enter_delay_sec`）を置いた後に Ctrl+Enter を送る
  - 2 つ以上をオンにすると、オンにした修飾キーを全て押したまま Enter を送る
  - 全てオフ（既定）なら、今と同じく Enter だけを送る
  - 設定画面で切り替えて保存すると、再起動せずに次の届けから効く
  - 修飾キーの項目を持たない今の `settings.toml` がそのまま読め、全てオフとして動く

ブラウザ添付の「Enter まで送る」プリセットの Enter には修飾キーを当てず、今と同じく Enter だけを送る。

設定画面では、欄の名前「Enter と一緒に押す修飾キー」の右に、「Ctrl」「Alt」「Shift」のチェックボックスを並べる。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| Win キーを Enter と一緒に押す | 要望は Ctrl・Alt・Shift で、Win キーとの組み合わせは Windows のショートカットに当たりやすい | 予定なし |
