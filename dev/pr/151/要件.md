# 要件

## 要望

`pyproject.toml` の改行を LF に揃え、`uv add` / `uv remove` で依存を変えた行だけが差分になるようにする。

- `pyproject.toml` の CRLF の行を LF に書き換えて commit する（中身の文字は変えない）
- `dev/設計書/開発コマンド/開発コマンド.yaml` の `依存の追加・更新・削除` の `effects` から、改行の混在で全行が差分になる記述を消す
- 基準:
  - `git ls-files --eol pyproject.toml` が `i/lf` を出す
  - `git diff --ignore-all-space` で `pyproject.toml` の差分が出ない（改行のほかに変わった文字が無い）
  - `uv.exe add {パッケージ}` を流した後の `git diff --stat pyproject.toml` が、足した行のぶんだけを出す

## 影響するユースケース

なし（アプリの振る舞いを変えず、`pyproject.toml` の改行と開発者が打つコマンドのページの記述だけを変える）。
