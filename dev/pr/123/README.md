# 画面の結合テストを 1 つのプロセスで全件流しても止まらず遅くならないようにする

## 概要

結合テストを設計書『テスト実行方法』の全件実行（1 つの pytest プロセス）で流して、画面の結合テストが止まらず全件 pass するようにする。

## 背景

[Issue #95](https://github.com/shuhei1101/voice-paste/issues/95) の不具合。
[PR #94](https://github.com/shuhei1101/voice-paste/pull/94) の結合テスト作成で、implementer が対象外として報告した（[報告](https://github.com/shuhei1101/voice-paste/pull/94#discussion_r4244672002)）。

- `tests/integration/ui` を 1 つのプロセスで流すと、`test_tray.py`・`test_recording_window.py` などを先に流したときに、後のテストの 1 件ごとの時間が延び続けて終わらない
- [PR #97](https://github.com/shuhei1101/voice-paste/pull/97) でも同じ事象が出て、ファイルごとに別のプロセスで流して全 pass を確かめた（[完了報告](https://github.com/shuhei1101/voice-paste/pull/97#discussion_r4253641137)）
- 「続けて回すと遅くなる」報告は [#110](https://github.com/shuhei1101/voice-paste/issues/110) から移された
