# 要件

## 要望

- 設定 `transcription.openai.model` の既定のモデルを、`gpt-4o-mini-transcribe` から後継のモデルへ変える
- OpenAI API への要求の手がかり・言語の渡し方を、設定のモデルごとに選ぶ
  - `gpt-transcribe` は、手がかりの語を `keywords[]`、言語を `languages[]` で渡し、`prompt` は送信しない
  - `gpt-4o-mini-transcribe`・`gpt-4o-transcribe`・`whisper-1` は、今のまま手がかりを `prompt`、言語を `language` で渡す
  - settings.toml で `gpt-4o-mini-transcribe` を指定した設定でも、今と同じ要求で起こせる
- 候補のモデルを料金・精度・手がかりと言語の渡し方で比べてユーザーへ示し、ユーザーが決めたモデルを既定にする
- 決めたモデルで OpenAI API を実際に呼び、文字起こしが返ること（疎通）を外部疎通テストで確かめ、決めたモデルとあわせてユーザーへ知らせる（[#213](https://github.com/shuhei1101/voice-paste/issues/213)）

`未確定`: 既定のモデル（決める段: 単一ユースケース設計の承認確認）

| 案 | 内容 | メリット | デメリット | 備考 |
| --- | --- | --- | --- | --- |
| A | `gpt-transcribe` | 今の `POST /audio/transcriptions` で使える後継。手がかりを語ごとに `keywords[]` で渡せる | 料金が $0.0045 / 分で、今の既定（$0.003 / 分）の 1.5 倍 | [モデルのページ](https://developers.openai.com/api/docs/models/gpt-transcribe) |
| B | `gpt-live-transcribe` | 話しながら起こせる | Realtime（`v1/realtime/transcription_sessions`）だけで、`POST /audio/transcriptions` で使えない。料金が $0.017 / 分 | [モデルのページ](https://developers.openai.com/api/docs/models/gpt-live-transcribe) |

推奨: A

後継のうち、録音を確定してから送信する今の方式で使えるのは A だけで、B はリアルタイムの文字起こしの方式を新しく作る必要がある。
精度の数値の比較は OpenAI が公開しておらず、決めたモデルで外部疎通テストを流して確かめる。
今の既定の `gpt-4o-mini-transcribe`・`gpt-4o-transcribe`・`whisper-1` は、どれも 2027-02-26 に提供が終わる（[Deprecations](https://developers.openai.com/api/docs/deprecations)）。

`未確定`: 設定画面で保存した settings.toml に書かれた `gpt-4o-mini-transcribe` の扱い（決める段: 単一ユースケース設計の承認確認）

設定画面の保存（`save_settings`）は全てのキーを書くため、一度でも設定画面で保存したユーザーの settings.toml には `model = "gpt-4o-mini-transcribe"` が書かれており、既定のモデルを変えてもそのユーザーには届かない。

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 書かれた値はそのまま使い、提供終了の前にユーザーが設定画面で変える | ユーザーの書いた値を書き換えない | 変え忘れると提供終了の後に文字起こしが失敗する |
| B | 読み込み時に `gpt-4o-mini-transcribe` を後継のモデルへ読み替えて settings.toml を書き換える | 変え忘れが無い | ユーザーが選んだ値を書き換える |

推奨: A

要望の「前のモデルを指定した設定でも動く」はユーザーの指定を保つことを求めており、書き換えは規約『ユーザー確認が必須な事項』の既存データの移行に当たる。
