# 要件

## 要望

- `voice_paste/` の全体（録音・音量の制御・文字起こし・貼り付け・トレイ・GUI・設定画面・履歴）と、起動の仕組み（`voice-paste.bat`・`activate.bat`・`setup/`）から、今の振る舞いを写した設計書を起こす
  - 起こすのはシナリオ（複合 UC・単一 UC）と、現状の棚卸し（外部 API・外部ライブラリ・設定・データ・アーキテクチャ図のサブシステムの粒度の部品の一覧）
  - 抽出するのは何を実現したいか（要件・ユースケース・外部システムとの接点）で、クラス / 関数 / 変数の命名・モジュール分割・処理の組み立て方は設計書に持ち込まない
  - 未実装・組みかけの機能は「実装なし」として記録する
  - 設定の既定値は根拠のない暫定値として写し、非機能要件の目標値にしない
- 起動口の `voice-paste.bat` はショートカットから使っているため、要るものとして記録する（中の整理は作り直しで行ってよい）
- 見つけた改善点は Issue に切り出さず、`dev/pr/10/リスクと技術的負債.md` に溜める。次の観点は漏らさず拾う
  - 責務が混ざっている箇所（`main.py`・`gui.py`・`settings_gui.py` のような大きなファイル）
  - 録音・区切り・文字起こし・補正・貼り付けが部品として分かれているか。貼り付けを外し、ほかのシステムから文字起こしを使えるようにする（[#1](https://github.com/shuhei1101/voice-paste/issues/1)）ための切れ目
  - 文字起こしのエンジン（ローカルの Whisper・OpenAI）の付け替えやすさ
  - 設定の持ち方（`.env` と設定画面から書き換える設定）
  - 置き換えたほうがよいライブラリ
  - GUI の見た目・メニュー項目の並びや分け方で、整理したほうがよいところ
  - 分かっている不具合（[#4](https://github.com/shuhei1101/voice-paste/issues/4)）と、足したい機能（[#5](https://github.com/shuhei1101/voice-paste/issues/5)）を作り直しで受けられるか
  - テスト（残す価値がなければ、作り直す前提で消す案でよい）
- コード（`voice_paste/`・`tests/`・`setup/`・起動のバッチファイル）は変えない
