# 要件

## 要望

設定画面を閉じたら（保存して再起動・今すぐ再起動・取り消し・窓の閉じる・アプリの終了のどの経路でも）、その `SettingsWindow` と、設定画面が作ったトップレベルの窓を破棄する。

- 完了の定義
  - offscreen で一式を作り、`open_settings` → 設定画面を閉じるを 5 回繰り返し、毎回 `deleteLater` の破棄を流して `gc.collect()` した後のトップレベルの窓の数が、開く前の数と同じ（今は 1 回ごとに 3 つ増え、5 回で 3 → 18）
  - 同じ測り方で、残る `SettingsWindow` が 0
  - 閉じた後に `open_settings` を呼ぶと、新しい設定画面が開く（前面に出すだけで終わらない）
  - 設定画面で値を変えたまま終了・再起動しても、変えた値を捨てる確認で止まらずに抜ける（[#71](https://github.com/shuhei1101/voice-paste/pull/71) の振る舞いを保つ）
