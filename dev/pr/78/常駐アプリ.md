## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 作成機能 | 開始で連続録音を指定すると、完了が来るまで録音を止めないセッションを始める。指定しなければ今の 1 回の録音 | `POST /sessions` の body の `continuous` |
| 区切り | 話し声の後で無音が設定の長さ以上続いたところで区間を切り出し、録音は止めない。無音だけの間は区間にしない | 見つけ方は Silero VAD（PoC で確かめた）。無音の長さは設定 `api.continuous.min_silence_sec`。無音が来ないまま区間の最大の長さ（30 秒）に達したら、直近の短い無音の中か今の位置で区切る |
| 文字起こし | 区間を区切った順に 1 つずつ今の文字起こしのワーカーで起こし、用語集で補正する。前の区間を起こしている間に区切った区間は順に待たせる | 録音に遅れず追いつくかを PoC で測る |
| 履歴・監査 | 区間ごとに録音と起こした文字を履歴に残す（履歴を残す設定のとき） | - |
| 通知 | 区間ごとに返送先へ送り、各返送に区間の通し番号を付ける。完了で最後の区間を送った後、終わりと区間の数を 1 回送る | 区間は `segment_number`、終わりは `result` の `completed` / `truncated` と `segment_count` |
| エラー返却 | 区間の文字起こしの失敗はその区間の `failed` として返送し、セッションは続ける。返送先に届かない区間は今の再送の後にログへ書き、次の区間へ進む | - |
| 停止・完了 | 完了で録音を止め、残りの話し声を最後の区間として起こしてから終わりを返送する | 連続録音への停止（`/stop`）は止めずに 409 で断る |
| 上限 | 連続録音のセッションの長さに上限を持ち、達したら完了と同じく残りを起こして終わりを返送する | 1 回の録音とは別の上限時間を設定 `api.continuous.session_limit_sec`（既定 4 時間）に持つ |
| 既存機能への影響 | 連続録音を指定しない開始・ホットキーの録音は今のまま。連続録音の間も入口をまたいだ排他を保つ | - |
| 性能 | 区切ってから返送が届くまでの時間を非機能要件に決める | 3 秒（PoC の実測 2.53 秒から） |

結論: 成立（要件の見直し後）。合意した成功条件のうち、背景音（ノイズ）の区切りの正しさと、境目の一致の 2 つを満たさなかった。背景音（ノイズ）は、区間が長くなるのを受け入れると要件を見直して決着した（[確認ログ](./確認ログ.md)）。境目の一致は下の終わりの位置の取り方の違いで、区切りの判定は一致している。

- 核心のリスクは起きなかった。録音を止めずに区切り、区間の文字起こしが話す速さに追いついた（区切ってから文字が出るまで最大 2.53 秒、待ち行列は常に 1 以下、かかった時間 ÷ 区間の長さは 0.08〜0.17）。境目での欠けも無かった
- 境目の一致は、無音で閉じた区間は全て 0.00 秒、最大の長さで閉じた区間は 0.43 秒で、外れたのは完了で閉じた最後の区間だけ。終わりの位置の取り方の違いで、区切りの判定の違いではない
- 背景音（ノイズ）では区切りの無音をわずかに超える 2.1 秒の間で区切れなかった。一度に渡しても同じで、ノイズの中では VAD が無音と判定する時間が 2 秒に届かない
- 人の声を含む背景音は話し声と見分けられない。結論の適用範囲の外とする

最小再現コードの要点（`poc/continuous_segmentation.py` の `StreamingVad` と `Segmenter._step`）:

```python
# 1 窓ごとに h・c・前の 64 サンプルを持ち越して Silero VAD を呼ぶ
batch = np.concatenate([self.context, window])[np.newaxis, :]
output, self.h, self.c = self.session.run(None, {"input": batch, "h": self.h, "c": self.c})
self.context = window[-VAD_CONTEXT:]

# 区間が MAX_SEGMENT_SEC に達したら、直近の短い無音の中か今の位置で区切る
if self.position - self.speech_start >= MAX_SEGMENT_SEC * SAMPLE_RATE:
    cut = self.last_short_silence or self.position
    self._emit(cut, cut, "最大の長さ")
# 話し声の後で確率が NEG_THRESHOLD 未満の時間が MIN_SILENCE_SEC 続いたら区切る
if prob < NEG_THRESHOLD:
    if not self.temp_end:
        self.temp_end = self.position
    silent = self.position - self.temp_end
    if silent >= SHORT_SILENCE_SEC * SAMPLE_RATE:
        self.last_short_silence = self.temp_end + silent // 2   # 最大の長さで区切るときの候補
    if silent >= min_silence:
        self._emit(self.temp_end + pad, self.temp_end, "無音")
```

diff の見どころ: `poc/continuous_segmentation.py` の `StreamingVad`（状態の持ち越し）・`Segmenter`（区切りと最大の長さ）・`run_scene`（入力のコールバックを模したブロックの流し方と計測）。実測値は `poc/results/results.json`（[927db73](https://github.com/shuhei1101/voice-paste/commit/927db73939297ec8992b83a5997b52c415708bfb)）。
