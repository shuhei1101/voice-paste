## 要望

次の 4 行に、knowledge の規約『文書のタグと description の記載』と『タグと用語の登録』に沿って、`topic:`・`tool:` のタグと、「何を受け持ち、どんなときに参照するか」の 1 文の description を付ける。

| ファイル | 行 | 付けるもの |
| --- | --- | --- |
| `docs/mock/files.yml` | `pages/settings/288/index.md` | `tags` |
| `docs/mock/files.yml` | `refs/288/index.md` | `tags` |
| `docs/_root/files.yml` | `../index.md` | `description`・`tags` |
| `docs/_root/files.yml` | `../design-policy.md` | `description`・`tags` |

- `docs/mock/files.yml` の 2 行のタグは、同じファイルの同じ種類の行に揃える（`pages/settings/*` は `topic:モック`・`topic:画面`、`refs/*` は `topic:モック`・`topic:pr`）
- `docs/_root/files.yml` の 2 行のタグは、#315 で設計書に付けた語彙から、使用されているタグを `group_by: tags` で確かめて選ぶ
- description は規約『タグと用語の登録』の点検の表（1 文・40〜120 字・Issue 番号とファイルのパスを書かない）を満たす
