# 文書と画面の文言の語を、knowledge の語の選び方の規約に合わせて修正する

## 概要

利用者と開発者が、画面の文言と文書の見出し・表・項目名を、元の英語を推測せずに読めるようにする。

## 背景

[Issue #174](https://github.com/shuhei1101/voice-paste/issues/174) の要望。
knowledge の規約『文章の書き方』の `## 語の選び方`・判定フローチャート『語の選び方』・規約『入力と文言』（[shuhei1101/knowledge#34](https://github.com/shuhei1101/knowledge/issues/34) で入った）を正として、このリポジトリの文書と画面の文言を直す。
画面のボタン・ラベル・メッセージと、設計書・公開ドキュメントの見出し・表・項目名に「送る」「足す」「消す」「直す」「版」「節」「印」「口」「形」「段」「題」などの和語・一字の語が多く使われている。
knowledge 側の文書の修正（[shuhei1101/knowledge#46](https://github.com/shuhei1101/knowledge/issues/46)）は済んでいる。
