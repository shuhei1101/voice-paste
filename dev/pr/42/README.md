# voice_paste_legacy と配布用のビルド・移行用の仕組みを消す

## 概要

起動を新しい構成へ切り替えた後に残る `voice_paste_legacy/`・配布用のビルドの仕組み・python-dotenv の依存・移行のために置いた一時的な仕組みを消し、参照も残さない。

## 背景

[Issue #23](https://github.com/shuhei1101/voice-paste/issues/23) の要望。
作り直しの方針（[#13](https://github.com/shuhei1101/voice-paste/issues/13)、記録は [#12](https://github.com/shuhei1101/voice-paste/pull/12) の `dev/pr/12/方針決め/`）の移行の Issue の並びの順 10（最後）にあたり、方針の終わりの定義「旧いコードと配布用のビルドの仕組みが消えている」を満たす。
起動の切り替え（[#22](https://github.com/shuhei1101/voice-paste/issues/22)、[#41](https://github.com/shuhei1101/voice-paste/pull/41)）は develop に入っており、ショートカットは新しい構成を起動する。
`voice_paste_legacy/` は普段使いから外れたが、`pyproject.toml`・テスト・計測のスクリプト・設計書が今も参照している。
連続録音と [#5](https://github.com/shuhei1101/voice-paste/issues/5) は、この後に API の上へ足す。
