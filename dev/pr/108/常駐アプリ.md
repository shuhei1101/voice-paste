## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 出力先の差し替え | `SessionManager` に、ホットキー・トレイから始めたセッションが transcribing の間だけ固定の出力先へ差し替える入り口を足す。差し替えたら `output_id` を書き換えて状態の変化を知らせる。transcribing 以外・API のセッション・カスタムプリセットで確定したセッション・オフの出力先は何もしない | ロックの中で状態を確かめて書き換える |
| 届ける出力先 | ワーカースレッドは届ける直前にロックの中で今のセッションを引き直し、その出力先で届ける | 差し替えと届け始めが重なったときは、先にロックを取った方で決まる |
| 切り替えの操作 | 各出力先の確定のホットキーを文字起こし中は切り替えへ繋ぎ、文字起こし中の表示に出力先ごとのボタン（名前の下にホットキー）を並べる。ボタンを押しても前面にならない（下のフォーカスの行） | 録音開始と同じキーの出力先は、文字起こし中は録音を始めずに切り替える |
| ボタンのホットキーの表示 | 切り替えのボタンに出すホットキーは、録音の画面の確定のボタンと同じく `ui.show_hotkeys` がオフなら出さない | 設定の title と使い方の説明を両方の画面に効く形に直す。録音の画面と文字起こし中の表示で分けるのはスコープ外（要件.md） |
| 窓を動かす | 文字起こし中の表示を、録音の画面と同じく見出しの行をつかんでドラッグで動かせるようにする。見出しの行・つかむ印・名前の下にホットキーを出すボタンは、録音の画面の部品を `ui/windows/window_parts.py` へ移して 2 つの窓で使う | 動かした位置はその回だけ使う（録音の画面と同じ） |
| 今の出力先の表示 | 文字起こし中の表示が、開いたときと差し替えの知らせを受けたときに今の出力先の名前を出す | 名前は `UiDeps.output_titles` から引く |
| フォーカス | 文字起こし中の表示は `WindowDoesNotAcceptFocus` のまま出し、切り替えのボタンを押しても見出しの行をつかんでも前面にならないようにする（前面を戻す処理は持たない）。ホットキーはフォーカスを動かさない | 結合テストは offscreen で Windows の前面を確かめられないため、実装の後に実機の Windows で、メモ帳に入力欄のフォーカスを置いたまま切り替えのボタンを押し・見出しの行を動かしても、届けたときにメモ帳へ貼られることと、見出しの行を動かしている間に窓がカーソルについて動くことを確かめ、`## テスト結果` に書く。前面になる場合は差し戻して設計を見直す。ついて動かない場合は、`QWindow.startSystemMove` の代わりに見出しの行の `mouseMoveEvent` で窓を `move()` する |
| 既存機能への影響 | 録音中・一時停止中の確定のホットキーとボタン、API の録音の流れは変えない | - |
