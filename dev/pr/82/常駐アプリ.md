## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ホットキーの表示 | 録音の画面の全てのボタンで、ホットキーを途中で切らずに出す。どちらの出し方でも、ボタンの大きさを中の名前とホットキーのラベルが要る大きさから決める（今は `QPushButton` の大きさが中のラベルを数えず、ラベルの要る幅より狭くなって切れる）。ホットキーが空のボタンは名前だけを出す | 出し方は名前の下にキーキャップ風（[要件](./要件.md) の `## 要望`） |
| 見出し | `outputs_heading`（確定して届ける）を画面設計と実装から消す。見出し「カスタムプリセット」は残す | - |
| 理由の文 | `open_app_window` が送出する `DeliveryError` の理由の文と、ログ・`opener.py` と `integrations/browser/__init__.py` のコメントの「AI チャット」を、ブラウザ添付のプリセットの呼び名に替える。決めた文言をモジュール構成の `open_app_window` の処理に書き、`test_open_app_window_when_failed` の期待値に理由の文を足す | 文言は [要件](./要件.md) の `## 要望` |
| 既存機能への影響 | ボタンの押したときの動き・ホットキーの受け付け・並び（主の操作・3 件ずつの折り返し）は変えない | - |
| 結合テスト | 見出し「確定して届ける」を確かめるテストを、出ないことを確かめるテストに替え、ホットキーが切れずに描かれることを確かめるテストを足す | - |
