# 設計書の flow を mermaid のコードブロックで囲む

## 概要

設計書の `flow` を ```` ```mermaid ```` のコードブロックで囲み、生成した Markdown で図として表示されるようにする。

## 背景

[Issue #205](https://github.com/shuhei1101/voice-paste/issues/205) の要望。
[#204](https://github.com/shuhei1101/voice-paste/pull/204) のレビューで、reviewer が対象外の逸脱として報告した。
共通の型 `mermaid`（`共通.schema.yaml#/$defs/mermaid`）は ```` ```mermaid ```` のコードブロックで書くことを求めているが、develop の一部の `flow` が囲まれていない。
Issue を起票した後に入った [#210](https://github.com/shuhei1101/voice-paste/pull/210)・[#220](https://github.com/shuhei1101/voice-paste/pull/220) も、囲まれていない `flow` を追加している。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.md) | 要望の整理・影響する UC 一覧・更新ドキュメント・スコープ外 |
| [常駐アプリ](./常駐アプリ.md) | 常駐アプリの計画書（シナリオとインターフェース定義の `flow` の囲み） |
