# 設定画面の文字起こしの設定をエンジンごとのタブに分け、選んでいないエンジンの設定も変えられるようにする

## 概要

ユーザーが設定画面の文字起こしの設定をエンジン（ローカルの Whisper・OpenAI API・Haas（WSL））ごとに分けて見られ、今選んでいるエンジンに関係なく、どのエンジンの設定も変えられるようにする。

## 背景

[Issue #272](https://github.com/shuhei1101/voice-paste/issues/272) の要望。
設定画面の「文字起こし」のまとまりは、エンジンの選択・ローカルの Whisper の欄・OpenAI API の欄・Haas の欄を 1 つの頁に縦に並べていて、どのエンジンの設定がどれかが分かりにくい。
Haas の認識の調整の欄を増やす [#271](https://github.com/shuhei1101/voice-paste/issues/271)（作業 PR [#273](https://github.com/shuhei1101/voice-paste/pull/273)）が並行して進んでいる。
