# 設定画面で保存が通ったら、前に出したエラーの一覧と欄の下のエラーを消す

## 概要

利用者が、設定画面で保存に通らなかった欄を直して保存し直したとき、前に出したエラーの一覧と欄の下のエラーが消え、保存が通ったことを見分けられるようになる。

## 背景

[Issue #169](https://github.com/shuhei1101/voice-paste/issues/169) の不具合。
`SettingsWindow.save` は保存が通った後に `_clear_errors` を呼んでおらず、前に出したエラーがどのまとまりでも残る。
画面設計『設定画面』のエラーの一覧（`error_summary`）は、保存を押して確かめに通らない欄があったときに出す要素で、保存が通った後も残す記述は無い。
[PR #166](https://github.com/shuhei1101/voice-paste/pull/166) の結合テスト作成で見つかり、切り出した。
