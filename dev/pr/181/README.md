# 起動のバッチファイルで .venv が使えなければ uv sync で作り直し、作れないときは理由を表示して止める

## 概要

ユーザーが `.venv` の無い・壊れたクローンでもショートカットから常駐アプリを立てられ、環境を作れないときは失敗したことと理由が分かるようにする。

## 背景

[Issue #178](https://github.com/shuhei1101/voice-paste/issues/178) の不具合。
[#114](https://github.com/shuhei1101/voice-paste/pull/114) で環境は `uv sync --frozen` で `.venv/` に作る構成に変わったが、`voice-paste.bat` は `.venv` が無いとシステムの `pythonw` で `-m voice_paste` を起動する。
システムの Python には voice_paste と依存が入っておらず、`pythonw` はコンソールを持たないため、起動に失敗してもエラーがどこにも出ない。
`start` の終了コード 0 で終わるため、`launcher.log` にも失敗が残らない。
