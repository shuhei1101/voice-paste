# AI Monitor v0.3.0 の配布物へ追従する

## 概要

voice-paste が準拠する AI Monitor の配布物を v0.2.0 から v0.3.0 へ追従する。

## 背景

[Issue #216](https://github.com/shuhei1101/voice-paste/issues/216) の要望（配布元が起票した追従 Issue）。
[ai-monitor-version.ini](https://github.com/shuhei1101/voice-paste/blob/develop/ai-monitor-version.ini) は v0.2.0 のままで、`dev/テンプレート/` の Schema のうち 7 つが v0.3.0 と違う。
規約・判定フローチャート・チェックシート・フェーズ手順と全プロジェクト共通のルール索引（`rules.global.yaml`）は、AI Monitor のクローンから直接読んでいる。
