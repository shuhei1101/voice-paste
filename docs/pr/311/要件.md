# 要件

## 要望

`haas_server/` の中を、マニフェスト（`pyproject.toml`・`uv.lock`）・起動スクリプト（`start.sh`）・コード（`__init__.py`・`main.py`・`app.py`・`audio.py`）に分けて配置する。
コードは knowledge の規約『pyproject.toml 標準テンプレート』の src レイアウトに合わせる。

動きは変えない。
次のものは変えない。

| 対象 | 今の値 |
| --- | --- |
| パッケージ名 | `haas_server`（`python -m haas_server.main {ポート}` で起動する） |
| 起動スクリプトが受ける引数 | 受けた引数を全て `haas_server.main` へ引き渡す |
| サーバーの環境の置き場所 | WSL の ext4 の `~/.local/share/voice-paste/haas_server/.venv` |
| ログの置き場所 | WSL の中の `~/.local/state/voice-paste/haas_server.log` |
| 単体・結合テストを実行する環境 | 常駐アプリと同じ `.venv` |

移したファイルを指す起動する側のパス（[src/voice_paste/integrations/haas/server.py](https://github.com/shuhei1101/voice-paste/blob/7d9ae053c7ce87a869492c465d3ada707cca6a6b/src/voice_paste/integrations/haas/server.py) の `HAAS_SERVER_DIR`）・テスト・`haas_server/files.yml`・`tests/files.yml`・`dev-docs.yaml`・設計書・公開ドキュメントを、移した後のパスに統一する。

| 対象 | 配置先・方法 | 根拠 |
| --- | --- | --- |
| コード | `__init__.py`・`main.py`・`app.py`・`audio.py` を `haas_server/src/haas_server/` へ移動する | リポジトリの直下の `src/voice_paste/` と同じ src レイアウトにする |
| コードの行の `files.yml` | `haas_server/src/files.yml` へ移動する | リポジトリの直下の `src/files.yml` と同じ配置にする。`src/` の中身が `haas_server/` だけにならない |
| マニフェスト・起動スクリプト | `pyproject.toml`・`uv.lock`・`start.sh` は `haas_server/` の直下に配置したままにする | リポジトリの直下の `pyproject.toml`・`voice-paste.sh` と同じ配置にする。`start.sh` だけのフォルダは knowledge の規約『フォルダ構成の切り方とレビュー』の「中身が 1 つだけのフォルダは作らない」に該当する |
| サーバーの起動での import | `package = false` のまま、`start.sh` が `haas_server/src` へ移って `-m haas_server.main` を起動する | 利用者の WSL のサーバーの環境を作り直さずに済む |
| テストでの import | 直下の `pyproject.toml` の pytest の `pythonpath` に `haas_server/src` を加える。別のプロセスでサーバーを動かす結合テストは環境変数 `PYTHONPATH` で同じフォルダを渡す | テストのコードの import 文（`haas_server.*`）を変えずに済む |
