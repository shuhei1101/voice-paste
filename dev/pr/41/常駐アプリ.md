## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 起動のバッチファイル | `voice-paste.bat` の起動先を `pythonw -m voice_paste`（引数なし）に替える。venv の有効化・CUDA の DLL の `PATH`・`chcp 65001`・`FOR_DISABLE_CONSOLE_CTRL_HANDLER` は保つ。今日以外の日付のログを消す処理は外す | 起動の記録の置き場所は `未確定`（[要件](./要件.md)） |
| 起動の引数 | `--data-dir` を任意にし、渡さなければ `resolve_app_paths(None)` で platformdirs の置き場所を使う。`--migrate-env` はそのまま | E2E・非機能要件テストは今までどおり `--data-dir` に一時フォルダを渡す |
| `voice-paste` コマンド | `[project.scripts]` の `voice-paste` を `voice_paste.main:main` へ向ける | `voice_paste_legacy` は [#23](https://github.com/shuhei1101/voice-paste/issues/23) で消すまで `python -m voice_paste_legacy` で起動できる |
| 品質シナリオ 3 | 話し終えてから貼り付くまでの時間を新しい構成で 20 回測る非機能要件テストを足し、中央値が 1.08 秒以下であることを確かめる。区間は刷新前と同じく録音を止めた時点から貼り付けのキーを押す直前まで | 実機のマイクと GPU を使うため `--run-e2e` を付けたときだけ走らせる。測る道具（本物の起動へホットキーを送るか、`build_handlers` の配線を直に呼ぶか）はモジュール構成設計で決める |
| 並走の記述 | 設定・ER 図・テスト実行方法の「並走の間」の記述を、普段使いが新しい構成になった後の内容に書き直す | `.env` と `voice_paste_legacy` の記述は [#23](https://github.com/shuhei1101/voice-paste/issues/23) で消す |
| テスト | `parse_args` と `main` の単体テストに、`--data-dir` を渡さないときに platformdirs の置き場所を使うことを足す（platformdirs の置き場所は差し替えて、普段使いの置き場所に触れない） | - |
