# 要件

## 要望

| No | 要件 | 終わりの条件 |
| --- | --- | --- |
| 1 | 設定画面と録音を同時に使用できる | 設定画面を開いたまま、録音開始のホットキーとトレイの「録音を開始」で録音を始めて確定・取り消しできる。設定画面のホットキーの欄で押したキーは、録音・確定・取り消しを動かさない |
| 2 | 設定画面が既にあるときは、トレイから開くとそのウィンドウを最前面に戻す | 設定画面がほかの窓の裏にあるときも最小化しているときも、トレイの「設定…」で新しい窓を作らずに既存の窓を最前面に出し、フォーカスを移す（Windows・Linux） |
| 3 | 用語集のプリセットを切り替えるショートカットを登録できる | ショートカットの行にキーの組み合わせと用語集のプリセットを登録して保存すると、そのキーで補正に使用する用語集のプリセット（`active_glossary_preset`）がそのプリセットに切り替わり、次の録音の補正に使用される |
| 4 | トレイのメニューから、設定画面の「用語集」「ショートカット」の箇所を直接開ける | トレイのメニューの項目を選ぶと、設定画面がそのまとまり（箇所）を選んだ状態で開く。既に開いていれば最前面に戻してそのまとまりへ切り替える |
| 5 | ショートカットの行と行の追加を、設定画面の上のほうに配置する | ショートカットのまとまりを開いたとき、スクロールせずに登録済みの行と行の追加ボタンが見える |
| 6 | 4 のメニューから「ショートカット」を開いたときは、行を 1 つ追加した状態で開く | 追加した行の用語集のプリセットの欄に、既定の用語集のプリセットが入っている |

- No 3 のショートカットは、キーを押すと補正に使用する用語集のプリセットを切り替えるものとする（利用者が Issue の起票元の話し合いで決めた解釈）
- No 6 の既定の用語集のプリセットは、追加した行の用語集のプリセットの欄の初期値とする（同上）
- 既存の settings.yaml はそのまま読み込めるようにする（設定のキーは追加だけ）

- 録音から届けるまでの間も、トレイから設定画面を開いて保存できる。保存した値は、動いている録音には使用せず次の録音から使用する
- ショートカットで切り替えたときは、切り替えたプリセットの名前をトレイの通知で出す

- ショートカットは設定画面のまとまりのメニューの先頭に「ショートカット」のまとまりを作り、見出しの右に「行追加」を配置する。行は「キーの組み合わせ」と「切り替える用語集のプリセット」
- トレイのメニューの「設定…」の直下に「用語集の設定…」「ショートカットの設定…」を並べる
