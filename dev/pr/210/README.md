# Linux で、キーの表示（Win → Super）と既定のホットキー・貼り付けのキーを Ubuntu に合わせる

## 概要

ユーザーが Ubuntu で、Super と表示されたキーの組み合わせを見て、GNOME の既定のショートカットとぶつからないホットキーで録音し、端末アプリを含むアプリへ貼り付けられるようにする。
Windows の表示と既定値は変えない。

## 背景

[Issue #198](https://github.com/shuhei1101/voice-paste/issues/198) の要望。
[#196](https://github.com/shuhei1101/voice-paste/issues/196)（[#202](https://github.com/shuhei1101/voice-paste/pull/202)）で Linux で常駐アプリが起動するようになったが、キーの表示と既定値は Windows の前提のままになっている。
設定画面・トレイ・録音の画面は pynput の `<cmd>` を「Win」と表示し、Linux の端末アプリでは貼り付けのキーが `Ctrl+Shift+V` になる。
起動から貼り付けまでを通すことと起動の手段は [#199](https://github.com/shuhei1101/voice-paste/issues/199)、Wayland は [#200](https://github.com/shuhei1101/voice-paste/issues/200) で扱う。
