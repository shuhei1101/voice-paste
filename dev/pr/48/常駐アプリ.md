## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 動かす | 録音の画面をドラッグで動かせるようにする。窓はタスクバーに出ない小さな枠なしの窓のまま保ち、見出しの行（状態・経過時間の行）をつかんで動かす | モック `dev/mock/pages/recording-window/48/a-head-controls/` |
| 隠す | 録音中にその回だけ録音の画面を隠す操作を置く。隠してもセッションの状態・録音・経過時間のストップウォッチは止めず、ホットキーの一時停止・取り消し・確定はそのまま効く。次の録音ではいつもどおり出す | 見出しの右端に「隠す」（横線のアイコン）と「×」を置く |
| 戻す | 隠した録音の画面を、トレイ（アイコンの左クリック・メニューの「録音の画面を出す」）と録音開始のホットキーから戻す。戻すときはフォーカスを取らずに出し、隠したときの経過時間・状態（録音中・一時停止中）のまま出す | 録音開始と同じホットキーの出力先がある設定では、今どおりその出力先で確定する |
| 閉じる | 閉じるボタン（×）を置き、押すと「取り消す」のボタンと同じく `UiDeps.cancel` を呼んで窓を閉じる | - |
| 前面 | 隠したとき・× で閉じたときに、前面が録音を始める前の貼り付け先へ戻ること（[#39](https://github.com/shuhei1101/voice-paste/pull/39) の PoC で確かめた振る舞い）を保つ | - |
| 位置 | 動かした位置はその回だけ使い、次の録音は `ui.position`・`ui.follow_cursor` で決まる位置に出す。文字起こし中の表示は、隠した回も出し、録音の画面を動かした回は確定した時点の録音の画面の位置に、動かしていない回は設定の位置に出す | - |
| 既存機能への影響 | `recording.hide_window`（常に出さない設定）・API から始めた録音（画面を出さない）・`ui.topmost`・`ui.follow_cursor` の振る舞いは変えない | - |
| テスト | 録音の画面とトレイの画面設計に足す要素・`action` ごとに結合テストを足し、録音する・トレイから操作するのシナリオに足すシナリオごとに E2E を足す | 足したシナリオの `test` は、設計書の検証がテスト関数の無い名前を受け付けないため、E2E テスト作成の段で関数と一緒に置く |
