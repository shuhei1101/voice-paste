# 設定画面のオンのチェックボックスの描画の結合テストを Linux でも通す

## 概要

設定画面のオンのチェックボックスの描画を確かめる結合テスト 4 件が、Linux でも Windows でも pass するようにする。

## 背景

[Issue #212](https://github.com/shuhei1101/voice-paste/issues/212) の報告。
[#210](https://github.com/shuhei1101/voice-paste/pull/210) の結合テスト作成で、Linux（Ubuntu 24.04）の `test_check_indicator_when_checkbox_on`・`test_check_indicator_when_checkbox_disabled`（`light`・`dark`）が fail すると分かった。
2 つのテストは、既定の設定で `recording.lower_volume` のチェックボックスがオンで出ることを準備にしている。
[#202](https://github.com/shuhei1101/voice-paste/pull/202) で Linux の `recording.lower_volume` の既定値が `False` になり、Linux ではこの準備が成り立たない。
