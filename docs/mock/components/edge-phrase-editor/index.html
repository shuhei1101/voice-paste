文言の一覧の欄

設定画面の「ハルシネーション」のまとまりに置く、文頭・文末から削除する文言の一覧の部品。行ごとに文言の欄と位置（文頭・文末・両方）の選択欄を並べ、表の下に「行を追加」と当てる決まりを置く。案 A は行の右端の上へ・下へ、案 B は行の左端のつまみで並べ替える。採用は案 B。

案 A: 通常（既定の一覧）

文頭・文末から削除する文言（上の行から順に当てる）
文言位置行の操作

削除する文言はまだありません。無い間は、文頭・文末から何も削除しません。

上の行から順に当てる。* は任意の文字列に一致する。

先頭の行の上へと、末尾の行の下へは押せない。

案 A: 追加した直後

文頭・文末から削除する文言（上の行から順に当てる）
文言位置行の操作

削除する文言はまだありません。無い間は、文頭・文末から何も削除しません。

上の行から順に当てる。* は任意の文字列に一致する。

「行を追加」で末尾に空の行を追加し、文言の欄へフォーカスを移す。位置の既定は文末。

案 A: 長い文言・3 つの位置

文頭・文末から削除する文言（上の行から順に当てる）
文言位置行の操作

削除する文言はまだありません。無い間は、文頭・文末から何も削除しません。

上の行から順に当てる。* は任意の文字列に一致する。

長い文言は欄の中で横に流し、行の高さを変えない。
