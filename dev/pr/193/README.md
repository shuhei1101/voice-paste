# 例外のメッセージの語を、語の選び方の規約に合わせて修正する

## 概要

利用者が、設定画面の入力チェック・トレイの通知・API の呼び出し元へ返るエラーで、例外のメッセージを文書と画面の文言と同じ語で読めるようにする。

## 背景

[Issue #190](https://github.com/shuhei1101/voice-paste/issues/190) の要望。
作業 PR [#189](https://github.com/shuhei1101/voice-paste/pull/189)（起点 Issue [#186](https://github.com/shuhei1101/voice-paste/issues/186)）は `src/`・`tests/` のコメント・docstring・ログの文言の語を修正し、利用者の目に触れる例外のメッセージを `## スコープ外` としてこの Issue へ切り出した。
`src/` の例外のメッセージ 3 か所に、knowledge の規約『文章の書き方』の `## 語の選び方` で避ける語（形・送り先・送れ・落ちた）が残っている。
