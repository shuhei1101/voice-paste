# 要件

## 要望

- トレイのメニューに、履歴のフォルダ（Windows は `%LOCALAPPDATA%\voice-paste\history\`、Linux は `~/.local/share/voice-paste/history/`。データの配置先を引き渡した起動ではその下の `history`）を開く項目を追加する。フォルダが無ければ作ってから開く
- トレイのメニューに、「録音を開始」と並べて、音声ファイルを 1 つ選んで文字に起こす項目を追加する
- 選んだ音声ファイルは、録音を確定した後と同じ流れ（設定のエンジンでの文字起こし・文頭と文末の決まった文言の削除・用語集の補正）で文字に起こし、ホットキーから始めた録音と同じ出力先の選び方で届ける
- 録音から届けるまでの間（API から始めた録音の間を含む）は、音声ファイルを選ぶ項目を押せなくする。音声ファイルの文字起こしから届けるまでの間は、録音を始められない
- 読めない音声ファイルを選んだときは、文字起こしの失敗と同じくトレイの通知で知らせ、待機中に戻る

- 音声ファイルから起こした結果は履歴に残さない。選んだ音声ファイルは元の場所から読み、コピーも移動もしない（要望の主な使い方は履歴の WAV の起こし直しで、残すと起こし直すたびに履歴に同じ録音が増えるため。単一ユースケース設計で決定）
- 選べる音声ファイルの形式は、外の端末の画面と同じく PyAV で音声のストリームを読める形式にする。形式は拡張子ではなく中身を開いて決める（2 つの入口で起こせるファイルを揃えるため。単一ユースケース設計で決定）
