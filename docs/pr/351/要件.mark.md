# 要件

## 要望

`project-index.yaml` の `nav` の「設計書」「コード」タブのサイドバーで、入れ子にしたほうが探しやすいグループを入れ子にする。

- 決まりは knowledge の規約『開発ドキュメントのナビゲーション』（`dev-docs-navigation`）に従う。入れ子は 2 階層までにし、上の階層は利用者の作業か機能の単位で分ける
- 1 つのグループを分けるかと分ける軸は、判定フローチャート『サイドバーのグループの分け方』（`flowchart-sidebar-group-split`）で、グループごとに決める
- 書き方は project-index の [設定](https://github.com/shuhei1101/project-index/blob/develop/docs/guide/設定.md) の `### nav` に従う
- 修正した後、開発ドキュメントサーバーの画面（入れ子にしたグループを開いた状態）をスクリーンショットで確認する
