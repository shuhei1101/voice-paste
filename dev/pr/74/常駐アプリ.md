## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 出力先の定義 | 出力先の ID・表示名・届ける関数に加え、出力先ごとの設定のモデル（各出力先のパッケージの `settings.py`）と、配線で注入するものを選ぶ関数（`inject`）を `OUTPUTS` の 1 件に持たせる | 外部連携の関数と今の設定は `OutputDeps` に束ねて渡す |
| 設定のモデル | 出力先の一覧の検証と既定の一覧を、`OUTPUTS` の定義から `build_settings_model` で組み立てる（`main.py` の `SETTINGS_MODEL`）。`settings.toml` の `outputs` の形と、ID の重なり・ホットキーの重なりの確かめは今のまま | 今の設定ファイルをそのまま読めることを単体テストで確かめる |
| 配線 | `_wire_outputs` は出力先の定義が持つ注入するものを部分適用し、出力先の ID ごとの表を持たない | - |
| 設定画面・録音の画面 | 出力先の名前は `UiDeps.output_titles`、出力先固有の欄（貼り付けて送信の Enter までの間）は設定のモデルの項目から引く。表示と操作は変えない | `ui` は `features` を import しない |
| テスト | 試しの出力先を 1 つ登録しただけで、設定の読み書き・確定のホットキー・設定画面の欄・録音の画面のボタン・届けに乗ることを確かめる。既存の単体・結合テストは全て通す | - |
| 依存の向き | import-linter の検査を通す | - |
