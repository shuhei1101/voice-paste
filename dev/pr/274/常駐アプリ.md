## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 区画の作り方 | 「文字起こし」の頁の先頭にエンジンの選択を置き、その下にエンジンごとの区画を置く | エンジンごとのタブ（[確認ログ](./確認ログ.md)） |
| 区画の欄 | ローカルの Whisper は今の「文字起こし（エンジン）」のエンジンの選択以外の欄と「文字起こし（詳しい調整）」の欄、OpenAI API と Haas（WSL）は今の各まとまりの欄と補助文をそのまま移す | 欄の部品・欄の名前・補助文は変えない |
| 編集 | どの区画の欄も、エンジンの選択に関係なく使える状態のままにする。保存は全ての区画の欄をまとめて確かめて書く | 今と同じ |
| OS で出さない欄 | 区画の欄が全て hidden_setting_keys にあるときは区画を出さない（Linux の Haas（WSL）） | `transcription.engine` の選択肢「Haas（WSL）」の出し方は今のまま |
| エラーの一覧 | 行を押すと「文字起こし」のまとまりとその欄の区画へ切り替えて欄へフォーカスを移す | |
| E2E の操作 | ResidentApp に区画を選ぶ操作を足し、test_change_settings の `transcription.local_whisper.beam_size` を変える前にローカルの Whisper の区画を選ぶ | |
