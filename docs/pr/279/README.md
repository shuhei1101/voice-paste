# ドメイン用語の「セッション」を「録音セッション」に、「返送先」を「コールバック先」に置き換え、用語集に登録する

## 概要

文書・設計書・画面の文言・コードのコメント・open の Issue に残る旧命名「セッション」「返送先」を、話し合いで決めた新命名「録音セッション」「コールバック先」に置き換え、用語集に新命名と使用しない旧命名を記載する。

## 背景

[Issue #278](https://github.com/shuhei1101/voice-paste/issues/278) の要望。話し合いで voice-paste のドメイン用語の命名を見直して新命名を決めたが、リポジトリの文書・設計書・画面の文言・Issue は旧命名のまま残っている。
リポジトリには、ドメイン用語を参照する用語集のページが無い。
同じ文書を書き換える [#257](https://github.com/shuhei1101/voice-paste/issues/257)（mdmark の表し方への移行）は、この PR の後ろに回っている。
