# 既存コードの作り直しの方針を決める

## 概要

現状の設計書とリスクと技術的負債の一覧を入力に、作り直し（[#1](https://github.com/shuhei1101/voice-paste/issues/1)）の方針をユーザーと決め、方針の Issue と移行の Issue を起票する。

## 背景

[Issue #11](https://github.com/shuhei1101/voice-paste/issues/11) の要望。
[#3](https://github.com/shuhei1101/voice-paste/issues/3) のリバースエンジニアリング（[#10](https://github.com/shuhei1101/voice-paste/pull/10)）で、現状のシナリオ・外部 API・外部ライブラリ・設定・データ・サブシステム一覧を起こし、改善点を[リスクと技術的負債の一覧](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/10/%E3%83%AA%E3%82%B9%E3%82%AF%E3%81%A8%E6%8A%80%E8%A1%93%E7%9A%84%E8%B2%A0%E5%82%B5.md)に溜めた。
ユーザーは master のコードをビルドせずに普段使いしており、起動は `voice-paste.bat` のショートカットで行っている。
