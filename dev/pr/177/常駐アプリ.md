## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定 | `transcription.local_whisper` に足すオプションのキーを持ち、反映は既存のキーと同じく再起動 | 足すオプションと既定の値は PoC 検証で決める（`要件.md` の `## 要望` の `未確定`） |
| 送る行 | クライアントが transcribe の行に足すオプションを載せる | 既存の `no_speech_threshold` と同じ載せ方 |
| 設定画面 | 「文字起こし（詳しい調整）」のまとまりの既存の欄と同じ並びに、足すキーの欄を足す | 欄の表示名は画面設計で決める |
| 既存機能への影響 | API から始めた録音・連続録音の区間も同じワーカーで起こすため、同じく定型句が出にくくなる | インターフェース定義の入出力は変えない |
| 性能 | 話し終えてから貼り付くまでの時間が、非機能要件の決定値に収まることを PoC で測る | 収まらなければ、`word_timestamps` の要らない組み合わせを選ぶ |
