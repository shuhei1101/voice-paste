# 要件

## 要望

設定画面のチェックボックスで、オンにした項目にチェックの印が出ない原因を調べ、オン・オフが見た目で見分けられるようにする。
対象は、明るい組・暗い組の両方のテーマでの設定画面の全てのチェックボックス（欄・プリセット・手がかりの語・用語集の「有効」の切り替えを含む）とする。

あわせて、アプリの画面の「印」（ラジオボタンの選んだ印・選択欄の開く印・つまみ・選んだボタンの印など、状態を表す小さな記号）を明るい組・暗い組で確かめ、見えない・見分けられないものがあれば同じ PR で直す。

印の見た目は次のとおりにする（[確認ログ](./確認ログ.md)）。

| 対象 | 見た目 |
| --- | --- |
| オンのチェックボックス・選んだラジオボタン | 箱と点を `accent_fg` で塗り、明暗ともチェックを `surface` で描く |
| オフのチェックボックス・選んでいないラジオボタン | `text_muted` の線で描く |
| ラジオボタンの選択肢の間 | 20px（印と名前の間の 8px より広くする） |
| チェックボックス・ラジオボタンのフォーカス | 印と名前の組を `accent_fg` の 1px の枠で囲む |
| 選択欄の開く印 | 別の枠を持たせず、`text_muted` の線の V 字を置く |
