# 要件

## 要望

Linux（Ubuntu 24.04 の Xorg のセッション）で、キーの表示と既定のキーを Ubuntu に合わせる。
Windows の表示と既定値、設定のスキーマは変えない。

- 表示
  - Linux の設定画面・トレイ・録音の画面・文字起こし中の表示で、pynput の `<cmd>` を「Super」と表示する（Windows は「Win」のまま）
  - 表示名は [#196](https://github.com/shuhei1101/voice-paste/issues/196) で作った OS の判定（`shared/os_kind.py`）から引く
- 既定のホットキー（`hotkeys.*`・`outputs[].hotkey`・`presets[].hotkey`）
  - Linux の既定のホットキーが、Ubuntu 24.04 の GNOME の既定のショートカットとぶつからずに働く
  - ぶつからないキーは Windows と同じ既定値のままにし、ぶつかるキーだけ Linux の既定値を共通の既定値への OS ごとの上書き（`OS_DEFAULT_OVERRIDES`）で変える
- 貼り付けのキー（`keyboard.paste_key`）
  - Linux の既定の貼り付けのキーで、一般のアプリ（テキストエディター・ブラウザ）へ貼り付けられる
  - Linux で端末アプリ（GNOME Terminal 等）へ貼り付ける手段がある
    - アクティブなウィンドウが端末アプリなら `Ctrl+Shift+V`、それ以外なら設定の貼り付けのキーを送信する
    - アクティブなウィンドウは Xorg から読む（python-xlib を `pyproject.toml` に Linux の条件付きの直接の依存として追加し、外部ライブラリの設計書を追加する）
  - Linux では、貼り付けのキーの主キーを XTEST で送信し、GTK4 のアプリ（GNOME Text Editor 等）でも貼り付けられる

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| Ubuntu の Xorg のセッションで起動から貼り付けまでを通すことと、Linux の起動の手段と手順 | 別の Issue の範囲 | [#199](https://github.com/shuhei1101/voice-paste/issues/199) |
| Wayland のセッションでのホットキーと貼り付け | 別の Issue の範囲。端末アプリの判定も Xorg のセッションに限る | [#200](https://github.com/shuhei1101/voice-paste/issues/200) |
| Linux での E2E の実行 | E2E の前提が Windows に依存し、Linux で通すしくみは #199 で扱う | [#199](https://github.com/shuhei1101/voice-paste/issues/199) |
| Ubuntu 以外のデスクトップ環境（KDE 等）の既定のショートカットとのぶつかり | 対応する Linux は Ubuntu 24.04 の GNOME（非機能要件『動作環境』） | 予定なし |
