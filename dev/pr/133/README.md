# 文字起こし中の表示の出力先の切り替えとドラッグを、実機の Windows で確かめる

## 概要

利用者が、文字起こし中の表示で出力先を切り替えたり窓を動かしたりしても、貼り付け先のフォーカスを奪われずに起こした文字を受け取れることを、実機の Windows で確かめる。

## 背景

[Issue #112](https://github.com/shuhei1101/voice-paste/issues/112) の要望。
[PR #108](https://github.com/shuhei1101/voice-paste/pull/108)（起点 [Issue #51](https://github.com/shuhei1101/voice-paste/issues/51)）で、文字起こし中の表示に出力先の切り替えのボタンを並べ、見出しの行をつかんでドラッグで動かせるようにした。
#108 の計画書の `フォーカス` の行は実装の後に実機で確かめることを求めていたが、offscreen の結合テストでは窓が前面になるかを確かめられない。
ユーザーの判断で、#108 は確かめずにマージし、確かめをこの Issue に切り出した（[スレッド](https://github.com/shuhei1101/voice-paste/pull/108#discussion_r4300614516)）。
