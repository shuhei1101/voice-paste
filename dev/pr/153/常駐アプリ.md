## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 出力先のプリセットの変更の数え方 | 要件.md の `## 要望` で決めた数え方で、`_changed_count` の件数に出力先のプリセットの変更を入れる | 足す・消すだけでは並べ替えに数えない |
| 数えに使う値 | `PresetListPanel` に開いたとき・保存したときのプリセットを並べ替え・消しても追える番号を持たせ、プリセットごとの値と、残っているプリセットどうしの順を返すメソッドを足す。`_flat_values` は種類・位置・項目ごとのキーの代わりにこの値を入れる | `HintPresetPanel.change_values` と同じ形にする |
| 保存の後の基準 | 保存が書けた後に、種類ごとの `PresetListPanel` の番号を今の並びで振り直す | `HintPresetPanel.mark_saved` と同じ順 |
| 確認を出すかの判定 | 出力先のプリセットを変えていれば確認を出し、変えていなければ出さない今の判定を保つ（件数が 0 か） | 保存の直後に閉じても確認を出さない今の順（保存の後に `_baseline` を置き直す）を保つ |
| 保存する値 | `collect` が返す `presets` の値は変えない | 数えだけを変える |
| 保存した知らせのホットキーの文 | `_hotkey_changed` は `_flat_values` の `presets.{種類}[{位置}].hotkey` のキーで出力先のプリセットのホットキーを比べているため、数えの値から外した後も、ホットキーの欄の値（`hotkeys.*`・`outputs[].hotkey`・種類ごとのタブの中の何件目かのプリセットの hotkey）を開いたときの値と比べて決める | 「新しいホットキーは、設定画面を閉じると効きます。」を出す条件を今のまま保つ。`SettingsWindow.save` の単体テスト `test_save_when_hotkey_changed` にカスタムプリセットの確定のホットキーを変えるケースを足して確かめる |
| 結合テスト | プリセットを足す・消す・項目を変える・同じプリセットの項目を 2 つ変える・並べ替える操作と、2 つのプリセットを変える操作、途中のプリセットを消す操作（並べ替えに数えない）、2 つの種類のタブで変える操作、保存してから並べ替える操作で、確認の本文の件数を確かめる | `tests/integration/ui/test_settings_window.py` |
