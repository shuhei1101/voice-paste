トレイ

常駐アプリの入口。アイコンで状態を示し、右クリックでメニューを開く。アイコンの左クリック（既定の操作）は「録音を始める」と同じ。

状態ごとのアイコン

  • 準備中
  • 待機中
  • 録音中
  • 文字起こし中
  • 失敗

アイコンにかざすと「voice-paste: 待機中」のように状態を文字でも出す。色だけで状態を伝えない。失敗は、文字起こしのエンジンを準備できなかった起動のときだけで、次の起動まで続く。

待機中のメニュー

  • 録音を始める Ctrl+Alt+D
  • 設定…
  • 設定フォルダを開く
  • ログフォルダを開く
  • 再起動
  • 終了

録音から届けるまでの間のメニュー

  • 録音を始める（処理中） Ctrl+Alt+D
  • 設定…（処理中）
  • 設定フォルダを開く
  • ログフォルダを開く
  • 再起動
  • 終了

API から始めた録音の間も同じ。「再起動」・「終了」を選ぶとアイコンはすぐ消え、再起動・終了はその回を届け終えてから行う。

準備に失敗した起動のメニュー

  • 録音を始める（準備に失敗） Ctrl+Alt+D
  • 設定…
  • 設定フォルダを開く
  • ログフォルダを開く
  • 再起動
  • 終了

設定を直して「再起動」できるよう、「設定…」は押せるまま残す。失敗の理由はトレイの通知で知らせる。
