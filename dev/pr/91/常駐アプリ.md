## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定 | `PasteAndSendSettings` に `enter_with_ctrl`・`enter_with_alt`・`enter_with_shift` の 3 つの真偽値の項目を足す。既定は全て `false`、反映は `immediate` | 設定の設計書に行を足した |
| 既存の設定との互換 | 項目を持たない `settings.toml` は既定の値（全てオフ）で読む。保存しても他のキーの値とコメントは変えない | 今の設定の読み書き（tomlkit）のまま |
| Enter の送り方 | `send_enter` が押したままにする修飾キーを受け、修飾キーを順に押し、Enter を押して離し、修飾キーを逆順に離す | `send_paste` と同じ順。修飾キーが無ければ今と同じ |
| 貼り付けて送信 | `paste_and_send` は送る直前に今の設定の修飾キーを読み、`send_enter` に渡す | 秒数（`get_enter_delay_sec`）と同じく呼ぶたびに今の設定を読む |
| ブラウザ添付 | 変えない。Enter まで送るプリセットは修飾キーを押さずに Enter だけを送る | - |
| 設定画面 | 設定のモデルの型から欄を組み立てる今の仕組みで、「出力先」のまとまりに 3 つのチェックボックスが並ぶ。画面設計の補足「まとまりと欄」に行を足す | 欄の名前は `未確定`（要件の論点。決める段: 画面設計） |
| ログ | `send_enter` の `[INFO]` に一緒に押した修飾キーを出す | - |
| シナリオ | 起こした文字を届けるに、修飾キーをオンにした貼り付けて送信の正常シナリオを足す。今の正常シナリオのセットアップに、修飾キーが全てオフであることを足す | 起こした文字を届けるは E2E を置かない（#65）。修飾キーを押す順は単体・結合テストで確かめる |
