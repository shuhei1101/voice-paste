# ブラウザの機能（/web/）の下で、Origin の無い POST を手元のプロセスから受け付ける

## 概要

同じ端末のほかのプロセス（MindStella のサーバー 等）が、Origin を付けずに `POST /web/transcriptions` へ音声を送信し、文字起こしのジョブを積めるようになる。

## 背景

[Issue #256](https://github.com/shuhei1101/voice-paste/issues/256) の要望。
[shuhei1101/mindstella#402](https://github.com/shuhei1101/mindstella/issues/402) で、MindStella のサーバーがプレビューで録音した音声を `POST /web/transcriptions` へ送信し、`GET /web/transcriptions/{job_id}` で結果を取得する。
今の常駐アプリは、`/web/` の下では Origin の無い GET・HEAD だけを通し、Origin の無い POST を 403 で拒否するため、Origin を付けないサーバーからの送信が通らない。
ユーザーは voice-paste を変更して Origin の無い POST を通す案を選んだ（[mindstella#402 のコメント](https://github.com/shuhei1101/mindstella/issues/402#issuecomment-6596079207)）。
