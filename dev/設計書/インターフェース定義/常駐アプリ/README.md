# 常駐アプリ

常駐アプリの API と、呼び出し元への返送

## 目次

<!-- table: data -->

| ページ | 概要 |
| --- | --- |
| [録音を開始する.py](./録音を開始する.py.yaml) | POST /sessions。画面を出さない録音（連続録音を含む）を始めてセッションの ID を返す |
| [録音を停止する.py](./録音を停止する.py.yaml) | POST /sessions/{session_id}/stop。録音を止めて完了を待つ |
| [録音を完了する.py](./録音を完了する.py.yaml) | POST /sessions/{session_id}/complete。録音を確定して文字起こしを始める |
| [呼び出し元へ返す.py](./呼び出し元へ返す.py.yaml) | API から始めた録音の結果（連続録音は区間ごとと終わり）を、開始で指定された返送先へ送る |
| [上限で打ち切る.py](./上限で打ち切る.py.yaml) | 完了が来ないままセッションの上限時間に達した API の録音を打ち切り、履歴に残して返送先へ知らせる |
| [設定のエンドポイントへ送る.py](./設定のエンドポイントへ送る.py.yaml) | 起こした文字を、設定の送り先のエンドポイントへ JSON で 1 回送る |
| [画面を配信する.py](./画面を配信する.py.yaml) | GET /web/。外の端末のブラウザで開く文字起こしの画面と素材を返す |
| [音声を受け付ける.py](./音声を受け付ける.py.yaml) | POST /web/transcriptions。ブラウザから送られた音声を積んでジョブの ID を返す |
| [文字起こしの結果を返す.py](./文字起こしの結果を返す.py.yaml) | GET /web/transcriptions/{job_id}。ジョブの状態・進み具合と、起こした文字か失敗の理由を返す |
| [ブラウザの音声を文字に起こす.py](./ブラウザの音声を文字に起こす.py.yaml) | 受け付けたブラウザの音声を 1 件ずつ起こして補正し、履歴とジョブに残す |
