# 設定画面のチェックボックスなどの印を、選んだ状態が見分けられるように表示する

## 概要

利用者が、設定画面でオンにした項目をチェックの印で見分けられるようになる。

## 背景

[Issue #155](https://github.com/shuhei1101/voice-paste/issues/155) の要望。
設定画面でオンにしたチェックボックスにチェックの印が出ず、オン・オフが見分けられない（[添付の例](https://github.com/shuhei1101/voice-paste/issues/155#issuecomment-6331843976)）。
アプリ全体のスタイルシートはチェックボックス・ラジオボタンの印の見た目を決めておらず、ほかの「印」にも同じ不具合が無いかを確かめてほしいという要望も含む。
