## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| パッケージの移し替え | `git mv voice_paste voice_paste_legacy` で移し、中の `voice_paste.` の import と patch の対象を `voice_paste_legacy.` へ置き換える | 履歴を追えるよう、移す commit と中身を直す commit を分ける |
| ログ | ハンドラーを付けるロガーを `voice_paste_legacy` にして、子ロガーのログが今と同じログファイルに出るようにする | ログファイルの名前（`{日時}_voice_paste.log`）は変えない |
| 名前を変えないもの | PID ファイル（`voice_paste.pid`）・ログと履歴の置き場所・トレイの名前・`.env` の読み込み先 | 普段使いの設定と履歴をそのまま引き継ぐ |
| 起動のバッチファイル | `-m voice_paste` を `-m voice_paste_legacy` にする | 失敗時のメッセージも追随させる |
| pyproject.toml | スクリプトの入口を `voice_paste_legacy.main:run`、パッケージの検出を `voice_paste_legacy*` にする | 新しい構成の `src/voice_paste/` は #16 で足す |
| 配布用のビルド | `setup/build_exe.bat` の入口のパスを `voice_paste_legacy\__main__.py` にする | ビルドの仕組みは #23 で消す |
| 既存のテスト | import と patch の対象を `voice_paste_legacy.` へ追随させる。サブプロセス版に変わった後の `whisper_transcriber.py` に無い `WhisperModel` を patch して今も pass しない 2 件は、理由を書いて skip にする | 2 件は #23 で消す |
| 特性テスト | `tests/nfr/test_transcription_parity.py` に、固めた録音・用語集・設定で今のローカルの Whisper で起こして補正した文字が固めた期待値と一致すること、補正だけを切り出した決まった入力と出力の一致を置く | Windows の GPU か `tests/nfr/fixtures/` の録音が無い環境では skip する |
| 特性テストの録音 | 履歴からローカルのエンジンで起こした長さの違う録音を 10 件選び、録音と、写す時点で効いている用語集と `.env` の文字起こしの設定を git 管理外のフォルダ（`tests/nfr/fixtures/`、中身が `*` の `.gitignore` を置く）へ写す。その録音・用語集・設定で `voice_paste_legacy` が返した文字を期待値として同じフォルダに固める | 録音と話した中身をリポジトリへ入れない。履歴は保持期間で消えるため写しを持つ。履歴の文字は録った時点の設定で作られており期待値にしない |
| 測定 | 選んだ約 10 秒の録音を今の経路（ワーカーの文字起こし → 補正 → クリップボード）へ流し、録音を止めた時点から貼り付けのキーを送る直前までをミリ秒で 20 回測る計測のスクリプトを置き、中央値を記録する。モデルの読み込みの時間と、ホットキーを受けてから録音が始まるまで・処理中のホットキーを捨てるまでの時間も同じスクリプトで測る | 今のログは秒の単位で中央値の比較に使えない。マイクと利用者の操作を使わず、貼り付けのキーは送らない（前面のアプリへ打ち込まない）。#22 で新しい構成を同じ区間で測る |
| 測定の記録 | 測った値を非機能要件の外部の制約・根拠・決定値に書き、測った手順と生の値をこの PR ドキュメントに残す | - |

### 特性テストの録音と期待値の作り方

録音の中身と話した文字はこの PR ドキュメントにもリポジトリにも載せない。

- 録音の選び方: メインリポジトリの `history/` にある録音のうち、`TRANSCRIPTION_ENGINE` が未設定（`local`）の `.env` で起こした録音から、長さが違う 10 件を選んだ。形式は全て 16 kHz・モノラル・16 bit
- 写したもの（全て `tests/nfr/fixtures/`、git 管理外）:
  - `recordings/{日時}.wav`: 上の録音を `history/{日}/{日時}_recording.wav` から写した
  - `yogo.csv`: メインリポジトリの `resources/yogo.csv`（`YOGO_FILE` が空で、`{リポジトリ直下}/yogo.csv` も無いため、普段使いで効いている用語集）
  - `whisper.env`: メインリポジトリの `.env` のうち `WHISPER_*` の 15 キー（`OPENAI_API_KEY` などの秘匿値は写していない）
- 期待値を作ったコマンド: 移す前の `voice_paste` に対して、次の手順を 1 つのスクリプトにして Windows の venv で実行した（`venv\Scripts\python.exe {スクリプト} {出力フォルダ} {補正だけの入力の JSON}`、スクリプトはリポジトリに置いていない）
  1. `whisper.env` の値を `voice_paste.config` の変数へ入れ、venv の `Lib\site-packages\nvidia\{cublas,cudnn,cuda_nvrtc}\bin` を `PATH` の先頭に足す
  2. `WhisperTranscriber()` を立て、録音ごとに `transcribe` → `apply_yogo_replacements(text, load_yogo(yogo.csv))` を呼ぶ
  3. 返った文字を UTF-8 のバイトで `expected/{日時}.txt` へ保存する
  4. 補正だけの入力 7 件（用語集に当たる 1 語・2 語・繰り返し・当たらない・空・改行を含む）を `apply_yogo_replacements` に通し、入力と出力を `correction_cases.json` へ保存する
- 期待値の安定: 同じ手順を 2 回実行し、10 件とも文字が一致することを確かめた
- テストの実行: venv に pytest が無いため、`pip install --target`（Windows の一時フォルダ）へ入れて `PYTHONPATH` で足して実行し、venv は変えていない

### 刷新前の測定

- 実行: リポジトリ直下で `venv\Scripts\python.exe -m scripts.measure_legacy_latency`（`PYTHONIOENCODING=utf-8`）。結果は `log/{日時}_latency_measure.json`（git 管理外）に残る
- 測った日時と環境: 2026-10-01 12:52（JST）、Windows・Python 3.14.3・NVIDIA GeForce RTX 5070・large-v3・cuda・int8（`tests/nfr/fixtures/whisper.env` の設定と用語集）。普段使いの常駐アプリ（`voice_paste`、モデル読み込み済みで待機中）が同じ GPU で同時に動いていた
- 使った録音: `tests/nfr/fixtures/recordings/20260930010513.wav` の先頭 10 秒（16 kHz・モノラル・16 bit）

| 計測 | 区間 | 回数 |
| --- | --- | --- |
| 話し終えてから貼り付くまで | 録音を止める（`stop_and_save`）→ 用語集の読み込み → 文字起こし → 補正 → クリップボードへ → 貼り付けのキーを押す直前（`send_paste` の待ち 0.1 秒を含む） | 20 回（先に捨てる 1 回） |
| モデルの読み込み | `WhisperTranscriber()` の生成（ワーカーの起動）から読み込みの終わり（`ready`）まで | 5 回 |
| ホットキーを受けてから録音が始まるまで | ホットキーのコールバック（`request_session`）→ 常駐のループ → `_run_once` → トレイの更新 → システム音量の取得 → `recorder.start()` → 録音中の画面の生成 | 20 回 |
| 処理中のホットキーを捨てるまで | セッション中に `request_session` を呼んで、警告を出して戻るまで | 20 回 |

- 使わなかったもの: マイク（`sd.InputStream` を何もしないものに差し替え、録音のフレームは止める直前の状態を作った）・システム音量の変更（`fade_volume` を何もしないものに差し替え。`get_master_volume` は実物）・ホットキーの監視（`GlobalHotKeys` を差し替えて、コールバックを直接呼んだ。OS のフックから呼ばれるまでは含まない）・トレイ（アイコンは `MagicMock`。更新の処理は実物）・録音中の画面（録音が始まった時点を控えて、解除されるまで戻らない画面に差し替えた）・貼り付けのキー（`Controller` を押された時刻だけ控えるものに差し替えた）。クリップボードは実物を書き換え、計測の後に元の文字へ戻した
- 含まないもの: 文字起こし中の表示・貼り付けまでのトレイの更新・履歴の保存・マイクを開く時間
- API の 2 つの応答時間: 今のコードに API が無いため、ホットキーの受付で測った値（下の 3 行目と 4 行目）を刷新前の値とし、API の開始の応答時間・処理中の開始へのエラーの応答時間へ読み替えた
