# 連続録音の区間ごとの返送に、話し始めと話し終わりの時刻を追加する

## 概要

連続録音の呼び出し元が、区間ごとの返送から、その区間の話し始めと話し終わりの時刻を受け取れるようになる。

## 背景

[Issue #344](https://github.com/shuhei1101/voice-paste/issues/344) の要望。
aituber のゲーム実況は、連続録音で起こした文字をセリフにし、発話の話し始めの時刻に遅延の秒数を加えた時刻に出す。
連続録音が区間ごとにコールバック先へ送信する本文（インターフェース定義『呼び出し元へ返す』）は `session_id`・`result`・`segment_number`・`text`・`error`・`segment_count` だけで区間の時刻を持たず、受信した時刻からは話し始めを復元できない。
