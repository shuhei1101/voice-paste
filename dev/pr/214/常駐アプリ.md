## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 起動のスクリプト | リポジトリの直下に `voice-paste.sh` を置く。`voice-paste.bat` と同じ順（uv を PATH か `~/.local/bin/uv` から探す → `uv sync --frozen` → `.venv/bin/python -c "import voice_paste"` → `.venv/bin/python -m voice_paste` を `setsid` で端末から切り離して起動）で動く | extra は `未確定`（要件.md） |
| 起動の記録 | `~/.local/share/voice-paste/log/launcher.log`（`XDG_DATA_HOME` があればその下）に、起動のたびに上書きで書く | 置き場所は platformdirs が引く Linux のログの置き場所と揃える |
| 失敗の表示 | 環境を作れないときは、`voice-paste.bat` と同じ `[ERROR]` の行と `See log: {launcher.log のパス}` を標準エラーに出し、0 以外の終了コードで終わる。端末を持たない起動（自動起動・アプリの一覧）では、`notify-send` があれば同じ行を通知する | `uv not found` の行の `voice-paste.bat` は `voice-paste.sh` に読み替える |
| 自動起動 | リポジトリの直下に `voice-paste.desktop` の雛形を置き、手順のページに `~/.config/autostart/` と `~/.local/share/applications/` へ置くコマンドを記載する。`Exec` はクローンの場所の `voice-paste.sh` を指す | 雛形の `Exec` の書き換えの手順はモジュール構成設計で決める |
| OS のパッケージ | `xclip`・`libportaudio2`・`libxcb-cursor0` を手順のページの環境の作り方に記載する。起動のスクリプトは入っているかを確かめない（無いときは常駐サービスが起動時・録音時に理由をログと通知に出す） | |
| 既定のホットキー | Linux の既定のホットキー（録音開始と貼り付けて送信・一時停止・取り消し・貼り付けのみ・コピーのみ）を Super+Alt（`<cmd>+<alt>+{d,z,q,v,c}`）にする。Windows の既定は変えない | 出力先のホットキーの既定を OS で分ける方法はモジュール構成設計で決める（[確認ログ](./確認ログ.md)） |
| 通しの確認 | VM で PipeWire の仮想マイク（`pactl load-module module-pipe-source`）に WAV を流し、起動のスクリプトから起動 → ホットキー → 文字起こし → テキストエディターへの貼り付けを通す。トレイ・設定画面・録音の画面のスクリーンショットを `dev/pr/214/` の下に残す | 仮想マイクの入力が sounddevice に届くかは PoC 検証で確かめる |

## PoC 結果

結論: 成立。
仮想マイクの入力から起動・録音・文字起こし・貼り付けまでは Ubuntu 24.04 の Xorg で通った。
ただし既定の録音開始のホットキー `<ctrl>+<alt>+d` が Ubuntu の既定のキー割り当てと重なり、既定の設定のままでは貼り付け先のウィンドウが隠れる。
また、モデルを取得する初回の起動ではトレイのアイコンが上のバーに出ない。
ホットキーは Linux の既定を Super+Alt にし、トレイのアイコンは別の Issue に切り出す（[確認ログ](./確認ログ.md)）。

所感:

- 初回の起動は待ち時間に上限が無く（`_restart` だけが 27 秒の上限を持つ）、再起動はモデルを取得済みの状態で走るため、27 秒への対処は要らない
- `<ctrl>+<alt>+d` の重なりは Ubuntu の `/usr/share/glib-2.0/schemas/10_ubuntu-settings.gschema.override` の `[org.gnome.desktop.wm.keybindings:ubuntu]` が `show-desktop` に `<Primary><Alt>d` を割り当てているため。`gsettings get` は `[]` を返すが、常駐サービスを止めても Ctrl+Alt+D で全ウィンドウが隠れる。同じ schema の Ctrl+Alt の割り当ては `d`・矢印・Tab・Escape・F キー・テンキーだけで、ほかの既定（`z`・`q`・`v`・`c`）とは重ならない。[#210](https://github.com/shuhei1101/voice-paste/pull/210) の「Ctrl+Alt+D は重ならない」という判断は、この Ubuntu の上書きを見落としていた
- 要件.md の `未確定`（extra）について: `--extra local-whisper` を含めた `uv sync --frozen` は VM で通り（faster-whisper 1.2.1・ctranslate2 4.8.3）、既定の設定のまま文字起こしまで動いた。推奨 B の裏付けになる

最小再現コードの要点（[`poc/setup_mic.sh`](https://github.com/shuhei1101/voice-paste/blob/0abc1de0d7560fefe69b121c52b017d3037d4d62/poc/setup_mic.sh)・[`poc/feed_mic.py`](https://github.com/shuhei1101/voice-paste/blob/0abc1de0d7560fefe69b121c52b017d3037d4d62/poc/feed_mic.py)）:

```bash
# PipeWire の仮想マイクを作り、既定の入力にする
pactl load-module module-pipe-source source_name=vp_mic file=/tmp/vp-mic.fifo format=s16le rate=16000 channels=1
pactl set-default-source vp_mic
```

```python
# WAV の PCM を FIFO へ実時間の速さで書き込む（速く書くと録音の長さと合わない）
fd = os.open(args.fifo, os.O_WRONLY)
start = time.monotonic()
for i in range(0, len(pcm), chunk):
    part = pcm[i : i + chunk]
    os.write(fd, part + bytes(chunk - len(part)))
    sent += 1
    delay = start + sent * CHUNK_SEC - time.monotonic()
    if delay > 0:
        time.sleep(delay)
```
