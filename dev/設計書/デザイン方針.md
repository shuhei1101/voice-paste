## モチーフ・装飾

| モチーフ・装飾 | 使う場所 | 補足 |
| --- | --- | --- |
| 枠で囲んだ等幅のキー | ボタン・トレイのメニュー・設定画面のホットキーの表示 | 下の線だけを太くする |
| 等幅の設定のキー | 設定画面の欄の名前の横 | `settings.toml` のキーをそのまま出す |

## 色の役割

<!-- table: data -->

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 主 | 地・窓の面・本文・線 | `color.*.bg` / `color.*.surface` / `color.*.sunken` / `color.*.text` / `color.*.text_muted` / `color.*.border` | 窓の面は真っ白・真っ黒にしない |
| 窓の縁 | 枠なしの窓（録音の画面・文字起こし中の表示）とメニューの外側の線 | `color.*.frame` | 白・黒の背景のアプリに対して 3:1 以上 |
| 差し色 | 主の操作のボタン | `color.*.primary` / `color.*.primary_hover` / `color.*.on_primary` / `color.*.on_primary_line` | 1 画面に 1 か所 |
| リンク・選択 | リンクの文字・選択中のマーカー（オンのチェックボックスの箱・選んだラジオボタンの点）・フォーカスの枠 | `color.*.accent_fg` | オンの箱のチェックは `color.*.surface` で描く。オフの箱と丸の線は `color.*.text_muted`。使えないマーカーは線とオンの箱の塗りを `color.*.border`、チェック・点・名前を `color.*.text_muted` にする |
| 状態色 | 録音中・一時停止中・文字起こし中の表示、成功・エラーの表示だけ | `color.*.recording` / `color.*.paused` / `color.*.busy` / `color.*.success` / `color.*.danger` | - |
| 知らせの地 | エラーの文の地・再起動が要る変更の知らせ | `color.*.danger_bg` / `color.*.notice_bg` | - |

<!-- /table -->

`*` は `light` か `dark`。

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 見出し・本文・ボタン | OS の UI 書体（`font.ui`） | - |
| 経過時間 | 等幅（`font.mono`） | 録音の画面で大きく出す（`size.time`） |
| ホットキー・設定のキー・エラーの詳細 | 等幅（`font.mono`） | 小さく出す（`size.text_key`） |

## 文言

| 要素 | 書き方 | 例 |
| --- | --- | --- |
| ボタン・見出し・状態 | 短い漢語・カタカナ語にし、文にしない。ひらがなは極力入れない | 録音開始・ファイル送信・再送信・削除・キャンセル・送信済み |
| 確認のダイアログ | 見出しだけ「〜しますか」の質問にし、ボタンは「キャンセル」と操作名にする | 結果を削除しますか / キャンセル・削除 |
| エラー・知らせ | 見出しは体言止めの 1 語、本文は原因と対処を体言止めで並べる | 送信失敗 / PC の voice-paste に接続不可。PC の起動を確認後に再送信 |
| 文字起こしの状態 | 「文字起こし」の語に揃える | 文字起こし待ち・文字起こし中・文字起こし完了・文字起こし失敗・文字起こし前 |

## 形状と奥行き

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| 窓・ダイアログ・メニュー | 1px の線、角丸 `shape.radius` | 枠なしの窓とメニューの外側の線は `color.*.frame`。影は付けない |
| ボタン・入力欄・選択欄 | 1px の線、角丸 `shape.radius` | 高さを `shape.control_height` に揃える。録音の画面のホットキーを持つボタンは、名前の下にキーを出す 2 行の高さで揃える |
| 設定画面の欄 | 行の間を線で区切る | 欄ごとに枠で囲まない |
| まとまりの見出し | 下の線 | - |

## 動き

| 場所 | 動き | 補足 |
| --- | --- | --- |
| 文字起こし中の表示 | スピナーが回る（`motion.spinner_ms`） | 動きを減らす設定では止める |
| 切り替えのつまみ | 滑る（`motion.switch_ms`） | - |

ほかの場所は動かさない。

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| グラデーション・光る影 | 控えめな道具の見た目とぶつかる | - |
| 色を敷いた面での区切り | 色は操作と状態にだけ使う | 区切りは線で行う |
| 絵文字のアイコン | 線の太さが揃わない | アイコンは線画の 1 セットに揃える |
