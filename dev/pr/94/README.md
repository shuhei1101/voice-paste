# アプリの明暗を設定で選べるようにし、録音の画面を背景から見分けやすい配色にする

## 概要

ユーザーがアプリの明暗を設定で「Windows の設定に従う」「ライト」「ダーク」から選べるようにし、録音の画面が出ていることを背景のアプリから見分けられる配色にする。

## 背景

[Issue #85](https://github.com/shuhei1101/voice-paste/issues/85) の要望。
ユーザーはライトで使うことが多く、今の録音の画面は白っぽい地が背景のアプリに溶け込み、画面が出ているかを見分けにくい。
develop の [ui/style.py](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/ui/style.py) は OS の明暗（`QGuiApplication.styleHints().colorScheme()`）だけで [ui/tokens.toml](https://github.com/shuhei1101/voice-paste/blob/develop/src/voice_paste/ui/tokens.toml) の `[color.light]`・`[color.dark]` を選び、明暗を選ぶ設定は無い。
ライトの窓の面（`surface`）は `#ffffff`、地（`bg`）は `#f6f8fa` で、真っ白に近い。
