## 要望

AI Monitor の配布物を v0.4.0 から v0.5.0 へ追従し、`ai-monitor-version.ini` を `v0.5.0` にする。
終わりの条件は次の表のとおり。

| 対象 | 終わりの条件 |
| --- | --- |
| 配布先の反映作業 | [反映作業](./反映作業/index.yaml) の全ての作業の確認スクリプトが通る |
| サイトのレイアウト | `python -m ai_monitor.distribution import-site --version v0.5.0` で `docs/_theme/` を取り込み、`docs/_theme/assets/vendor/mdmark/` が無く、記録のファイル `ai-monitor-theme.yaml` のバージョンが `v0.5.0` |
| 文書のマーカー | リポジトリの文書（`docs/pr/` を含む）を `mdmark check` に渡すと `legacy_mark` と `map_unknown_class` が出ない |
| MCP ツール | v0.4.0..v0.5.0 で増えた MCP ツール（`wait_for_issues` 等）が、voice-paste を担当するエージェントへ渡っている（`settings.yaml` の `mcp_tools` を持たないエージェントは既定の割り当てで渡る） |
| 規約・テンプレート・判定・フェーズ手順 | v0.4.0..v0.5.0 で変わったものに、voice-paste の成果物が従っている |
