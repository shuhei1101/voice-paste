# 要件

## 要望

- 配信元の設定 `dev-docs.yaml` の `documents[]` に、LLM の呼び出し（`llm_call`）を含む種類の行を、[shuhei1101/ai-monitor の反映作業『配布先の配信元の設定への種類の行の追加』](https://github.com/shuhei1101/ai-monitor/tree/develop/docs/pr/3744/反映作業/配布先の配信元の設定への種類の行の追加)の実行スクリプトで追加する。追加した後、`describe(source: voice-input)` の種類の一覧に `llm_call` が並ぶ
- OpenAI API の文字起こし（`src/voice_paste/integrations/openai/transcriber.py`）の LLM の呼び出しの設計書を、`template-llm-call` に沿って `docs/llm-call/` に 1 枚作成する
- 作成した設計書と実装が食い違う箇所は、実装を設計書に合わせる。食い違いが無ければ実装は変えない
- スキルはこのリポジトリに無い（`SKILL.md`・`.claude/skills/` が develop に無い）ため、エージェントフロー（`type: skill`）の設計書は作らない
