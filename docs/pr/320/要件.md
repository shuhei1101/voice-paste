# 要件

## 要望

develop の workflow `.github/workflows/test.yml` を初めて起動し、次を行う。

| 項目 | 終わりの条件 |
| --- | --- |
| E2E テスト | テスト実行方法の E2E テストの層（`TL-6`）の全件実行（`--run-e2e`）で `tests/e2e/workflow/test_test_yml.py`（IF-15 の 5 つのフロー）を回し、結果のログを置く |
| ランナーでの全件実行 | 単体テスト（バック）・結合テスト（バック）の層を `run_runner` で回し、passed・skipped の件数を手元の実測（単体 937 passed・57 skipped、結合 807 passed・1 skipped）と比べた表を計画書に書く |
| 外部ライブラリの確認状態 | LIB-34〜36 の `verification` を、回した結果で `済` にする |

fail した場合と、skip の件数が手元と違う場合は、原因を調べて計画書に書き、直す作業を別の Issue にする（この作業 PR では直さない）。
