# 要件

## 要望

release/v0.6.0 の E2E（[release PR #182](https://github.com/shuhei1101/voice-paste/pull/182)）で fail したテスト不備の 2 件を、`tests/e2e`・`tests/support` の中だけで修正する。
`src/` と設計書のシナリオは変えない。

| Issue | 終わりの条件 |
| --- | --- |
| [#184](https://github.com/shuhei1101/voice-paste/issues/184) | テストの読み上げる文の組（`tests/support/continuous.py` の `THREE_SENTENCES`・`tests/support/inprocess.py` の `LONG_READING`・`tests/e2e/複合ユースケース/test_transcribe_continuously_from_other_system.py` の `THREE_SENTENCES`）か、テストの設定を、#166 で入った既定の `DEFAULT_EDGE_PHRASES` の動きに合わせる。#184 の表の 8 件と、同じ文の組を使う `test_deliver_transcript.py`・`test_record.py`・`test_transcribe_recording.py` の、用語集で消す言葉（`DELETED_WORD`）を使うテストが pass する |
| [#185](https://github.com/shuhei1101/voice-paste/issues/185) | ワーカーを止める時刻が `process_table`（`tests/support/processes.py`）の速さに依存しないようにし、文字起こしの途中で確実にワーカーを止める。修正箇所は `tests/support/inprocess.py` の `kill_one_worker`・`kill_workers_twice` と、テスト本体の `_kill_workers_twice`・`workers_before = app.worker_pids()`。`test_transcribe_recording.py` の `test_normal_when_worker_dies`・`test_error_when_worker_dies_again` と、`test_paste_voice_text.py` の `test_error_when_worker_dies_again` の 3 件が pass する |

満たす基準:

- #184: 3 つの読み上げる文の組の「ありがとうございました」を、`DEFAULT_EDGE_PHRASES` のどの文言にも文末で当たらない文と、その文を起こした文字に含まれる言葉の組に替える（#184 の案 A）。テストの設定の `edge_phrases` は変えず、既定の一覧のまま流す
- #184: `test_transcribe_recording.py` の用語集で消す行（`DELETE_ROW`）は、替えた 3 文目の言葉（`DELETED_WORD`）を誤変換にした行にする
- #185: ワーカーを止める時刻には PowerShell の一覧を引かず、`os.kill` で番号のプロセスを直ちに止める（#185 の案 A のうち、テストの中で閉じる方。`taskkill /F /T` もこの PC で数秒かかるため使わない）
  - 1 回目: 確定の前に、立ち上がっているワーカーの番号を引いておき、確定の直後に止める
  - 2 回目（やり直したワーカーも落とすテスト）: やり直しのワーカーの ready のログに書かれたランチャーの番号から、Toolhelp のスナップショットで子孫の番号を引き、ready の直後に止める
- 修正したテストが確かめる内容（区間ごとの言葉・区間の順・届いた回数・ワーカーの立て直し・失敗の知らせ）は変えない

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 連続録音の 1 区間が既定の文言だけのとき、空の文字で届く動き | #166 の要件どおりの補正の動きで、#184 の切り分けでも実装の誤りを示す記録が無い。テストの読み上げる文を既定の一覧に当たらない文へ替えるため、この動きは変えない | 予定なし |
| `tests/nfr/test_segment_callback_latency.py` の `SILENCE_SENTENCES` の「ありがとうございました」 | 確かめるのは届いた区間の数と返送までの時間だけで、起こした文字の中身を見ない（#184 の扱いの判断で確認済み） | 予定なし |
| 常駐アプリが持つワーカーの番号を `src/` から読めるようにする（#185 の案 A の後半） | `src/` を変えるとテストだけの修正でなくなる。テストの中で閉じる直し方で足りる | 予定なし |
| 読み上げた音をさらに長くつなぐ（#185 の案 B、`LONG_SPEECH_REPEAT`） | 止める時刻が一覧を引く速さに依存したまま残り、PC の負荷で再び fail しうる | 予定なし |
