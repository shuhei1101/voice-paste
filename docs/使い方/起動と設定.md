# 起動と設定

ショートカットからの起動と終了、設定・履歴・ログの置き場所

## 起動する

デスクトップかスタートメニューの `voice-paste.bat - ショートカット` を開く。
コンソールは出ず、トレイに voice-paste のアイコンが出る。
文字起こしのモデルを読み込む間は準備中のアイコンで、読み込みが終わるとアイコンが待機中になり、録音を始められる。

常駐中にもう一度ショートカットを開くと、前の常駐サービスに終わるよう頼み、終わってから新しい常駐サービスが立つ。
常駐サービスはいつも 1 つだけ動く。
前の常駐サービスが 54 秒までに終わらないときは、新しい常駐サービスは立たずに終わり（トレイのアイコンは出ない）、理由は `%LOCALAPPDATA%\voice-paste\log\` の日付つきのログに書かれる。

起動に失敗したときは、トレイのアイコンが失敗の表示になり、理由が通知される。

- `settings.toml` を読めないときは、「録音を始める」も「設定…」も押せない。「設定フォルダを開く」から `settings.toml` を直し、「再起動」を選ぶ
- 文字起こしのモデルを読み込めないときは、録音を始められない。「設定…」から設定を開いて直せる
- API の待ち受けを始められないときは、API だけが使えず、ホットキーとトレイからの録音は使える
- ホットキーを受け付けられないときは、トレイから録音できる

起動の記録（起動した時刻・使った Python・終了コード）は `%LOCALAPPDATA%\voice-paste\log\launcher.log` に書かれる。
起動のたびに上書きされる。

## トレイから操作する

トレイのアイコンを右クリックするとメニューが開く。

| 項目 | 操作 |
| --- | --- |
| 録音を始める | 録音を始める（アイコンの既定の操作）。[録音して貼り付ける](./録音して貼り付ける.md) |
| 録音の画面を出す | 録音中に隠した録音の画面を戻す。隠している間は、アイコンの左クリックもこの操作になる |
| 設定… | 設定画面を開く |
| 設定フォルダを開く | `settings.toml` のあるフォルダをエクスプローラーで開く |
| ログフォルダを開く | ログのフォルダをエクスプローラーで開く |
| 再起動 | 常駐サービスを終え、同じ引数で新しく起動する。`settings.toml` の今の設定で立つ |
| 終了 | 録音の受付・API・文字起こしのワーカーを止めて終わり、アイコンを消す |

録音から届けるまでの間は「録音を始める」と「設定…」を押せない。
「録音の画面を出す」は、録音の画面を隠しているときだけ押せる。
その間に「再起動」「終了」を選ぶと、アイコンはすぐに消え、その回が終わってから再起動・終了する。

## 設定

設定は `%APPDATA%\voice-paste\settings.toml` に置く。
無ければ起動時に既定値で作る。

設定画面（トレイの「設定…」）で変えて保存する。
`settings.toml` を直接書き換えてもよく、その場合は再起動してから効く。
設定画面の「再起動で反映」の印がある項目は、保存した後に再起動してから効く。

設定のキーと既定値の見本はリポジトリの直下の `settings.sample.toml` にある。

## 履歴とログ

履歴・ログ・一時の音声・API のトークンは `%LOCALAPPDATA%\voice-paste\` の下に置く。

| 置き場所 | 中身 |
| --- | --- |
| `history\{日付}\` | 確定した録音（WAV）と起こした文字（テキスト）。`history.enabled` が `false` のときは残さない |
| `log\` | 日付つきのログ、`launcher.log`、クラッシュの記録 |
| `tmp\` | 履歴を残さない設定のときに、文字に起こすまで置く録音 |
| `api_token` | API のトークンとポート。[API](../リファレンス/API.md) |

保持期間を過ぎた履歴とログは、起動時と常駐中の 24 時間ごとに消える。

| 設定のキー | 既定値 | 消す対象 |
| --- | --- | --- |
| `history.retention_days` | 1 日 | この日数より前の日付の履歴のフォルダ |
| `logging.retention_days` | 7 日 | この日数より前の日付のログ |

`launcher.log` は日付の名前を持たないため、保持期間では消えない。

## `.env` から移した設定

刷新前の設定（リポジトリの直下の `.env`）は `settings.toml` へ移してあり、元の `.env` は `.env.migrated` の名前で残っている。
刷新前の履歴（リポジトリの直下の `history\`）は `%LOCALAPPDATA%\voice-paste\history\` へ写してある。

次の設定は写していない。

- OpenAI で文字を起こす設定（`TRANSCRIPTION_ENGINE=openai`・`OPENAI_API_KEY`）。文字起こしのエンジンはローカルの Whisper だけになった
- 1 回だけ録音して終わる設定（`RESIDENT_MODE`）。常駐だけになった
