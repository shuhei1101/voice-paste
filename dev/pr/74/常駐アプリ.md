## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 出力先の定義 | 出力先の ID・表示名・届ける関数に加え、出力先ごとの設定のモデルと既定値、配線で注入するものを `OUTPUTS` の 1 件に持たせる | `未確定`（置き場所の案は [要件](./要件.md)。決める段: モジュール構成設計） |
| 設定のモデル | 出力先の一覧の検証と既定の一覧を、`OUTPUTS` の定義から組み立てる。`settings.toml` の `outputs` の形と、ID の重なり・ホットキーの重なりの確かめは今のまま | 今の設定ファイルをそのまま読めることを単体テストで確かめる |
| 配線 | `_wire_outputs` は出力先の定義が持つ注入するものを部分適用し、出力先の ID ごとの表を持たない | - |
| 設定画面・録音の画面 | 出力先の名前と出力先固有の欄（貼り付けて送信の Enter までの間）を、`main.py` が渡す出力先の定義から引く。表示と操作は変えない | `ui` は `features` を import しない |
| テスト | 試しの出力先を 1 つ登録しただけで、設定の読み書き・確定のホットキー・設定画面の欄・録音の画面のボタン・届けに乗ることを確かめる。既存の単体・結合テストは全て通す | - |
| 依存の向き | import-linter の検査を通す | - |
