# 要件

## 要望

設定画面の「文字起こし」のまとまりを、エンジンの選択（`transcription.engine`）と、エンジンごとの区画に分ける。

| 区画 | 置く欄 |
| --- | --- |
| ローカルの Whisper | `transcription.local_whisper` の全てのキー（今の「文字起こし（エンジン）」のモデル・デバイス・計算の型・言語と、「文字起こし（詳しい調整）」の欄） |
| OpenAI API | `transcription.openai` の全てのキー（model・language・base_url） |
| Haas（WSL） | `transcription.haas` の全てのキー（distribution・port） |

- 今選んでいるエンジンに関係なく、全ての区画を開いて値を変え、保存できる（選んでいないエンジンの欄を使えなくしたり隠したりしない）
- 設定のキー・settings.yaml の書き方・反映（immediate / restart）は変えない
- 動いている OS で全ての欄を出さないエンジン（Linux の Haas（WSL））は、区画ごと出さない
- エラーの一覧の行を押すと、その欄の区画へ切り替えて欄へフォーカスを移す
- 区画の名前は `transcription.engine` の選択肢の名前（「ローカルの Whisper」「OpenAI API」「Haas（WSL）」）にそろえる

- 区画はエンジンの選択の下にエンジンごとのタブで並べる
- 設定画面を開いたときは今選んでいるエンジンのタブを出し、エンジンの選択を変えても出しているタブは替えない
- 今選んでいるエンジンのタブの名前の右に「使用中」を出し、エンジンの選択を変えると「使用中」だけを移す
- 確認に通らない欄があるタブの名前の右に「エラー {件数} 件」を出す
