## 要望

`dev-docs.yaml` の `nav` のはじめに・使い方・リファレンスのタブを、`page` の並びから `auto`（`document: files_guide`、`filter` に `category`）へ書き換える。

- `docs/guide/files.yml` に `category` を持つ行を追加したら、`nav` を書き換えずに、その `category` のタブへ出る
- 前提として、knowledge の `schemas/knowledge-files.schema.yaml` に `category` を追加する。knowledge へ Issue を起票し、その完了を待ってから `files_guide` の行の `schema.ref` を `category` を加えたタグへ上げる
- 修正した後、開発ドキュメントサーバーの画面（3 つのタブに `files.yml` の文書が `category` ごとに出ているか・project-index の `auto.filter` の警告が出ていないか）をスクリーンショットで確認する
