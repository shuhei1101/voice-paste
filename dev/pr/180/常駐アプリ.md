## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 一覧の取得 | `/web/` の下に、用語集のプリセットの名前の一覧（設定の並び）と設定で選んでいるプリセットの名前を返す GET の API を追加する | `/web/` の下の Origin の許可リストで守る。返すのは名前だけで、用語集の中身は返さない |
| 送信の指定 | `POST /web/transcriptions` の multipart に、プリセットの名前の任意の項目を追加する | 項目名は `POST /sessions` に揃えて `glossary_preset` にする |
| 入力チェック | 指定した名前が今の設定の一覧に無いときは、音声を積まずに 400 で返す | `POST /sessions` の確かめと同じ関数を使う |
| 補正 | ジョブに受け付け時のプリセットの名前（指定が無ければ空）を持たせ、起こした後にその名前で補正する。空なら設定で選んでいるプリセットを補正の時点で引く | `POST /sessions` の補正と同じ `correct(text, glossary_preset)` を使う |
| 画面の選択欄 | 音声送信の区画の録音開始・ファイル送信の上に、用語集のプリセットの選択欄を置く。録音中は変えられない（送信中は次に送る音声のために変えられる） | ラベルは「用語集のプリセット」、既定は先頭の「設定に従う（{名前}）」（要件.md） |
| 一覧を取得できないとき | 選択欄を既定だけにして送信は続けられるようにし、取得できなかったことを選択欄の近くに出す | 文言はモック作成で決めたもの（確認ログ.md） |
| 再送信 | 端末内の音声の再送信も、再送信した時点の選択で送る | - |
| 選択の保存 | 選択を端末（localStorage）に覚え、開き直したときに戻す（確認ログ.md） | 覚えた名前が一覧に無ければ既定に戻す |
| 既存機能への影響 | 指定しない `POST /web/transcriptions` は、今の補正の結果と変わらない | - |
