# 今のコードを voice_paste_legacy へ移し、刷新前の値を測って特性テストを固める

## 概要

今の `voice_paste/` を `voice_paste_legacy/` へ移して起動のバッチファイルから今と同じに動かし、刷新前の文字起こしの特性テストと、話し終えてから貼り付くまでの時間の測定の記録を残す。

## 背景

[Issue #15](https://github.com/shuhei1101/voice-paste/issues/15) の要望。
作り直しの方針（[#13](https://github.com/shuhei1101/voice-paste/issues/13)、方針決めは [#12](https://github.com/shuhei1101/voice-paste/pull/12)）は段階的な置き換えで、新しい構成も `voice_paste` の名前を使うため、今のコードを `voice_paste_legacy/` へ移して普段使いを続ける。
この Issue は[移行の Issue の並び](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/5_%E3%83%AA%E3%82%B9%E3%82%AF%E3%81%A8%E7%A7%BB%E8%A1%8C%E8%A8%88%E7%94%BB.md)の順 2 にあたり、ここで固める特性テストと測る値が[品質シナリオ](https://github.com/shuhei1101/voice-paste/blob/develop/dev/pr/12/%E6%96%B9%E9%87%9D%E6%B1%BA%E3%82%81/2_%E5%93%81%E8%B3%AA%E7%9B%AE%E6%A8%99.md) 2・3 の基準になる。
[#26](https://github.com/shuhei1101/voice-paste/pull/26) で起こした非機能要件は、品質シナリオの決定値をこの Issue の測定まで未確定で置いている。
ユーザーは master のコードをビルドせずに普段使いしている。
