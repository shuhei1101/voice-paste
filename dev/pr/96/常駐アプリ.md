## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定 | `UiSettings` に録音の画面のボタンにホットキーを出すか `show_hotkeys`（bool）を足す。既定は `true`、反映は `immediate` | 設定の設計書に行を足す。`UiSettings` の末尾に置く。設定画面の欄の名前は description の最初の文から作られるため、最初の文を設定の設計書の `title` にそろえる |
| 既存の設定との互換 | 項目を持たない `settings.toml` は既定の `true` で読む。保存しても他のキーの値とコメントは変えない | 今の設定の読み書き（tomlkit）のまま |
| 録音の画面 | `_rebuild_buttons` で `ui.show_hotkeys` が `false` のとき、一時停止・再開・取り消し・出力先・カスタムプリセットの全てのボタンへホットキーを空で渡し、名前だけを上下の中央に出す | ホットキーの受付（`HotkeyListener`）は変えない。窓を出すたびに組み直すため、保存の後に出す録音の画面から効く |
| 設定画面 | 「画面」のまとまりの末尾に、ホットキーを出すかのチェックボックスを置く | 欄の部品は型（bool）から決まり、画面設計の補足「まとまりと欄」に行を足す |
