## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 依存の宣言 | `pyproject.toml` の `dependencies` の `faster-whisper~=1.0` の次の行に `av>=11,<19` を足す | 下限は faster-whisper 1.2.1 の `Requires-Dist: av>=11` |
| 外部ライブラリ（faster-whisper） | 調べた不具合に、`av` 19 で `av.open` が `metadata_errors` を受け付けず `TypeError` になることと、対処（`av<19` を宣言）を足す | - |
| 外部ライブラリ（av） | `av.yaml` を新規に作り、版（採用 18.1.0）・版の固定の仕方（`>=11,<19`）・使用箇所（faster-whisper が録音を読む）・上限の理由を書く | - |
| 既存機能への影響 | 新しく作った venv で `pip install -e . --group dev` を流し、入った `av` が 19 未満で、E2E の文字起こしのケースが pass する | 普段使いの venv は `av` 18.1.0 のままで変わらない |
