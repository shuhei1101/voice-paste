## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 実機のマイクで録音する E2E のケース | 消す | 録音を始めないケース（トレイから操作する・設定を変える・常駐アプリを起動するの一部）は残す |
| 録音のファイルを渡して文字に起こすテスト | 録音の入力を、録音のファイルを流すものに差し替えて渡し、ローカルの Whisper（GPU）で起こした文字を確かめる。`--run-e2e` を付けたときだけ流す | E2E に置き、常駐アプリを pytest のプロセスの中で `build_handlers` で配線する。録音はテストの中で SAPI で決めた文を WAV へ書き出して作る |
| 実機のマイクで録る非機能要件テスト 3 つ | 録音の入力をテストの中で書き出した無音の WAV を流すものに差し替えて測り直す。API の開始・処理中の 2 つは pytest のプロセスの中で `build_handlers` を配線し、セッションの上限時間は SessionManager を上限時間 3 秒で自分で組む | 開始・処理中は `test_paste_latency.py` と同じ形 |
| `tests/support/` | 消したケースだけが使う関数・ファイル（`speak`・`speak_and_confirm`・貼り付け先 など）を消す | 残すケースが使うものは変えない |
| シナリオ | 各シナリオの `test`・`test_file` を、消したケースから外し、置くテストへ付け替える | シナリオの流れと期待値は変えない |
| テスト実行方法・非機能要件 | 上の変更に合わせて、実機のマイクで録音する前提と測り方を書き換える | - |
